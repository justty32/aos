Python：零第三方套件

沒有 pip、沒有 venv。 Python 這一側只用標準庫；你只要有 python3（3.11 以上已實測）。C／C++ 零件另外要 nlohmann-json（建置時才要）。

兩條讓殼找得到指令的路

三個環境變數（Get started 用的）install.sh（想長期裝才跑）
做什麼只改目前這個殼的 AOS_HOME、PATH、PYTHONPATH把指令 symlink 進一個 PATH 上的資料夾，並登記 Python 路徑
寫到哪哪裡都不寫（關掉殼就沒了）兩處：~/.local/bin（預設，可改 DEST）底下的 symlink；Python user site 的 aos-proto8.pth（兩行：repo 的 py/、lib/ 絕對路徑）
適合先試試看每個新殼都想直接用

三個變數的寫法在 Get Started 第 2 步。

# 先看看會做什麼，什麼都不動
~/aos/proto8/install.sh --dry-run
# 真的裝
~/aos/proto8/install.sh
# ~/.local/bin 不在 PATH 上的話（install.sh 會提醒），加進你的殼設定檔，例如 ~/.bashrc：
export PATH="$HOME/.local/bin:$PATH"

只有要移除時才跑（這行還沒實測）：

# 拿掉：只移除指進這份 repo 的連結，和內容完全相符的 aos-proto8.pth
~/aos/proto8/install.sh --uninstall
  • 要先建置：cpp/*/bin 一支都沒有時，install.sh 會報 ImplsMissing 並退 1。
  • 它不改 PATH、不改任何 shell 設定檔；目的地不在 PATH 上只會印一行提醒，要自己加。
  • aos-proto8.pth 只寫進你跑 install.sh 時那支 python3 的 user site（例如 ~/.local/lib/python3.14/site-packages/）。之後換成別的版本的 Python，要用那個版本再跑一次。
  • 可以重跑：已經裝好的會報「already」，不會重複裝。
  • 用 symlink 不是複製：repo 搬了位置要重跑；舊連結會被報「指向別處」，自己 rm 再跑。
  • 同名的別的東西不會被蓋掉（印 skip、最後 LinkFailed、退 1）。
  • 請把 repo clone 在 Linux 的檔案系統上（WSL 不要放 /mnt/c）。
install.sh 會連哪些指令

掃 cpp/*/bin/*（C++ 的，例如 aos-exec、aos-loop、aos-fsm、aos-daemon）與 cmd/*/bin/*（Python 的，例如 aos-daemon-ctl、aos-agent、aos-tools），只連有執行權限的檔。完整清單與錯誤代號見 proto8/install.sh 檔頭說明。實測：裝好後連了 30 支（11-14 的版本；數目會隨版本變）；只把 ~/.local/bin 放進 PATH 的新殼裡，aos-exec、aos-agent 都找得到，Python 也 import 得到 aos 的模組。--uninstall 還沒實測。
