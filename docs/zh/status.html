原型 · demo 版

aos 還是原型：檔案格式和指令還會變。只支援 Linux（WSL2 可以）。一棵樹住一台機器；樹和樹之間現在還不會互相連線。

今天能做（已實測）還沒有之後的方向
不用模型起一棵樹，對假腦的 agent 說話，看 history 與資料夾（Get Started）兩台機器同時連線（一棵樹一次住一台）一步一步把 agent 換成確定的程式，token 用量往零走。
同一棵樹掛兩隻 agent，各自對話（教學）版本相容（檔案格式、指令會變）從一隻 agent 開始，最後換成一支程式。
把一個資料夾當函數呼叫（Get Started）Windows、macOS 原生會改進自己的函數：先做一個幫你寫函數的函數。
接一個 OpenAI 相容端點，讓 agent 用真模型叫工具（接真腦；本機代理實測，雲端帶金鑰的還沒）套件管理器安裝像看公司一樣看全景：部門、員工、狀態。（進行中）
同一台機器上搬樹：停下、整個複製到新位置、接著跑（示範 A；假腦）穩定 API
100 隻 agent 排隊共用一個一次只能處理 2 個的端點，全部答完（示範 B；假腦，量的不是速度）安全隔離保證（沙箱是實驗功能）
換一條排隊規則，結果跟著變：限住某個寄件人一天幾次（示範 C；假腦）
一層套一層：樹底下再起一個 daemon，agent 掛在裡面照常對答（示範 D；只套一層，假腦）
