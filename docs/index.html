02 / 介紹

介紹

重造計算模型

aos 把 Linux 當成硬體，在上面重新分一次：誰是 CPU、誰是板子、什麼可以拿來算。

以 Linux 做硬體。 一隻 agent，說穿了是一個一直在跑的迴圈：問模型、用工具、再問模型。這跟 CPU 做的事很像，所以我們乾脆把它當成一顆 CPU。CPU 一多，就要有地方插，於是有一支專門管它們的程式，那就是板子。而整套東西底下的硬體，就是 Linux：行程、檔案、權限，它早就做好了，我們直接站上去。

有了 CPU 和板子，下一步，就是作業系統了。作業系統是什麼？就是硬體上權限最高的那支程式，它的工作是幫人把硬體用得更好：排程其他程式、分配資源、管權限。aos 的核心 kernel 做的是同一件事，只是它底下的「硬體」不是一台電腦，而是 Linux，加上 agent 要用到的各種東西。

什麼都可以是處理單元。 既然 agent 可以是一顆 CPU，那會算東西的就不必只是程式。好比一位畫家：畫畫沒辦法直接變成一道指令，但可以拆成三件普通的事：把需求寄給他、等他回信、把畫歸檔。這樣包起來，他對 aos 來說就是一個處理單元（PU），跟一張 GPU、一個外部的模型服務是同一類，照樣排程。

可以嵌套。 還有一點：這一層可以再套一層。kernel 上面分兩塊，一塊是做事的 agent，一塊是另一個 kernel；那個 kernel 上面，又可以再分一次。

今天做到哪：一層套一層，照字跑過；把外部的模型服務包成一個資料夾來叫，跑過；把人或 GPU 包成處理單元，還沒有示範。

以往沒考慮過的成本

程式的成本，不只時間和記憶體。

一行 a=1+2。 有了這個計算模型，再回頭看一行最普通的程式：a=1+2。它佔一點記憶體，跑一下子，一般算到這裡就結束了。那除此之外呢？人看懂它要多久？原始碼佔多少地方？a 這個名字會不會蓋掉別人的？這些其實都是成本。

對 a=1+2 來說，這些當然可以忽略不計。但換成更大、更特別的程式，就不能不算了，種類恐怕還不只這幾種；用了 AI，還要再加上 token。上面那位畫家也一樣：他擅長什麼、一週能畫幾張，全是要算的。

為這些成本設計的 kernel。 現在常見的 kernel，優化的多半是 CPU、記憶體、時間這些常見的資源。aos 的 kernel 就是為剩下的那些成本設計的：每個請求都先經過它，要優化什麼，由你來定。很多 agent 搶少少幾個模型的時候它怎麼排，下面第二套演示會走一遍。

今天做到哪：這扇門今天管過的是模型呼叫：100 隻 agent 排隊共用 2 個位子（假模型）、每個寄件人一天最多幾次，都照字跑過。看懂要多久、名字會不會撞這類成本，還沒有 kernel 在管。

新的軟體開發範式

先讓 agent 把事做到，再一塊一塊換成程式。

工具有了，下一步，是拿它怎麼寫軟體。

檔案系統當語言。 最好的寫程式方式，Lisp 早就示範過：程式就是資料，程式可以寫程式，也可以改自己。那為什麼大家不用？不好除錯，也碰不到底層。但現在有了 LLM，事情不一樣了：站在更高的層面看，Lisp 這一套反而變得有優勢，因為寫程式、改程式的，可以是模型自己。剩下的問題是：拿什麼當這個語言，模型用得順，人也看得到？我們的答案是檔案系統：一個資料夾就是一個函數，裡面用什麼語言寫都行，權限直接用 Linux 的，出了問題打開來看就知道。最重要的是，模型本來就會讀寫資料夾，不用另外教。

agent 也是一個函數。 前面把 agent 當成一顆 CPU；換個角度看，它也只是一個函數：一個迴圈，裡面問模型、用工具。這個函數哪裡不確定、哪裡花 token？都出在問模型那一步。

一塊一塊換成程式。 所以開發就變成這樣：先放一隻什麼都能做的 agent，把事情做到；再把它拆成幾個小步驟，把要問模型的那幾步，一個一個換成程式。這件事可以叫 agent 自己來：跟它說「這個資料夾就是你，替自己加一個新工具」，它在自己的資料夾裡加一個資料夾就行了。模型也只是一種處理單元，換掉它，就是換一個處理單元。我們的目標，是這樣來回下去，讓 token 一路往零走。

今天做到哪：把資料夾當函數來叫，照字跑過；agent 替自己加工具，程式裡有，這版還沒驗；一路換到不用模型，還沒做，是我們要去的方向。

04 / NOW

今天 clone 下來就能做的

  • 不用模型起一棵樹，對假腦的 agent 說話，看對話檔與資料夾。
  • 同一棵樹掛兩隻 agent，各自對話（教學）。
  • 把一個資料夾當函數呼叫。
  • 接一個支援工具呼叫的 OpenAI 相容端點，讓 agent 用真模型叫工具（接真腦）。

現況

aos 還是原型：檔案格式和指令還會變。只支援 Linux（WSL2 可以）。一棵樹住一台機器；樹和樹之間現在還不會互相連線。

agent 會用你的帳號執行程式：你的帳號碰得到的檔案，它都碰得到。請在拋棄式帳號、虛擬機或容器裡試；換一個資料夾並不能隔離。沙箱是實驗功能。

實測環境：只在一台 Manjaro 機器上照字跑過；Python 3.11 與 3.14 都通；建置走 vcpkg。其他發行版、不用 vcpkg 的建置還沒驗。
