# 2026-09-24 proto5 在 Python 3.12 實跑

結論：**不用改程式**。main HEAD `94b314f` 的 1016 條測試在 3.12.13 和 3.14.7 上都一次全綠，沒有版本差異要修，也沒遇到 flaky。

## 怎麼裝的

- `uv python install 3.12` → 裝到 `~/.local/share/uv/python/cpython-3.12-linux-x86_64-gnu/bin/python3.12`（3.12.13）。
- 本機預設 `python3` 是 3.14.7。

## 跑了哪幾次（都在 `proto5/lib` 下）

| 次 | 指令 | 結果 |
|---|---|---|
| 1 | `PYTHONDONTWRITEBYTECODE=1 uv run --python 3.12 --no-project python -m unittest discover -s test` | Ran 1016，OK，39.4 秒 |
| 2 | 同上，但 `PATH` 前面塞一個 `python3 → 3.12` 的捷徑 | Ran 1016，OK，39.7 秒 |
| 3 | `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s test`（3.14.7） | Ran 1016，OK，44.4 秒 |

為什麼要跑第 2 次：`proto5/cli/aos-*` 六支的開頭都是 `#!/usr/bin/env python3`，kernel 拉 cpu／daemon 時是照這行找 `python3`。第 1 次只有測試本身在 3.12，被拉起來的子程序其實還是 3.14。第 2 次把 `PATH` 上的 `python3` 換成 3.12，子程序也跑在 3.12，這樣才算整條都驗過。

另外補做：用 3.12 把 `proto5` 底下全部 55 支 `.py` 和 `cli/` 六支腳本都編譯一遍，沒有語法錯誤。也用 grep 找了 3.13／3.14 才有的東西（`copy.replace`、`warnings.deprecated`、argparse 的 `deprecated=`／`suggest_on_error`、`except A, B:` 不加括號、`annotationlib`、`uuid7`、`compression.zstd` 等），一個都沒找到。
