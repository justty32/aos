# playbook/workflows — 工作流架構

← [playbook README](../README.md)｜部門對照見 [../company.md](../company.md)

這裡放**可重複套用的做事流程**：一件任務從頭到尾怎麼拆階段、什麼時候該降級（強模型→笨模型→確定性程式）、什麼時候該叫模型評審、驗收怎麼掛。跟 [AGENTS.md](../../../AGENTS.md) 的分層思想、[wf/WORKFLOWS.md](../../../wf/WORKFLOWS.md) 的差別是——那兩份講的是這個 repo 本身怎麼運作，這裡放的是**某一類具體任務**（例如「一批角色補檔」這種製造類工作）反覆做出來、值得照抄的流程形狀。

**誰來放**：某隊收尾時發現自己走的路線（例如「先強模型做一輪、找出重複的步驟、換笨模型接手、最後寫死成程式」）別的任務也能照搬，就把流程寫成一份說明放進來。

**怎麼放**：每份都要交代「從哪段抽的」（連到來源報告）、「適合什麼活」（什麼樣的任務形狀適用這條路線）、「哪裡可再用」（下次遇到類似任務，第一步照抄哪裡、在哪個點該停下來看品管分數再決定要不要繼續降級）。
