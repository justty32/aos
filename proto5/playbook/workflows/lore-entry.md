# 工作流樣板：一個條目一張單（lore-entry）

**適合**：有原文可查的資料整理——「把一個人／一個地點／一個事件整理成一份詞條＋一份附出處的證據表，再回填幾個索引」。
2026-09-25 從 arknights 補人物隊抽出；照抄後把 `<…>` 換掉。

## 1. 開單：一個條目一張單

- **單一個**：門房規則直接開單，不叫領隊（省一整輪模型）。句型要能抓出條目名，驗收寫死在規則裡：

```json
{"name": "one-entry", "pattern": "補人物 ?(?P<name>[^\\s，,、：:；;]+)", "do": "handoff",
 "handoff": {"assignee": "writer-1", "workflow": "<專案的工作流入口檔>",
             "goal": "補「{name}」：讀 <草稿資料夾>/{name}/ 的草稿，逐句回原文核對改正後寫成 <詞條路徑> 與 <證據路徑>，回填 <索引們>。",
             "facts": "<草稿資料夾>/{name}/", "done_when": ["…見第 2 節…"]},
 "tests": {"hit": ["補人物 某某"], "miss": ["補一批人物：甲、乙、丙", "不要補人物 某某"]}}
```

- **一批**：沒有規則，落穿給領隊；領隊人格裡放**同一份 done_when 樣板**，叫它照抄、只換名字，**不要自己讀草稿**。一人一張，輪流派給寫手。共用索引檔要寫手用 `lock` 搶（單子 goal 寫「要拿鎖」才拿，單人時不拿，省一輪）。

## 2. done_when：先機械、後模型

| 順序 | 條目 | 誰驗 | 抓什麼 |
|---|---|---|---|
| 1 | `file_exists` 詞條、證據 | 驗收員（程式） | 檔在不在 |
| 2 | `check last_line_contains` {詞條, "詳見："} | 驗收員 | 詞條收尾格式 |
| 3 | `check contains` {詞條, "<證據相對路徑>"} | 驗收員 | 詞條連到證據 |
| 4 | `check max_bytes` {證據檔, 5119}、{證據子資料夾, 5119, missing_ok} | 驗收員 | 單檔大小上限、超了有沒有拆 |
| 5 | `check contains {索引, "[名](名.md)"}` | 驗收員 | 索引有加一行 |
| 6 | `cmd_ok` 專案自己的全庫連結檢查（白名單條目要掛原文庫） | 驗收員（牢裡） | 斷鏈 |
| 7 | `cmd_ok` 專案自己的單檔檢查（簡體殘留、lint…） | 驗收員（牢裡） | 用字 |
| 8 | `judge` 證據表每列行號對得上原文、推論與明寫分開、未知明講 | 審查員（模型） | **要讀原文**，強模型 |
| 9 | `judge` 詞條每句在證據裡有依據 | 審查員 | 語感＋對照 |
| 10 | `judge` 導航表一列、計數重新點算 | 審查員 | 其實能變程式（見報告〈哪些是機械〉） |

- 機械條目寫在前面：沒過就不會開審查單，省掉最貴的那一步。
- 「全庫」類檢查（斷鏈、全庫簡體）要先確認**基線是 0**，不然寫手永遠過不了、錯不在它。基線不乾淨就只跑「這個人的檔」那種指令。
- `cmd_ok` 白名單要整串相等，所以「這個人的檔」這種指令要把人名寫進白名單（人寫，每批換）。

## 3. 人格要放的東西

- **寫手**：專案規矩原文照抄（不要自己發明）；「你自報乾淨不算數，審查員會對原文」；原文很長要 grep 找行號再 read offset／limit；卡住回 BLOCKED 說試過什麼。
- **審查員**：「寫手自報不可信，每個不同原文檔至少對一列、重大結論（生死、身分、同一人）一律對」；why 要寫到哪個檔哪一列，寫手照這句改。
- **領隊**：done_when 樣板＋「不要自己讀草稿」。

## 4. 環境（開跑前確認，每條都踩過）

1. 原文庫在專案外：專案裡放**相對**符號連結（`corpus/raw -> ../../<庫名>/raw`），成員名冊與 `cmd_ok` 白名單都唯讀掛 `<庫名>`——主機和牢裡同一條相對路徑都解得開。絕對連結在牢裡會斷。
2. 驗收員的 `cmd_ok` 牢**只掛專案**，要讀原文庫的指令一定要在白名單那條寫 `mounts`。
3. 推理型模型：模板 `llm` 寫 `params: {"max_tokens": 32000}`、`timeout_ms` 開到 10 分。
4. 先用 `aos-jail` 在牢裡把每條 `cmd_ok` 手跑一次，退 0 再開真跑。
