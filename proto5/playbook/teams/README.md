# playbook/teams — 團隊組織架構

← [playbook README](../README.md)｜部門對照見 [../company.md](../company.md)

這裡放**可重複套用的團隊編制**：名冊模板、角色怎麼分工、誰管誰、哪個位置用哪顆模型。跟 [`spec/team/`](../../spec/team/README.md) 的差別是——`spec/team/` 講的是機制本身（門房、郵差、驗收員怎麼運作），這裡放的是**套用機制之後、某一種具體任務適合怎麼編隊**的成品，方便下次遇到類似任務直接照抄名冊、改幾個名字就能用。

**誰來放**：某隊收尾時發現自己這次的團隊編制（例如「三個工人＋一個審查」這種分工）別的任務也適用，就把名冊或設定檔放進來，附一段說明。

**怎麼放**：每個檔案都要交代「從哪段抽的」（連到來源報告）、「適合什麼活」（哪種任務規模、哪種風險）、「哪裡可再用」（照抄哪個檔、要改哪幾個欄位）。
