# 讓模型指定工具呼叫順序

> 等 agent 規範重寫後再判。

**問題**：模型一次叫多個工具、其中幾個標 `_run: cpu` 時，訊息順序有保證，實際執行順序沒有（多顆 cpu 同時跑）。重架構後沒有 tool cpu 了，工具是普通程式、交給 kernel 派到 exec cpu（[cpu §4.1](../spec/cpu.md)、[kernel §3 第 8 步](../spec/kernel.md)），並行的問題一樣。「先建資料夾再寫檔」這種組合可能亂。

**2026-09-22 拍板**：接受並行，這是模型一次叫很多又不給順序的問題，agent 不處理。

**以後從哪下手**：提供一個特殊工具，讓模型宣告這批呼叫誰先誰後；agent 收到就照宣告串行送。
