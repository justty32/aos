# learn — 長期吸收一個主題，長出可回訪的筆記樹

[WORKFLOWS](../WORKFLOWS.md)｜[INDEX](../INDEX.md)

主題開放、會一讀再讀：建主題地圖、逐子主題做筆記、把不懂的留成 open questions。**learn 是 [digest](digest.md) 的升級形態**——digest 的產物長出 `topics/` 與 `questions.md`，它就是 learn；動作幾乎一樣，差在目的是長期吸收而不是讀完即止。

**何時用**：使用者說「我想學 X」「幫我建 X 的學習筆記」，而且之後還會回來繼續。
**何時不用**：只要一次看懂一份材料 → [digest](digest.md)。（例：「幫我讀懂統計檢定」——只是這次要看懂，走 digest；要持續學下去，走 learn。）查一次就忘的事實直接查。

## Done when

- 下方主題地圖每列狀態欄是 `已懂 / 在學 / 待學` 其中之一，沒有空欄。
- 這輪讀的每個子主題各有一個筆記檔，每節末有來源（URL / 書名頁碼）。
- `questions.md` 存在，且記下這輪冒出來、還沒答的問題。

## 流程

1. **畫主題地圖**：把主題拆成子主題，各標已懂 / 在學 / 待學。
2. 逐子主題讀來源、做筆記，**用自己的話重述**——複製貼上不算學會。
3. 不懂的進 open questions，不假裝懂；答掉了就從 questions 移進筆記。
4. 來源記清楚，一手勝二手。
5. 每輪結束更新主題地圖的狀態欄——這份地圖就是下次回訪的入口。

## 交接

- 材料本身還沒讀懂 → 先跑一輪 [digest](digest.md) 再回來。
- 學到能產出東西 → [write](write.md)；筆記樹亂到難找 → [organize](organize.md)。
- 跨 session 的「讀到哪、下一步讀什麼」→ [SESSION-LOG](../SESSION-LOG.md) 一行。

> 〔模板說明〕本檔從單檔開始；主題地圖以外的東西（`topics/`、`questions.md`、`sources.md`）長出來時照 [STRUCTURE](../STRUCTURE.md) 四級成長升級成 `learn/` 資料夾，本檔變 `learn/README.md`。
