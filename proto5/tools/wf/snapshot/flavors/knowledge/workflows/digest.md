# digest — 讀懂一份材料，產出摘要與出處索引

[WORKFLOWS](../WORKFLOWS.md)｜[INDEX](../INDEX.md)

把指定的長文、報告、影片逐字稿、一疊連結讀完，留下**摘要 + 可回溯的出處**。材料範圍有限、讀完即止。

**何時用**：使用者說「幫我讀懂這份 / 這幾份」「做個摘要」「把這堆連結整理成索引」。
**何時不用**：查一個即時事實、不需留存 → 直接查證回答。這個主題之後會一讀再讀、要長期吸收 → [learn](learn.md)。

## Done when

- 下方「材料索引」表裡這次指定的每一列，狀態欄都是 ✅。
- 每份材料有一個摘要檔，含「一句話 / 重點 / 對我的用途 / 來源」四段。
- 每列「來源」欄有 URL 或可定位的位置（書名頁碼、檔案路徑），不留空。

## 流程

1. 先把材料登進索引表，狀態 `⬜ / ✅ / ⏸️`。
2. 取得原文，記來源 URL / 標題 / 日期。
3. **讀原文**，不要只信搜尋摘要或二手轉述；原始來源與摘要衝突時，以原始來源為準。
4. 照下方模板產出摘要；跨材料浮現共同主題時，併成一份主題筆記。
5. 更新狀態欄。讀不完的標 ⏸️ 並寫下卡在哪。

## 交接

- 讀懂了要動筆 → [write](write.md)；讀懂了要行動 → [plan-a-thing](plan-a-thing.md)。

- 材料多到難定位 → 去 [common/info-map](common/info-map.md) 登一列。
