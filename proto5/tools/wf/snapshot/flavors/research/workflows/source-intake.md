# source-intake — 一件材料入庫

[WORKFLOWS](../WORKFLOWS.md)｜[INDEX](../INDEX.md)

本包的**主線**：把一件外部材料（論文、報告、規格、影片逐字稿）從原文抓進來，產出摘要（需要時加翻譯），登進索引真相層，補一句歷史日誌。

**何時用**：使用者說「把這篇／這批入庫」「抓文 → 摘要 → 登索引」，或 [backlog](backlog.md) 裡某一列要開始處理。
**何時不用**：材料**已在庫裡**、只是要查它的結論 → 直接讀該件的摘要回答。跨多件做主題全景 → [survey](survey.md)。讀完即止、不進庫的一次性材料 → knowledge 包的 digest。

## Done when

- `{{摘要目錄，如 summaries/}}/<id>_<題名>.摘要.md` 存在；有翻譯時翻譯檔也存在，且兩檔 frontmatter 互指。
- `index/` 所屬分類檔有該件的列，狀態欄非 ⬜（規則見 [common/index-rules](common/index-rules.md)）。
- `logs/<當月>.md` 多一行，寫做了什麼＋數字變化（例：`index 452→464`）。
- `{{驗證指令，如 python tools/validate.py}}` 回傳 0。

## 流程

1. **抓取**：`{{抓取指令，如 curl <url> | python tools/to_text.py}}`。原始檔放 `raw/`，**用完即清；但驗收收線前不清**（見下節）。
2. **驗證抓對了**：比對 `{{材料 id，如 DOI / URL / 報告編號}}` ↔ 題名 ↔ 作者，對不上就重抓。來源工具會回錯物，這步不能省。
3. **產摘要**：照 [TEMPLATE.summary](TEMPLATE.summary.md) 落檔。
4. （可選）**翻譯**：涵蓋問題、方法、主要結果、結論與局限；大表、附錄、參考文獻、重複例子擇要即可，不要求逐字或零遺漏。
5. **登索引**：在 `index/` 所屬分類檔表尾加一列並標狀態。
6. **補日誌**：`logs/<當月>.md` 一句話。
7. 需要時重建衍生層（`{{重建指令，如 python tools/build_html.py}}`），commit；push 依鐵律 2（授權來源）。

**一件一件做完**：一件走完 1–7 再開下一件，不留一堆半成品。

## 批次做

- **一輪上限 {{每輪件數上限，如 5}} 件**，超過分輪。
- **逐件 `ls` 並開檔驗收**，確認存在且內容相符。**不採信工具或子 agent 的自述**——回報「已完成」但檔案不存在／內容不符的情形實際發生過。
- **數字一律標「作者自報」並附 `raw/` 出處**；本檔自己推得的判斷加「（本檔補註，非作者自陳）」。摘要的「局限」段預設會被讀成作者自陳，混進自己的批評就是竄改材料。
- **驗收（含數字與歸屬核對）沒收線前不得清 `raw/`**——它是唯一能回頭核對的來源，清掉只能重抓。清理排在驗收之後，不要和登索引綁同一步。

## 易錯點

- **來源工具會回錯物**：抓 A 拿到 B、拿到空殼頁都發生過。先比對 id ↔ 題名再動筆（步驟 2）。
- **工具附帶的摘要／轉述一律不採信**：它只負責取得原文，內容自讀原檔。
- **材料自身的數字會互相矛盾**：照原文寫並標示矛盾，不要自行擇一當定論。
- 其餘見 [common/gotchas](common/gotchas.md)（門檻：第二次撞到才記）。
