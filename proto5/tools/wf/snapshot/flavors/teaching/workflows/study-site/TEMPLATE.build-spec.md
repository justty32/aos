## 教學頁契約

每章至少約 <N> 個純文字字元，且依序提供：白話 why → 一句話答案 → 最小前置 → 首次術語展開 → 逐步因果 → 至少一個可手算例 → 互動前的完整說明 → 可觀察證據 → 常見誤解與適用邊界。互動不計分、不鎖頁。

字典頁純文字至少 <N> 字元；每條必備<白話／位置與角色／如何生效／具體例子／不要混淆>。

## 互動與公式

每個互動元件一列，**欄位不得留空**；計算式含 `|` 時寫成 `&#124;` 或改用清單（未跳脫的 `|` 會把式子攔腰截斷）。

| id | type | min | max | step | value | 計算式 | 判準（怎樣算對）| 數值實例（輸入 → 預期輸出）|
|----|------|-----|-----|------|-------|--------|------------------|---------------------------|
| `<id>` | `range`／`select`／… | | | | | | | |

- `select` 的選項與 value **順序**也要寫死。
- 每個公式標符號、單位、假設、量綱；至少兩個極端案例。
- 每個數值實例都要有人**獨立重算**過（規格的算術錯會被照抄進產品）。
