← [progress.json](../progress.json)

- `$ref` 的路徑照 aos 的慣例，從放它的檔所在的夾（`wf/`）算；指到 `.md` 就是整份內文。
- 每檔第一行是一句話：`wf/tools/compact_reload.sh` 在 HANDOFF 空時只印這一行加路徑，不印全文。
- 條目關掉（刪那一鍵）時，同名的 md 也該收掉；刪檔照鐵律 2 要授權。
- `改寫前-<鍵>.md`：11-22 整理時把條目改寫成剩下的事，改寫前的長段逐字留在這裡，條目的 see 指過來。
