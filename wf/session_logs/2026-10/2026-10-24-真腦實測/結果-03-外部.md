## 真跑結果

| 項目 | 結果 | 腦／付費呼叫 |
|---|---|---|
| `aos-ai doctor` | `brain.reachable: true` | 0 |
| `spawn boss2 --tool ask_agent --tool agent_status` → ask「請叫 helper 算 17*23」→ run | **能用**：`ok:true`、答案 `391`（不是 FAKE）；老闆叫 `ask_agent` 起 `ws/agents/helper/`、helper 叫 math；真模型把 `{"ok": true, "answer": "391\n"}` 自己摘成「391」（打磨方向第一條驗了） | 腦 4 次、6.6 秒 |
| 工具出錯（題目要它用名字 `Helper Bob`） | **原本壞、修好了**：老闆停在 act（`ToolFailed`），hint 叫人「再 run 一次」，但重跑會再叫同一個壞參數、永遠卡住（10-24 函式庫遷移把工具錯改成退 1 時漏了 aos-ai 這條）。修後老闆照錯誤那行回「名字不合」、交答案 | 腦 1＋2 次 |
| skill：`claude -p --plugin-dir …/claude_skill/aos --model sonnet`「起一隻 helper2，問它 '17*23'」 | **能用**：5 回合、答 391；helper2 用的是真腦（`AOS_BRAIN_URL` 傳下去） | claude 1 次約 0.08 美元＋腦約 2 次 |
| agent-fay q1「列出這個資料夾的檔案並回一句話」（`ws-real/`，照 env.sh） | **能用**：腦自己選了 codex、codex 照實列出 `.stack/ cur/ new/`、答案進 `out/q1.txt`；`.stack/codex/session.txt` 有；16 秒 | 腦 2＋codex 1 |
| agent-fay q2「請交給 claude 幫手：out/ 底下有哪些檔」 | **能用**：claude 答「只有 out/q1.txt」；`.stack/claude/session.txt` 有；9 秒 | 腦 2＋claude 1（非互動上限 0.5 美元） |

合計：LiteLLM 約 13 次；付費的是 `claude -p` 一次（約 0.08 美元）、fay 叫 claude 一次、叫 codex 一次。

交接表那條「成功＝有 `turns.jsonl`」不對：`turns.jsonl` 只有畫面開著（attach）時 hook 才寫，agent 非互動叫的時候沒有，這是照設計（[cli-tools](../../../../proto8/thinking/2026-10-24-cli-tools.md) 第 4 點）。

## 修了什麼

- **`aos-ai spawn --tool-errors back｜stop`**（`proto8/ai_tools/bin/aos-ai`）：範本是 agent-dan（act.py 跟它一模一樣）時預設 `back`＝act 換成 agent-pip 的（工具退非 0 那行接成 tool 訊息回給腦、不停；錯誤開頭仍是 `agent-dan:`）；`stop`＝agent-dan 原樣停。別的範本照範本自己的 act（回 `tool_errors: "template"`），對它們給這個旗標＝`ArgumentsBad`。`ToolFailed` 的 hint 補一句「腦給錯參數時重跑會再叫同一個」。`ask_agent`／`spawn_agent` 起的子 agent 也走這個預設（它們叫 `aos-ai spawn`，lib 沒改）。
- 測試 `test_ai_tools.py` 多一案 `test_tool_errors_back_or_stop`（假 server 叫 `Bad Name`：back 答完、stop 停在 act、hint 有提旗標、別的範本與亂給值不收、不留半隻），先把預設改成 stop 確認會紅。
- 文件：ai_tools/README（spawn 列、遷移那段）、SKILL.md 一句、thinking [ai-tools](../../../../proto8/thinking/2026-10-24-ai-tools.md) 決定 9 換新、實測補真腦一條、「JSON 原樣」那條補結論；code map [06-周邊工具](../../../workflows/common/code-map/proto8/06-周邊工具.md)、[08-tests-10-24](../../../workflows/common/code-map/proto8/08-tests-10-24.md)。
- 驗證：unittest 455 個 OK（2 skip）、run.sh 六段結束碼 0、ctest 8 個全綠。commit 見 git log（訊息開頭「真腦實測 03 外部」）。
