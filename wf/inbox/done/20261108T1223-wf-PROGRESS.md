# arcagi 第二輪收輪：evaluation 28/400（+7、退步 0），aos 接上四件＋謂詞自動產生

## 成績（白話）
- 正式考卷 evaluation：**對 28 題／共 400 題**（第一輪 21 題）。練習卷 training：對 79／400（第一輪 57）。兩邊都沒有一題比第一輪退步。
- 沒達到的目標：evaluation 想要 ≥30；「輸入輸出一樣大」的 270 題只從 3 題進到 7 題（想要 ≥10）。

## 學到什麼
- 新積木（挑物件再改它、切格子）在練習卷上很有效（換色類 0→9），正式卷的題更複雜，只多 7 題。
- 物件抽取把「整張圖最多的顏色」當背景，同一題不同例子的背景會不一致，害自動產生的判斷積木用不上——下一輪先修。
- 「兩次嘗試」沒加分：搜尋找到解就停，幾乎沒有不同的第二答案。

## 代定了什麼（全文 notes/rounds/r02/代定清單.md，16 條）
- 物件積木只當程式第一步（不然搜尋慢 2.5 倍）；只懲罰「鄰域規則表」這種最會背答案的學習器；兩次嘗試離線算、不改量具。
- 錢怎麼算：解一題 1000 分、頂層留 20%、80% 按積木被引用分紅、花費＝搜尋時被試的次數、房租每輪 100；三輪 0 收入只列「建議退休」。
- 第一次的退休建議（9 塊，含 rot90 等基礎幾何）不執行，下一輪加「必要名單」。
- 使用者 12:05 新想法「優化產生積木」：本輪先做判斷型（謂詞）的自動產生；抽取型、公式型只定格式，下一輪做。

## 用了哪些程式方法
- 純 Python 零依賴：網格 DSL＋逐層枚舉（深度 3、觀察等價去重、參數從範例推、最短程式勝出）。
- 新增：物件層（4 種切法、12 種屬性、選擇器從範例推、物件換色表學習器）、格線切塊、第二候選、巨集（從過關程式抽常見片段）、謂詞產生器（枚舉 1～2 個條件的判斷，在練習卷打分、0 分不落地、被更短的蓋住標 covered；21321 個候選留 60 個）。

## aos 接了哪些
- 積木＝aos 資料夾程式：arcagi/aos/blocks/<名>/ 有 _metainfo.json＋_entry，`aos-exec --ws aos aos/blocks/flip_lr` 能單獨叫；狀態 retired 的不進搜尋；巨集、謂詞落一個資料夾就生效、不改程式碼。
- 求解器＝資料夾程式：`arcagi eval --external "aos-exec --ws aos aos/solver {input} {output} {trace}"`，20 題跟原本同分。
- node-pool 記帳（簡化版）：arcagi/aos/pool/ 有 epoch 0～2，守恆都成立；近失敗寫進積木的 _gradients.jsonl。
- 想法 21 covered；產生器本身是節點（_gen/pred_combiner），抽它產出的積木分紅 20%（epoch 2 分到 80）。
- 沒接：aos-llm（要 llm-kernel daemon、額度 >85%）、元優化（aos 那邊也還在定）、aos-loop／fsm（批次求解用不到狀態機）。
