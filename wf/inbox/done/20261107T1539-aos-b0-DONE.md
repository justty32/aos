## 白話總結
- agent 在哪一階段不另寫欄位，看工具就知道：有能跑任何指令的 bash＝開放期；bash 關進沙箱＝謹慎期；沒有這種工具＝專屬工具期。
- 能「跑任何東西」的不只 bash：`self_tools`、`agents`、`thought` 也能把自寫資料夾登記成工具，照實標出。所以只有窄領域專精 agent 走得到最後一步——正合「領域越窄越能工具化」。
- 往下一階段交給 evolve-design 的審視者，多三招：常用指令做成專屬工具、bash 關沙箱、bash 拿掉；機器只准收緊，放寬只能人做。
- 確定性用 evolve-design 的 measure 重跑三次互比，分三層報（腳本步一字不差／LLM 步按模型記分／整個地點幾個檔一字不差），不合成一個分數。
- 核對程式發現：現有沙箱寫法擋不住指令白名單，bash 工具本身用 Python，所以謹慎期只保證「只寫工作區、不連網」，真正封死要到專屬工具期。
