## agent-fsm 與 sol

- sol 讀完必讀只回一句「會照做」就結束回合，隊長看不出來：隊長卡先 goal set，或 general.A.txt 加「Never end a turn with a plan」，或 subagent state 標「回合已結束」。（fsm範本.md「sol 讀完必讀後只回一句」）
- sol 的可寫範圍分在 guard.json 的 write_roots 與 shell-boxed 的 sandbox 兩份，換工作區要改兩邊，擋下時也不說是哪份：ok-fsm 有圖紙（8d5d435ca，sandbox 向 guard 問 scope），還沒施工。（fsm範本.md「sol 的可寫範圍寫在兩份清單」）
- system 文字不能分層、不能 $ref，各線整份抄：interfaces 的 system 收檔案清單或 $ref，或 subagent add 收 system。（fsm範本.md「agent-fsm 的 system 文字不能分層」）
- 範本 system.txt 叫 agent 讀知識庫卻沒給路徑：寫 `$AOS_HOME/knowledge`，改前用真模型驗一次。（fsm範本.md「system.txt 叫 agent 讀知識庫」）
- 工具說明沒分短版（送腦）與長版（self_tools get）。沒查證。（fsm範本.md「範本預設掛 55 支工具」）
- 缺取隊員最後回答的指令：`aos-agent history -t NAME last [--text]`。（fsm範本.md「蒐集用 sol 的工具包寫不了純文字檔」）
- fsm 隊員沒有 user_send／user_verify：做一個選掛的 user 包。self_tools add 也不能一次加一整包（收 pack 參數，不急）。（fsm範本.md「fsm 隊員沒有 user_send」「self_tools add 一次只能加一支」）
- 小錯兩件：llm_settings.py 檔頭說 fixed 欄位「照舊蓋過」，實際回 RequestBad；wait.py 的 kernel_dir() 沒對 AOS_LLM_KERNEL 去空白。（fsm範本.md 同名兩條）

## eca 與 eca-claude 範本（範本預設值，改前先問使用者）

- cli.json 在 dontAsk 下只放行 Write、Edit、Bash，Read／Glob／Grep 出了工作區被拒、只好用 Bash cat：加這三個。反方向：預設權限全開，產品版要不要一份保守預設。兩題一起問。（fsm範本.md「dontAsk 下沒放行 Read」「eca-claude 範本預設權限全開」）
- 沒關 Claude Code 自動記憶，工作區在別的 repo 底下時會讀寫那個 repo 的記憶：settings 加 `"autoMemoryEnabled": false`。（fsm範本.md「沒關 Claude Code 的自動記憶」）
- eca 身沒有「goal 暫停後來信提醒一次」（只有 agent-fsm 有）。（fsm範本.md「eca（aos-eca-turn）沒有 goal 暫停後來信的提醒」）
- cli.json 只有定義那一份，不能只替一隻打開 live_mail、a2a：stack 裡放覆寫檔疊上去。（fsm範本.md「eca 的 cli.json 只有定義那一份」）
- ctl stop／rm 遇到正在答題的 eca 回 SessionBad busy answering：排隊到這輪結束，或在 tooldef 寫出 no_wait。（指令與工具.md「ctl stop／rm 遇到正在答題的 eca」）
- brain_failed 事件兩種身欄位不同（eca 沒有 error），self_hook 說明沒寫。（fsm範本.md「brain_failed 事件」）

## commit-request 與 wf/tools

- claim 拿整串路徑逐字比：git status 抄來的轉義中文路徑、或 claim 一個資料夾，看似成功其實沒保護到：norm() 先反轉義，資料夾改前綴比對，至少印警告。（指令與工具.md「claim 把 git 轉義過的中文路徑原樣存下」「claim 一個資料夾」）
- submit `--rm` 在 agent 的 dontAsk 下整條被拒：加 `--moved 舊:新`，或 `--help` 寫明要由人跑。（指令與工具.md「commit-request 的 --rm 被 agent 的權限模式整條擋下」）
- 小改善：claims 加篩選、一行一筆並標 stale；一個參數塞多個路徑時提示；check_anchors 加 `--files` 或跳過 wf/temp；submit 依路徑印「存檔即生效還是換樹才生效」，wf/tools 加照順序換檔的 land。（指令與工具.md 同名各條）

## 工具說明與 --help 跟程式不符

- 字樣要改：remove 的 counter_files 只有刪資料夾才有；stat 漏 broken、ls 漏 missing；todo 漏 StackMissing；mailbox 的 keep 寫「from your workspace」但絕對路徑照收、`#` 只有 json 工具當分界；ctl add 與 aos-daemon-ctl 的 `--limits` 寫「'{}' = none」實際是 daemon 預設，也漏 mem_total_mb、procs_total；aos-daemon-ctl rm 寫 stop, then remove 實際直接 SIGTERM；subagent 的 system 是整份取代沒寫。（指令與工具.md「四支工具的 tooldef」「`#` 在 json 工具和檔案工具裡」「ctl add 的 --help 對 --limits」「aos-daemon-ctl 的說明寫 rm」「subagent 的 system set」）
- stat 遇到讀不了的資料夾丟 traceback：回 ReadFailed。（指令與工具.md「stat 工具遇到讀不了的資料夾」）
- 低優先：glob 不照樣式深度剪枝；aos-lock 名牌只記 WS、release 不比 STACK；clock 沒有 skip_next；agent_def new 照抄 README 相對連結全斷；scan 只印「0 hits in 0 files」。（指令與工具.md 同名各條）
