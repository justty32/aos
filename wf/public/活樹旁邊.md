## 哪些檔存檔就生效：實際查連結，不能用推的

- **適用**：要回答或放行「這個改動是存檔即生效，還是換樹重抄才生效」。
- **事實（11-14 家機）**：`~/.local/bin` 的 `aos-*` 都是連到 repo 的連結，它們 import 的 `proto8/cmd/`、`proto8/py/`、被指令直接 import 的 `proto8/lib/agent/*.py` 存檔當下活樹就在用。活樹另有 `lib`、`templates`、`knowledge`、`py` 四份複本，樹裡跑的東西用的是複本，換樹重抄才生效。好幾線把這兩類搞反（ok-limits 的 `daemon_ctl/entry.py`、ok-wake 的 `cli_print.py`、ok-fsm 的 `goal_state.py`、ok-pilot 的 C/D）。
- **做法**：`readlink -f ~/.local/bin/<指令>`，再 grep 那支指令的 `sys.path.insert`，看它 import 的是 repo 還是複本（例：`aos-daemon-ctl` 第 378 行插的是 repo 的 `proto8/py`）。這屬於看活樹，**先請部長點名再查**（見下面「唯讀查看」）。活樹那份 `py/` 複本實際誰在 import，11-14 沒查到。
- **驗過**：head-core 11-14（notes.md 13:29；commit 50e7a35bc）；ok-kf 整合換樹清單時逐線更正；ok-kb 14:55 唯讀查。
- **出處**：`wf/temp/{head-core,ok-kf,ok-limits}/wrapup-1114/經驗.md`；`wf/temp/ok-kb/to-top/06-活樹在哪台與proto8-py兩邊都列.md` 第一節

## 換存檔即生效的檔：備份、暫存檔改名、被 import 的先換、每換一檔就 import

- **適用**：改 `proto8/cmd`、`py`、`lib/agent/*.py` 的既有檔。改到一半的檔會被正在跑的 agent 讀到；多檔之間順序一反，中間那一刻整支指令 import 不起來，而且是活的。
- **做法**：
  1. `git diff --quiet <base> -- 檔`，確認 repo 的檔還跟暫存樹的基準一樣；claim。
  2. 原檔備份到 repo 外。
  3. `cp --preserve=mode` 到同夾的暫存檔，再 `mv -f`，用 `cmp` 核對。
  4. **多檔：順序寫死在腳本裡，被 import 的先換**（例 `entry.py → __init__.py → common.py → who.py → add.py → 測試 → 文件`）。每換一檔就跑：import 該模組、import 用到它的模組、`aos-agent --help`，一件失敗就停。整套先在 `git archive` 的乾淨複本上照同樣順序演一遍，輸出附在交件信。
  5. 經 clean.sh 跑定向測試：從 HEAD archive 一份、把這幾檔的實際內容疊上去跑。能的話在暫存樹起自己的 daemon 實跑一次，看 stderr 是空的。
  6. 新碼先放成新函式；接上舊路徑另外找部長放行（06 第 5 條）。
- **放行的人**：自己把新檔跟 repo 現行檔 diff 一次，看檔頭 import 的名字在被 import 的檔裡有沒有；放行條件寫成「被 import 的先換、驗過名字都在，才換 import 它的」。審 diff 的人要問換檔順序。
- **驗過**：add-parent 那批（bcaf76823，14 檔每步都過；新 `__init__.py` 配舊 `entry.py` 會 ImportError，是獨立審稿員抓到的，`~/code/limits-1114/ws/phase1/land2.sh`（11-15 已刪））；ok-sec f4ae9fcf0（5 檔）；ok-kmsg（先換 `hints.py` 再換呼叫端）；head-comm 在 ok-wake C2 看出順序反了（7747a7627）；ok-limits d543a0b4d。
- **出處**：`wf/temp/{ok-limits,head-core,ok-sec,ok-kmsg,head-comm,ok-devt}/wrapup-1114/經驗.md`

## 唯讀查看活樹也要任務書點名；寫的界線照字面讀

- **適用**：為了查「哪份碼在跑」「有沒有人在用某變數」「新提示會不會誤報」想看活樹。
- **坑**：四條線都順手越線：讀活樹 daemon 的 `/proc/<pid>/environ`（只列名字也算）、grep `~/aos-home` 的 `.env` 與 `daemon.json`、看 `~/aos-home` 頂層與 `py/` 清單、讀自己程序鏈的 `AOS_*`。06 第 1 條：唯讀查看只限任務書點名的。
- **做法**：
  - 要活樹的事實：開查前把要看的路徑一條條列給部長，點了名才看，或寄一句請頂層代查。查不到就寫「沒查到」，不要為了答完整再多看一處。06 第 9 條要的 pgrep 不算在內，照跑。
  - 授權別人看活樹的檔，**路徑寫到檔**（點名「xiaosi/ 底下的 live.jsonl」，實際在 `xiaosi/claude/live.jsonl`；線照「點名位置沒有就不往別處找」回報，才補點名）。要寫進授權範圍的路徑先 grep 程式確認。
  - 寫的界線比想像的寬：一行 CSS 也算寫活樹。授權範圍照字面讀：「准裝 v2.0」不含 v1 的修正。
  - 暫存腳本開頭一律先清 `AOS_*`、PATH 拿掉 `~/.local/bin`，否則測試可能悄悄用到活樹在跑的執行檔。
- **驗過**：ok-kb（14:55 自己報給 head-front）、ok-limits（head-core 指出）、ok-kf、ok-kmsg（事後報備）、head-front、ok-view（13:09 那次）、head-comm、ok-wake，都是 11-14。

## 查祕密有沒有擴散：值不落地、只印檔名和變數名

- **適用**：查 API key 這類值有沒有被寫進檔、log；或要看某個行程的環境。
- **坑**：為了 `grep -F -f` 把值寫進 `/dev/shm`，等於又複製一份，還得另外請使用者授權刪（授權只蓋題目寫到的那個檔，見 [user-zone-mail](user-zone-mail.md)）。把整份 env 傾印成 `env.txt` 會帶出 API key。
- **做法**：在行程內比對只印檔名，或只比雜湊；`grep -l`，或 `sed` 只取等號左邊；看環境檔先濾掉含 KEY、TOKEN、SECRET 的行，只印變數名；再用 `git ls-files` 濾掉 repo 抄本，雜訊少很多。不把整份環境變數寫進檔、log 或信（aos-teams 第 5 件）。
- **驗過**：ok-board 11-14（`board-1114/07` §三；已另投 advice「原型傾印環境的風險」）、head-comm、ok-kf、ok-kb。
- **出處**：`wf/temp/{ok-board,head-comm,ok-kf,ok-kb}/wrapup-1114/經驗.md`

## 換樹當晚：pin 是 main 的一個 commit，不能跳過中間某一筆

- **適用**：當晚要把 main 換進活樹；線想說「這個 commit 有問題就從今晚拿掉」。
- **做法**：
  - 拿不掉。只有兩條路：收件截止前修好或 revert；或把 pin 往前釘（之後的 commit 今晚都不換）。所以「要不要隨今晚進活樹」在 submit 之前決定，不想進就等 pin 釘完再交。收件前先跟各部講清楚。
  - 一個 commit 同時改 C++ 和 `proto8/knowledge/`、而當晚不重編那支執行檔：活樹的知識庫會寫著執行檔沒有的功能。跟管換樹的線講定當晚也重編，或等 pin 釘完才 submit。
  - 線比估的早交時，立刻想「它會不會被今晚的 pin 帶到」，馬上通知換樹的線加預演和換後驗（ok-kmsg 說 16:30 交，14:22 就進 main）。
  - 管換樹的線：定一個最後收件時刻，往回推所需時間（11-14：全套約 11 分鐘、重編 5～10、預演 5、送審 10～15，16:00 收件、最早 16:45 換）。整夾從 pin 的 `git archive` 換，互相依賴的檔不會錯開、執行權限也保留。預演驗「退回逐位元相同」（程式、權限位、定義夾、使用者資料各算一個雜湊，`~/code/ts-1114/rehearse.sh`（11-15 已刪） 38-42 行）。換下來的東西搬進 `~/.aos/saves/tree-swap/run-*`、不刪（b8ff23ada）。
- **驗過**：ok-kf 11-14（預演 r1、r2、r4 全綠）；head-tools（ok-misc 的 T20 定成 pin 釘完才交）；head-comm（d6a564191）。
- **出處**：`wf/temp/{ok-kf,head-tools,head-comm}/wrapup-1114/經驗.md`；信 01794635974847863838.4107905.2456049、01794637492911742744.901833.2607856
