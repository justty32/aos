## proto8／proto8-1 逐檔總覽

（10-13 從 code-map.md 原文搬來；新增或刪檔時這裡與該 README 一起改。）

`proto8/`（Python）的逐檔表在 [proto8/lib/README.md](../../../../proto8/lib/README.md)（命令列與 stdio 範本 `aos_cli.py`、`檔#/位置`＋指示詞（語法糖）`aos_directives.py`、inst `aos_inst.py`、loop `aos_loop.py`＋共用的 ctl／state `aos_ctl_state.py` 與行程群組 `aos_proc.py`、daemon `aos_daemon.py`（重用 loop 的拍引擎）＋表與策略格 `aos_daemon_table.py`＋指令與控制資料夾 `aos_daemon_folder.py`、fsm `aos_fsm.py`（只管狀態→格，state 窗只有 phase）＋方法表 `aos_methods.py`、agent 的現成格庫 `aos_agent_lib.py`（think／tool（每次在 `work/<n>/` 跑、寫 `args.json`）／route／intake（args.json 接進 history、接完改名 `args.taken.json`）／done，外加給 loop.json 用的 `fsm`（照 lookup 找 fsm.json `aos_mailbox.py`（信＝inst、回信＝N-30 結果、stdout／stderr 落旁檔）＋閘門 `aos_gate.py`（兩種 kernel 共用）與 LLM kernel 的身體 `aos_gate_kernel.py`（N-42 第一種，細節 `kernel.md`）＋通用 kernel 的身體 `aos_kernel.py`、判官那一半 `aos_kernel_judge.py`、規則判官 `judge_rules.py`（N-42 第二種，細節 `kernel2.md`）＋inst 樹工具 `aos_tree.py`（print／inline，同像性；看狀況的小工具，不屬規範）＋真的腦 `aos_brain_openai.py`（OpenAI 相容）與 `aos_brain_ollama.py`（ollama 原生 `/api/chat`，能設 num_ctx；兩顆都在 assistant 訊息頂層帶 `usage` 給 kernel 記額度），薄入口 `proto8/bin/aos`（`aos <名>`＝`python3 lib/aos_<名>.py`、`aos agent …`、`aos brain …`，放進 PATH 讓 argv 寫指令名），測試在 `tests/` 按程式分檔（`helpers.ENV` 把 `proto8/bin`、`demo/bin` 接到 PATH 前面）；各程式的細節在同資料夾的 `directives.md`、`inst.md`、`loop.md`、`daemon.md`、`fsm.md`、`agent.md`、`kernel.md`、`ctl-state.md`），demo 在 [proto8/demo/README.md](../../../../proto8/demo/README.md)（daemon；demo 腳本的薄入口 `demo/bin/aos-demo`（`aos-demo fsm/x.py`＝從 demo 資料夾算的腳本，其他指令照跑並給 `AOS_DEMO`）；fsm／agent 的在 `demo/fsm/`：本身是 agent 定義資料夾（`fsm.json`、`loop.json`、`cells/`（idle.py、thinking＝內層 `think/fsm.json`、tool、done）、`brain.json`＝假腦 `brain/fake.py`、`system.md`、`tools/clerk.json`（agent 當工具：`sh -c` 三步叫報時員）），換用的腦 `brain/openai.json`／`lmstudio.json`／`ollama146.json`／`qwen146.json`，報時員定義資料夾 `clerk/`（含 `tools/clock.*`），`run.py` 建 frame、在裡面跑 loop.json；LLM kernel 的在 `demo/kernel/`：daemon／loop／kernel 設定由 `run.py` 寫成完整檔、閘門 `gate.json`／`gate-fake.json`、假腦 `brain.py`、腦包閘門的 agent 定義資料夾 `boss/`（工具 `tools/clerk.json` 借 `demo/fsm/clerk/` 並在它的 frame 綁 boss 的腦）；通用 kernel 的在 `demo/kernel2/`：設定由 `run.py` 寫成完整檔、活 `job.py`（llm／cpu／human）、閘門 `gate-*.json`、判官 `judge-rules.json`（`_schema`→`judge.schema.json`）／`judge-broken.json`／`judge-agent.json`＋agent 判官定義資料夾 `judge/`（入口 `ask_judge.py`：暫存 frame 跑 `judge/loop.json`、讀 ret.json））；改 proto8 的檔就同步那份。`proto8-1/`（tasks：`aos_seq.py`、`aos_par.py`、`aos_if.py`、`aos_not.py`、時鐘 `aos_tick.py`、共用 `aos_tasks.py`（stderr 的錯誤重用 proto8 的 `aos_cli.error()`）、`bin/`
