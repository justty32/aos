### `proto8/tests/`（10-24 新增的 17 份）之一

- `bench_intent_context.py`：**不是測試、手動跑的對比**（檔名不叫 `test_*`，unittest／ctest 都撿不到）。同一段 15 題、主題跳來跳去又回頭引用的對話，各跑 agent-dan（整份 history）、agent-kai（按意圖組 context）、kai0（kai 但腦沒有 recall），比每題送出的 token 與答對率；`--upstream` 給了＝真腦（夾一個記錄用的轉送 server），沒給＝「照證據回答」的假腦、token 用字數粗估。結果放 `--out`（預設 `~/code/try/intent-context/runs/<時間>/`）。
- `test_ai_tools.py`：`proto8/extras/ai_tools` 的 `aos-ai` 命令列（spawn 起 agent、丟題、前景跑、背景 start／wait／stop、名字等邊界、失敗當資料帶提示、make 生成 loop／fsm／單子／函數／metainfo／工具與格、explain 與 `--here` 跟 aos-exec 算的一樣）與給 agent 掛的工具（`ask_agent`、`make_*`、`explain_aos`，10-24 遷移後在 `lib/aos`、aos-ai 的錯照 lib 契約退 1 一行）、spawn 出來的 agent 工具出錯回給腦答完（10-24 晚，範本原樣複製、`--tool-errors` 拿掉）；假腦或照規則回的假 server，不叫真模型；14 個。10-30 起 queue 版：預設範本 nia、ask 回信號、`--id` 拿掉、answered／loop_phase、要假 server 的把 nia 的 endpoint/default 換成 openai（`openai_brain`），helper 是 nia 假腦；只剩生成 fsm 格那案用 agent-dan（題目手放 `ws/new/`）。
- `test_compact.py`：agent-hal 的土法 compact（工具呼叫各一句 → 逐段總結＋保留行 → 最後修飾）：沒過門檻不動、三步次數、沒答完那題原樣留、保留行驗收、第 2 步失敗再跑接著做、再壓一次、`SummaryEmpty`（最後與某段）、沒回 JSON 走退路、`HistoryChanged`、沒變小不換；agent-hal 端到端與假腦；假 server 照「第幾步」回；13 個。
- `test_fay.py`：agent-fay（claude／codex CLI 當工具、人可以接進去；10-24 遷移後工具在 `lib/agent`、錯的開頭是工具名、`PromptBad` 改 `ArgumentsBad`），用假的 claude／codex 不花額度：同一段對話續兩題、codex exec 再 resume、錯的代號、`attach -d` 開畫面後改從 tmux 送字、hook 接回答、人 attach 打字再 Ctrl-\\ 跳出（pty 模擬）、hook 不回＝`ReplyMissing`；沒 tmux 就 skip 畫面那幾個；7 個。
- `test_file_tools.py`：資料夾與檔案的八個工具（原 demo/file-tools，10-24 遷移後指 `lib/base`；ls 與分頁、stat、view 的 JSON 一層層與文字大綱、json_edit 經 aos-json、mkdir／move／copy、trash 可救回、路徑出不去、`_tooldef.json` 形狀；錯照 lib 契約是 stdout 同一行）與 agent-pip 逐層看一個 agent 資料夾、改 `loop.json`（假 server）；11 個（路徑出界那個以 `subTest` 逐工具逐參數）。
- `test_grow.py`：`proto8/extras/grow/aos-grow`（函數往上長一級／縮回一級）：乾跑不寫、agent-dan 複本長完跟原本各跑兩題結果一樣（含腦掛掉的路徑）、長上去再縮回來＝原值、搬位置時 `cwd`／`$ref`／`$env AOS_CD` 改指回原處、拒絕的情況；6 個。
- `test_gus.py`：agent-gus（小念頭：規劃 steps → 每步 fork 成同一隻 → 只帶回結論 → 彙整）：假腦、只帶結論、不拆、深度上限、遞迴與額度、`PlanBad`（繞圈、太多步、needs 指錯，以 `subTest` 逐個）、規劃回散文＝當不拆（10-24 真腦實測加）、小念頭失敗與逾時當結論回給母體的腦、needs 失敗的步不起（10-24 晚）、結論截斷、別的程式叫小念頭；真模型一個連不上就 skip；14 個。
- `test_human.py`：`proto8/extras/human` 的 `aos-say`、`aos-listen`、`aos-chat`；10-30 起對 agent-nia 的拷貝（註冊檔改絕對；腦壞＝endpoint 換 openai 指 `dead_brain.DEAD`）：say 寄一封有序的信（body、序號、`--stack`／`AOS_STACK`、`--name` 拿掉）、listen 答案先到不漏／先開再跑／信在 cur/ 時等並說停在 `endpoint/default`、`--status` 看 queue 與 loop phase（含常駐 idle 的 loop 被 ctl paused）、`--last`／跟著印、chat 兩句接 history、agent 失敗再跑接著做、不帶 agent 等別人跑；16 個。
- `test_janet.py`：Janet 編成 aos（`proto8/extras/langs/janet`）：agent-dan 編出來跟手寫的檔一樣、跑起來一樣，loop＋fsm 數數、seq／par／if、seq 遇錯停、編譯錯的代號；沒裝 janet 整個 skip；6 個。
