### `proto8/extras/cli_hub`（aos-hub：常駐 kernel 管所有 claude／codex 實例、代答 say／listen、pause／stop，10-27 起、10-28 重寫）

說明在 [cli_hub/README](../../../../../proto8/extras/cli_hub/README.md)；設計 [thinking 2026-10-28-hub-adapter](../../../../../proto8/thinking/2026-10-28-hub-adapter.md)、[10-28 hub-kernel](../../../../../proto8/thinking/2026-10-28-hub-kernel.md)、[10-27 claude-switch](../../../../../proto8/thinking/2026-10-27-claude-switch.md)。

| 哪裡 | 負責什麼 |
|---|---|
| `bin/aos-hub-kernel` | 常駐 kernel（python3）：`$AOS_HUB/kernel.sock` 一行 JSON 問答（`register`／`add`／`ls`／`open`／`pause`／`stop`／`shutdown`），實例只記在記憶體；serve 迴圈替「代答」實例照 P-11～P-14 收題（信箱＝實例的 stack `<資料夾>/.stack/`，CLI 的 cwd＝資料夾）、叫工具的 `_entry`、寫 `out/`、搬 `done/`、在 stack 的 `trace.jsonl` 接一行（`question`／`error`）、放 `server.txt`；`stop` 把小格搬到 `<stack>/hub_archive/`、拷 CLI 對話（`cli_session.transcripts`）；import cli_session（`open_cell`、`close`），把它的 `die` 換成丟例外 |
| `bin/aos-hub` | 命令列（python3），全部經 kernel：`ls`、`state`、`add`、`open [-d]`（還沒納管先 add；接＝`tmux -S <格>/tty.sock attach`）、`pause [--idle 分]`、`stop`、`watch`（把 `live.jsonl` 新長的行印成人看的） |
| `bin/hub_ipc.py` | 兩支共用：`$AOS_HUB`（沒設＝`HubMissing`）、`ask(請求)`（連不上＝`KernelMissing`） |
| `reap.json` | 自動收起：aos-loop 的 loop.json，每分鐘跑一次 `bin/aos-hub pause --idle 30` |
