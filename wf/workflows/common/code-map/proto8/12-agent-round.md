### agent 自己的格（不是給腦叫的工具）

一輪（round）照順序叫的那幾格：每格一個資料夾程式，叫法 `aos-exec <格> <agent 資料夾絕對路徑> [子命令]`，stdin／stdout 是資料、錯 stderr 一行 `名: 代號 原因` 退 1；格與格之間經 `lib/agent/parts.py` 的 `find(agent, 槽)` 互相找（11-01 起；之前是 `aos-parts which --json`），找到就 `aos-exec <它回的> <agent> …`、env 交給 aos-exec（`.env` 預設不蓋）。沒有 `_tooldef.json`／`_metainfo`（不是工具）。設計與代定：[thinking 2026-10-28 agent-round](../../../../../proto8/thinking/2026-10-28-agent-round.md)（§ 2～§ 5、文末「實作時代定」）；說明在 [lib/README「agent 自己的格」](../../../../../proto8/lib/README.md)。
