## `extras/grow/`（函數長大／縮回）

| 檔 | 負責什麼 |
|---|---|
| `aos-grow` | `up`（內嵌單子 → `NAME.json` → `NAME/`）、`down`、`--dry-run`（11-04 起旗標在 CALLER 前，用 `bin/aos_flags.py`）；改呼叫方的相對路徑讓行為不變，最後才改呼叫方 |

## `extras/langs/janet/`（Janet 寫 aos、編成資料夾）

| 檔 | 負責什麼 |
|---|---|
| `bin/aos-janet` | 命令列：子環境跑原始檔、拿 `program`、交給 emit |
| `aos.janet` | 寫法：JSON 值與檔案節點 |
| `combine.janet` | `aos-seq`、`aos-par`、`aos-if` |
| `emit.janet` | 寫到磁碟（檔案節點長成子資料夾） |
| `json_write.janet` | Janet 值 → 好讀的 JSON |
| `code_write.janet` | Janet 程式碼 → 原始碼字串 |
| `examples/count.janet`、`examples/steps.janet` | loop＋fsm 數數；seq／par／if |

## `extras/langs/lua/`（Lua 寫 aos、編成資料夾）

| 檔 | 負責什麼 |
|---|---|
| `aos.lua` | 建構子（`dir`、`file`、`inst`、`loop`、`fsm`、`daemon`…）、JSON 編碼、攤平成檔案清單 |
| `bin/aos-lua` | 命令列：`build`、`json`、`ls` |
| `examples/clocks.lua` | 全內嵌的 agent-ann；一個 daemon 顧三個時鐘 |

## `extras/sandbox/`（把一個函數關起來跑）

| 檔 | 負責什麼 |
|---|---|
| `bin/aos-sandbox` | 照設定排好 `[s6-softlimit] [s6-setuidgid] bwrap … -- prog` 再 exec 走 |
| `examples/bash-boxed/_entry`、`examples/bash-boxed/sandbox.json` | 庫的 bash 包一層 sandbox |
| `examples/bash-boxed/inner`、`examples/bash-boxed/_tooldef.json` | 捷徑指到 `lib/base/bash` |
| `examples/cli-tool.json` | claude／codex CLI 當工具的設定（連網、寫自己的設定資料夾） |
| `examples/agent.json` | agent 當工具的設定（斷網、`rw` 綁 kernel 信箱） |
| `root/setup.sh` | 要 root 的那半（預設乾跑）：s6、帳號 `aos-run`、sudoers、`--mailbox` |
