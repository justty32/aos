## `bin/`（Python 純標準庫的命令列）

| 檔 | 負責什麼 |
|---|---|
| `aos_flags.py` | 旗標解析 `parse()`（含不帶值的 `switches`、可重複收的 `multi`〔11-04〕）、`Error.code`；這幾支共用，extras 的 aos-mcp、aos-grow、aos-sandbox 也 import 它（形狀照 CONVENTION P-44，11-04） |
| `aos-tick` | 時鐘往前走一格：讀 n 寫 n＋1（先寫 `.名字` 再改名） |
| `aos-tools` | agent 資料夾的工具註冊檔 `tools.json`：`add`／`rm`／`ls`／`get`／`call`（`--no-cache`）；`--overlay O`＝疊覆蓋層 `{"add", "rm"}`（`load_tools`／`read_overlay`，add／rm 只寫 O，11-05） |
| `aos-daemon-ctl` | 把 proc 掛到 aos-daemon 上：`add`（子項一律帶 `def`＝XXX 絕對路徑，11-04）／`rm`／`start`／`stop`（寄信到 `procs_ctl_mailbox`）、`sleep`／`wake`（`procs_slept`／`procs_woken`，11-05）；stop／start／sleep／wake 照表檢查 phase（`phase_cmd`／`need_phase`，用錯＝`PhaseBad`，11-05）、`pause`／`resume`（直接寫子 loop 的 ctl）、`ls`（讀 `procs_state.json`，路徑欄拼回絕對 `resolve`、多一欄 `reason`，11-05）、`where --stack`；沒設 `AOS_DAEMON` 找 cwd 的 `./.stack`（`daemon_dir`，11-05）；`add --def`（11-05）；寄信的六個子命令收 `--reply-to BOX`（`REPLY`／`reply_box`→`send` 交給 aos-post，11-05 edge-agent 題 2）；信箱與小格裡 `loop.json` 的名字照 `procs_state.json` 頂層回報（`names_of`，11-04）；`add` 判型照入口最終指到的 JSON（`find_loop`，11-04） |
| `aos-eca-turn` | 外部 coding agent 的一輪：queue（`aos-post take-all`／`see`／`done`，批次照 `aos_ws.letter_key`：有序先、無序後）→ `cli_session.ask` → history（`--one`、`--on-empty`、`--on-busy`） |
| `aos-eca-screen` | eca 的 screen 子介面身體（`demo/eca-claude/screen/_entry` 叫）：`open [-d]`／`close`／`watch`（11-04 從 aos-eca 搬來；吃 `AOS_STACK`、`AOS_WS`）；watch 遇 loop 不在了就走（定義 `loop.json` 的 state 窗 phase done／stopped 或 pid 不在＝stderr 一行後退 0，11-05） |

## `extras/agent/`（統一的 agent 介面 aos-agent，11-04；取代 11-04 刪掉的 extras/human、extras/eca）

| 檔 | 負責什麼 |
|---|---|
| `bin/aos-agent` | （11-05 edge-agent 題 2：`reply_mailbox`／`reply_in`／`ctl_wait`＝ctl add／rm／start／stop／sleep／wake 每封開暫時回信信箱、經 `aos-daemon-ctl --reply-to` 寄，回信 `applied: false`＝立刻 `AddRejected`／`CtlRejected`，用完刪）（11-05 edge-agent：`kernel_row`／`is_kernel`／`kernel_hint`＝`AOS_KERNEL` 有設時對 kernel 本身直接寄 daemon、kernel 沒在跑就立刻 `WaitFailed`；`off_table`＝listen 等到一半那隻下了表就說怎麼救；chat 每句前重查表）每個子命令只管一隻（`--target`／`$AOS_AGENT`、`--daemon`／`$AOS_DAEMON`）：**`ctl` 下＝掛上與管理**（11-05 `cmd_ctl`／`CTL_CMDS`）：`add`（讀 `interfaces.json` 宣告、等上表；等的時候看 `procs_state.json` 的 `mailbox_warning`，提到這封信＝`AddRejected` 立刻退，11-04 夜）／`rm`、`start`／`stop`／`sleep`／`wake`／`pause`／`resume`（經 aos-daemon-ctl；sleep／wake 11-05）、沒設 `AOS_DAEMON` 找 `./.stack`（11-05）、`add` 認定義宣告的 `entry`（送 `--def`，11-05）、`ls`、`state`／`status`（有覆蓋層多一行 `tools overlay: N added, M removed`，`overlay_count`，11-05 feat-proto）、`where`（預設印 stack、`--ws` 印工作區）、`who`（`cmd_who`：`--stack S`／`$AOS_STACK` 落在表上哪一列的 stack 裡＝印名字、`--json`；給 lib/agent/self_tools 認自己，11-05 feat-proto）；**頂層**：`say`／`listen`／`chat`（`aos_ws`）、`open`／`close`／`watch`（表的 `def` 欄＝定義→`screen` 入口）、`tools`（這隻的覆蓋層 `<stack>/tools.json`，經 `aos-tools --overlay`；11-05 起只存差異、`make_copy` 刪了）、`llm`（讀定義 `llm.json` 疊 stack 那份改過的鍵；`set`＝`aos-json set --str`、`reset` 刪；11-04 晚） |
| `using-aos-agent.sh` | 給人的殼 source：帶名字＝`export AOS_AGENT`；`AOS_DAEMON` 沒設＝export `$PWD/.stack`（11-05）；定義 `say`／`listen`／`chat`／`status` 四個函數 |
| `stack.gitignore`、`stack.gitattributes` | 搬家範本（11-05，不是程式）：image（`ws/.stack/`）進 git 時擋哪些（`**/tmp/`、`**/.*`、`**/stderr.txt`、`**/*.sock`、`**/lock`）、`* -text` 不轉換行；用法在 `docs/04-搬家.md` |
