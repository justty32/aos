## `bin/`（Python 純標準庫的命令列）

| 檔 | 負責什麼 |
|---|---|
| `aos_flags.py` | 旗標解析 `parse()`（含不帶值的 `switches`、可重複收的 `multi`〔11-04〕）、`Error.code`；這幾支共用，extras 的 aos-mcp、aos-grow、aos-sandbox 也 import 它（形狀照 CONVENTION P-44，11-04） |
| `aos-tick` | 時鐘往前走一格：讀 n 寫 n＋1（先寫 `.名字` 再改名） |
| `aos-tools` | agent 資料夾的工具註冊檔 `tools.json`：`add`／`rm`／`ls`／`get`／`call`（`--no-cache`） |
| `aos-daemon-ctl` | 把 proc 掛到 aos-daemon 上：`add`（子項一律帶 `def`＝XXX 絕對路徑，11-04）／`rm`／`start`／`stop`（寄信到 `procs_ctl_mailbox`）、`pause`／`resume`（直接寫子 loop 的 ctl）、`ls`（讀 `procs_state.json`）、`where --stack` |
| `aos-eca-turn` | 外部 coding agent 的一輪：queue（`aos-post take-all`／`see`／`done`，批次照 `aos_ws.letter_key`：有序先、無序後）→ `cli_session.ask` → history（`--one`、`--on-empty`、`--on-busy`） |
| `aos-llm` | 看／改 agent 定義裡的腦（11-04）：讀 `interfaces.json` 的 `aos-agent.llm`→`aos-exec --stack <暫存> <定義>/<llm> def show／set` |
| `aos-eca-screen` | eca 的 screen 子介面身體（`demo/eca-claude/screen/_entry` 叫）：`open [-d]`／`close`／`watch`（11-04 從 aos-eca 搬來；吃 `AOS_STACK`、`AOS_WS`） |
| `aos-eca-llm` | eca 的 llm 子介面身體（`demo/eca-claude/llm/_entry` 叫）：`def`＝cli.json 的 `--model`、`stack`＝`$AOS_STACK/llm.json`；`show`／`set`／`reset` |

## `extras/agent/`（統一的 agent 介面 aos-agent，11-04；取代 11-04 刪掉的 extras/human、extras/eca）

| 檔 | 負責什麼 |
|---|---|
| `bin/aos-agent` | 每個子命令只管一隻（`--target`／`$AOS_AGENT`、`--daemon`／`$AOS_DAEMON`）：`add`（讀 `interfaces.json` 宣告、等上表）／`rm`、`start`／`stop`／`pause`／`resume`（經 aos-daemon-ctl）、`ls`、`state`／`status`、`where`、`say`／`listen`／`chat`（`aos_ws`）、`open`／`close`／`watch`（表的 `def` 欄＝定義→`screen` 入口）、`tools`（stack 裡的副本 `tools.json`，經 aos-tools）、`llm`（`llm` 入口的 `stack` 對象） |
| `using-aos-agent.sh` | 給人的殼 source：帶名字＝`export AOS_AGENT`；定義 `say`／`listen`／`chat`／`status` 四個函數 |

## `extras/grow/`（函數長大／縮回）

| 檔 | 負責什麼 |
|---|---|

## `extras/langs/janet/`（Janet 寫 aos、編成資料夾）

| 檔 | 負責什麼 |
|---|---|
| `bin/aos-janet` | 命令列：子環境跑原始檔、拿 `program`、交給 emit |
| `aos.janet` | 寫法：JSON 值與檔案節點 |
| `combine.janet` | `aos-seq`、`aos-par`、`aos-if` |
| `emit.janet` | 寫到磁碟（檔案節點長成子資料夾） |
| `json_write.janet` | Janet 值 → 好讀的 JSON |
| `code_write.janet` | Janet 程式碼 → 原始碼字串 |
| `examples/count.janet`、`examples/steps.janet` | loop＋fsm 數數；seq／par／if |

## `extras/langs/lua/`（Lua 寫 aos、編成資料夾）

| 檔 | 負責什麼 |
|---|---|
| `aos.lua` | 建構子（`dir`、`file`、`inst`、`loop`、`fsm`、`daemon`…）、JSON 編碼、攤平成檔案清單 |
| `bin/aos-lua` | 命令列：`build`、`json`、`ls` |

## `extras/sandbox/`（把一個函數關起來跑）

| 檔 | 負責什麼 |
|---|---|
| `bin/aos-sandbox` | 照設定排好 `[s6-softlimit] [s6-setuidgid] bwrap … -- prog` 再 exec 走 |
| `examples/bash-boxed/_entry`、`examples/bash-boxed/sandbox.json` | 庫的 bash 包一層 sandbox |
| `examples/bash-boxed/inner`、`examples/bash-boxed/_tooldef.json` | 捷徑指到 `lib/base/bash` |
| `examples/cli-tool.json` | claude／codex CLI 當工具的設定（連網、寫自己的設定資料夾） |
| `examples/agent.json` | agent 當工具的設定（斷網、`rw` 綁 kernel 信箱） |
| `root/setup.sh` | 要 root 的那半（預設乾跑）：s6、帳號 `aos-run`、sudoers、`--mailbox` |
