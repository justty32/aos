## `bin/`（Python 純標準庫的命令列）

| 檔 | 負責什麼 |
|---|---|
| `aos_flags.py` | 旗標解析 `parse()`（含不帶值的 `switches`）、`Error.code`；這幾支共用 |
| `aos-tick` | 時鐘往前走一格：讀 n 寫 n＋1（先寫 `.名字` 再改名） |
| `aos-tools` | agent 資料夾的工具註冊檔 `tools.json`：`add`／`rm`／`ls`／`get`／`call`（`--no-cache`） |
| `aos-daemon-ctl` | 把 proc 掛到 aos-daemon 上：`add`／`rm`／`start`／`stop`（寄信到 `procs_ctl_mailbox`）、`pause`／`resume`（直接寫子 loop 的 ctl）、`ls`（讀 `procs_state.json`）、`where --stack` |
| `aos-eca-turn` | 外部 coding agent 的一輪：queue → `cli_session.ask` → history（`--one`、`--on-empty`、`--on-busy`） |

## `extras/human/`（人對 agent 說話、看回答）

| 檔 | 負責什麼 |
|---|---|
| `bin/aos-say` | 一句話＝一則 user message，`aos-post send --ordered <stack>/queue`，印信號 |
| `bin/aos-listen` | 等最新那封的回答（`history.jsonl` 最新的 assistant）、`--timeout`、`--status` |
| `bin/aos_human.py` | 兩支共用：`Where`（`--stack` ＞ `$AOS_STACK` ＞ `<ws>/.stack/`）、讀 `/proc` 看誰在跑 |

## `extras/ai_tools/`（aos-mcp；aos-ai 與 Claude skill 11-03 刪了）

| 檔 | 負責什麼 |
|---|---|
| `bin/aos-mcp` | MCP server（stdio JSON-RPC）：把登記檔裡的工具經 aos-tools 給 MCP client |

## `extras/eca/`（把外部 coding agent 掛到 aos-daemon 底下）

| 檔 | 負責什麼 |
|---|---|
| `bin/aos-eca` | 沒有狀態、每個子命令只管一隻：建立／刪除、掛上／拿下 daemon（經 aos-daemon-ctl）、`open`／`close` 畫面、`start`／`stop`、`ls`、`state`、`watch` |

## `extras/grow/`（函數長大／縮回）

| 檔 | 負責什麼 |
|---|---|
| `aos-grow` | `up`（內嵌單子 → `NAME.json` → `NAME/`）、`down`、`--dry-run`；改呼叫方的相對路徑讓行為不變，最後才改呼叫方 |

## `extras/langs/janet/`（Janet 寫 aos、編成資料夾）

| 檔 | 負責什麼 |
|---|---|
| `bin/aos-janet` | 命令列：子環境跑原始檔、拿 `program`、交給 emit |
| `aos.janet` | 寫法：JSON 值與檔案節點 |
| `combine.janet` | `aos-seq`、`aos-par`、`aos-if` |
| `emit.janet` | 寫到磁碟（檔案節點長成子資料夾） |
| `json_write.janet` | Janet 值 → 好讀的 JSON |
| `code_write.janet` | Janet 程式碼 → 原始碼字串 |
| `examples/count.janet`、`examples/steps.janet` | loop＋fsm 數數；seq／par／if |

## `extras/langs/lua/`（Lua 寫 aos、編成資料夾）

| 檔 | 負責什麼 |
|---|---|
| `aos.lua` | 建構子（`dir`、`file`、`inst`、`loop`、`fsm`、`daemon`…）、JSON 編碼、攤平成檔案清單 |
| `bin/aos-lua` | 命令列：`build`、`json`、`ls` |
| `examples/agent_ann.lua`、`examples/clocks.lua` | 全內嵌的 agent-ann；一個 daemon 顧三個時鐘 |

## `extras/sandbox/`（把一個函數關起來跑）

| 檔 | 負責什麼 |
|---|---|
| `bin/aos-sandbox` | 照設定排好 `[s6-softlimit] [s6-setuidgid] bwrap … -- prog` 再 exec 走 |
| `examples/bash-boxed/_entry`、`examples/bash-boxed/sandbox.json` | 庫的 bash 包一層 sandbox |
| `examples/bash-boxed/inner`、`examples/bash-boxed/_tooldef.json` | 捷徑指到 `lib/base/bash` |
| `examples/cli-tool.json` | claude／codex CLI 當工具的設定（連網、寫自己的設定資料夾） |
| `examples/agent.json` | agent 當工具的設定（斷網、`rw` 綁 kernel 信箱） |
| `root/setup.sh` | 要 root 的那半（預設乾跑）：s6、帳號 `aos-run`、sudoers、`--mailbox` |
