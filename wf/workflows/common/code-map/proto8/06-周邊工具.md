## `bin/`（Python 純標準庫的命令列）

| 檔 | 負責什麼 |
|---|---|
| `aos_flags.py` | 旗標解析 `parse()`（含不帶值的 `switches`、可重複收的 `multi`〔11-04〕；`HELP` 設了就認 `--help`＝印 stdout 退 0〔11-05 stdio-unify〕）、`Error.code`；三扇門共用小函式（11-05 stdio-unify）：`die`（錯誤行 `程式: error: 代號 原因`、退 1）、`warn`（提醒行 `程式: warning: 句子`）、`error_line`／`split_line`（組／拆錯誤行）、`run`（Ctrl-C 退 130 不吐 traceback）；這幾支共用，extras 的 aos-agent、aos-mcp、aos-grow、aos-sandbox 也 import 它（形狀照 CONVENTION P-44，11-04） |
| `aos-tick` | 時鐘往前走一格：讀 n 寫 n＋1（先寫 `.名字` 再改名） |
| `aos-tools` | agent 資料夾的工具註冊檔 `tools.json`：`add`／`rm`／`ls`／`get`／`call`（`--no-cache`）；`--overlay O`＝疊覆蓋層 `{"add", "rm"}`（`load_tools`／`read_overlay`，add／rm 只寫 O，11-05）；登記格選填 `env`（`entries` 驗、`cmd_call` 合進環境、`add --env K=V`，11-05 晚 agent-knowledge R1） |
| `aos-daemon-ctl` | 把 proc 掛到 aos-daemon 上：`add`（子項一律帶 `def`＝XXX 絕對路徑，11-04）／`rm`／`start`／`stop`（寄信到 `procs_ctl_mailbox`）、`sleep`／`wake`（`procs_slept`／`procs_woken`，11-05）；stop／start／sleep／wake 照表檢查 phase（`phase_cmd`／`need_phase`，用錯＝`PhaseBad`，11-05）、`pause`／`resume`（直接寫子 loop 的 ctl；`wait_applied`＝等它 state.json 的 `ctl_seq` 追上才回、最多 5 秒、等不到提醒，11-05 晚 listen paused bug）、`ls`（讀 `procs_state.json`，路徑欄拼回絕對 `resolve`、多一欄 `reason`，11-05）、`where --stack`；沒設 `AOS_DAEMON` 找 cwd 的 `./.stack`（`daemon_dir`，11-05）；`add --def`（11-05）；`add --limits JSON`（11-05 feat-proto 件 5：`limits_arg` 驗、寫進子項物件的 `limits`；`ls --json` 帶列上的 `limits`）；寄信的六個子命令收 `--reply-to BOX`（`REPLY`／`reply_box`→`send` 交給 aos-post，11-05 edge-agent 題 2）；信箱與小格裡 `loop.json` 的名字照 `procs_state.json` 頂層回報（`names_of`，11-04）；`add` 判型照入口最終指到的 JSON（`find_loop`，11-04） |
| `aos-eca-turn` | 外部 coding agent 的一輪：queue（`aos-post take-all`／`see`／`done`，批次照 `aos_ws.letter_key`：有序先、無序後）→ `cli_session.ask` → history（`--one`、`--on-empty`、`--on-busy`） |
| `aos-eca-screen` | eca 的 screen 子介面身體（`demo/eca-claude/screen/_entry` 叫）：`--eca ECA_DIR open [--detach]`／`close`／`watch`（11-05 stdio-unify R6 改成 P-44 形、`aos_flags.parse`；D6 把 ECA_DIR 改成子命令前的旗標，因 aos-exec 把動作接在入口 argv 最後；11-04 從 aos-eca 搬來；吃 `AOS_STACK`、`AOS_WS`）；watch 遇 loop 不在了就走（定義 `loop.json` 的 state 窗 phase done／stopped 或 pid 不在＝stderr 一行提醒後退 0，11-05） |
