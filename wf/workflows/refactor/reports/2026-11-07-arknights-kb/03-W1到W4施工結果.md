## 偏離與自決

現行 aos-lock 已無 `--lease-ms`。使用現行 `--lease-ticks ceil(10000 / tick_interval_ms)`，預設 10 ticks；有 AOS_TICK 時沿現行 tick，到期時間會受時鐘暫停影響；沒時鐘退牆鐘，向上取整使租約至少 10 秒。沒有新增鎖 op 或另造鎖協議。

合法 JSON 無法同時以 Markdown `# ` 起頭，因此 `.json` 葉 edit 只驗合法 JSON，Markdown 葉才驗標題。8000 bytes 上限含補上的結尾換行，避免寫入後超過 read 的預設上限；不強制摘要。

鎖 subprocess 有 5 秒保險上限；登記取得狀態與 release 期間暫擋 TERM／INT，確保收到終止仍能放鎖。release 的非 0／啟動失敗／逾時都只 warning。葉升級另保留原葉權限到 README；捷徑葉升級鎖的是會被 unlink 的目錄項所在父層。

共用模組名稱沿既有同層模組慣例；寫入操作拆 `locking.py`／`writing.py`，沒有把第三份找根／定址複製進新工具。根捷徑防繞過屬落實已定根唯讀規則。
