## 逐條發現（續）

### 4. Python 有兩份一模一樣的讀時鐘程式
- **類別**：設計｜**嚴重度**：品質（冗餘）
- **檔:行**：`proto8/lib/tool_io.py:35-110` 與 `proto8/py/aos_ws.py:26-93`
- **commit／哪隊**：`b190e00c0`（T1，T 隊，codex sol）；「各一份」是 tick-time 03 § 二的設計（fable）
- **問題**：
  - `_tick_decimal`、`now_tick`、`tick_interval_ms`、`deadline_after`、`expired` 兩份逐行相同，實測行為也相同。
  - 分層規則允許 `py` import `lib`，而且 `py/aos_flags.py:57` 已經這樣做了（`warn_missing_tick = tool_io.warn_missing_tick`）。所以第二份沒有分層上的理由。
  - 以後改規則（例如第 1 條的空白處理）要改兩處，漏一處就會出現行為分岔。
- **使用者原話**：「……都會盡量把這種常見的功能，統一成單一介面，這樣只需要改介面，那就能好。」（11-05，引在 `wf/workflows/common/conventions.md:28`）
- **建議**：可以直接修。讓 `aos_ws` 的這五個函式改成轉用 `tool_io` 的，只留 `Error` 型別的轉換。

### 5. 每次起 tick: true 的 daemon 都會印一行 missing-file warning
- **類別**：程式現況｜**嚴重度**：品質
- **檔:行**：`proto8/impls/aos-util/src/tick.cpp:26-34`；`proto8/impls/aos-daemon/src/daemon/daemon.cpp:70`
- **commit／哪隊**：`3bada8a0a`（warning，R 隊，codex sol）＋`d6c38be32`（T7）
- **問題**：
  - 實測：根 daemon 每次起，log 第一行就是 `AOS_TICK points to a missing file; treating the clock as 0`，原因是 `_tick` 第一格還沒寫。
  - 使用者要的 warning 是「設了但指錯」時讓人看見，現在「剛起」和「指錯」長得一樣。看久了，真正指錯時也會被當成雜訊略過。
  - tick-time 04 邊緣 7、05 邊緣 1 都已經記了，試驗場 README 也寫了「正常」，但程式沒改。
- **使用者原話**：env-portability Q5 選「印 warning (Recommended)」，題目是「`AOS_KERNEL`／`AOS_TICK` 設了但指不到時」（`proto8/thinking/2026-11/06/env-portability/README.md:32`）。
- **建議**：daemon 展開 `tick` 時，檔不在就先寫一個 `0`（推薦，跟第 1 條一起修）。這樣只有真的指錯才會印。

### 6. 兩個沒人用、或容易誤會的小地方
- **類別**：程式現況／條文｜**嚴重度**：品質
- **檔:行**：`proto8/py/daemon_ctl/post.py:136-161`；`proto8/cmd/aos-agent/docs/04-搬家/01-六段食譜.md:63`
- **commit／哪隊**：`a858fe1a0`（T6，sol）；`57e55e650`（P8，P 隊，commit 訊息寫 codex 跑過）
- **問題**：
  - `daemon_ctl.ask()`／`ping()` 加了 `timeout_ticks`，但整個 repo 沒有任何呼叫者傳它（grep `cmd`、`py`、`lib` 都沒有）。tick-time 05 說是「讓內部呼叫者可以給 tick」，目前是寫了沒人用的參數。
  - 搬家食譜第 63 行寫「在樹根開 tick、子項繼承，需獨立時間的子樹才自帶」。可是範本 `kernel/llm-kernel`、`kernel/daemon-judge` 預設就帶 `tick: true`，使用者也裁了試驗場三個鐘「留著」。照食譜做，以為只有一個鐘，其實總機、判官各有各的。要凍住整棵樹得讓根 sleep，暫停根的 `_tick` 不夠（tick-time 05 頂層註）。HANDOFF 11-06 夜第 3 點②已列這條。
- **使用者原話**：三個時鐘「領班的鐘＝留著、總機的鐘＝留著」（`proto8/thinking/2026-11/05/tick-time/05-T5T6T8與試驗場.md:39`）。`daemon_ctl` 那條沒找到原話，是 KISS 推論。
- **建議**：食譜那句改成「範本已各帶一個鐘；要凍住整棵樹就讓根 sleep」（可以直接修）。`timeout_ticks` 參數先留著或拿掉都行，請使用者決定，影響很小。
