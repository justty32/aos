# hackathon — 收場四棒的任務書（書記／評委／資料員／祕書）

← [hackathon README](../README.md)｜**發給參賽者的在 [briefs.md](../briefs.md)**

> **本資料夾＝一個角色一份任務書。** 四份都是**整段複製去發**用的，各自獨立成立。
> 共同的順序與規則寫在本檔，個別的模板在下表那四個檔。

**每一輪**參賽者交件之後，這四棒**依序**跑（都寫同一個紀錄檔，**不能平行**）：

```
書記（發生了什麼）→ 評委（打分＋意見）→ 資料員（下一輪的資料包）→ 祕書（白話導讀）
```

**這四位都不帶 persona。** 他們是寫給使用者看的，帶了風格就變成模仿秀，反而更難讀。

## 四份任務書（一個角色一份，依序）

| 檔案 | 裡面有什麼 | 什麼時候看 |
|---|---|---|
| [scribe.md](scribe.md) | **書記**的任務書模板：檔頭表格、每輪固定五段、只准寫一個檔 | 每輪第 ② 棒，參賽者交件之後 |
| [judge.md](judge.md) | **評委**的任務書模板：persona 四行、評分表、這一節要有的六點 | 每輪第 ③ 棒，書記之後 |
| [researcher.md](researcher.md) | **資料員**的任務書模板：下一輪資料包的固定四塊 | 每輪第 ④ 棒，評委之後 |
| [secretary.md](secretary.md) | **祕書**的任務書模板：白話導讀的固定四塊 | 每輪第 ⑤ 棒，收場最後一棒 |
