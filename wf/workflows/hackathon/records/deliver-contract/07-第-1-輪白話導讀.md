## 第 1 輪白話導讀

以第 2 輪導讀為準，見 [15](15-第-2-輪白話導讀.md)。第 2 輪導讀沒解釋的錯誤：

- `ENOTDIR`：要當資料夾走的路徑其實是普通檔案，無法在裡面建投遞檔。
- `USAGE`：命令參數寫法不符草案，是呼叫方式錯，不是內容或目標壞掉。
- `fatal: not a git repository`：比賽場地沒有可用的 Git 紀錄，不能用 `git status` 查改了什麼；不是程式壞掉。
