# core scope 黑客松 — 白話導讀（祕書）

← [本場索引](../README.md)｜[hackathon](../../../README.md)

**使用者從這裡開始讀。** 每輪祕書把發生的事翻成白話，錯誤訊息一條一句翻譯，最後一塊講「所以呢」。

| 檔案 | 裡面有什麼 | 什麼時候會想看 |
|---|---|---|
| [第 1 輪白話導讀](round-1.md) | 這一輪到底發生了什麼、冒出來的新詞、錯誤訊息各是什麼意思、所以呢。 | 第一次讀這場，從這裡開始。 |
| [第 2 輪白話導讀](round-2.md) | 多一塊「跟上一輪比，變了什麼」，其餘同上。 | 只想知道第 2 輪跟第 1 輪差在哪。 |
| [第 3 輪白話導讀](round-3.md) | 同第 2 輪的五塊結構。 | 只想知道三輪跑完的結論怎麼影響 OPEN-QUESTIONS 第 2 題。 |

> 原本是單檔 `plain.md`，照 [DEV-GUIDE](../../../../../STRUCTURE.md) 的「膨脹即拆」按輪次拆成本資料夾。
