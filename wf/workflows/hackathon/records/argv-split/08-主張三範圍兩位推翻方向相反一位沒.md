#### 主張三（範圍）：兩位推翻、方向相反；一位沒打穿但改了問題的形狀；一位同意方向但推翻理由

**p4：投遞本來就不在 `aos exec` 裡。**

```
$ grep -rn 'deliver' core/inst/src/run*.cpp app/src/main.cpp
exit=1  <- nothing
```

「把 deliver 外放」不是在拆 `aos exec`，是替一件本來就在世界外面、沒實作過的事寫一支程式。他的三版比較：

| | 外放幾支 | 空回合 | 退出碼 3 | 規格 §4 相對路徑 | 世界裡有幾個 `.aos` |
|---|---|---|---|---|---|
| 今天／甲 | 0（投遞不在回合裡） | 2.2 µs | 保住 | 對 | 1 |
| **丙** | **1（彙整）** | 2.2 µs（有閘門） | **保住，連診斷訊息一字不差** | 對 | 1 |
| 乙 | 4 | 802 µs | **丟了（回 10）** | **壞了（`exit` 檔跑進 `.cpu/`）** | **2** |

「**如果一定要外放大於零支，答案是恰好一支，而且是彙整，不是投遞。**」理由是只有彙整有政策旋鈕（排序、配額、優先權、按 mtime、按時段）；取件是一次 `rename`、釋放是一次 `unlink`，外放它們買到零。

**p1：量到一個真的重複執行 race，出在 aggregate。**同一 world 放 N 個推進者，批次只追加一行 log：

```
=== 甲：16 個並行的真 aos exec，30 次試驗 ===
  30 次試驗，異常 23 次（最糟一批被跑 3 次）
=== 乙：16 個並行的外部 aos-claim，30 次試驗 ===
  30 次試驗，異常 0 次
併發度掃描（每格 30 次）：N=2 0/30   N=4 0/30   N=8 2/30   N=16 14/30
=== 對照：甲 但事先彙整好，16 個 aos exec 只搶 claim ===  異常 0 / 30
```

機制與裁決見〈p1 那個「16 並行、30 次有 23 次重複執行、race 在 aggregate」〉：資料支持「修 aggregate」，不支持他寫的「優先外放 aggregate」。

**p2：同意 deliver 該外放，推翻研討會的理由。**

- 乙做得到甲做不到：換彙整政策（差異就是一行 `head -n 2`）；用非 C/C++ 寫第二顆 CPU；原子的併發保護。
- 乙壞掉而甲沒壞：規格第四節路徑基準垮掉；驗證邊界跟著搬走（整批靜靜蒸發）；每閒置回合 7.4 次 fork（除非加守門）。
- 「claim 與 release 就是回合邊界本身，所以不能出去」被他的 mode c 推翻：出去的是**機制**（誰去 rename、誰去 unlink），留下來的是**租約**（誰在那段時間裡活著）。真正不能出去的是握著 fd、等子行程的那個行程。
- **使用者原話的字面版在邏輯上不可能**：要跑「取件」這一筆指令，得先取件。〈壞 2〉同時被實測：

  ```
  $ cat $W/.aos/inst.json
  [{"argv":[".../aos-claim",".../sc-selfclaim"],"exit":"claim.exit"}]
  $ aos exec $W
  aos-claim: refusing: .../sc-selfclaim/.aos/inst.json.runi already exists
    回合退出碼 = 0
    那一筆 aos-claim 自己的退出碼（寫在 exit 檔裡）= 3
  ```

**p3：「外放」有兩種形狀，研討會只討論了一種。**（a）機制是 driver 用 argv 叫的程式；（b）機制是批次裡的一筆 instruction。〈壞 2〉（退出碼 3 退化、`--loop` 不停）與〈壞 4〉（argv 字串變磁碟格式）只在（b）成立；（a）下退出碼 3 保留：

```
$ timeout 5 ../kit/p3-exec --loop 20 wL3
p3-exec: refusing: .aos/inst.json.runi already exists
p3-exec --loop rc=3  （3 = 停了）
$ timeout 5 ../build/bin/aos exec --loop 20 wL3
aos exec --loop rc=3
```

「**使用者原話問的『全部都用 argv 去執行』有這兩種讀法，而研討會沒有分開，六個壞裡至少有兩個是（b）專屬的。**」（裁決：（a）下保留 3 是 driver 的設計決定，〈壞 2〉變形成「沒人管的退出碼約定」。）
