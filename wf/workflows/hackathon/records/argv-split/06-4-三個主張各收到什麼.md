### 4. 三個主張各收到什麼

#### 主張一（成本）：四位都量了，四位都推翻了那個數字；驗收條件四位都做到了

**「一次 fork＋execve 約 1–3ms」四位都推翻：它不是常數，由被叫的那支程式怎麼啟動決定。**

| 被 exec 的那支 | p1（`spawn_bench.c`，`taskset -c 2`，n=2000） | p2（`forkexec.c`） | p3（`bench_fork.py` 線性回歸） | p4（`bench.c`，n=2000） |
|---|---|---|---|---|
| 純 `fork`＋`_exit` | p50 **27.1 µs** | p50 **35.7 µs** | — | — |
| 靜態小 C | p50 **71.9 µs** | p50 **84.0 µs** | — | — |
| 動態小 C／`/bin/true` | p50 **128.4 / 130.4 µs** | p50 **142.8 / 149.4 µs**（vfork 115.1） | 斜率 **0.222 ms/筆** | p50 **151.5 µs** |
| `/bin/sh -c :` | p50 **432.0 µs** | p50 **449.1 µs** | 單支底價 **0.437 ms** | p50 **447.2 µs** |
| `aos`（busybox 式） | p50 **769.0 µs** | p50 **789.2 µs** | 斜率 **0.861 ms/筆** | p50 **778.8 µs** |
| python3 腳本 | p50 **5487 µs** | p50 **5720.8 µs** | 單支底價 **5.669 ms** | — |

跨度 68 倍，90% 由 callee 決定、跟 fork 幾乎無關。成本論證改用「一次外放 = 130 µs（binary）／430 µs（shell）／790 µs（`aos`）／5.5 ms（python）」。

**空回合今天只要微秒級。**採用 **6–9 µs**（`--loop` 內部的邊際成本）：

| 量法 | 數字 |
|---|---|
| p1：`rchar` 當回合計數器，60 秒、56667 回合，±0.18 µs | CPU **8.6 µs**；wall 減實測 nanosleep → **6.4 µs** |
| p3：ctypes 掛 inotify 精確數回合（`--loop 1`，3776 回合） | CPU **7.9 µs/回合**（單點，可能 ±50%） |
| p2：`aos exec 空世界` 減 `aos 無參數` | 27.2 µs——含行程進入成本，量的是另一件事，不採用 |
| p4：`round.c` 逐系統呼叫複本 | 2.2 µs——複本，與自己的交叉驗證 8.5 µs 差四倍未調和，不採用 |

**外放之後：**

| 誰 | 情境 | 數字 |
|---|---|---|
| p1 | `split_driver` 五模式 | inproc 2.30 µs／deliveronly 2.28 µs／guarded 2.21 µs／mtimeguard **1.11 µs**，皆 0 fork；full(C) **158.55 µs / 1.00 fork**；full(sh) **490.63 µs**；full(py) **10641 µs** |
| p2 | `--loop 10`，兩點消去 | 甲 **22.9 µs/回合**；乙天真版 **2852.1 µs/回合**；乙＋守門 **43.6 µs/回合** |
| p3 | 單支底價相加 | 外放 1 支 +0.861 ms；外放 3 支 +2.58 ms |
| p4 | 外放彙整一支 | **154 / 450 / 802 µs**（`/bin/true` / `sh` / `aos`）；倍率以 2.2 µs 為分母，不能用 |

**驗收條件「零工作的回合必須是零 fork」做得到。**最硬的兩組證據：

- p2 `/proc/stat` 的 `processes`，基準線與案例交錯量：

  ```
  基準（什麼都不跑）        32        甲 aos exec --loop 10        32     -> 每閒置回合 0 次 fork
  基準（什麼都不跑）        53        乙 split-loop 10（無守門）   5955   -> 每閒置回合 7.4 次 fork
  基準（什麼都不跑）        77        乙+守門 split-loop --gate    37     -> 落在噪音裡，0 次 fork
  基準（什麼都不跑）        34
  ```
- p3 兩把儀器：gdb `catch fork`（0／1／3 筆 instruction → 0／1／3 次命中）；`ns_last_pid` 位移每回合 `/bin/true` 0.00、`aos exec` 0.00、`p3-exec` 2.06、`p3-exec --idle-fast` 0.01。

這條驗收條件是外放的必做項。成本不是外放的固有代價，是「每回合無條件 fork」的代價。

**閘門要 stat `.runi`，否則退出碼 3 消失。**（p4）照資深工程師原話只 stat `inst.json` 與 `inst.tempd`：

```
$ AOS_GATE=1 ./bin/aos-round4 L     # 閘門只 stat inst.json 與 inst.tempd
  乙 WITH gate   EXIT=10   <-- 3 沒了
$ AOS_GATE=0 ./bin/aos-round4 L
aos-claim: refusing: L/.aos/inst.json.runi already exists
  乙 WITHOUT gate EXIT=3
```

**`--loop` 的週期決定成本有沒有關係。**（p4）`--loop 0` 會被夾成 1，下限 1 ms。`--loop 1` 時多 802 µs 讓週期從 1.0 ms 變 1.8 ms、吃掉近半顆核心；`--loop 100` 時是 0.8% 的雜訊。研討會把一個週期參數的問題講成了架構問題。
