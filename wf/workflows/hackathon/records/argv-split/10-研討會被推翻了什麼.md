## 研討會被推翻了什麼

逐條對照實測；裁決在 [〈研討會被推翻了什麼〉逐條裁決](16-研討會被推翻了什麼逐條裁決.md)、[六個壞](17-六個壞.md)。

### 三個好

| 研討會原本怎麼說 | 這輪實測到什麼 |
|---|---|
| **好 1**：投遞外放是唯一無爭議的淨賺 | 四位都做出來跑通（最短 p4 的 5 行 shell）。但投遞根本不在 `aos exec` 裡（p4 `grep` → `exit=1`），外放它 `aos exec` 一行不動 |
| **好 2**：介面變 argv 之後 shell 或 Python 一樣拿得到同一套協定 | 可行，四位都證實。價碼：`python3 -c pass` 5.669 ms／支＝`aos` 子命令的 6.5 倍、`/bin/sh` 的 13 倍；python 版 10641 µs/回合，回合率 94/s 對 `--loop 1` 要求的 944/s。今天 argv 那層不存在，`aos` 只有 `exec`/`init`/`tooljson`/`llms` 四個子命令 |
| **好 3**：彙整政策從編譯期寫死變成換一支程式 | 玩具形態三位驗到（配額版跟原版差一行 `head -n 2`；12 行 `sh`＋`jq` 逆序＋每回合最多 2 份；p4 的丙）。跟「零 fork 閒置閘門」衝突（p4） |

### 六個壞

| 研討會原本怎麼說 | 這輪實測到什麼 |
|---|---|
| **壞 1**：`.runi` 的崩潰不變式會降級成約定；三種死法在磁碟上一模一樣 | （a）一模一樣：四位證實；（b）唯一理由是同一個行程：三位推翻，今天就分不出來；（c）外放就分不出來：三位做出反例。p4 分歧（見主張二） |
| **壞 2**：退出碼 3 退化成「批次裡某一筆 exit=3」，`--loop` 失去停止條件 | 形狀（b）證實（`aos-claim` 那筆回 3、回合回 0）；形狀（a）退出碼 3 保留。新路徑：閘門只 stat `inst.json`、`inst.tempd` 會把 3 變成 10 |
| **壞 3**：契約從編譯期型別搬到執行期退出碼與檔名 | 下限更低：不驗 schema 的外部彙整器讓整批無聲蒸發，連 `.bad` 都沒有 |
| **壞 4**：`aos aggregate` 這種字串變成 `.aos` 磁碟格式的一部分 | 沒人測；只在形狀（b）成立 |
| **壞 5**：最常走的路徑變最貴；閒置回合外放後至少多一次 fork＋execve | 方向證實，倍率 15×–600× 取決於叫誰；「至少多一次 fork」被推翻，零 fork 做得到；有沒有關係由 `--loop` 週期決定 |
| **壞 6**：可呼叫的東西就會被呼叫，然後人把自己弄壞 | 沒人碰 |
