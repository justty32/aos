# 轉交提案（**未拍板，主持人不自己改規格**）

← [核心行程、子行程，與外部處理器的契約](README.md)

`kernel.json` 已拍板要收（[decisions.md](decisions.md)）。**待定的是它的形狀**：

1. **「世界本身沒有抽象」**（`.aos` 標準第十二節）——`World`（root fd ＋版本＋能力）是現成答案，
   root fd 順帶解掉 `chdir` 擋住多核那條。
2. **`.aos/kernel.json` 進 `.aos` 標準第三節版面的樣子**，以及第五節「一回合＝一整批」要不要
   改寫成「一回合＝序言＋批次＋尾聲」。若採 kernel **分層合成**（root 強制段＋父政策＋本地 hooks），
   第三節不只是加一個檔。
3. **拓樸選 A（完整巢狀）、B（集中 lane），還是「同一磁碟 ABI、兩種執行拓樸」。**
   可以先不選，但**磁碟 ABI 要先固定**——這是第三條成立的前提。
4. **親緣綁路徑還是 UUID。** 它決定 `procs/`／`lanes/` 版面的第一層。
