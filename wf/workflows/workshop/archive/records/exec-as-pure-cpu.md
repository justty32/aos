# exec 只當一顆純 CPU——把彙整／取件／釋放／投遞全變成 argv 程式

| 欄位 | 內容 |
| --- | --- |
| 主題 | 假如 `aos exec` 只做「取指令、執行指令」，彙整（aggregate）／取件（claim）／釋放（release）／投遞（deliver）全部改成用 argv 執行的普通程式，而且它們仍然都算 core——這個體系的好壞 |
| 開場日期 | 2026-08-26 |
| 已跑輪數 | 2 輪，已收場 |
| 狀態 | 收場，沒有第 3 輪。結論沒有收斂成一個答案（研討會不要求），共同判斷是四比零的「deliver 外放、claim／release 留內」；轉交提案未拍板。 |
| 參與的身份 | 資深工程師／架構師／作業系統研究者／要接這工具的開發者（四位） |
| 缺哪個角度 | **沒有**產品經理、普通用戶／新手、獨立的維運席位（維運只被資深工程師從「半夜被叫起來」的角度部分涵蓋）。另有若干缺口，見下面〈這場沒有誰在場〉。 |
| 參與者是什麼 | Claude Opus 5 sub agent，**不是 codex**。**沒有設 reasoning effort 參數。** |
