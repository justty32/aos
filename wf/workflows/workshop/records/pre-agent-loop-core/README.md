**議題**：在開始 T5 agent loop 之前，應該先做出哪些 aos core 核心小專案？（「零個」是合法答案。）

**使用者提出的四個構想**：取下一條指令（inst 慣例 vs 通用 lib）、快取／暫存器
（暫名 `.aos/inst.cached`，要更精簡的名字）、`aos wait`（回呼而非硬 sleep）、
`aos func foo`（每輪投遞兩筆：本步工作＋抓下一條）。變數與控制流明說不做，要往 lisp 走。
