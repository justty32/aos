**主題**：CPU 只該做「取指令→執行→再取」。匯聚、排下一回合、跑 funcs 該不該變成
`inst.json` 裡**恆常存在的頭尾核心系統指令**？「行程」在 aos 裡是什麼——資料夾是主行程、
funcs 是子行程、都由核心 CPU 執行；多核就是多支 `aos exec` 指向不同 `inst.json`；外部處理器
簡單到不必引用 aos lib。本場不設範圍外，可以主張推翻現有任何決定。

## 續場資訊

四個 codex session context 留著，R3 用同一批 id（resume 後 `thread_id` 不變）。**只在開場那台機器上有效**——office Windows。

> **`codex exec resume` 不吃 `-s` 與 `-C`**（沙盒與工作目錄從原 session 繼承），
> 帶了會 usage error 退出碼 2。`--json`／`-o`／`-c` 照常。事件欄位是 **`thread_id`**，不是 `session_id`。
