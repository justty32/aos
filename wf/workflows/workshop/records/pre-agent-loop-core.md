# 議題：agent loop 之前要做哪些 core 小專案？

← [workshop](../README.md)

> **這份是舊的「辯論風格」紀錄**（工作流原名 `council`，角色是對立的立場）。**內容仍然有效。**

這場紀錄已拆成資料夾：**[pre-agent-loop-core/README.md](pre-agent-loop-core/README.md)**（檔頭資訊與導航都在那裡）。

| 檔案 | 裡面有什麼 | 什麼時候會想看 |
|---|---|---|
| [R1 結論（發散）](pre-agent-loop-core/r1.md) | 五條共識、四項分歧、新論點、下輪焦點 | 想知道使用者那四個構想各自被判成什麼 |
| [R2 結論（交鋒）](pre-agent-loop-core/r2.md) | 兩人改立場、一人撤回；`k/` 續體與 `c/` 熱快取分成兩層 | 想知道投遞 API 與兩層快取的形狀怎麼定的 |
| [R3 結論（收斂＋新概念）](pre-agent-loop-core/r3.md) | 四題取捨的票數與代價；使用者注入的「有限資源」新概念與 `aos queue` 版面 | 要查某一題最後怎麼定的，或要談有限資源排隊 |
| [總結論與轉交建議](pre-agent-loop-core/conclusion.md) | T5 之前做什麼／不做什麼、模型上的收穫，以及**四件還沒拍板的轉交建議** | **要拍板那四件轉交建議時** |
