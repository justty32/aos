## 第 2 輪

### 成形的方向

**四比零這件事被三位各自統計出來、寫進了自己的第 2 輪**：四個身份全部獨立說「deliver 該外放、claim／release 該留內」，無人主張整包外放。這是全場最強的訊號。

**`.runi` 從一個檔名升級成一份租約。** 三位獨立走到這裡（資深工程師從診斷、架構師從身分驗證、OS 研究者從原子性），連補救手段都撞在一起。資深工程師把三件事疊成一個東西：`.runi` 帶 header（pid、boot id、時間、筆數），一疊解三件事——三種現場分得出來、release 驗身分才刪（擋掉「放錯位置的 release 中途開鎖」）、recover 就是把 header 印給人看。

**架構師在這裡補了一個沒人講的細節，而且它會改變做法**：`.runi` 現在的內容**就是那批 JSON**，出事時 `cat` 一下就知道卡住的是哪一批；包一層 header 會毀掉這一點。所以 receipt 要**旁邊放**（`inst.json.runi.receipt`），而且**先寫 receipt、後 rename `.runi`**——孤兒 receipt 無害，反過來不成立。

開發者對這條的立場值得單獨記：**他不否決「claim／release 留內」，他要的不是呼叫權，是可見性。** 照留內，另外給一支唯讀的 `aos world status <folder>`，印 `.runi` 在不在、幾筆待彙整、幾個 `.bad`、上一回合何時結束。

**`--loop` 的停止條件該搬回檔案系統**（架構師）。他對「退出碼 3 會消失」的解法是：3 不是「某支程式的碼」，是**世界的狀況**。所以 `--loop` 停不停不該去讀子程序的退出碼，該在每回合開頭自己 `stat` 一次 `.runi`。這把契約從退出碼搬回檔案系統狀態，**而那本來就是這個模型的唯一真源**；這樣即使 claim 哪天真的外放，停止條件仍然留在 `aos exec` 裡面。

**「零工作的回合必須是零 fork」**（資深工程師把架構師的閒置路徑提案推成一句可驗收的規則）。回合開頭 stat `inst.json` 與 `inst.tempd`，兩邊都空就 return。

**bootstrap 那份特權檔，三位各自改了它一次，形狀不一樣**：

- OS 研究者自己收回了 R1 的單層 `boot.json`，改成 FreeBSD 的雙層：**開機批次編進執行檔當內建預設，`.aos/boot.json` 只在存在時覆蓋**——刪光了照樣能開，而單層 inittab 改壞就進不去系統。
- 架構師改的是它的性質：它不該是「指令表」，該是**角色表**。理由是依賴方向——boot.json 若只是一批 instruction 串在最前面，它仍然跑在 claim 之後，彙整還是沒自舉；改成角色表（誰扮演 aggregate、誰扮演 deliver），`aos exec` 開頭讀它、直接 execve、不經 `inst.json`，悖論才真的解掉。**他同時宣布這張表就是他 R1 講的 `kernel.json` 間接層，兩者合併成同一張。** 這樣被凍結的東西就從「`aos aggregate` 這個字串」換成「一個能隨 `.aos/version` 一起版本化的檔」——字串收不回來，版本化的檔收得回來。
- 開發者要的是它的操作面：instruction 不寫程式名，`kernel.json` 寫 `"aggregate": "@self"`；他不動零行照樣能跑，要換就打 `aos world kernel set aggregate ./my-aggregate.py`。
- 資深工程師管的是它的失敗語意：改壞 boot 批次不是「起不來」，是**每回合失敗一次、退出碼仍然 0**（第八節：子行程非零不影響回合碼）。所以 boot 批次必須有**不同的失敗語意**——任一筆非零就中止本回合、不跑 payload、回專屬碼並停 `--loop`，否則那個特權位置會變成一個靜默的無限迴圈。

**recover 得進規格，不能只是個指令**（架構師）。一旦 `aos world recover` 存在，「crash 現場留給人」就從「人拿 shell 修」變成「人跑一支 aos 指令」，而那支指令要做的是**規格目前沒有定義的狀態轉移**（把 `.runi` 搬回 `inst.json`）。所以它不能只當 `aos world` 的一員，得在規格第六節明文成為**第四步**（連同「棄置」），否則它是一支在規格外偷偷改世界的程式。

**先做 deliver，其餘等 receipt 格式定下來**（開發者）。他把順序講得最清楚：不是四支一起拆，是 deliver 先單獨出去，因為 T5 那份 agent loop 腳本是這套協定第一個真正的外部使用者，現在得自己 `mktemp`＋`rename`，有 `aos deliver` 就縮成一行。
