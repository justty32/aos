# 01 名詞表
← [入口](README.md)

這份是整套 spec 的共同語言。正文之後只用這些詞；學名只在括號裡出現一次。每個詞一句白話，加上「它住在哪個檔」。

## 空間

| 詞 | 一句白話 | 住在哪 |
|---|---|---|
| **地**（也叫資料夾、世界） | 一個裡面有 `.aos/` 的資料夾。它同時是一支程式，也是這支程式正在跑的樣子。路徑就是它的身分；資料夾刪了它就死了。 | [02](02-layout.md) |
| **頂層** | 一塊地裡除了 `.aos/` 以外的部分。人寫的東西放這裡。 | [02](02-layout.md) |
| **`.aos/`** | 一塊地裡機器的地盤。人不手改，只透過 `aos` 子命令碰它。 | [02](02-layout.md) |
| **原稿** | 人（或 LLM）寫在頂層的程式檔，檔名 `*.aos.json`。 | [03](03-source-and-compile.md) |
| **子地**（子資料夾） | 一塊地裡面另一塊地。預設躺著不動，父點名才開。 | [07](07-call-and-delivery.md) |
| **父／子** | 開的那一方是父，被開的那一方是子。 | [07](07-call-and-delivery.md) |
| **家**（`AOS_HOME`） | daemon 住的那塊地，預設是使用者的 `~`。使用者層的設定、登記表、帳簿都在 `$AOS_HOME/.aos/`。 | [08](08-daemon.md) |

## 程式與它跑起來的樣子

| 詞 | 一句白話 | 住在哪 |
|---|---|---|
| **編譯器** | 把原稿拆平成一步一步的程式，寫進 `.aos/program/`。不確定的東西只准在原稿，編譯是確定的。 | [03](03-source-and-compile.md) |
| **載入器** | 一塊地被開的那一刻，把頂層原稿讀進 `.aos/`（叫編譯器）並開出第一條串的那個動作。跑中不理原稿。 | [03](03-source-and-compile.md)、[06](06-exec-and-run.md) |
| **模板** | 編譯好的一段程式：一串有名字的步。可重用，跑起來就是一條串。 | [03](03-source-and-compile.md) |
| **步**（step） | 模板裡的一格動作。只有三種：跑一筆指令、開一塊子地、等一個結果。 | [03](03-source-and-compile.md)、[05](05-series-format.md) |
| **指令**（inst） | 一次 POSIX 呼叫寫成的 json：argv 陣列、環境變數、工作目錄、三條流的檔案路徑。是最底下再也拆不開的一格。 | [04](04-inst-format.md) |
| **串**（series） | 一個模板跑起來的實體：記著跑到第幾步（游標）、狀態、暫存器。 | [05](05-series-format.md) |
| **批** | 一塊地上正在跑的全部串。一塊地一次跑的是一批，不是一條。 | [05](05-series-format.md) |
| **接力棒**（`.aos/series.json`） | 記著這批有哪幾條串、各跑到哪的那個檔。兩格之間程式不存在，全靠它接。 | [05](05-series-format.md) |
| **游標** | 一條串現在停在模板的哪一步。 | [05](05-series-format.md) |
| **暫存器**（代號、符號表） | 串裡有名字的值，只在這條串裡有效。 | [05b](05b-series-lifetimes.md) |
| **堆疊框** | 一條串專用的臨時資料夾 `.aos/frames/<串 id>/`，串跑完就丟。 | [05b](05b-series-lifetimes.md) |
| **中間值** | 拆平之後夾在兩步之間的結果，落在堆疊框裡的檔。 | [03](03-source-and-compile.md) |

## 時間

| 詞 | 一句白話 | 住在哪 |
|---|---|---|
| **格**（tick） | 一次 `aos exec`：讓一塊地走一步，做完就交回。一格裡所有該動的指令一起跑，彼此看不到結果。 | [06](06-exec-and-run.md) |
| **時鐘** | 一支 `aos run`：反覆 exec 的那個東西。走法有三種（固定次數、隔一段時間、到條件）。 | [06b](06b-run-rules.md) |
| **通用停法** | 這次 exec 沒產出新指令、而且沒有任何串在等，才停。所有時鐘都適用。 | [06b](06b-run-rules.md) |
| **預算** | 一支 run 最多走幾格；超過就停並寫停止原因檔。 | [06b](06b-run-rules.md) |
| **停止原因檔**（`.aos/stopped.json`） | run 停下來（或 exec 判串失敗）時寫的檔：為什麼停、停在哪條串哪一步。 | [06b](06b-run-rules.md) |
| **同步**（借父的鐘） | 子地沒有自己的時鐘，父走一格它跟著走一格；父的這一步停在原地等它跑完。 | [07](07-call-and-delivery.md) |
| **脫節**（自己有鐘） | 子地自己登記一顆時鐘，父不等它；父每格看結果落點有沒有檔。 | [07](07-call-and-delivery.md) |
| **閒著**（idle） | 接力棒不在，或所有串都 `done`。有 `failed`／`stopped` 的串不算閒著，要先 `aos reset`。 | [06](06-exec-and-run.md) |
| **在等** | 一條串停在 `await` 步、或停在同步 `call` 步而子還沒閒著。在等的串不算沒事做，run 不會因此停。 | [05](05-series-format.md)、[06b](06b-run-rules.md) |

## 呼叫與交接

| 詞 | 一句白話 | 住在哪 |
|---|---|---|
| **呼叫記錄**（`.aos/calls/<id>.json`） | 父開子地時寫的一筆：開了誰、同步還是脫節、結果要落在哪。 | [07](07-call-and-delivery.md) |
| **結果落點** | 父在呼叫記錄裡指定的一條路徑；子跑完把結果寫到那裡。不是寫死的路徑。 | [07b](07b-result-path.md) |
| **狀態檔** | 緊鄰結果落點的 `<結果落點>.status.json`。它在＝壞了，裡面寫原因。 | [07](07-call-and-delivery.md)、[07b](07b-result-path.md) |
| **三態** | 結果檔不在＝還沒好；結果檔在＝好了；狀態檔說壞＝壞了。 | [07](07-call-and-delivery.md) |
| **投遞** | 把一個 json 檔放進別人的收件匣。三次改名、寫→刷→改名→刷目錄。 | [07](07-call-and-delivery.md) |
| **收件匣**（`.aos/inbox/`） | 一塊地收投遞的地方。裡面的東西下一格才被取走。 | [07](07-call-and-delivery.md) |
| **信**（mail） | 投遞物的一種：不執行，留給地上的程式（通常是 agent）讀。 | [07](07-call-and-delivery.md)、[10](10-agent.md) |
| **控制收件匣**（`.aos/control/`） | 專收「停」這類控制訊息的收件匣，走同一套投遞。 | [08](08-daemon.md)、[12](12-cli.md) |

## 角色

| 詞 | 一句白話 | 住在哪 |
|---|---|---|
| **daemon** | 一支常駐程式：替每塊登記的地起一支 `aos run` 子行程，自己只看管。 | [08](08-daemon.md) |
| **登記表**（`$AOS_HOME/.aos/registry.json`） | 所有正在走或停著的時鐘都記在這一份檔裡。 | [08](08-daemon.md) |
| **agent** | 一塊地，它的程式是「把 prompt 丟給 LLM 世界→拿清單→跑工具→再丟」這個圈。 | [10](10-agent.md) |
| **LLM 世界** | 一塊專門處理 LLM 請求的地，自己有鐘。別的地要用 LLM 就投一筆請求給它。 | [09](09-llm-world.md) |
| **處理單元**（unit） | LLM 世界後面一個真的模型端點：位址、模型名、聰明度分級（tier）、並行上限。 | [09](09-llm-world.md) |
| **帳簿**（`$AOS_HOME/.aos/ledger.jsonl`） | 每次 LLM 呼叫記一行：誰叫的、用了多少、花了多久。 | [09](09-llm-world.md) |
| **用量檔** | LLM 世界寫在落點旁的 `<結果落點>.usage.json`（這一筆用了多少），與 agent 自己累加的 `.aos/usage.json`。 | [07b](07b-result-path.md)、[10](10-agent.md) |
| **工具登記表**（`.aos/tools/<名>.json`） | 一塊地上模型可以叫的程式，一工具一檔。 | [11](11-tools-and-contacts.md) |
| **通訊錄**（`.aos/contacts.json`） | 誰住在哪個資料夾。只回答這一句。 | [11](11-tools-and-contacts.md) |
| **門房** | 站在資料夾樹前面、看著檔案動靜的那支程式。第一級只看不擋（inotify）。 | [13](13-doorman-l1.md) |
| **使用者** | 恰好一個人，也是一隻住在 `~` 的 agent。 | [10](10-agent.md) |

## 三個規定用詞

- **必須**：照做，不照做就不是 aos。14 章每條必須對一個檢查。
- **建議**：照做比較好，不照做也合規。
- **禁止**：做了就不是 aos。

## 舊詞對照（正文不用）

回合＝格；loop＝run；pu＝地；tick 也叫格；「子的固定產出資料夾」＝已改為父指定的結果落點；`.aos/agents/`＝已取代，agent 就是一塊地。

## 待使用者拍板

本檔沒有條款，只有定義；定義來源見各檔。

## 現況對照

今天的程式沒有「步」「串」「接力棒」「呼叫記錄」「結果落點」這些東西；最接近的是 `.aos/inbox/`、`.aos/batch/<turn>/`、`.aos/every/`。
