# 03 原稿與編譯
← [入口](README.md)

人（或 LLM）寫原稿，編譯器拆平成模板，exec 照模板走。亂只准在寫的那一段。正本是 [source](schemas/source.schema.json) 與 [program](schemas/program.schema.json) 兩份 schema。

## 三段式

- **S-03-01** 一段程式必須走「寫 → 編譯 → 執行」三段：寫的那段可以不確定，編譯與執行必須確定。〔裁決 2026-09-01〕
- **S-03-02** 原稿、模板、接力棒、指令必須全部是 json；禁止把括號語法或 shell 腳本當成其中任何一站的格式。〔裁決 2026-09-01〕
- **S-03-03** 原稿必須放在一塊地的頂層，檔名 `*.aos.json`；`main.aos.json` 是入口。禁止人手寫 `.aos/` 裡的檔。〔裁決 2026-09-03〕
- **S-03-04** 編譯必須是確定的：同一份原稿編兩次，吐出來的檔必須逐位元組相同。禁止時間戳、隨機數、機器產的 id 進模板。〔主編補〕
- **S-03-05** 子地永遠不會被壓進模板的步；模板與資料夾樹之間唯一的橋必須是 `call` 步。〔裁決 2026-09-03〕

## 原稿長什麼樣

原稿頂層有 `format_version` 與 `templates`（模板名 → 模板）。模板有 `interface` 與 `steps`。原稿步有 `name`、`do`，可選 `then`、`on_fail`、`select`。

- **S-03-06** 一份原稿必須可以定義多個模板；同一塊地裡模板名必須唯一，撞名拒絕。〔主編補〕
- **S-03-07** `_comment` 欄必須允許出現在原稿的任何一層，編譯器必須一律略過它。〔預設 2026-09-05，E-04〕
- **S-03-08** 模板的 `interface`（`params` 參數表、`returns` 回傳型別與回傳哪一步）必須只住在原稿；編譯器檢查完必須丟掉，模板與指令禁止帶型別。〔預設 2026-09-05，E-06〕
- **S-03-09** 參數必須用 `${參數名}` 在步的字串欄裡引用；`frame`、`land`、`tick` 是保留名，禁止當參數名。〔主編補〕
- **S-03-10** `do` 的 `kind` 必須是 `inst`、`call`、`await`、`use` 四種之一；`use` 是「叫本原稿另一個模板」，用 `template` 欄指名，只在原稿存在。〔主編補〕

## 巢狀與拆平

原稿准巢狀：一步的引數可以是另一步的結果，也可以直接嵌一個動作。編譯器負責拆平。

- **S-03-11** `inst.argv` 的元素與 `call`／`use` 的 `args` 值必須允許四種寫法：字串、`{"b64":"…"}`、`{"from":"<步名>"}`（那一步的結果）、`{"do":{…}}`（就地嵌一個動作）。〔裁決 2026-09-01〕
- **S-03-12** 編譯器必須把巢狀拆平成一步一名：每個內嵌動作提成一步，排在用到它的那步前面。〔裁決 2026-09-01〕
- **S-03-13** 每一步的結果必須落在堆疊框的 `${frame}/<步名>`；`{"from":"x"}` 必須換成 `${frame}/x`。〔裁決 2026-09-01〕
- **S-03-14** 提上來的步名必須是 `<外層步名>__<序號>`，序號從 1 起、由左到右數；`use` 展開出來的步名必須是 `<那一步的名>__<內層步名>`。原稿自己寫的步名禁止含 `__`。〔主編補〕
- **S-03-15** 「接下來做什麼」必須寫在步的 `then` 欄：省略＝下一步、`"end"`＝這條串做完。步名禁止叫 `end`。〔裁決 2026-09-01〕
- **S-03-16** 一格之內沒有資料流：編譯器禁止把「後一步讀前一步結果」的兩步併成一步，所有銜接必須跨格。〔裁決 2026-09-01〕
- **S-03-17** `use` 必須用內聯展開（把被叫模板的步抄進來、參數就地代換），禁止遞迴；成環必須拒絕。〔主編補〕
- **S-03-18** 巢狀深度（內嵌動作與 `use` 展開合計）上限必須是 8，超過拒絕。〔主編補〕

## 開子地與「選」

- **S-03-19** 同步子地必須寫成 `{"kind":"call","child":"…","mode":"sync"}`，編譯成一個 `call` 步；父每格對子做一次 `aos exec`，這一步停在原地直到子閒著。〔裁決 2026-09-03〕
- **S-03-20** `call` 的 `result`（父指定的結果落點）省略時，編譯器必須填 `${frame}/<步名>`。〔主編補〕
- **S-03-21** 一步可以帶 `select`：一條路徑，那一步成功後 exec 必須讀那個檔第一行當下一步的名字。通常那一步是投給 LLM 世界再 `await`。〔裁決 2026-09-05〕
- **S-03-22** `select` 讀到的第一行必須是本模板裡存在的步名；不是就這條串失敗，原因代碼 `bad_select`。〔裁決 2026-09-05〕
- **S-03-23** 同一步同時有 `select` 與 `then` 時，`select` 必須贏；建議不要兩個都寫。〔主編補〕
- **S-03-43** `select` 指的檔不在、讀不到、或第一行空白，那一步必須算失敗，原因 `bad_select`；禁止退回走 `then` 或下一步。〔主編補〕

## 編譯器吐什麼

- **S-03-24** 編譯器必須為每個模板吐一個檔 `.aos/program/<模板名>.json`。〔預設 2026-09-05，E-02〕
- **S-03-25** 步只有三種 `kind`：`inst`（帶 `inst`，可帶 `expect`）、`call`（帶 `child`、`mode`、`result`，可帶 `args`、`clock`、`cleanup`，後者見 [07](07-call-and-delivery.md)）、`await`（帶 `result`，可帶 `max_ticks`）。禁止第四種。`clock` 的形狀跟登記表一樣，見 [08](08-daemon.md)。〔主編補〕
- **S-03-26** 模板裡的 `inst` 物件代換完之後必須過 [inst schema](schemas/inst.schema.json)，編譯器必須自己驗一次。〔主編補〕
- **S-03-27** 模板裡 `inst` 的 `id` 必須等於步名；exec 把它落成 `.aos/ticks/<N>/insts/<id>.json` 時必須換成機器產的 id。〔主編補〕
- **S-03-28** 被別的步當引數用的 `inst` 步，原稿沒寫 `stdout` 時編譯器必須設成 `${frame}/<步名>`；禁止順手也設 `expect`。〔主編補〕
- **S-03-38** 檔頭必須有 `source_hash`：那個模板所在原稿檔的內容 sha256（小寫 hex）。它只給 `aos status` 顯示看。〔主編補〕

## 編譯器拒絕什麼

- **S-03-29** 遇到不認得的欄位必須拒絕，不准略過。唯一例外是 `_comment` 與具名擴充區 `ext`。〔裁決 2026-08-28〕
- **S-03-30** 必填欄位缺了、同一模板裡步名重複，都必須拒絕。〔主編補〕
- **S-03-31** `then`、`on_fail`、`returns.from`、`{"from":"…"}` 指到不存在的步，必須拒絕；`select` 只檢查是不是非空路徑。〔主編補〕
- **S-03-32** `use` 給的引數個數或型別跟被叫模板的 `interface` 對不上，必須拒絕。〔預設 2026-09-05，E-06〕
- **S-03-33** 拒絕時必須退出碼 3，並在標準錯誤寫一則人看得懂的訊息：哪個原稿檔、哪個模板、哪一步、為什麼。禁止只吐一個碼。〔主編補〕
- **S-03-34** 拒絕時禁止留下半份 `.aos/program/`（做法見 S-03-41）。〔主編補〕

## 載入器

- **S-03-35** 一塊地閒著時被 `aos exec` 開，載入器必須在那一刻讀頂層全部 `*.aos.json`、編譯、寫進 `.aos/program/`，再為 `main` 開串。〔裁決 2026-09-03〕
- **S-03-36** 串在跑時必須不理原稿：原稿改了不影響這一批，下次被開才重讀。要立刻生效必須先停掉再開。〔裁決 2026-09-05〕
- **S-03-37** 沒有 `main.aos.json`、或它沒有名叫 `main` 的模板時，載入器必須拒絕開串並退出碼 3。〔主編補〕
- **S-03-39** 每次載入必須重編一次。禁止拿 mtime 或大小判「沒變」而沿用上次的 `.aos/program/`，`source_hash` 也不准拿來決定重不重編。〔主編補〕
- **S-03-40** 一個沒有 `main.aos.json` 的資料夾被父開，這一格必須算失敗；父的 exec 必須在那一步的 `result` 旁代寫狀態檔 `reason: no_source`。禁止靜默成功。〔主編補〕
- **S-03-41** 載入或編譯失敗必須歸「沒跑起來」那個頻道：編譯器必須先建 `.aos/program.tmp/`，全部寫成才改名就位，失敗必須整個刪掉；這塊地若是父開的，父的 exec 必須代寫狀態檔 `reason: compile_error`。〔主編補〕
- **S-03-42** 載入做完之後，run 期間禁止再讀頂層原稿一個位元組；`.aos/program/` 是這一批唯一的真相。〔主編補〕

## 範例

一份原稿（`main.aos.json`）：數 md，再叫子地 `plot` 畫圖。

```json
{
  "format_version": 1,
  "_comment": "數 md",
  "templates": {
    "main": {
      "interface": { "returns": { "type": "path", "from": "draw" } },
      "steps": [
        { "name": "count", "then": "draw",
          "do": { "kind": "inst", "inst": { "argv": ["wc", "-l",
            { "do": { "kind": "inst",
                      "inst": { "argv": ["sh", "-c", "ls ${land}/*.md"] } } }] } } },
        { "name": "draw", "then": "end",
          "do": { "kind": "call", "child": "./plot", "mode": "sync",
                  "args": { "data": { "from": "count" } } } }
      ]
    }
  }
}
```

編出來的 `.aos/program/main.json`：

```json
{
  "format_version": 1,
  "name": "main",
  "source_hash": "9f2c0a1b3d4e5f60718293a4b5c6d7e8f90a1b2c3d4e5f60718293a4b5c6d7e8",
  "steps": [
    { "name": "count__1", "kind": "inst", "then": "count",
      "inst": { "format_version": 1, "id": "count__1",
                "argv": ["sh", "-c", "ls ${land}/*.md"],
                "stdout": "${frame}/count__1" } },
    { "name": "count", "kind": "inst", "then": "draw",
      "inst": { "format_version": 1, "id": "count",
                "argv": ["wc", "-l", "${frame}/count__1"],
                "stdout": "${frame}/count" } },
    { "name": "draw", "kind": "call", "child": "./plot", "mode": "sync",
      "result": "${frame}/draw", "args": { "data": "${frame}/count" },
      "then": "end" }
  ]
}
```

看得出來的：內嵌那筆提成 `count__1` 排到前面；`{"from":"count"}` 變成 `${frame}/count`；`interface` 不見了。

## 待使用者拍板

沒特別標的都是〔主編補〕。

- S-03-04 編譯確定、禁止時間戳與隨機數進模板
- S-03-06 一份原稿可定義多個模板，模板名一塊地內唯一
- S-03-07 `_comment` 任何層級都可以，編譯器略過〔預設，E-04〕
- S-03-08、S-03-32 型別只住 `interface`，編譯器檢查後丟掉〔預設，E-06〕
- S-03-09 參數寫成 `${名}`；`frame`、`land`、`tick` 保留
- S-03-10 原稿多一種 `use`（叫本原稿另一個模板），編譯後不存在
- S-03-14 提上來的步名 `<外層步名>__<序號>`，人寫的不准含 `__`
- S-03-17、S-03-18 `use` 用內聯展開、禁止遞迴；巢狀深度上限 8
- S-03-20 `call` 的結果落點省略時填 `${frame}/<步名>`
- S-03-23、S-03-43 「選」跟 `then` 同時出現選誰贏；檔不在、空行都失敗（`bad_select`），不准退回 `then`
- S-03-24 一模板一檔 `.aos/program/<模板名>.json`〔預設，E-02〕
- S-03-25 步只有三種 kind，禁止第四種

編譯與載入：

- S-03-26、S-03-27 模板裡的 `inst` 要過 inst schema；`inst.id` ＝步名，exec 落檔換掉
- S-03-28 被當引數用的 inst 步自動補 `stdout`，不補 `expect`
- S-03-30、S-03-31 缺必填、步名重複、跳到不存在的步都拒絕
- S-03-33、S-03-34 拒絕時退出碼 3、寫人看得懂的原因、不留半份輸出
- S-03-37、S-03-40 沒有 `main` 模板就拒絕開串；被父開的話父代寫狀態檔 `no_source`
- S-03-38、S-03-39 檔頭記 `source_hash` 只給 `aos status` 看；載入一律重編，不看 mtime
- S-03-41 載入／編譯失敗＝這格失敗，先建 `.aos/program.tmp/` 再改名，狀態檔 `compile_error`
- S-03-42 run 期間禁止再讀頂層原稿

沒人裁、我選了一邊的兩處：

- 矛盾：ideas D-01 給入口腳本另取了一個檔名，E-02 說載入器編進 `.aos/program/`。選了 E-02，因為 D-01 那個預設在總表已註明作廢。
- 矛盾：「一筆指令的 `id` 是機器產的 32 位 hex」（04）跟「模板必須確定」（S-03-04）打架。選了「模板裡的 `id` 用步名，落檔時才換成機器產的」，因為模板要能逐位元組重編；要跟 04 對齊。

## 現況對照

今天沒有原稿、編譯器、載入器：`aos deliver` 直接送單筆指令，一批是 `core/loop` 從收件匣湊出來的。`.aos/` 裡沒有 `program/`，`core/wire` 只認得指令與結果兩種協定，巢狀、拆平、`${frame}` 都不存在。
