# 05b 暫存器、堆疊框與多寫者
← [入口](README.md)

接力棒的欄位與游標怎麼推在 [05](05-series-format.md)。這一份接著講三件事：串裡的名字怎麼被換掉、跑出來的東西活多久、這個檔誰能寫。條款編號跟 05 是同一條線。

## 一、暫存器怎麼替換

- **S-05-15** 步的字串欄裡的 `${名}` 必須由 exec 在跑之前用串的 `regs` 換掉。五個內建名必須一直可用：`${frame}` 是堆疊框路徑、`${land}` 是這塊地的根、`${tick}` 是這一格的格號、`${home}` 是家（`$AOS_HOME`）的路徑、`${llm_world}` 是 LLM 世界的路徑。查不到的名字必須算這一步失敗。〔裁決 2026-09-05〕
- **S-05-60** `${llm_world}` 必須由 exec 讀家的 `config.json` 的 `llm_world` 填；沒有那一欄就用 `${home}/.aos/llm`。地本身禁止去讀家的設定檔，只准用 exec 換好的這個值。〔主編補〕
- **S-05-59** 替換必須只做一遍，換進去的字串裡再出現 `${名}` 禁止再換一次：不然一段外面來的文字就能決定 exec 讀哪個檔。〔主編補〕

## 二、兩種壽命

- **S-05-37** 暫存器壽命的東西必須放 `.aos/ticks/<格號>/tmp/<指令 id>/`：只有那一筆指令看得到，指令跑完 exec 必須刪掉。〔裁決 2026-09-01〕
- **S-05-38** 堆疊框壽命的東西必須放 `.aos/frames/<串 id>/`：開串時 exec 建，串改成 `done` 的同一步 exec 必須刪掉。〔預設 2026-09-05，E-05〕
- **S-05-39** `failed` 與 `stopped` 的串的堆疊框必須留著給人看，等 `aos reset` 才清。〔預設 2026-09-05，E-05〕

## 三、誰能寫、怎麼寫

- **S-05-40** 寫接力棒必須照這四步：寫 `.aos/series.json.tmp` → fsync 這個檔 → rename 蓋過 `series.json` → fsync `.aos/` 這個目錄。禁止就地改。〔裁決 2026-09-05〕
- **S-05-41** 只有拿到 `.aos/lock` 的那一支 exec 可以寫接力棒；其他人一律禁止寫。〔主編補〕
- **S-05-42** 外部想插手一條串（中斷）必須投進 `.aos/inbox/` 或 `.aos/control/`，由 exec 在下一格自己改接力棒；禁止直接改這個檔。〔主編補〕
- **S-05-43** 讀到不合 schema 的接力棒必須整份拒絕、這一格不跑，退出碼 `3`。〔主編補〕

## 待使用者拍板

〔預設〕：

- S-05-38 堆疊框在串改 `done` 的同一步刪（E-05）。
- S-05-39 壞掉的串的堆疊框留著給人看（E-05）。

〔主編補〕：

- S-05-60 `${llm_world}` 由 exec 從家的設定填，預設 `${home}/.aos/llm`。
- S-05-59 替換只做一遍，不遞迴。
- S-05-41 只有拿鎖的 exec 能寫。
- S-05-42 中斷走投遞或控制收件匣。
- S-05-43 不合 schema 整份拒絕，退出碼 `3`。

註：`${home}` 與 `${llm_world}` 是「一塊地只看得到自己地上的東西」（M-01）的一個明示例外——agent 第一步就要投給 LLM 世界，串剛開跑時 `regs` 是空的，沒有這兩個名就走不動。開的洞只有兩條路徑，不含家的其他東西。

## 現況對照

今天沒有堆疊框，也沒有「指令跑完就刪的暫存目錄」：暫存檔散在 `.aos/batch/<turn>/` 底下，誰清沒人管。今天寫檔是就地覆蓋，沒有暫存加改名那一套，也沒有 `.aos/lock`，所以兩支同時跑的程式會互相蓋掉對方的進度。
