# 02 不是新舊打架的題：用「日期晚的贏」判不了，要使用者另外定

← [條文打架分類](../2026-11-17-條文打架分類.md)｜路徑相對 `proto8/docs/`。

**對讀-1a 改回「核心」後怎麼分**：裁題 1 已定改回「核心」，但 C-74 寫明分層的「核心」只指 aos-exec，名詞表那一大塊原本也叫核心。同一個詞有兩個意思。這是名詞怎麼分，不是新舊。

**對讀-1b 「self 一家」**（C-90）：沒找到使用者說過這個詞，thinking `2026-11/10/self-family/README.md:1` 寫的是「一家子」。問題是能不能留在「只收使用者說過的」純概念裡。這是用詞的出處，不是新舊。

**對讀-3 P-06 八個或九個 key**：P-06 說 aos-loop 認八個；aos-loop 程式與 README 還認 `on_timeout_ms`（預設 5000），NORMS loop 段（11-11 clock-hook）也寫了。補到八個的 11-13 cv-P06:A 用意是「照程式補齊」，當時漏數了這一個。算條文對不上程式。

**對讀-5 P-43「同形」**：P-43 說 eca 跟 agent-fsm 同形（_entry…），實際上 eca 的 `_entry` 是 aos-loop，agent-fsm 的是 `ctl add`＋body.json。條文對不上範本。

**對讀-10-C83**：C-83 的「代定（11-07 落實時，可翻案）」掛在 ① 與檔尾，看不出管哪一句；root daemon 那點條文寫「例外」，原話是「實作上可以稍微拉扯一下」。這是標記放哪、措辭多硬。

**對讀-10-C81 三類或四類**：使用者同一句話說「基本就三類」，後面列了四樣，條文自己標了待確認，實作沒差。這是原話數錯，不是新舊。

**對讀-10-身分**：「身分」「身份」兩種寫法並存（純概念上半一處「身份」、下半兩種各一處；整個 docs 有 15 檔用「身分」、9 檔用「身份」）。用字統一。

**對讀-11-P20**：P-20「格的旋鈕不走環境變數」是獨立規則，NORMS 的 ④ 旋鈕（`NORMS/10-…/07-…/03-AOS_-變數的四種性質.md:14`）已經有了。問的是要不要拉進慣例純條文（約 +80 B）。

**對讀-11-C54**：C-54 的複數規則與錯誤代號（使用者 11-11 表態概念層要列、帶「推薦」）沒進純概念。問的是要不要拉上來（約 +130 B）。

**對讀-12 步驤**：CONCEPTS 檔頭舊句原字是「步驤」（錯字），11-17 照舊句逐字改回時保留了。問的是要不要改成「步驟」。

**對讀-14 入口檔不在頂層**：CONVENTION 無號列「入口檔不在資料夾頂層：cd 到 `AOS_CD`」（待決、照預設）跟 N-59 第 4 件內容重複。問的是慣例裡要不要留這列。

**NORMS-7 檔頭那句**：純規範檔頭「一兩句寫不完的限定條件照分檔全文做」原文沒有，是濃縮線加的文件層說明，不是規則。
