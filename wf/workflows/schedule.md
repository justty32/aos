# schedule — 一次性行程（臨時、指定時刻）

← [WORKFLOWS](../WORKFLOWS.md)｜[INDEX](../INDEX.md)

記「心血來潮、指定一個時刻、做一次就沒了」的請求——「下午五點重啟 X」「今晚 8 點提醒我 OO」，並在 [tick](tick.md) 心跳時把到點的做掉、做完刪列。清單就在本檔。

**何時用**：① **登記**——你說「幫我登記行程：17:00 重啟 X」；② **執行**——[tick](tick.md) 心跳叫起本檔。
**何時不用**：不常變動、固定循環的常規事務 → [routines](routines.md)。重活不在心跳裡跑。

## Done when

- **登記**：下面「一次性時刻表」多一列，**時刻**欄是含日期的絕對時刻。
- **執行**：到點項做完，且該列已從表中刪除。

## 流程

### A. 登記（使用者請求時）

1. 聽清「**時刻 + 內容**」。
2. **換算成絕對時刻**（含日期）：相對講法（「五點」「今晚 8 點」「明天」）依現在時間換算——`TZ='Asia/Taipei' date '+%F %A %H:%M'`。
3. 寫進下面時刻表一列：時刻 / 內容 / 執行者。
4. **回一句確認**：登記了什麼、幾點做。**不當場做**（那是心跳的事）。

### B. 執行（tick 心跳叫起時）

1. 判當地時間（同上第 2 步的取法）。
2. **掃時刻表**：有沒有「時刻 ≤ 現在」還沒做的列。
3. **到點就做**——**使用者親自排的＝已有授權來源（鐵律 2）**，照做；但做的當下情況有變、或會有登記時預期外的不可逆影響 → 先問再動。重活記一行 open、另開 session。
4. **做完刪掉該列**（一次性，別留著下次重跑）。
5. **錯過很久才醒到的**（睡眠 / 關機隔天才開）→ 看性質決定**補做**或**跳過**，兩種都要**告知使用者**做了哪個。
6. 沒到點的留著、略過。不推外部通知：到點就當場做、當場說。
