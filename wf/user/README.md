# wf/user：使用者專屬區

← [AGENTS.md](../../AGENTS.md)｜詳細用法的規劃：[使用者專區-1122](../../proto8/thinking/2026-11/22/使用者專區-1122/README.md)

使用者 11-22：「開一個wf/user，這就是這個repo的使用者專屬區，並且可以去規劃相關的用法」

## 這裡是什麼

這是使用者自己的抽屜。agent 各有一格私有地盤 `wf/ws/<名>/`，這一格是人的：筆記、待辦、給 agent 的交代、草稿，都可以放這裡。

不要跟 `~/.aos/user/` 搞混。那是 aos 的「使用者專區」，是 agent 寄問題給使用者的信箱，題目會出現在全景頁上。兩邊的方向相反：

- `wf/user/`：人寫給自己、寫給 agent 的東西，進 git，換台會跟著走。
- `~/.aos/user/`：agent 寄給人的問題與人的回覆，只在這台機器上，不進 git。

## agent 在這裡能做什麼

**（規劃中，待使用者定）** 現在先用保守的預設：

- **可以讀**：使用者叫你看、或你做事需要時，直接讀。
- **不主動寫**：不新增、不修改、不整理、不改名、不刪這裡的檔，除非使用者叫你寫。叫了也只寫他指定的那個地方，寫的字標明是 agent 代寫的。
- **不改他的原話**：要引用或轉抄到別處（例如 `wf/workflows/common/user.md`）可以，原檔不動。
- **不把這裡當信箱用**：要問使用者的題目照舊寄使用者專區（`aos-user send`），不寫進這裡。
- **這只是規矩，不是牆**：跟 `wf/ws/` 的地盤規矩一樣，現在沒有任何程式擋。

## 要注意的事

- **這個 repo 是公開的**（GitHub 上是 public）。這裡的檔一旦 commit 又 push，任何人都看得到。不想公開的東西，先放 `wf/user/temp/`（任何一層的 `temp/` 都不進 git），以後怎麼放等規劃定案。
- 交件照舊走 `wf/tools/commit-request`，單檔超過 1 MB 會被擋。
- 放什麼、誰能寫、怎麼讓 agent 發現新東西、手機上怎麼看，都在上面那份規劃裡，等使用者拍板。
