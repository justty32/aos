## 建置與測試

```sh
python3 install.py                                    # 在 proto8 跑，編全家、裝進 proto8/bin
make -C proto8/cpp -j8 BINDIR=$AOS_HOME/bin aos-loop  # 開發時只重編這支
```

測試（建好之後；測試到 `proto8/bin/` 找執行檔）：`python3 -m unittest discover -s tests`——`tests/test_on_start_stop.py` 驗 `on_start`／`on_stop`：跑滿、身體 10、身體失敗、SIGTERM、ctl stop、`on_start` 失敗只 warning、`on_stop` 逾時、單子寫法、`on_timeout_ms` 壞、SIGKILL 不跑。
