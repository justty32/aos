## 建置與測試

```sh
cmake -B build && cmake --build build
```


獨立回歸測試（不加 ctest）：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 proto8/impls/aos-daemon/tests/test_ctl.py
PYTHONDONTWRITEBYTECODE=1 python3 proto8/impls/aos-daemon/tests/test_lifecycle.py
PYTHONDONTWRITEBYTECODE=1 python3 proto8/impls/aos-daemon/tests/test_poke.py
```

從 repo 根跑；test_poke 檢查 poke 的 ctl／mail／all 模式、喚醒延遲、連續 poke 不重啟子項及 pid 身分防護。控制模組、help、agent 提示與 prune 自檢／mtime 門檻／rm 共用路徑由 test_ctl 檢查，真 daemon、真控制工具、最小 fsm 與生命週期矩陣由 test_lifecycle 檢查。實測用 mktemp -d 的 scratch，不碰試驗場；程式印 evidence 目錄，matrix.json 保存結束碼、訊息、phase、reason 與是否下表。prune 五種列的實測另見 [daemon-prune](../../../thinking/2026-11/07/daemon-prune/README.md)。
