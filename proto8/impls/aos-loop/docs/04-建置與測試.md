## 建置與測試

```sh
cmake -B build && cmake --build build
```

測試（建好之後）：`python3 -m unittest discover -s tests`——`tests/test_on_start_stop.py` 驗 `on_start`／`on_stop`：跑滿、身體 10、身體失敗、SIGTERM、ctl stop、`on_start` 失敗只 warning、`on_stop` 逾時、單子寫法、`on_timeout_ms` 壞、SIGKILL 不跑。
