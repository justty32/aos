## 1. 一句話

proto8 ＝ **一個資料夾（世界），裡面每個子資料夾是一個計算任務：一份 `task.json`。有 `argv` 的會被跑；有 `capacity` 的是資源；有 `needs` 的要排到某個資源的格才跑。tick 每 N 秒照排序器寫的順序表起行程；排序器自己也是一個任務。** 任何人（含模型）用 `ls`、`cat`、改 JSON 就能看懂、操作整個世界。

跟第一版差在：排序的是「任務→資源的格」不是「先起哪個資料夾」；核心不認 `in/`／`out/`、不讀九軸、不等任務、不殺行程；需求也是一個資料夾；`belief.json`、`steps.json`、`priority` 從核心階段拿掉。

## 2. 世界長什麼樣（候選，§5 (a)(b) 答了才定）

```
world/
├── .aos/
│   ├── tick.json          {"round": 1832, "at": "…"}            核心寫
│   ├── order.json         排序器寫（形狀見 §3）；誰都能手寫一份
│   ├── rounds.jsonl       一回合一行：起了誰、誰退出、退出碼    核心寫
│   └── snapshots/1850.zip
├── scheduler/task.json    {"argv": ["python3", "run.py"]}        排序器：普通任務
├── scheduler/goal.md      7 行白話：這個世界照什麼排
├── painter-a/task.json    {"serves": "paint", "capacity": 4, "traits": {"good_at": ["人物"], "bad_at": ["風景"]}}
├── painter-b/task.json    {"serves": "paint", "capacity": 1, "traits": {"good_at": ["風景"]}}
├── brain/task.json        {"serves": "llm", "capacity": 1, "traits": {"model": "luna"}}
├── human/task.json        {"serves": "human", "capacity": 1}      你的座位
├── req-01/task.json       {"needs": "paint", "argv": ["python3", "../painter-a/draw.py"], "traits": {"want": "人物"}}
└── req-02/task.json       {"needs": "paint", "traits": {"want": "風景"}}
```

**核心只認四個鍵**：`argv`、`needs`、`serves`、`capacity`。其他（`traits`、九軸）核心一個字都不讀。
**狀態不存欄位、用檔案推**（另一條路的做法）：資料夾裡沒 `run.json`＝排隊；有 `run.json` 沒 `exit`＝跑著；有 `exit`＝做完。`ls` 一眼看出。

**九軸怎麼放**：`task.json` 可以有 `axes` 一段（`life`、`determinism`、`rerun`、`kill`、`state`、`io`、`reach`；見 九軸報告 §1（已刪：AI 產出，使用者 10-12 夜要求刪除）），**第一版沒有任何程式讀它**，寫了只是給人和模型看。`needs`／`serves`／`capacity` 就是第 4 軸（資源）的需求側與供給側。

## 3. 核心只做一件事：tick

```
每 N 秒（固定，不等任何人）：
  round += 1
  讀 .aos/order.json；它的 round 不是上一回合 → 當沒有
  有表：照表，每個資源的格有空就起排在前面的任務（cwd＝任務資料夾，環境 AOS_ROOT、AOS_ROUND、AOS_SLOT）
  沒表：有 argv 又沒 needs 的全起（排序器因此永遠會被起、漏了自己也復活）
  已經在跑的不重起；退出的記一行 rounds.jsonl
  看到 .aos/snapshot 旗標：這回合不起任何人、zip（排除 snapshots/）、刪旗標
  寫 tick.json
```

一支檔、純標準庫、**≤150 行**。不等、不殺、不讀軸、不認 `in/`／`out/`、stdout／stderr 繼承（任務要留日誌自己導）。
起行程 `start_new_session`；寫檔 → fsync → rename；暫存名 `.` 開頭、掃資料夾忽略 `.` 開頭（打撈 b-1、b-6、b-7）。

`order.json`（排序器實驗的形狀＋找洞的 `round`）：
```json
{"round": 1833,
 "assign": {"painter-a": ["req-03", "req-01"], "painter-b": ["req-02"], "brain": [], "human": []},
 "wait": ["req-04"]}
```

**任務之間怎麼講話**：核心沒有協定。寫檔、看檔，就這樣；慣例（檔名帶自己的名字、先寫 `.tmp` 再 rename、讀完就刪）寫在 README 給任務作者看，核心不管。
