## 用法例子

11-04 在 WSL 逐條跑過（11-05 輸出改英文、主要幾條重跑過；11-05 起掛上與管理收進 `ctl`，下面照新寫法；信箱模式 daemon、`demo/agent-fsm` 複製一份到 `../agents/bob` 加 `interfaces.json`、假腦；路徑縮短成 `…`）：

```
$ export AOS_DAEMON=…/d                       # daemon 的 $AOS_STACK（絕對路徑）
$ aos-agent ctl add --name bob ../agents/bob
…/d/procs/bob
$ aos-agent ctl add --name ann ../agents/bob      # 同一份定義再掛一隻
$ aos-agent ctl ls
bob          running  …/ws  queue 0
ann          running  …/ws  queue 0
$ export AOS_AGENT=bob                        # 或 source proto8/extras/agent/using-aos-agent.sh bob，之後直接 say／listen
$ aos-agent say 現在幾點 && aos-agent listen --timeout-s 30
000000000001.0179…
FAKE ANSWER to: 現在幾點 (tool said: 2026-11-04T06:09:02Z)
$ aos-agent ctl state
name    bob
state   running (daemon phase running)
ws      …/ws
stack   …/d/procs/bob
def     …/agents/bob
queue   0 queued
answer  FAKE ANSWER to: 現在幾點 (tool said: 2026-11-04T06:09:02Z)
$ printf '你好\n再一句\n' | aos-agent chat    # 提示符與開場在 stderr，stdout 只有回答
FAKE ANSWER to: 你好 (…)
FAKE ANSWER to: 再一句 (…)
$ aos-agent listen --last 1
== #4
> 按掉前
FAKE ANSWER to: 按掉前 (…)
$ aos-agent tools add clock2 …/lib/base/clock     # 11-05 起：只記差異（覆蓋層），見 03-tools覆蓋層
{"name": "clock2", "kind": "dir", "path": "…/lib/base/clock"}
(created overlay …/d/procs/bob/tools.json (it records only what this agent added or removed; later changes to the definition still show through; tools reset deletes it))
(note: this definition (…/agents/bob) is also used by ann; only bob's own copy (in its stack) changed, theirs did not (to change them all, edit the definition: aos-tools / aos-json))
$ aos-agent ctl state | grep '^tools'              # 11-05 feat-proto：有覆蓋層才多這行
tools   overlay: 1 added, 0 removed (+clock2)
$ AOS_STACK=…/d/procs/bob/tools/x/ aos-agent ctl who   # 11-05 feat-proto：這個 stack（或它底下的工具小格）是哪隻的
bob
$ aos-agent ctl who --stack …/d/procs/bob --json
{"name": "bob", "stack": "…/d/procs/bob", "ws": "…/ws", "def": "…/agents/bob"}
$ AOS_STACK=/tmp/elsewhere/ aos-agent ctl who
aos-agent: InstanceMissing /tmp/elsewhere is not inside the stack of any proc on the daemon table …/d
$ aos-agent tools reset
deleted overlay …/d/procs/bob/tools.json; back to the definition's …/agents/bob/tools.json only
$ aos-agent open
aos-agent: ScreenMissing bob does not declare the screen sub-interface (no screen); follow answers with aos-agent listen --follow --target bob
$ aos-agent ctl stop
stopped, stack kept (…/d/procs/bob); say still queues letters meanwhile, aos-agent ctl start --target bob to carry on
$ aos-agent say 停著時寄的
000000000005.0179…
(queued in …/d/procs/bob/queue/new/; nothing is running bob now; it is stopped on the daemon table (bob is stopped); start it: aos-agent ctl start --target bob)
$ aos-agent ctl start && aos-agent listen --timeout-s 30
started (same stack); 1 queued letters will be answered next
FAKE ANSWER to: 停著時寄的 (…)
$ aos-agent ctl sleep                             # 11-05 加（11-05 隊長實跑過）
asleep, stack kept (…/d/procs/bob); say still queues letters meanwhile, aos-agent ctl wake --target bob wakes it (it also wakes when the daemon restarts)
$ aos-agent ctl start
aos-agent: PhaseBad bob is sleeping; use wake (start only starts stopped ones)
$ aos-agent ctl wake
awake (same stack); 0 queued letters will be answered next
$ aos-agent ctl rm bob
removed bob (deleted stack …/d/procs/bob)
$ aos-agent ctl state
aos-agent: InstanceMissing bob is not on the daemon table (removed with rm, or it exited 0 and left the table; the stack may still be there: aos-agent ctl add with the same name to pick it up again)
```

`chat` 等答案時按 Ctrl-C：退 130、stderr 一行 `(that message was sent; read the answer later with aos-agent listen --target bob)`，agent 照答（測試第 8 案；上面 `listen --last 1` 的「按掉前」就是這樣寄出、之後才答的）。
