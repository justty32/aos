## 用法例子

11-04 在 WSL 逐條跑過（信箱模式 daemon、`demo/agent-fsm` 複製一份到 `../agents/bob` 加 `interfaces.json`、假腦；路徑縮短成 `…`）：

```
$ export AOS_DAEMON=…/d                       # daemon 的 $AOS_STACK（絕對路徑）
$ aos-agent add --name bob ../agents/bob
…/d/procs/bob
$ aos-agent add --name ann ../agents/bob      # 同一份定義再掛一隻
$ aos-agent ls
bob          running  …/ws  queue 0
ann          running  …/ws  queue 0
$ export AOS_AGENT=bob                        # 或 source proto8/extras/agent/using-aos-agent.sh bob，之後直接 say／listen
$ aos-agent say 現在幾點 && aos-agent listen --timeout-s 30
000000000001.0179…
FAKE ANSWER to: 現在幾點（tool said: 2026-11-04T06:09:02Z）
$ aos-agent state
名字   bob
狀態   running（daemon phase running）
工作區 …/ws
stack  …/d/procs/bob
定義   …/agents/bob
queue  0 封
回答   FAKE ANSWER to: 現在幾點（tool said: 2026-11-04T06:09:02Z）
$ printf '你好\n再一句\n' | aos-agent chat    # 提示符與開場在 stderr，stdout 只有回答
FAKE ANSWER to: 你好（…）
FAKE ANSWER to: 再一句（…）
$ aos-agent listen --last 1
== #4
> 按掉前
FAKE ANSWER to: 按掉前（…）
$ aos-agent tools add clock2 …/lib/base/clock
（建了副本 …/d/procs/bob/tools.json（從 …/agents/bob/tools.json 複製；之後不跟定義變，回去跟用 tools reset））
{"name": "clock2", "kind": "dir", "path": "…/lib/base/clock"}
（注意 ann 也用這份定義（…/agents/bob）；只改了 bob 的副本，它們不變（要一起變就改定義：aos-tools／aos-json））
$ aos-agent tools reset
刪了副本 …/d/procs/bob/tools.json，回去用定義的 …/agents/bob/tools.json
$ aos-agent open
aos-agent: ScreenMissing bob 沒宣告子介面 screen（沒有畫面）；看回答用 aos-agent listen --follow --target bob
$ aos-agent stop
停了，stack 留著（…/d/procs/bob）；這期間 say 的信照收，aos-agent start --target bob 接著答
$ aos-agent say 停著時寄的
000000000005.0179…
（已寄進 …/d/procs/bob/queue/new/；目前沒有程式在跑 bob，它在 daemon 表上停著（bob 是 stopped），叫它起來：aos-agent start --target bob）
$ aos-agent start && aos-agent listen --timeout-s 30
起來了（同一個 stack），queue 裡 1 封接著答
FAKE ANSWER to: 停著時寄的（…）
$ aos-agent rm bob
刪了 bob（stack …/d/procs/bob）
$ aos-agent state
aos-agent: InstanceMissing daemon 表上沒有 bob（rm 過、或自己結束下了表；stack 可能還在，要接著用就同名再 aos-agent add）
```

`chat` 等答案時按 Ctrl-C：退 130、stderr 一行「那句已寄出，回答之後用 aos-agent listen --target bob 看」，agent 照答（測試第 8 案；上面 `listen --last 1` 的「按掉前」就是這樣寄出、之後才答的）。
