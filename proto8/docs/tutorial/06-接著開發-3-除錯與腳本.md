# 06 接著開發（三）：用 aos-gdb 下斷點、用 Python 寫腳本

## 6.6 aos-gdb：停下來看它在幹嘛

**結論**：`aos-gdb -d .stack ann` 打開一個接上 ann 的 Python 提示字元，`a` 就是 ann。`a.bp.add.before_tool("shout")` 下斷點（回一個斷點物件，號碼 `b.id`），`a.bp.resume()` 等它停，停住時用 `a.look` 看，`a.bp.step()` 走一格、`a.bp.resume()` 繼續、`a.bp.pause()` 現在就停。像 gdb 的 break／continue／step。

### 斷點掛在 hook 上：骨架已經帶了

斷點是掛在 agent 的 **hook**（事件發生時順手跑的小程式，像 git hook）上的，所以定義要宣告 hook。骨架的 `defs.Agent(...)` 已經帶了 `hooks={}` 那行（第 04 章），ann 不用改什麼，直接下斷點。

- 那行被刪掉（或像 bob 那樣衍生時沒寫 `hooks=`）就會報 `HooksMissing`，錯誤行後面那句就是修法：`agent.py` 的 `defs.Agent(...)` 裡加回 `hooks={}`，重新編譯（不用重起 agent）。
- 想要範本那組現成的 hook——定時看信箱等——就寫 `hooks=std.hooks()`。

### 下斷點、看、走一格、繼續

```sh
aos-gdb -d .stack ann
```

在 `gdb>` 後面一行一行打（每個呼叫先印出它背後那條 `$ aos-agent …` 指令，下面省略大部分）：

```python
b = a.bp.add.before_tool("shout")
a.say("please shout"); a.bp.resume()
a.look.history(1)
a.bp
a.bp.step()
a.bp.rm(b); a.bp.resume()
a.listen()
```

- `b` 是斷點物件：`b.id` 是號碼（這裡是 1；刪了不再拿來用，下一個是 2），`b.kind` 是種類（`before_tool`），`b.fired` 這類屬性每次讀都重新查；刪掉之後再讀會報錯 `breakpoint 1: it is gone from ann (removed); …`。`a.bp.rm`／`set`／`get` 收 `b`，也收號碼 `1`；`a.bp.set(b, ...)` 也回斷點物件。指令與字條裡看到的名字是補零的 `gdb_0001`（號碼補到 4 位，斷點多了列出來照號碼排），`b.id` 照舊是 `1`。
- 停在 `before_tool`＝腦已經決定叫 shout、**工具還沒跑**（`a.look.history(1)` 看得到腦要叫什麼）。
- `a.bp.step()`＝讓這一格做完就停（工具真的跑了，停在下一格 think 前）。
- 拿掉斷點再 `resume()`：它把事做完、閒下來，`resume` 就回「沒停：閒著」，不會卡死。Ctrl-D 離開；斷點留在 agent 上，直到 `a.bp.rm(b)`／`a.bp.clear()`。
- 不想卡著等：`p = a.bp.resume(wait=False)`（`step`、`pause` 也一樣）送出就回；`p.is_done()` 問好了沒（`False`＝還在等它停），好了之後 `p.wait()` 拿到的跟不給 `wait=False` 時印的同一段（例 `stopped at breakpoint 2 (after_tool: shout), before think`）。不想等了就 `p.cancel()`：只是不再等，已經送出的放行或暫停不收回（`step` 送的暫停照樣讓它這一格做完就停）。
- 停在斷點時，表上照樣寫 `running`：daemon 不知道 gdb 的存在（刻意的）。要問停了沒，用 `a.bp.stopped()`、`a.bp.why()`。

<details><summary>其他種斷點、其他看法</summary>

- `a.bp.add.after_tool("x")`、`tool_error("x", times=2)`、`brain_failed("BrainFailed")`、`before_queue()`、`after_queue()`；直接打 `a.bp.add` 列出全部種類。
- 條件：`py="..."`（變數 `ev`）或 `sh="..."`（退 0＝算、退 10＝不算）。
- 觀察者：`a.bp.add.watch(py=lambda t: len(t.history(0)) > 6)`，另一支行程每 0.5 秒看一次，成立就停（晚一格）。
- `a.look.where()`、`a.look.queue()`、`a.look.stderr(20)`、`a.look.file("stage.txt")` 讀 stack 的檔。
- 全部說明在 `py/aos/apps/gdb/README.md`。
</details>

## 6.7 用 Python 寫腳本：`from aos.py import agent`

**結論**：一個呼叫＝一條指令。`agent.attach("ann", daemon=".stack")` 拿到遙控器 `a`，`a.say(...)`＝`aos-agent --target ann say ...`；失敗一律丟 `Failed`，帶 `e.code`。

寫 `ask.py`：

```python
"""ask ann one question from a Python script, through the aos.py entry"""
import os, sys
sys.path.insert(0, os.path.join(os.environ["AOS_HOME"], "lib"))
from aos.py import agent, daemon_ctl, Failed

a = agent.attach("ann", daemon=".stack")
letter = a.say("hello from python")
print("answer:", a.listen(letter=letter))
print("table:")
print(daemon_ctl.ls(daemon=".stack"))
try:
    agent.attach("nobody", daemon=".stack").say("hi")
except Failed as e:
    print("failed:", e.code, "|", e)
```

```sh
python3 ask.py
```


`listen(letter=...)`＝只等那一封的回答。`a.ctl.state(json=True)` 之類給 `json=True` 回解好的 dict。`aos-gdb` 裡的 `a` 跟這裡是同一種東西。
