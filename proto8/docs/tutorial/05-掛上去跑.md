# 05 掛上去跑

**結論**：`aos-agent ctl add` 把編譯好的那夾掛上板子；`say` 寄一句話、`listen` 等回答；`ctl state` 一眼看全身；`ctl stop`／`ctl start` 停了再接著跑，記憶留著。

## 掛上去、說一句話

```sh
aos-agent -d .stack ctl add --auto-restart -w . agents/ann
aos-daemon-ctl -d .stack ls
aos-agent -d .stack --target ann say hello
aos-agent -d .stack --target ann listen --timeout-s 20
```

```

llm	running	803252	-	-	-

FAKE ANSWER to: hello (tool said: 2026-11-19T06:56:29Z)
```

- `ctl add` 印的是 ann 的 stack（跑起來的樣子）在哪。
- `-d .stack`＝對哪塊板子；`-w .`＝ann 的工作區是整個專案夾（它的工具看檔從這裡算）；`--target ann`＝對哪一隻。
- `say` 印的是那封信的名字。假腦照規矩先叫 `peek_now_time` 看時間，再回 `FAKE ANSWER to: …`，所以括號裡是工具的回答。

## 停了再接著跑

```sh
aos-agent -d .stack ctl stop ann
aos-daemon-ctl -d .stack ls | grep ann
aos-agent -d .stack ctl start ann
aos-daemon-ctl -d .stack ls | grep ann
ls .stack/procs/ann
```


停著時 `say` 照樣收信，`start` 後接著答。stack 裡幾個常看的：`history.jsonl`（跟腦的對話）、`queue/`（信箱）、`stage.txt`（現在在狀態機哪一格）、`stderr.txt`（錯誤記錄）。

<details><summary>停的四種方式（aos-agent ctl --help 的表）</summary>

| 要什麼 | 指令 | 表上變成 | 回來用 |
|---|---|---|---|
| 這一輪做完再停 | `ctl stop` | stopped | `ctl start` |
| 現在就停 | `ctl sleep` | sleeping | `ctl wake`（板子重開也會叫醒） |
| 原地暫停（行程還活著） | `ctl pause` | running | `ctl resume` |
| 從表上拿掉 | `ctl rm` | （沒這列） | 再 `ctl add`（stack 留著，除非 `--purge`） |
</details>
