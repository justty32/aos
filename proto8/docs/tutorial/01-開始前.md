# 01 開始前

**結論**：只要兩件事——這台設好 `AOS_HOME`、`proto8` 裝過一次（`install.py`）。之後每開一個視窗先 `source` 一行。要起 eca_main（第 05b 章）另外要 `claude` 指令裝好、登入過。

## 要先有什麼

```sh
export AOS_HOME=~/repo/aos/proto8      # 一台設一次；寫進 ~/.zshrc 或 ~/.bashrc 就不用每次打
source $AOS_HOME/env.sh                 # 每個新視窗先打這行：把 aos 的指令放上 PATH、清掉別棵樹留下的 AOS_* 變數
ls $AOS_HOME/bin | head -4
which aos-exec
```

你會看到：

```
aos-agent
aos-asuser
aos-clock
aos-clock-register
~/repo/aos/proto8/bin/aos-exec
```

`which aos-exec` 找不到＝還沒裝：`python3 $AOS_HOME/install.py`（**未實跑**：寫教學時是在 `git archive` 抄出的複本裡裝的，沒在 repo 裡跑）。repo 更新過，也要重跑一次 `install.py` 才生效——執行期只認 `bin/`、`lib/`，不認原始碼 `py/`、`cpp/`。

## 整套的一張圖

用你的比喻：daemon 是**板子**（開機後一直在、管上面插的每樣東西），kernel 是插上去的**核心**（這裡是 llm kernel：agent 要想事情，就寄信給它），agent 是跑在上面的**應用程式**，`agent.py` 是它的 **C 原始碼**，編譯出來的那夾 json 是 **.o**。

| 比喻 | aos 裡叫 | 起它的程式 | 定義（原始碼／.o）放哪 | 跑起來的樣子放哪 |
|---|---|---|---|---|
| 板子 | 根 daemon | `aos-exec root` → `aos-daemon` | `root/` | `.stack/` |
| kernel | llm kernel | 掛在板子上的一台小 daemon | `llm/` | `.stack/procs/llm/` |
| 應用程式 | agent `ann` | `aos-loop` → `aos-fsm` | `agents/ann/` | `.stack/procs/ann/` |
| 應用程式（Claude Code 當腦） | agent `eca_main` | `aos-loop` → `aos-eca-turn` → `claude` | `agents/eca_main/` | `.stack/procs/eca_main/` |
| 編譯器 | `python3 agent.py --compile` | Python | `agents/ann/agent.py` | — |
| 標準庫 | `std`（隨 aos 發） | — | `$AOS_HOME/lib/` | — |
| gdb | `aos-gdb` | Python REPL | — | 斷點記在 `.stack/procs/ann/` |

「跑起來的樣子」叫 **stack**：像一支行程的記憶體加工作目錄，放它的記憶（`history.jsonl`）、信箱（`queue/`）、錯誤記錄（`stderr.txt`）。定義只讀，stack 才會變。

教學走完，資料夾長這樣（全部從一個空資料夾開始）：

```
~/code/aos-tut/
  root/              板子的定義（抄 daemon-root 範本）
  llm/               kernel 的定義（抄 llm-kernel 範本）
  agents/ann/        應用程式：agent.py（原始碼）＋編譯出的 json（.o）
  agents/bob/        從 ann 衍生的第二隻
  agents/eca_main/   Claude Code 當腦的那隻（抄 eca-claude 範本）
  tools/shout/       你自己寫的一支工具
  mylib/             你自己的一個小庫
  ask.py             用 Python 操作 agent 的腳本
  .stack/            板子開機後自己長出來（procs/llm、procs/ann、procs/bob、procs/eca_main 在裡面）
```

## 兩個視窗

- **視窗 A**：板子在這裡前景跑，會一直印狀態變化；Ctrl-C＝整塊板子關機。
- **視窗 B**：其餘指令都在這裡打。

兩個視窗都先做：

```sh
source $AOS_HOME/env.sh
mkdir -p ~/code/aos-tut && cd ~/code/aos-tut
```

<details><summary>為什麼不用 ~/aos-home、start-api</summary>

`templates/start-api` 一行抄好整棵樹（根＋llm kernel＋一隻 agent），適合「直接要一棵能跑的樹」；`templates/start-eca` 是 eca 版（根＋一隻 Claude Code 當腦的 agent）。這份教學照「板子 → kernel → 應用程式」一塊塊自己插，看得到每塊是什麼；兩者跑起來一樣。`~/aos-home` 是你平常用的那棵，教學不碰它。
</details>
