## 主題（10-15 使用者定：概念、規範、實作之外，再用主題分）

每個主題都有自己的概念、規範、實作；各分檔第一行寫出三者在哪。**主題不是層**（[C-74](../CONCEPTS/01-設計理念/02-C-51.md#分層10-22-使用者定)：層照誰依賴誰分）——基礎層＝資料夾程式與執行（核心 aos-exec）、inst、命令列與指示詞、loop、daemon、窗；標準庫＝組合子（fsm、tasks）；parts 是 agent 慣例層的約定；最上層＝agent、kernel；時空的時鐘 aos-clock 擱置、不歸層；設計理念、總則跨層。條號不重編。
