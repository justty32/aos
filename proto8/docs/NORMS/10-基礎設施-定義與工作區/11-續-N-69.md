  - **`_metainfo` 也是口子**（[thinking 11-12 metainfo](../../../thinking/2026-11/12/metainfo/README.md)）。使用者 11-12：「…或許可以這樣說，_metainfo就是一個天然的，蒐集那些同節點下散落的(aos體系中的)各種_*」；「_tooldef要不要搬進去，我覺得是可選的，就是說，我希望我們吃_tooldef的工具，都能支援_metainfo(不強制啦)，支援的方式就是他可以指定一個節點，然後他先看看有沒有_metainfo，有的話就先讀，然後再看看有沒有獨立出來的_tooldef，有的話就再讀。如果_metainfo內有tooldef，外面也有獨立出來的_tooldef，那就兩者合併，外面獨立出來的會覆蓋掉_metainfo內的。當然，這是不強制的啦，後續其他程式自己想怎麼做都可以，反正我們就是推薦這樣。」；「_metainfo這東西，他就是只活在概念與規範中，我們目前是不做單一程式去處理的，我們就是定下來，啊其他工具要不要支援，就看他們自己」；「index_view也要認_metainfo。」；「description 寫進 _metainfo <- 先不寫入。只有{}的_metainfo.json也算agent定義。」
    - **兩格**：節點的 `tooldef`、`index` **可以**寫在 `_metainfo` 裡（名字＝外面那個去掉 `_`，使用者「_index進去後就是index，去掉_」），跟特性平鋪並排；也可以照舊獨立放在外面（`_tooldef.json`、`_index.json`，JSON 物件的 `_tooldef`、`_index` 鍵）。現有的獨立檔不搬、不刪。值跟外面那份一樣：`tooldef`＝P-41 的工具說明物件；`index`＝`{名: {"description": …, "index": …}}`（`index` 選填，指到另一份 index 的路徑；檔內 `_index` 本身也可以是這種路徑字串），天然位置在被描述的節點上一層（寫法與門檻在 [knowledge/docs/01](../../../knowledge/docs/01-樹長怎樣與多庫.md)）。節點的正文 `_description.json`／`_description` 只放外面。
    - **推薦讀法**：給一個節點，先讀 `_metainfo` 那一格、再讀獨立那份，兩者合併，**獨立那份蓋過 `_metainfo` 裡的**。合併只有一層：`tooldef` 頂層鍵淺合併（同名頂層鍵整鍵以外面為準，`parameters` 整鍵換）；`index` 逐項整項覆蓋。兩處都沒有＝照那支工具原本「沒有」的處理。`_metainfo` 那處壞了只略過那處、提醒一句，照用獨立那份（使用者 11-12 「_metainfo.json 壞掉時，index_view 對那個資料夾不該直接報錯。」；tooldef 的工具比照）；只有壞掉的那處＝照那支工具原本「壞掉」的代號，句子指明哪一處；獨立那份壞了照它原本的處理。這是推薦、不強制。
    - **不做專門處理 `_metainfo` 的程式**，也不做共用讀取模組；各工具要不要支援看它自己。寫的一方不變（`tool_spec`、`tools_def` 照舊寫獨立的 `_tooldef.json`／`_tooldef`）。**照推薦讀法支援的**：`aos-tools`（登記與 `ls`／`get`／`call`：資料夾、JSON 檔、`檔.json#/指標` 都認）、`py/aos/tool_io.py`（工具啟動時讀自己夾的定義：argv 旗標轉型、`--help`）、`tools_def`（`check` 與分階段把裡面的 `tooldef` 也算「有」，兩處都有時多印一行 note）、`index_view`（`py/aos/index.py`：`_metainfo` 裡的 `index` 為底、疊上獨立的 `_index`，再給 `index` 參數就是三層，後面蓋前面）。定義樹（`defs`）不把「沒有 `_entry`、`_metainfo.json` 非空而且只有 `tooldef`／`index`」的夾當成定義；`{}` 或有其他任何鍵的照舊算定義。
    - **不進 `_metainfo` 的**：`_entry`（與 `_entry.json`）、`.env`——aos-exec 跑的時候要用（使用者「_entry確實不能搬進去」）；`_description`（使用者「description 寫進 _metainfo <- 先不寫入。」）；C++ 基礎層不讀 `_metainfo`。可執行檔工具只有 `--tooldef`。**裝不下的節點**（陣列、別人的 json、可執行檔）只有 `index` 延伸：寫在最近一個裝得下的上層節點的 index 裡，鍵寫相對路徑（`list/0`、`other.json#/key`）。
    - **模型看到的**：特性看不到；模型看到的只有 tooldef，支援的工具給的是合併後的那份。工具不藏 `_metainfo`（`ls`、`json_ls` 照實列，C-48）。
