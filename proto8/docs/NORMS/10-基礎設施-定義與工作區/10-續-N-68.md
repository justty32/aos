**他見的帳：`observed.jsonl` 與 `aos-observed` 介面**（11-07 evolve-design 概念一、三，使用者裁定 ltn-5「stack 照刪、刪前抄子帳」；impl-plan 批 3 實作）白話：叫的人在**自己的** stack 記實測，一個 stack 一份 `observed.jsonl`、只追加，共用模組是 `lib/observed.py`。stack 的 `interfaces.json` 宣告 `"aos-observed": {"file": "observed.jsonl"}`，上層只照這個宣告找帳，不猜路徑（C-52 可認公開介面）。一行四種 `kind`：`self`（首寫自動補：`def`、`ws`、`started_at`、設了才有的 `llm_kernel`）、`think`（問腦一次：`letter`、`endpoint`、`model`、`usage`、`elapsed_ms`）、`tool`（叫一次工具或函數：`name`、`def`、`stack`、`code`、`elapsed_ms`、`in_bytes`、`out_bytes`，有子帳時 `child`）、`cmd`（bash／run_python 在自己小格記的一條指令，`exit` 是內層結束碼）。`child` 是相對本 stack 的路徑，指向收掉子 agent 前抄下來的整棵帳（`<小格>/observed/<子名>/`，只抄宣告了 `aos-observed` 的夾）。**子帳位置的交接**：會生子 agent 的工具（thought（11-11 改名 `do_task`，[do-task-rename](../../../thinking/2026-11/11/do-task-rename.md)；**11-11 再註**：這支開小幫手的工具拿掉了，`do_task` 這個名字改給 save／load 版〔在自己的 history 留紀錄點、結束時換成總結〕，複製自己去做另成工具 `fork`，[fork-and-do-task](../../../thinking/2026-11/11/fork-and-do-task/README.md)）、subagent）抄完帳，在自己小格寫一個一次性檔 `.observed_child.json`（`{"child": "observed/<子名>"}`）；叫它的那層（agent-fsm 的 act、`observed.call()`）叫之前先刪舊的、叫完讀出來寫進 `tool` 行的 `child`、讀完就刪（`lib/observed_children.py`）。這個檔是工具與它的叫用者之間的約定，其他程式不讀。代定，[impl-plan 代定 8](../../../thinking/2026-11/07/impl-plan/代定.md)。
