- **P-47 外部 MCP server**（使用者 11-11 選項框裁 M1～M8，[new-tools](../../../thinking/2026-11/11/new-tools/README.md#裁定2026-11-11使用者選項框)、[03](../../../thinking/2026-11/11/new-tools/03-mcp-client.md)；11-12 三題「都按照推薦。」，[external-mcp](../../../thinking/2026-11/12/external-mcp/README.md#已裁的三題使用者-11-12都按照推薦)；fsm 那條 [08 施工結果](../../../thinking/2026-11/12/external-mcp/08-fsm施工結果.md)）：別人寫好的 MCP server 怎麼接進 aos。
  - **一台 server 一份 server 檔**：server 檔就是一份包檔，怎麼連那台（stdio＝怎麼起；http＝網址）、要哪幾支、金鑰檔在哪都寫在裡面，不另讀別的設定（M2「寫在包檔裡」）。工具預設全收、可以挑（M6「預設全收、可以挑」）。
  - **兩條路，寫在哪就走哪條**（M8「每台伺服器自己選」）：
    - **經 aos**：人跑 `aos-mcp-import` 連一次 server，把工具凍結進 server 檔，再把它疊進定義的 `tools.json`（`$override`）——每支外部工具變成一支普通的 aos 工具（M1「匯入成包、每支一支」），agent-fsm 與 eca 都用得到，hook 攔得到、`self_tools` 關得掉單支。說明匯入時凍結，server 改了要人跑 `sync` 看過差異才更新（M7「可選。默認用凍結的。」；每次重問那個選項還沒做）。每次叫起一台 server、叫完收掉（M4「先做每次呼叫起一台。後續我們可以做一個專門的常駐aos proc，有需求的話就指向他，將request丟給他。」）。
    - **CLI 自己接**（只有 eca）：`cli.json` 選填 `mcp_servers` 列 server 檔，claude／codex 自己連、自己列工具。這條凍結不了說明（M7 的例外，11-12 題二）；列了的那台整台免核准，想收緊在 server 檔寫 `only`（11-12 題三）。
    - 一台選一條：兩條同時掛，腦會看到同一支工具兩個名字。
  - **誰能加**：不另設限制（M5「不限制，有權限就能用。」）。
  - **金鑰**：只放使用者自己的 env 檔，server 檔只記位置（M3「env 檔，只記位置」）；起行程那一刻才讀，不寫進定義、設定、命令列、stack（[N-67](../../NORMS/10-基礎設施-定義與工作區/09-N-67.md) ⑦⑧）。
  - **stdio server 的環境與起點**：外部 stdio server 拿到起它那個行程的全部環境變數，不做白名單，風險自己承擔（使用者 11-12「1.不用，風險自己承擔。」）。stdio server 一律在 server 檔所在的資料夾起，`command` 與 `args` 的相對路徑都從那裡算，兩條路同一條規則；要工作區的路徑寫指示詞（使用者 11-12「2.這個我不是很清楚，如果你覺得要統一那就統一吧，我直覺上感覺OK，反正之後出事再說」，做法是代定 G13、可翻案，[08](../../../thinking/2026-11/12/external-mcp/08-fsm施工結果.md#代定隊長與寫手定的可翻案)）。
  - 欄位、旗標、錯誤代號與其他代定（X1～X22、G1～G13）見 [templates/docs/01 接外部 MCP server](../../../templates/docs/01-eca-claude.md#接外部-mcp-server11-12-external-mcp)、[aos-mcp-import](../../../cmd/aos-mcp-import/README.md)。
