## 四、題目與答案

- **P-11** **aos agent 的輸入是 queue**：`$AOS_STACK/queue/`，一個 [N-16](../../NORMS/05-基礎設施-窗/05-N-16.md) 的**有順序信箱**（同一個信箱也收無序的信，排在有序的後面），一封信＝一則訊息（`body` 是一則 OpenAI message 物件，照 P-41 history 的一行；不是 message 物件＝壞信，人一律經 `aos-agent say`〔P-42〕，衝突 5）。agent 認領（rename 進 `cur/`）、把 `body` 接進 `history.jsonl`，**接進那刻就把信收掉**（`aos-post done`；預設刪、要留紀錄進 `archive/`）——跟外部 coding agent「交給 CLI 就算完成」（P-12、P-43）同一個做法；信的內容已在 history，`cur/` 不再留一份。沒答完的那題看 history 尾巴是不是 user（加上 `stage.txt` 停在哪格），不看 `cur/`；`cur/` 只剩認領了還沒接進 history 的（例：idle 在兩步之間被殺）。**回答就是 history 最新那則 assistant，沒有別的回答通道**；檔案成品落在工作區：檔案這種結果＝工作區內容，沒有別的結果通道（C-65 工作區只放交辦的東西與成果；C-34 求值＝空間狀態的變化）。誰說、誰看、誰停見 P-42。範本 `templates/agent-fsm`。（使用者 10-30「這一層更接近訊息的queue概念」、看完規劃回「都照建議」，[10-29 agent-bob](../../../thinking/2026-10/29/agent-bob/04-頂層對八題的再想.md#決定10-30) 決定 33、35、36，[thinking 10-30 agent-lifecycle](../../../thinking/2026-10/30/agent-lifecycle/07-衝突.md#決定10-30) 條文草稿、衝突 1、4、5、方向題 1；接進就收：使用者 11-04 衝突 1 選「接進對話紀錄就收」，[thinking 11-04 loop-fsm-agent](../../../thinking/2026-11/04/loop-fsm-agent/04-衝突與方向題.md#決定11-04使用者)；`archive/`、無序的信：使用者 11-03 晚「aos-post這塊都按照建議。」，[thinking 11-03 aos-post](../../../thinking/2026-11/03/aos-post/README.md)；N-16；C-65 執行中的東西落 stack；C-56）
- **P-12** 一次收一批（queue 裡現有的全部、照順序），答完才收下一批；`cur/` 有沒做完的先接：資料夾是 `$AOS_STACK/queue/` 的 `new/`、`cur/`；`cur/` 裡已經有認領了還沒接進 history 的（例如 idle 在兩步之間被殺、人修好重跑），先接那些、再從 `new/` 拿新的，idle 也把 `cur/` 算成還有信。沒答完的那題看 history 尾巴與 `stage.txt`（P-11），所以 P-20 的「接著做同一題」對 think 失敗也成立。範本 `templates/agent-fsm` 一次收一批（queue 裡全部、照處理順序，think 一次答整批），信接進 history 就收（P-11）；思考中來的信留在 queue，答完回 idle 再收、跟下一批一起答（範本的預設；使用者 11-04 方向題 2 選「等答完回 idle 再收」，P-41）。外部 coding agent（P-43）是例外：信交給 CLI 就算完成、當場收掉，CLI 中途掛掉的那批不接著做、不自動重答，要重答由人再 say；`cur/` 只留認領了還沒交出去的；畫面開著的 claude 身走 CLI 的收件口時，交出去＝寫進收件口成功的那一刻，等回答時又來的信也當場收、不等這批答完（見 P-43）。（開頭＝使用者 11-13「cv-P12:A」，[convention-vs-agent-fsm](../../../thinking/2026-11/13/convention-vs-agent-fsm.md)；原型現狀；拍板點 1；queue：[thinking 10-30 agent-lifecycle](../../../thinking/2026-10/30/agent-lifecycle/07-衝突.md#決定10-30) 條文草稿；一次收一批、等答完再收：使用者 11-04「接下來是弄aos loop/fsm agent了」、看完規劃四題都選建議並說「記完就實作」，[thinking 11-04 loop-fsm-agent](../../../thinking/2026-11/04/loop-fsm-agent/02-跟-eca-對照.md#條文要加的註實作時一起11-04-註條文原字不動)、[04 衝突與方向題](../../../thinking/2026-11/04/loop-fsm-agent/04-衝突與方向題.md#決定11-04使用者)）
