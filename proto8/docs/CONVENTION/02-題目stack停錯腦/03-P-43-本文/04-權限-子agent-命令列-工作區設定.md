- **權限**：claude 開自己的內建工具（讀寫、改檔、指令、`Agent`、`Skill`），權限照 dontAsk 加白名單、不加任何全繞過權限的旗標；codex 用 `workspace-write` 沙箱、不唯讀（使用者 11-12「eca這塊，放寬claude，codex拿掉唯讀沙盒。」，[eca-file-tools](../../../../thinking/2026-11/12/eca-file-tools.md)；開 `Agent`、`Skill`：使用者 11-12「claude code cli自己本身有Task工具，可以的話幫我加入claude eca範本和定義中(Skill也加上)。」，[eca-task-subagent](../../../../thinking/2026-11/12/eca-task-subagent.md)）。旗標字面在 [templates/docs/01](../../../../templates/docs/01-eca-claude.md)。
- **子 agent 那台（`tools_sub`）**：`cli.json` 選填 `tools_sub`（寫法同 `tools`）＝給 CLI 子 agent 用的另一份 aos 登記檔；寫了，claude 的子 agent 只拿到這份（server 名 `aos_sub`），叫主 agent 那台（`aos`）會被擋；沒寫＝不切，子 agent 照 CLI 預設繼承全部（使用者 11-12「將aos mcp切成幾個，一個是給主agent用的，另一個是比較少功能的，給子agent用的」「去做吧」，[eca-task-subagent](../../../../thinking/2026-11/12/eca-task-subagent.md)）。範本那份只放不改東西、也不是講這隻 agent 自己的工具；`self_tools`／`aos-agent tools` 的加減只進主 agent 那台（代定、可翻案，[eca-task-subagent 代定](../../../../thinking/2026-11/12/eca-task-subagent.md#代定清單可翻案)）。**`tools_sub` 切兩台只在 claude 身有效**：codex 沒有只給子 agent 的 MCP 設定，codex 身寫了 `tools_sub`＝`CfgBad`（代定、可翻案，同上），現況 codex 的子 agent 跟主 agent 拿一樣的 aos 工具；要不要關掉 codex 的子 agent 或由 aos 擋，使用者還沒裁（[未定題](../../../../thinking/2026-11/12/eca-task-subagent.md#未定題要使用者裁)）。
- **外部 MCP server**：`cli.json` 選填 `mcp_servers`（列 server 檔）＝CLI 自己接外部 MCP，見 [P-47](../09-P-47.md)。
- **當工具叫、命令列**：同一個定義也可以當工具叫（`aos-eca-turn --one`：stdin `{"prompt"}` 進、stdout 出，P-41 工具契約；`lib/agent/claude`、`codex` 就是這個形；`--one` 也認 `--on-busy`、不收 `--on-empty`）。管畫面與 session 檔的命令列是 [aos-agent](../../../../cmd/aos-agent/README.md)：畫面 `aos-agent open`／`close`／`watch`（身體是 `cmd/aos-eca/bin/aos-eca-screen`，定義裡 `screen/` 子介面的入口）、掛／拔 `aos-agent ctl add`／`ctl rm`、說／看照 P-42（`say`／`listen`／`chat`）；工具、不算規範。（名字：使用者 10-31「aos eca turn」，[eca § 10-31 兩個改法](../../../../thinking/2026-10/30/eca/10-10-31-使用者原文-turn-的定義檔只認固.md#10-31-使用者想法turn-的兩個改法先記之後處理)、[§ 10-31 改名](../../../../thinking/2026-10/30/eca/11-10-31-使用者想法-turn-改名-把-tu.md#10-31-使用者想法turn-改名把-turn-讓出來先記之後處理)；落點與旗標是實作時代定、可翻案，[§ 實作時代定（10-31）](../../../../thinking/2026-10/30/eca/13-實作時代定.md#實作時代定10-31隊長與工人照原則定的細節可翻案)）
- **eca 照吃工作區設定**：eca 的 cwd＝工作區 `AOS_WS`；`CLAUDE.md`、`.claude/settings.json`（hooks、env）、agents／commands／skills 照吃，跟人在該資料夾開 Claude Code 一樣、不隔離。信任提問時送字可能丟信、`AOS_STACK` 等傳進 claude、同工作區讀得到彼此 history、WSL codex 預設模型不能用等狀況，使用者 11-04「.claude調查這塊。全部都是自己要承擔的風險」、不擋，見 [eca-claude-dir](../../../../thinking/2026-11/04/eca-claude-dir.md)。CLI 自己的工具（Bash、Write、Edit）由 CLI 自己的機制擋，aos 的 hook 不管（使用者 11-13「eca的bash工具，就是讓eca自己的機制擋」「現在就是勇敢一點，就全面開放」）：範本預設不帶任何擋的 hook；想擋的人把 Claude Code 的設定放工作區 `.claude/settings.json`，或放那隻 agent 的定義——`cli.json` 的 `settings`（選填，claude 身），aos 把它併進自己加的那一個 `--settings`（使用者 11-13「都按照建議」，[ops-agent-six-suggestions 第 1 題乙](../../../../thinking/2026-11/13/ops-agent-six-suggestions.md)）；`flags` 裡自己寫 `--settings`＝`CfgBad`。
