- **history 跟著 CLI 走**（使用者 11-12「連 aos 那邊的歷史也要一起清，eca就是要同步，eca就是會變成以他為主，aos體系要盡量跟上。codex要做畫面。然後aos-say/listen我希望也能支援這些」「chat也要」，[eca-slash](../../../../thinking/2026-11/12/eca-slash.md)）：CLI 的 slash 指令照 CLI 自己的做、aos 跟上——`/clear` 連 aos history 一起清（原文搬走、不刪），`/compact` 後 history 換成 CLI 壓縮後的摘要或留下的話（使用者裁「1.要。2.幫我貼進去。3.要動，希望能同步。4.不用」）；`aos-agent say`／`listen`／`chat` 送一封剛好是 `/clear`、`/compact`、`/status`、`/usage`、`/exit` 的信也有同樣效果，畫面開著時 `/clear`、`/compact` 直接打進畫面。CLI 自己的 `/goal` 經 say／chat 也用得起來，但跟 aos 的 `goal.json` 各管各的、不同步（使用者「aos goal工具本來就不會給eca用」）。agent-fsm 不做這些（裁定 4「不用」）。各指令怎麼判、等多久是代定，見 [templates/docs/01](../../../../templates/docs/01-eca-claude.md)。
- **工具**：`cli.json` 選填 `tools`＝aos-tools 的登記檔（相對路徑從 cli.json 的資料夾算；沒寫＝定義同層的 `tools.json` 疊上那隻 stack 的覆蓋層 `$AOS_STACK/tools.json`〔`aos-agent tools` 改的：一份普通登記檔，`"$override"` 指回定義那份，`tools` 只記加的與不要的（`"名": null`＝不算工具；使用者 11-10「null就是null，我們不做rm功能」，[aos-tools-cli 08](../../../../thinking/2026-11/10/aos-tools-cli/08-施工結果.md)），reset 刪覆蓋層，不是整份副本，P-15；使用者 11-05「tool差異我看了，我覺得OK。」，見 [portable-flow](../../../../thinking/2026-11/05/portable-flow/README.md)〕，有就接，使用者 11-03「如果cli.json沒有指定，那就去找默認的tools.json」；每題讀＝下一題生效）、選填 `tools_flags`（原樣給 aos-mcp）；接 aos-mcp 的 MCP 設定由 cli_session 每次起 CLI 前寫在 CLI 小格（claude `mcp.json`；codex 走 `-c`，對名為 aos 的 server 明寫帶 aos 工具要的 `AOS_*`、不整個環境照倒，並且只對 aos 這台免核准，codex 自帶工具的核准與沙箱不動：使用者 11-11 選「修」「aos 工具免核准」，[self-system 02](../../../../thinking/2026-11/11/self-system/02-施工結果與代定.md#已裁使用者-11-11-選項框)），`--ws`／`--stack` 是那隻實例的工作區與 stack，定義不被寫（P-15），[thinking 11-03 eca-tools](../../../../thinking/2026-11/03/eca-tools/README.md)。
- **eca 用自己的基礎工具，aos 只給專屬的**：CLI 自己就有、而且更順手的不給——檔案與 shell 基礎工具（look、change、delete〔含 trash〕、shell 四包）、subagent 一族、fork、do_task、goal、todo 都不掛；範本只掛 aos 專屬的（時鐘與小工具、events、self、def、mailbox、json、jsonx、index）。人要替 eca 設目標用 `aos-agent goal`，aos-eca-turn 照樣丟提醒（代定、可翻案，[11-11 goal](../../../../thinking/2026-11/11/goal/README.md)）。（使用者 11-11「subagent相關的工具都還是別給eca吧，eca本身就有他自己的了，甚至更順手。」「eca基本都有goal，所以goal不用給eca。todo也不用。」「然後eca通常都有自己的基礎工具如read/write/ls，那對它們更順手，也不用給」「eca不給fork。」「eca 不給 do_task」、11-12「可以先定這樣，然後trash也拿掉。」，[playground 04](../../../../thinking/2026-11/11/playground/04-修與第二輪實測.md)、[fork-and-do-task](../../../../thinking/2026-11/11/fork-and-do-task/README.md)、[eca-file-tools](../../../../thinking/2026-11/12/eca-file-tools.md)）
