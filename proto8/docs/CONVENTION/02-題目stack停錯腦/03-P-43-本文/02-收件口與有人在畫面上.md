- **畫面開著的 claude 身，信投進 CLI 的收件口**（使用者 11-13「1.a2a這個按照建議。馬上送，eca他會自己處理。say/chat被當成不是使用者打的，我覺得可以，真的有要的話，就自己open進去說。」，[eca-a2a-notify](../../../../thinking/2026-11/13/eca-a2a-notify.md)、[a2a-施工結果](../../../../thinking/2026-11/13/a2a-施工結果.md)）：不貼字，往那個 Claude Code session 自己的跨 session 訊息收件口寫（一條 Unix socket；程式裡這條路叫 `a2a`，它跟 a2a 協議的關係見 [P-48](../10-P-48.md)）。一封信一則訊息、各有署名：帶 `name` 的署寄件人，沒帶的（新信通知、時鐘信、goal 提醒、開場白、換台提要）署「aos通知中心」；內文照舊（N-43 的 `[aos] 種類: 內容`）。CLI 會跟模型說這則不是它的使用者打的；人要用使用者的身分說話，就 `aos-agent open` 進畫面自己打。**馬上送**：不看 `--on-busy`（只有拿不到小格 lock 時才看，見下一項），有人接在畫面上、畫面正在跑一輪都照投（CLI 手上那步工具做完就讀到），人在輸入框打到一半的字不會被動到；等回答時 queue 又來的信也當場認領、投進去，投出去才接進 history、收信，來的是 slash 指令就不加投、留到下一輪（等回答時也投、第一批有回執之後才加投是代定、可翻案，[a2a-施工結果 代定 5、7](../../../../thinking/2026-11/13/a2a-施工結果.md#代定可翻案)）。**投不進去就退回貼字**（`--on-busy` 照下一項）：沒記到收件口（由畫面的 hook 記進小格的 `a2a.json`；接上這條路之前就開著的畫面沒記、不自動換，重開畫面才換——使用者 11-13「都按照建議。」，[a2a-施工結果 第 4 題](../../../../thinking/2026-11/13/a2a-施工結果.md#要使用者裁的)）、連不上（stderr 一行 warning）、投了之後 CLI 閒著 30 秒沒有回執（那一批已經收信，貼的時候不再退讓；那個畫面之後照舊貼字，到它下一次開新 session——重開畫面、`/clear` 這類——才再試）。要關掉：`cli.json` 寫 `"a2a": false`。畫面沒開、codex 身、slash 指令、當工具叫（`--one`）不走這條路。
- **有人在畫面上**（貼字那條路，與拿不到小格 lock 時；走收件口的只有拿不到 lock 時才看這個開關，見上一項）：有人接在畫面上（`SessionBad`）不算錯：這次退 0 不動、信留在 `cur/`，下一次再試（`interval_ms`）；這個退讓是開關 `--on-busy yield|answer`（預設 `yield`）；`--on-busy answer`＝不退讓、照常答：lock 拿不到就等、有人接在畫面上照樣貼、畫面正在跑一輪就等它講完再貼（逾時照 `ReplyMissing`），**不是丟信**（使用者 10-31「關於有人在畫面上動他的話他就不嘗試丟棄這件事情我希望能夠有一個開關可選項」）。CLI 那層的錯照 P-20 停下等人（退 1）。不寫 trace（使用者 11-03「整個拿掉」，[thinking 11-03 trace](../../../../thinking/2026-11/03/trace.md)）。暫停粒度＝一批信（停不進它的工具呼叫中間，黑盒子的天然差異；aos-loop 包的是 aos-eca-turn、不是 CLI，衝突 5）；人在畫面上自己打的話不進 history（方向題 2，全貌看 `transcripts/`）。
