### 給人用的指令（11-06 註）

給人（或用 shell 工具的 agent）操作的指令，照 unix／linux 習慣、以人為主、要有 `--help`，見 [C-82](../../CONCEPTS/05-agent/02-agent-的工具與agent-就是一台狀態機.md)；使用者原話與裁定見 [human-cli](../../../thinking/2026-11/06/human-cli/README.md)。純 aos 函數的補充旗標見 [P-45](08-P-45.md)。

- ~~**短旗標共用表**：只准 `-h`＝`--help`、`-j`＝`--json`、`-t`＝`--target`、`-d`＝`--daemon`、`-n`＝`--name`、`-w`＝`--ws`、`-s`＝`--stack`、`-f`＝`--follow`、`-y`＝`--yes`；同名同義，每支只挑自己有的長旗標，沒列的不准開；help 旗標行寫成 `-j, --json`，`--timeout-s`／`--last` 先不給短名。已定（11-06，[裁定](../../../thinking/2026-11/06/human-cli/README.md)、[原表](../../../thinking/2026-11/06/human-cli/03-慣例草案.md)、[新兩題](../../../thinking/2026-11/06/human-cli/06-方向題.md)）。~~（11-07 改：sol 審查 #22，改成下句）
- **短旗標各支自定**：每支定自己的短名，可不同義；`aos_flags.SHORT` 與 aos-util 常用表只是預設，呼叫端可傳自己的對照表。help 旗標行寫成 `-j, --json`。（11-07 使用者裁定 sol 審查 #22）
- **不手寫 man**：`--help` 是一屏版、README 是長版；真要 man 就從 `--help` 生成。已定（11-06，[方向題 3](../../../thinking/2026-11/06/human-cli/06-方向題.md)）；現況沒有手寫 man，生成等需要才做。
- **不可逆子命令**：stdin 是終端才問 `[y/N]`，非終端不問、照做；一律提供 `--yes`／`-y` 跳過，答 No 退 0、加提醒行 `程式: warning: nothing done`。清單只有 `aos-agent ctl rm`、`aos-agent tools reset`、`aos-agent llm reset`；判準是「刪掉的東西別處沒有副本、而且沒有 `--dry-run`」，不含 aos-tools rm、aos-json del。已定（11-06，使用者「不可逆動作那塊，幫我加上--yes跳過」，[裁定](../../../thinking/2026-11/06/human-cli/README.md)、[新題 1](../../../thinking/2026-11/06/human-cli/06-方向題.md)）；答 No 的細節是 fable 代定，見 [H11](../../../thinking/2026-11/06/human-cli/03-慣例草案-續.md)；11-06 已實作（S8-0 `confirm` `8d400c74`、S8-b 三個子命令 `f6578378`）。
