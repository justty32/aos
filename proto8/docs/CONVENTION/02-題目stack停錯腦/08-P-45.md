## 十三、命令列（續）

- **P-45 純 aos 函數的旗標映射**（11-06 註；使用者 11-05 已定，[json-argv 原話](../../../thinking/2026-11/05/json-argv/README.md)、[07 回覆](../../../thinking/2026-11/05/json-argv/07-使用者回覆-11-05晚.md)）：純 aos 函數少用旗標，大多輸入走 stdin JSON；旗標提供人勉強能用的介面。使用者「旗標我覺得只是一種補充手段，用來簡單修改一些設定，而不是把所有東西都完全映射過去。」
  - 使用者原話「--xxx yyy，就可以映射到stdin json中的\"xxx\":\"yyy\"這樣」；`--xxx yyy` → `"xxx":"yyy"`，巢狀 `--a.b x` → `{"a":{"b":"x"}}`。現況 J1 從 `_tooldef.json` 的 schema 生旗標與 help、連字號換底線、按型別轉值，點路徑只換 stdin 的那一葉；鍵本身含 `.` 的從 stdin 給是 [apply-ideas 代定 6](../../../thinking/2026-11/06/apply-ideas/README.md)（可翻案），見 [J1 結果](../../../thinking/2026-11/05/json-argv/08-J1實作結果.md)。
  - 同鍵優先級是**旗標 ＞ stdin ＞ 環境變數**，重疊不報錯；使用者「關於優先級，就是旗標>stdin>環境變數，至於程式自己讀的設定檔，我們不管。」現況 J1 已有旗標覆蓋 stdin，環境變數當預設由各程式自理（[07](../../../thinking/2026-11/05/json-argv/07-使用者回覆-11-05晚.md)、[J1](../../../thinking/2026-11/05/json-argv/08-J1實作結果.md)）。
  - **只吃想吃的**：使用者「是的，不報錯，因爲json的格式自由，而我們只吃json裏面我們想吃的。」函數只取認得的 JSON 鍵，其餘忽略；現況 J1 保留 stdin 多鍵忽略，未知旗標仍報 `FlagUnknown`。J2 已讓 27 支 lib 工具的參數說明由同一份 `_tooldef.json` 生成、claude／codex 也走 tool_io（[07](../../../thinking/2026-11/05/json-argv/07-使用者回覆-11-05晚.md)、[J1](../../../thinking/2026-11/05/json-argv/08-J1實作結果.md)、[J2 結果](../../../thinking/2026-11/05/json-argv/09-J2實作結果.md)）。
