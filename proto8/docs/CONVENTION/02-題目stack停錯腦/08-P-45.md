## 十三、命令列（續）

- **P-45 純 aos 函數的旗標映射**（使用者 11-05 定，[json-argv 原話](../../../thinking/2026-11/05/json-argv/README.md)、[07 回覆](../../../thinking/2026-11/05/json-argv/07-使用者回覆-11-05晚.md)）：純 aos 函數少用旗標，大多輸入走 stdin JSON；旗標提供人勉強能用的介面。使用者「旗標我覺得只是一種補充手段，用來簡單修改一些設定，而不是把所有東西都完全映射過去。」
  - 使用者原話「--xxx yyy，就可以映射到stdin json中的\"xxx\":\"yyy\"這樣」；`--xxx yyy` → `"xxx":"yyy"`，巢狀 `--a.b x` → `{"a":{"b":"x"}}`。tool_io 從 `_tooldef.json` 的 schema 生旗標與 help、連字號換底線、按型別轉值，點路徑只換 stdin 的那一葉；鍵本身含 `.` 的從 stdin 給是 [apply-ideas 代定 6](../../../thinking/2026-11/06/apply-ideas/README.md)（可翻案），見 [J1 結果](../../../thinking/2026-11/05/json-argv/08-J1實作結果.md)。
  - 同鍵優先級是**旗標 ＞ stdin ＞ 環境變數**，重疊不報錯；使用者「關於優先級，就是旗標>stdin>環境變數，至於程式自己讀的設定檔，我們不管。」旗標覆蓋 stdin 由 tool_io 做，環境變數當預設由各程式自理（[07](../../../thinking/2026-11/05/json-argv/07-使用者回覆-11-05晚.md)、[J1](../../../thinking/2026-11/05/json-argv/08-J1實作結果.md)）。
  - **不認得的鍵報錯**：走 tool_io 的函數，stdin JSON 裡 schema 沒宣告的鍵＝`ArgumentsBad`（使用者 11-10「那就報錯」，[self-tools 04](../../../thinking/2026-11/10/self-tools/04-不認得的鍵報錯.md)）；schema 寫 `additionalProperties: true` 的物件、沒宣告 `properties` 的下層自由物件照收（自由物件那半是代定、可翻案，[self-tools 04](../../../thinking/2026-11/10/self-tools/04-不認得的鍵報錯.md#代定可翻)）；不認得的旗標報 `FlagUnknown`。J2 讓 lib 裡 27 支工具的參數說明由同一份 `_tooldef.json` 生成，claude／codex 也走 tool_io（[07](../../../thinking/2026-11/05/json-argv/07-使用者回覆-11-05晚.md)、[J1](../../../thinking/2026-11/05/json-argv/08-J1實作結果.md)、[J2 結果](../../../thinking/2026-11/05/json-argv/09-J2實作結果.md)）。
