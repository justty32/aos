## 系統自己改進函數（11-07）

- **C-84** **系統自己改進函數：改好的自動換上，變差自動退回，容忍短暫退步**（使用者 11-07，[thinking evolve-design](../../../thinking/2026-11/07/evolve-design/README.md)；C-42「自我迴圈改進的閉環」、C-22「能寫死的換成程式」的具體做法）：「自動換，退步自動退回。不過可以想想看神經網路這塊，有時候他的epoch會稍微退步，但下次又會進步補回來。」白話：一隻改進用的 agent（審視者）改出比較好的新版定義，就自動換上；換上後如果真的變差，就自動退回前一版。判斷「變差」不能太急，要像訓練神經網路那樣容許某一輪稍退、下一輪補回來。每次換上都留前一版，退回才有東西可退。容忍的具體判準（現在是「品質一次不合格就退；成本看換上後 3 個 case 的平均，貴超過一成才退」）是代定、可改，不是這條的一部分。已定；換上／退回的工具與盯的機制排在 evolve-design 落地步 11～13。

審視者自己動手寫程式的權限一步步放：起步只開處方（寫下要怎麼改、為什麼，施工交別人），做滿三個地點後放手讓它自己寫；換便宜模型那一招從第一天就自動（使用者 11-07：「按照推薦。但這就隨意。」）。改進這件事本身也是一個函數：審視者跑的過程一樣留紀錄，所以另一隻 agent 可以拿「審視者」當目標來改進它（使用者同一句：「甚至這個過程本身也可以記錄下來，讓另一個agent進行改進流程。」）。正在跑的定義（包括審視者自己）不會被換掉。已定；處方階段排在 evolve-design 落地步 12、放手寫程式排在步 15、第二層審視排在步 16。

產出格式對、意思卻錯的（語意錯），先交給高階模型當裁判打分；人抽查為輔，抽到的錯補進考題的期望答案，以後一般比對就擋得住（使用者 11-07：「一開始先用人去看，但最近我比較忙，可以先用高階模型。這個也很自由，也可以先設計一套模式，後續慢慢優化。」）。裁判跟其他比對器同一個介面，換人、換模型、換規則都只是換那一格。已定；裁判比對器範本排在 evolve-design 落地步 9。 **11-07 傍晚改讀**：arknights 裁定 4「重跑一致率只記錄、不當門檻」管的是產出條目要不要因一致率不夠被擋（照舊只記）；新版定義能不能換上是另一道門，可以看一致率。（11-07 使用者裁定，傍晚選項框 ltn-2 選推薦，[lift-to-norms](../../../thinking/2026-11/07/lift-to-norms/README.md)）

**改進者用 gpt 系的腦時**（11-07 晚審裁定 8 選推薦 C）：gpt 腦的改進者可以提案、自動實驗；改出來的新版要換上正式定義（進主線）前，由 Claude 審過。出處 [晚審 04b 第 8 題](../../../../wf/workflows/refactor/reports/2026-11-07-晚審/04b-要使用者裁定-續.md)。已定；怎麼接進換上工具，實作待排。

**判準本身也能被改進，審視者可以一層層疊**（11-07 傍晚使用者裁定；evo-B 選「審視者自己的單位成本連續幾輪沒降、或 spent 比它省下來的還多時才跑」、evo-C 選「從過去真實的 review.json 挑轉正的那幾輪當好答案」，tool-evolve 的階段、門檻與確定性報法 te-1／te-5／te-6 都選推薦）。備註原話：evo-B「如果審視者一直都做的不錯，那就沒必要改進他。這套判斷標準本身也是靈活的，可以被改進的。想想看，審視者，審視"審視者"的審視者，這樣一層層堆疊，每層之間的標準都可以靈活變換。」；evo-C「兩者都可以。這套標準本身也可以靈活變換與改進。」；te-1「這個"階段"，本身也可以被改進和變換。」；te-5「這套本身也是靈活且可以改進的。有需要的話，metainfo評估中可以加入"人類可理解性"，這需要使用者(也就是我)參與評分。」；te-6「也是靈活且可改進。」；之後補一句：「很多東西都可以靈活改進，所以後面我就不寫了」。白話：什麼時候改、走到哪個階段、連續幾個 case 才算數、好答案從哪來、怎麼評分，這些判準本身也是可以被改的東西，不是寫死的規則；條文和設計裡寫到的數字與階段（三個地點、連續 2 個 case、0.8～1.25 算準、工具權限三段等）都是起步值。審視者做得好就不必去改它；做不好時，可以由上一層審視者改，上一層又可以被再上一層改，每層用的標準都可以不同。好答案可以從過去真實紀錄裡挑，也可以由人或高階模型手寫，兩種都行。需要時，評估可以加「人類可理解性」一項，這項要使用者本人參與評分。出處 [kb-ideas 想法 15](../../../thinking/2026-11/07/kb-ideas/README.md)、[evolve-design](../../../thinking/2026-11/07/evolve-design/README.md)、[tool-evolve](../../../thinking/2026-11/07/tool-evolve/README.md)。
