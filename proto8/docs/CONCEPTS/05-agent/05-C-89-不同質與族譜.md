## 不同質 agent 與族譜

<a id="c-89"></a>
- **C-89** **不同質 agent：定義就是身分，同不同質看簽名，族譜＝資料夾樹＋出生時寫一次的血緣紀錄，狀態看所在位置**（使用者 11-07 想法 8：「我希望這輪增加一百個agent，並且每個都不要太同質化，不要只有prompt相似，要有獨特工具，獨特設定與記憶。」；一百個是「方向，不湊數」；傍晚選項框 ad-1～ad-5 選推薦，[agent-diversity](../../../thinking/2026-11/07/agent-diversity/README.md)）。檔名與資料夾名見 [NORMS 命名續](../../NORMS/命名-續-概念搬來的檔名.md)。
  1. **定義就是身分**（C-46）：比對、目錄、族譜都以定義資料夾為單位；daemon 表上的實例、執行時的覆蓋層、呼叫方逐題指定的腦，都不算新 agent。
  2. **同不同質只看簽名，差一軸就算不同**（ad-2；晚審第 10 題備註「以ad-2爲準」）；prompt（system 文字）與「誰叫它」都不算。**簽名比工具與腦；有宣告記憶根的定義，再多比記憶**（使用者 11-14 專區 U5 選 decl「比工具、腦；有宣告記憶根的再比記憶」，專區回覆 reply_id `64cd11aaf4131c02`，ok-pilot 經手）；C-19 那句簽名照這條讀。現行定義檢查（`py/tools/aos/defs` 的 dup）只比工具與腦；以後有定義宣告了記憶根，dup 要多比這一軸（程式現在還沒有這一段）。只有有腦的定義進不同質檢查，腳本與 kernel 定義只在樹裡、有 README 與血緣紀錄（ad-1）。
  3. **同質是缺陷，不是合併令**：撞簽名的，建議其中一隻長出自己的工具或記憶；要證明職責相同（同一份 case、同一道門都過）才合併。
  4. **族譜＝資料夾樹＋出生時寫一次的血緣紀錄**（`agent_def new` 寫，[C-42](01-續-C-42.md)），之後不回寫；樹的層次是類別，血緣紀錄是血緣。它是原始碼的出處（像 git 的 fork 紀錄），不是執行時的上層：aos-exec、fsm、agent 都不讀它（C-46「沒有 `parent` 鏈」照舊）；執行時誰生的誰不另記（C-42）。
  5. **狀態看所在位置**：在可用的定義樹裡＝可用（叫到才起，躺著就是 sleep）；搬進同深度的退休樹＝退休。退休由隊長按、`git mv`、不刪，復職就搬回來；描述抽屜不加狀態欄（實測不回寫）。
  - **誰生**（ad-3）：前三個地點由隊長生，之後審視者可以自動生新定義；生之前先查有沒有簽名全同的現成定義，有就不生、改用它。退休永遠由隊長按。生新定義不算「函數改自己」（[C-84](03-C-84.md)）。
  - **放哪**（ad-5）：演化出的定義樹放工作區，備註原話：「可以定期將定義提取出來。之後其他工作，比如我要拆另一個遊戲時，可以運用。」
