# C-54 命名方法（R1～R13，10-23 晚；R13 10-30 夜）

**來源**：使用者 10-23 晚提的方法（「關於命名規則這塊，我想嘗試一些新的概念，在現有的原則與規則上添加一些能讓人更快看懂的...算小技巧吧」，全文見 [thinking](../../../thinking/2026-10/23/naming-method/01-使用者原文.md#使用者原文整理版)），「先試試看，不要急着寫進去」；問「這種命名規則，那些unix年代的老人，或是linux的開發者，有慣例嗎」→「好，幫我去查，順便再幫我弄一套，結合了這些的新命名規則」；八題選完後「寫進去吧」。

骨幹是使用者的六步：**一句話說程式做什麼 → 要加功能先一句話說那個功能 → 替檔／主題取名 → 列格子、每格一句白話 → 從白話挑字造名 → 簡化**。下面 12 條是這六步加上 Unix／Linux 老慣例。C-54 的其他規則（一詞一義、縮寫表、主題在前、小寫底線、複數只加 s、錯誤代號四種、例外）見 C-54，這裡不重寫，只標出它們在哪一步用。（**11-06 註**：錯誤代號結尾 11-04 加 `…Exists`、11-06 使用者選項框加 `…Rejected`，「四種」照六種讀，見 C-54 錯誤代號那點的加註與 R10。）（**11-06 註**：使用者 11-06 選項框「寫進 C-54 (Recommended)」加 R14，見 [03-R14](C-54-命名方法/03-R14.md)；標題的「R1～R13」照「R1～R14」讀。）
