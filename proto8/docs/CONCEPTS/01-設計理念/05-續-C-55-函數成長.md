## 布局成長（續）：函數成長（10-24 使用者說）

- **C-55 函數成長：函數也照這套長**（使用者 10-24「當一個函數太過膨大，或是其特性達到某個點之後，就會將其弄成資料夾，底下是子函數」，規劃後「我現在沒空管這些小事，都按建議做」；[thinking 10-24 函數成長](../../../thinking/2026-10/24/fn-grow/README.md)）。檔案那邊仍以 [wf/STRUCTURE.md](../../../../wf/STRUCTURE.md) 為唯一出處；這段講的是「函數」＝aos-exec 跑得動的一個東西（C-73 那四種）怎麼長。分六級：

  | 級 | 長相 | 呼叫方那格寫 |
  |---|---|---|
  | 0 內嵌 | 單子直接寫在呼叫方那格（fsm 格、loop 的 `exec`） | `{"argv": [...], ...}` |
  | 1 同檔具名 | 同一份設定檔裡另一個 key | `"fsm.json#/fns/x"` |
  | 2 單檔 | 旁邊一份 `x.json`，內容就是那張單子（不包 `_entry`） | `"x"`（不帶 `.json`） |
  | 3 資料夾、只有入口 | `x/_entry`（同一張單子） | `"x"` |
  | 4 資料夾、不只入口 | `x/_entry`＋只有它用的腳本、prompt、`.env`、`_metainfo.json` | `"x"` |
  | 5 資料夾裡有子函數 | `x/` 自己有 loop／fsm，各格是它的子函數、各自從第 0 級長 | `"x"` |

  - **呼叫方從第 2 級起只寫名字**：aos-exec 找不到 `x` 會補 `.json`、`x` 是資料夾就走進去（N-61），所以 2 → 5 呼叫方一個字不用改。同一份 JSON 要放子函數時，才照 C-72 包成 `{"_entry": 單子, "子": …}`。
  - **往上長的訊號**（任一條成立就該看一下，都不是硬上限）：門檻沿用 STRUCTURE 的數字（1 KB、300 行、8 KB、觸發 B），加函數才有的——同一份檔 ≥ 2 格放一模一樣的單子（→ 1）；被 ≥ 2 份檔叫、或要讓人單獨看它（→ 2）；有了只有它用的非 JSON 檔、或跨呼叫要自己保管東西（→ 3、4）；裡面有 ≥ 2 個要跑的步驟、要能暫停續跑（`_metainfo` 的 `interrupt` 是 `resumable`）、估時 `cost.time_ms` ≥ 60000（N-68）（→ 5）。訊號都沒了就往回併一級；縮回只在整理時手動做，不自動。
  - **搬了跑起來要一樣**：先寫新的、最後才改呼叫方（N-05）；只改位置相關的值，讓它們指回原處——單子的 `cwd`（沒寫＝入口所在的資料夾，搬進資料夾就補 `".."`）、相對的 `$ref` 檔名（`"#/…"` 補上原檔名）、`{"$env": "AOS_CD", "$path": …}`；伴隨檔搬進去時，argv 裡那一項改成 `{"$env": "AOS_CD", "$path": "/檔名"}`。單子用了 `$env AOS_CF`／`AOS_CO` 的不搬（每跳重設，N-57）。錯誤訊息裡的「誰」會跟著變（只有字，結束碼一樣）。
  - **`_metainfo` 跟著單子走**：搬的時候整張單子跟著走，單子裡的 `_metainfo` key 也在裡面；長到資料夾以後，讀資料夾的人只看 `_metainfo.json`（[N-69](../../NORMS/10-基礎設施-定義與工作區/11-N-69.md)），要給讀者看就自己拆成檔。
  - **能力也分階段長**：一支 aos 函數理想上是一步步補出來的——① 資料夾＋`_entry.json`＋旁邊一支小腳本＝aos-exec 跑得動 ② 補 `_metainfo.json` ③ 補 `_tooldef.json`＝腦能當工具叫；三樣也可以是同一份 JSON（或 `檔.json#/指標` 指的物件）裡的 `_entry`、`_metainfo`、`_tooldef` 三個鍵（C-72）。幫腦造工具的 `tools_def` 照這個流程走。使用者 11-10 深夜（頂層把他的例子複述成上面三步後）：「Hmmm，應該說，這些是我理想中的一個，然後tools_def之後應該要能配合這個流程」；「可以的話，或許，你知道的，json跟資料夾很像，所以或許，也可以在指定json檔案，或指定json object中(透過路徑#/)。添加_entry,_metainfo,_tooldef這些key」（[tools-def](../../../thinking/2026-11/10/tools-def/README.md)）。
  - 原型 [aos-grow](../../../cmd/aos-grow/README.md)（Python）：`up --to file|dir [--take PATH]` 長一級、`down` 縮一級，`--dry-run` 先印不寫；不保證一樣的地方列在它的說明與 thinking。
