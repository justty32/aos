# 基礎設施

子主題：inst、loop、daemon、窗、命令列、指示詞與路徑、組合子（tasks、fsm）、資料夾程式、工作區與 stack。窗、命令列、指示詞與路徑沒有專屬的概念條，只有規範（見上）。

> 註：「基礎設施」是主題名（照內容分），不是層。分層（[C-74](01-設計理念/02-C-51.md#分層10-22-使用者定)）裡組合子 tasks、fsm 屬**標準庫**，其餘子主題（inst、loop、daemon、窗、命令列、指示詞與路徑、資料夾程式、工作區與 stack）屬**基礎層**（aos-exec 是其中的核心）。
