## 分層（每層只依賴下層）

```
<agent>/                   最上層：agent 本身（也是函數；例 templates/agents/agent-fsm）
  tools/<名> ─捷徑─▶ lib/tools/<層>/<名>/   引用，不複製（見下「怎麼引用」）；lib/ 是 install.py 從 py/ 抄的
py/tools/agent/            高層：裡面是一整隻 agent（或外部 agent CLI）的工具（claude、codex…）；它們的共用模組 agent_tool.py、cli_session.py 與 cli_*.py 在 py/aos/agentlib/、介面宣告讀法 declared_files.py 在 py/aos/（S3 前在 agent/）
py/tools/aos/              中層：動 aos 自己東西的工具（jsonx_*〔認 $ref／$env 的 JSON 工具〕、框架站 kernel）
py/tools/base/             底層原語：檔案、資料夾、JSON、行程（bash）、小工具——Linux＋Python 標準庫（不叫 aos 的程式；例外 json_*：讀寫交給 aos-json，寫入帶 --raw）、只碰 $AOS_WS
py/aos/json.py             json 工具一族（base 的 json_*、aos 的 jsonx_*）共用的程式，各夾 _entry 只是殼
py/aos/file_walk.py            grep、glob 共用的走樹與檔名樣式（隱藏名、.gitignore、預算）
py/aos/hook_run.py             hook 的共用引擎，只做一件事：照名字起 handler（寫 <stack>/hookeds/<名>/event.json、用 aos-exec 跑、timeout_ms）、交回各自的退出碼與 stdout；aos-hook fire、agent 的 py/aos/agentlib/hooks.py 與框架站的 py/tools/aos/kernel/hooks.py 都用它（攔不攔、改哪些鍵、condition、失敗怎麼算留在各自那份）；只 import aos.hook_lists、aos.directive_value
py/aos/py/fn.py                寫工具（與 hook）的公開名字 fn（@fn.tool、@fn.hook、fn.param、fn.fail、fn.block、fn.main）；只轉出，本體在下面兩支
py/aos/fn_mark.py              裝飾器的記號，從函數（簽名、型別註記、docstring）與明寫的算出說明書（明寫的贏、逐參數），組裝交給 tool_spec
py/aos/fn_run.py               fn.main：工具的四個旗標與執行（接在 tool_io 上：驗參數、叫函數）、hook 的回話（None／dict／fn.block 退 10）
py/aos/fn_spec.py              編譯時把 agent.py 的 @fn.tool／@fn.hook 函數抽成定義夾的 fn/<名>.py（找外面的名字用 symtable）
py/aos/agent_spec_hooks.py     agent_spec 的 hook 那塊（hooks=… 怎麼疊、驗、算出被勾清單 hookeds.json；收函數 hook）
py/aos/tool_spec.py            說明書的內部零件：參數、_tooldef／_metainfo 怎麼組與驗、寫進位置、掃 fn.fail 代號（fn 與 tools_def 用）
py/aos/spec_base.py            tool_spec 與 agent_spec 共用的底：SpecBad／DefBad、推名字、--compile／--dry-run 小旗標殼、寫檔後端（暫存檔＋改名；程式檔、defs.extern 的連結）
py/aos/tool_io.py              最底：每個工具共用的開頭（--help、Ctrl-C、錯誤行／提醒行、讀 stdin＋旗標映射與最小型別檢查、查工作區、訊息裡的路徑 place／os_reason）——不是工具，是共用模組
cpp/                       基礎層與標準庫（C-74）：aos-exec 把工具叫起來，loop／fsm 跑 agent
```

aos 套件裡的 `aos.flags` 系列是給指令與範本用的，lib 的工具（`tools/` 的 `base/`、`aos/`、`agent/` 底下）不 import `aos.flags`；`cmd`／範本需要工具共用功能時可以依賴 `lib`（K-5）。

層名只是資料夾名，不進工具名；還沒有工具的層不先建空資料夾（STRUCTURE：不預先建空檔）。
