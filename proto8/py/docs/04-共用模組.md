# aos 套件裡給指令與範本用的共用模組（py/aos/，裝好是 lib/aos/；11-18 S4 前平鋪在 py/ 頂層）

← [lib](../../README.md)｜用它的：[cmd](05-commands.md)、[templates](../../templates/README.md)、[kernel](../../templates/kernels/README.md)

不是指令、不進 PATH，一律 `from aos import …`（例 `from aos import flags as aos_flags`）。指令（`bin/` 裡 `install.py` 照 `py/entries.json` 生的入口）把同一個家的 `lib/` 放上 `sys.path` 再跑 `aos.apps.<名>` 的模組；家外的程式（抄出去的範本格、工具）找 lib 只經 `$AOS_HOME/lib`，沒設 `AOS_HOME` 就報 `HomeMissing`。

**給人用的那一層在 `aos.py`**（[入口](../aos/py/__init__.py)，線 aos-pylib-cut-1119；使用者 11-19 裁定見 [aos-pylib-1119/07](../../thinking/2026-11/19/aos-pylib-1119/07-使用者裁定.md)）：`from aos.py import agent, daemon_ctl, std`、`from aos.py.agent import defs`、`from aos.py import fn`（函數當工具／hook：`@fn.tool`、`@fn.hook`、`fn.main`；本體 `aos.fn_mark`、`aos.fn_run`，說明書零件 `aos.tool_spec`；11-20 線 aos-pylib-k1-1120）。這個夾裡的＝公開的，夾外的 `aos.*`＝內部零件（這頁其餘的表）。`agent`、`daemon_ctl` 是 `aos-agent`、`aos-daemon-ctl` 的薄殼：一條通則（`aos-agent --daemon D --target N X Y --flag v ARG` ↔ `agent.attach(N, daemon=D).X.Y(ARG, flag=v)`）由通用代理 `aos.py._shell` 實作，一個呼叫＝一條指令，指令以後加的子指令自動有；`a.bp`（斷點）與 `a.look`（讀 stack 的檔）是僅有的兩個延伸，本體在 `aos.gdb`。`defs`＝`aos.agent_spec`（`defs.Agent` 的本體在 `aos.agent_spec_agent`）、`std`＝`aos.agent_spec_lib.std` 的轉匯出（檔不搬）。模組名規則：指令 `aos-X-Y` ↔ `aos.py.X_Y`；其他指令的模組第二次有人要才加。

分層：`aos.flags` 系列是給指令與範本用的，lib 的工具（`tools/` 的 `base/`、`aos/`、`agent/` 底下）不 import `aos.flags`。CLI 對話與介面宣告的共用模組在 `aos.agentlib`（[索引](03-索引-agent等.md)）：`cli_session.py` 與 `cli_*.py`；介面宣告讀法 `aos.declared_files` 在 `aos` 頂層（K-5）。

兩鐘函式只有 `py/aos/tool_io.py` 一份（`aos_ws` 的 `deadline_after`、`expired` 包它：缺檔提醒開頭用 `argv[0]` 檔名、錯丟 `aos_ws.Error`），跟 `aos-util` 同義：`AOS_CLOCK` 沒設或空就沒有時鐘；指到缺檔時，每行程每路徑印一次英文 warning，仍當 0、不建檔；空檔當 0。

`daemon_ctl.ask(d, body, timeout_s=None, direct=False, *, timeout_cycles=None)` 與 `ping(d, timeout_s=None, direct=False, *, timeout_cycles=None)`：兩種期限擇一；兩者都省略仍等 3 秒，原有 positional 秒數與 `direct` 位置不變。`timeout_cycles` 必須是 signed 64-bit 範圍內的正整數（不收 bool）；並給秒數、非法格數＝`Fail("ArgumentsBad", ...)`，時鐘內容壞了＝`Fail("ClockBad", ...)`，寄信前先驗時鐘期限。時鐘期限共用 `aos_ws.deadline_after`／`expired`，停鐘就繼續等、沒設時鐘才按 `AOS_CLOCK_INTERVAL` 退牆鐘；秒數永遠看單調鐘。`aos-daemon-ctl` 與 `aos-agent ctl` 的人用 `--timeout-s`、預設與行為不變。
