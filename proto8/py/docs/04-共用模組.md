# aos 套件裡給指令與範本用的共用模組（py/aos/，裝好是 lib/aos/；11-18 S4 前平鋪在 py/ 頂層）

← [lib](../../README.md)｜用它的：[cmd](05-commands.md)、[templates](../../templates/README.md)、[kernel](../../templates/kernel/README.md)

不是指令、不進 PATH，一律 `from aos import …`（例 `from aos import flags as aos_flags`）。指令（`bin/` 裡 `install.py` 照 `py/entries.json` 生的入口）把同一個家的 `lib/` 放上 `sys.path` 再跑 `aos.apps.<名>` 的模組；家外的程式（抄出去的範本格、工具）找 lib 只經 `$AOS_HOME/lib`，沒設 `AOS_HOME` 就報 `HomeMissing`。

分層：`aos.flags` 系列是給指令與範本用的，lib 的工具（`tools/` 的 `base/`、`aos/`、`agent/` 底下）不 import `aos.flags`。CLI 對話與介面宣告的共用模組在 `aos.agentlib`（[索引](03-索引-agent等.md)）：`cli_session.py` 與 `cli_*.py`；介面宣告讀法 `aos.declared_files` 在 `aos` 頂層（K-5）。

兩鐘函式只有 `py/aos/tool_io.py` 一份（`aos_ws` 的 `deadline_after`、`expired` 包它：缺檔提醒開頭用 `argv[0]` 檔名、錯丟 `aos_ws.Error`），跟 `aos-util` 同義：`AOS_CLOCK` 沒設或空就沒有時鐘；指到缺檔時，每行程每路徑印一次英文 warning，仍當 0、不建檔；空檔當 0。

| 模組 | 是什麼 | 誰 import 它 |
|---|---|---|
| `aos/flags.py` | 命令列旗標解析 `parse` 與三扇門小函式（`die`、`warn`、`run`…），常用預設短名表 `SHORT`（`parse(…, short=…)` 可傳自己的短名對照，各支可不同義）、不可逆動作前的確認 `confirm`；切 token 包 `py/aos/tool_io.py` 的 `tokenize_flags`（照上面的順序找共用模組），說明在 [05-commands/02](05-commands/02-aos-clock與已定值.md) | `py/aos/apps/` 的每支 Python 指令、templates/agent-fsm 的格、kernel/llm-kernel 的 fake_slow |
| `aos/ws.py` | 放一則訊息、等答案、讀 stack 的共用小零件；叫 aos-post、stderr 照轉的包裝（`run_post`；`aos_clock_register.send`、aos-mailbox 要收 stderr、設 timeout，各自叫） | aos-agent、aos-eca-turn（本體 `py/aos/apps/eca/`）、daemon_ctl |
| `aos/daemon_ctl/` | 找 daemon、讀表、寄信等回信的共用套件（`from aos import daemon_ctl`）；`__init__.py` 對外名字、`base.py` Fail 與常數、`entry.py` 判型組信、`table.py` 找 daemon／讀表／上一層看法／prune 自檢與 mtime 篩選、`ctl.py` phase 檢查與 pause／resume 寫 ctl、`shutdown` 停 daemon 本身（寫它自己 ctl 的 stop、poke、等退出）、`poke.py` 門鈴與 `read_state`／`check_alive`（核 daemon 身分）、`post.py` 寄信／回信／ask／ping。prune 只查檔案與 stopped 原因；只有 poke 與 shutdown 讀 `/proc` 核 daemon 的 `pid`＋`started_at_ticks`＋`boot_id`，其餘都不讀 `/proc`。說明在 [05-commands/03](05-commands/03-aos-daemon-ctl.md)、[04](05-commands/04-aos-daemon-ctl續.md) | aos-daemon-ctl、aos-agent、aos-eca-screen、aos-tools（`entry.is_program` 判型） |
| `aos/clock_register.py` | 時鐘登記表（clock-letters）：時鐘檔旁 `<名>_register.json` 的讀寫、box 的相對／指示詞解法、信的 body、`fire(時鐘, cycle)` 寄到期的格（只回提醒句子、不丟例外）。說明在 [py/aos/apps/clock_register](../aos/apps/clock_register/README.md) | aos-clock、aos-clock-register |
| `aos/sweep.py`、`aos/sweep_files.py`、`aos/sweep_proc.py` | 清道夫本體：一輪與 purge 的流程、鎖、報告／stderr 的 copytruncate 封存、保留期、purge／表外子 loop 的認法與收法（讀 `/proc`、送訊號，N-17 例外二）。讀表與寫 ctl 沿用 `daemon_ctl`。說明在 [aos-sweeper](../aos/apps/sweeper/README.md) | aos-sweeper、aos-daemon-ctl sweep |

`daemon_ctl.ask(d, body, timeout_s=None, direct=False, *, timeout_cycles=None)` 與 `ping(d, timeout_s=None, direct=False, *, timeout_cycles=None)`：兩種期限擇一；兩者都省略仍等 3 秒，原有 positional 秒數與 `direct` 位置不變。`timeout_cycles` 必須是 signed 64-bit 範圍內的正整數（不收 bool）；並給秒數、非法格數＝`Fail("ArgumentsBad", ...)`，時鐘內容壞了＝`Fail("ClockBad", ...)`，寄信前先驗時鐘期限。時鐘期限共用 `aos_ws.deadline_after`／`expired`，停鐘就繼續等、沒設時鐘才按 `AOS_CLOCK_INTERVAL` 退牆鐘；秒數永遠看單調鐘。`aos-daemon-ctl` 與 `aos-agent ctl` 的人用 `--timeout-s`、預設與行為不變。
