### C. 外部 agent 的 session 檔接管

14. **CLI 的 session 檔在哪**：claude code 在 `~/.claude/projects/<cwd 編碼>/<session-id>.jsonl`，資料夾名的編碼有損、不能反推 cwd，aos 不自己算；session id 由我們給（`--session-id <uuid>`），找檔用 `projects/*/<id>.jsonl`。`CLAUDE_CONFIG_DIR` 會把整個設定（含登入）搬走，不能拿來只搬 session。codex 在 `~/.codex/sessions/<年>/<月>/<日>/rollout-<時間>-<thread-id>.jsonl`，id 從 `thread.started` 拿，`CODEX_HOME` 同樣是整個搬。
15. **放哪**：實例的小格 **`<資料夾>/.stack/<工具名>/transcripts/<kind>-<id>.jsonl`**（C-65 執行中的東西落 stack）。
16. **symlink**：CLI 一邊講一邊寫同一個檔，symlink 永遠是最新的；發現 symlink 指不到（CLI 自己清了、或 `--no-session-persistence`）＝`listen --status`／`state` 說一句「CLI 自己的對話檔已不在」，不報錯、不補（決定 27：不保證）。不封存：stop 只從 daemon 拿掉、小格留著，刪小格是 remove（使用者 11-02 晚，[eca 14](../2026-10-30-eca/14-11-02-晚使用者想法.md#決定11-02-晚使用者)、[15](../2026-10-30-eca/15-實作時代定.md)）。
17. **何時建、誰建**：**hub-adapter（`lib/agent/cli_session.py`）**在拿到 session id 那一刻建（claude：非互動第一次跑或開畫面時；codex：收到 `thread.started`）；`register` 進 hub 的「只登記」實例也建。小格被人 `rm` 就一起沒了（P-17）。
18. **跟決定 26「紀錄 aos 不管」**：26 說的是交流標準不管紀錄；這裡是 hub 這支程式替黑盒子留一個指向它自己紀錄的連結，不進 NORMS、只寫在 hub 的說明與 CONVENTION 的 adapter 那條（[決定](07-衝突.md#決定10-30)衝突 2）。

### D. 其餘三題照隊長建議（決定 35）

19. **history 放 `$AOS_STACK/history.jsonl`**（P-41 原樣），試驗場 bob-1／bob-2 也放 stack。
