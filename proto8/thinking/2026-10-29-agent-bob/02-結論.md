## 結論（10-29 晚實作與實跑；以下做法除了標「使用者定」的，都是隊長照原則代定、可翻案）

### 1. 兩隻 agent 怎麼做

- **agent-bob-1（射後不理）**：`_entry` 一行轉 `main.py`。開場白寫死在定義的 `prompt.txt`：「先讀工作區的 task.md，照它做，做完就結束。」叫一次 `claude -p` 就退——退不退是腦（`claude -p`）決定的（使用者定）。工作區放 `task.md`（讀 `note.txt`、算剩幾顆、寫 `result.md`）與 `note.txt`。對話照 A 記 `$AOS_WS/history.jsonl`（開場白一則 user、最後回答一則 assistant）。
- **agent-bob-2（射後有理）**：自己寫的 Python 循環，**自己永不退**。開場：對話簿空的就先答定義裡的開場白（讀 `brief.md`、然後等）；之後一直看工作區的 `new/`——**就是 aos-say 丟題的那個信箱**（P-11），照檔名順序一題一題：搬 `cur/` → 接進對話簿當 user → 整本交給 `claude -p` → 回答接回、寫 `out/<題名>`（aos-listen 等的就是它）→ 題目進 `done/`。暫停／停照 N-07 的形狀讀 `$AOS_STACK/ctl.json`：`paused`＝不拿新題（手上那題照做完）、`stopped`＝手上那題做完退 0；SIGTERM＝當場退。給 listen 看的照 hub 的補法：`$AOS_STACK/server.txt`（「pid 程式名」）、`trace.jsonl` 每題一行。
- 兩隻的權限鎖照 A 抄（haiku、$0.2、300 秒、`--restricted`、`--strict-mcp-config`、`dontAsk`、`--no-session-persistence`、拿掉 `CLAUDE*`／`AI_AGENT`）。

### 2. 實跑（haiku）

- **bob-1**：`aos-exec --ws ws-bob-1 agent-bob-1` → **退 0**、整趟 5.5 秒；claude **4 回合**、$0.0012。`result.md` 寫出來了，算式與答案（1308）對。
- **bob-2**（背景 `aos-exec --ws ws-bob-2 agent-bob-2 &`，外面只用 `aos-say`／`aos-listen`）：
  - 開場答完（6.5 秒）就停著等，不退。
  - 三句：「買三杯招牌要付多少」255 元；「那如果再多買一杯同樣的呢」**340**（接得上上一句）；「店長叫什麼、哪天會撲空」阿明、週三。**say 到 listen 印出 3.3／4.1／5.5 秒**，幾乎全是 claude 自己的時間（3.2～5.3 秒），輪詢 0.3 秒。
  - 寫 `{"paused": true}` 再 say 一句：**10 秒後題目還在 `new/`，沒動**；寫 `{}` 放行，6.3 秒後答出（照三題各給一個詞，記憶對）。
  - 寫 `{"stopped": true}`：閒著時 0.2 秒退；答到一半寫的，**那題答完才退 0**（答「你第一句話是請我先讀 brief.md…」，連開場白都記得）。
  - SIGTERM：退 143，題目留在 `cur/`（下次開先做它）。
  - `aos-listen --status` 認得它（「在跑 agent-bob-2」，靠 `server.txt`）；但「狀態」一欄是 `-`，看不出 paused。
  - 每題 $0.0003～0.0007。整晚 bob-1、bob-2、hub 三樣合計不到 $0.01。
- **aos-say／listen 能不能直接套到 bob-2：能，沒墊 adapter**。bob-2 照 P-11 收題，say／listen 一行沒改就用起來。

### 3. say／listen 現在的契約，三方怎麼對上

| | aos agent（agent-dan／bob 範本、這次的 bob-2） | aos-hub 接的 claude／codex | say／listen 認什麼 |
|---|---|---|---|
| 題放哪 | `$AOS_WS/new/<題名>` | `<資料夾>/.stack/new/<題名>`（kernel 替它收） | say：工作區的 `new/`；沒設 `AOS_STACK` 且 `.stack/new/` 在＝改丟 `.stack/new/` |
| 答在哪 | `out/<題名>` | 同左（在 `.stack/` 裡） | listen 等 `out/<題名>` |
| 誰在服務 | `/proc` 猜 aos-loop／fsm／exec；bob-2 寫 `server.txt` | kernel 寫 `server.txt` | listen 兩個都認 |
| 卡在哪、失敗 | fsm 的 `trace.jsonl` 每格一行；bob-2 每題一行 | kernel 每題一行（`question`、`error`） | listen 讀 stack 的 `trace.jsonl` 最後一行 |
| 中途偷看 | agent-dan 的 `$AOS_STACK/history.jsonl` | CLI 自己的對話檔、`live.jsonl`（`aos-hub watch`） | `listen --follow` 讀 **stack 裡的** `history.jsonl` 與 `trace.jsonl` |
| 暫停、停 | bob-2：`$AOS_STACK/ctl.json`（N-07）；fsm 範本：沒有 | `aos-hub pause`（關畫面、**照樣收題**）／`stop`（歸檔、不再收） | 沒有 |

- **say（塞話）三方已經共用**：P-11 的 `new/`＋out/ 同名，就是 [hub-adapter 結論一](../2026-10-28-hub-adapter/01-使用者原文.md#結論一agent-對話協議從-aos-saylisten-抽出來的)的「agent 對話協議」。
- **listen 等答案也共用**；**「偷看」不共用**：listen 只看 stack 的 `history.jsonl`，bob-2 照 A 的代定把對話簿放在工作區，所以 `--follow` 看不到它在說什麼；claude／codex 的中途要走 `aos-hub watch`，是另一條路。
- **暫停／停沒有共用**：bob-2 用 ctl.json，hub 用自己的指令，兩邊的「pause」意思還不一樣（見下面衝突 3）。
- **建議的三方最小契約**（只提、repo 程式沒改）：
  - **say＝往目標信箱的 `new/` 丟一題**，信箱的找法照現在（工作區，或 `.stack/`）。
  - **listen＝看三樣**：答案 `out/<題名>`；誰在服務 `server.txt`；中途在幹嘛＝stack 的 `trace.jsonl`（每題／每格一行）＋ `history.jsonl`（一行一則 `{"role","content"}`）。服務者要讓人偷看，就把對話簿放 stack（P-41 本來就這樣），或在 stack 留一份。
  - **暫停／停＝服務者 stack 裡的 `ctl.json`（N-07 的 `paused`／`stopped`）**：aos agent 自己讀；hub 代答的實例由 kernel 讀它那格的 ctl.json（`paused`＝不收題、`stopped`＝等於 `aos-hub stop`）。這樣「外面那層」不管是人、hub、還是別的程式，都只寫一份檔。

### 4. 對照 aos-hub：拿它包 bob-2，缺什麼、多什麼

試法：`aos-hub-kernel &`、`aos-hub add --tool hub-bob ws-hub`，`hub-bob` 是自己寫的**一題一答**工具（stdin `{"prompt"}`、stdout 回答、對話簿照樣記 `history.jsonl`，跟 bob-1 一樣是 `claude -p`）。

- **能直接套的那半**：hub 的 kernel **本身就是那個停著等的循環**。say「招牌一杯多少」85 元（6.5 秒）、「那兩杯呢」170（5.9 秒，記憶對），`listen --status` 顯示「在跑 aos-hub-kernel」，`aos-hub stop` 歸檔、kernel 關掉後 `ls` 報 `KernelMissing`。也就是說：**「停著等的腦」＝hub kernel＋一題一答的工具，bob-2 自己那個循環 hub 已經有了。**
- **缺的**：
  1. hub 包不了「自己會循環的程式」：它只會起一題一答的工具、或 claude／codex 的畫面（tmux）。bob-2 那種自己 `aos-exec` 起來、自己等的，hub 不會開、不會關，也不會替它寫 ctl.json。
  2. **hub 的 pause 不是「不收題」**：`aos-hub pause` 回「本來就沒畫面（已收起）」，之後 say 的題照答（hub 的 pause＝關畫面、對話留著）。要「先別動」的那種暫停，hub 沒有。
  3. `aos-hub open` 只認 `kind` 是 claude／codex（`CfgBad`）；自己的工具沒畫面可接。
  4. 中途偷看：hub 的 `watch` 只讀 claude／codex 非互動那條的 `live.jsonl`，自己的工具沒有。
- **多的**（bob-2 用不到）：畫面（tmux、Ctrl-]）、對話 id 與 `--resume`、stop 時拷 CLI 自己的對話檔、閒 30 分自動收起、只登記的實例、`SessionBad` 重試。
