| 優先級 | 有限資源下「誰先」的那個先後 | 2.2 |

## 2. 規則（他說「一定是這樣」的）

- **C-01** aos 存在的理由是讓大語言模型方便使用；目標多到只能靠模型寫，所以核心要讓模型好用（2.1）。
- **C-02** aos 蓋在現有作業系統上，硬體層的計算分配不重做（2.5）。
- **C-03** 由下往上：Linux → daemon → 時空 → 排程與資源分配 → agent（2.5、2.10）。
- **C-04** daemon 完全處理 Linux 那邊的事；它之上的東西不碰 Linux（2.5）。
- **C-05** 空間就是資料夾，時間就是 tick；這一塊已定，不再討論（2.5、2.12）。
- **C-06** tick 之間，所有與外部有關的狀態一致（09-24）。
- **C-07** 體系用的表達方式以模型天生就會的為準，為的是讓它能自省（2.6、09-23）。
- **C-08** 計算任務＝一個 POSIX 行程，不是 thread；不必再往下分種類（2.7）。
- **C-09** 任務處理過程中用到的東西，只要有限，就是資源（2.7）。
- **C-10** 資源的有限用格數表示；任務排進格就自己跑（3b）。
- **C-11** 排序演算法＝決定哪個任務先給哪個資源；就這樣，不多說（2.7）。
- **C-12** 排序與資源分配本身是計算任務；資源本身也當行程看——一切都是計算任務，核心沒有第二種東西（2.8）。
- **C-13** 每個計算任務都有固定的基礎特性（九軸），其中確定性是任務自己的屬性（2.9）。
- **C-14** 基礎特性之外，人可以任意附加特性（2.9）。
- **C-15** 排序程式可以由人寫，也可以由「生成排序程式的程式」叫模型寫（2.10）。
- **C-16** tick-tock 的本質是定義時間、讓時間能停；停下來後 agent 看到的就是那個時間點的世界，可直接打包（2.11）。
- **C-17** 停下來時正在跑的任務可以不被迫停止；世界裡可以含「這件事正在跑」（2.11）。
- **C-18** agent 是狀態機、是函式、也是計算任務；直接接進核心，不特別處理（2.13、2.14）。
- **C-19** agent 的簽名＝腦（模型）＋記憶（人格、近期）＋手腳（工具）（2.17）。
- **C-20** agent 是複合型任務（外迴圈便宜、叫的模型與工具貴），所以要被排程；最核心的一題是「很多 agent 時誰先用腦」（2.18、2.19）。
- **C-21** 可預測性有主體性，不是任務的屬性，是觀察者的認識（2.14、2.15）。
- **C-22** 提高 agent 可預測性的方法只有一個：當 S 表示式拆開，能寫死的節點換成程式（2.16）。
- **C-23** agent 內部怎麼設計是後面的事，先把底打好（2.20）。

## 3. 概念層的空白（只寫觀察，不給答案）

1. 2.7 的例子一個任務只需要一個資源（人類輸入），2.18 的 agent 同時要腦和工具——一個任務「同時需要多個資源」時排序是什麼意思，他沒說。
2. 「排進格就自己跑」（3b）和「別人把東西丟給資源、它一次處理一個」（2.8）是兩種主動方——任務跑，還是資源跑任務——沒合在一起講。
3. 格什麼時候算空出來：行程退出、任務說放、還是 tick 到了——三者在他的話裡都找得到影子，沒指定哪個。
4. 資源也是行程，而「人類輸入」這種行程是長駐的——對一個不會結束的行程，「一次計算結束」是什麼，沒說。
5. 畫家擅長人物不擅風景、畫累了要休息（2.3）——資源除了「幾格」還有「擅長什麼」和「狀態會變」，這兩樣住在資源上、任務上、還是排序器裡，沒說。
6. 畫家「一週三四張」是時間上的有限，「一次只能處理三四件」是同時數上的有限——格數講的是哪一種，格和 tick 有沒有關係，沒說。
7. 任務「需要人類輸入」這件事是誰認出來的：任務自報、九軸裡的某一軸、人類附加的特性、還是排序器判斷——他只說特性「跟資源有點像但不是」。
8. 人出現在三個位置：是資源（2.7）、是排序依據（2.18「哪些人類想先看」）、會中途插話（09-19）——這三個「人」是不是同一個概念，沒說。
9. 「目標」是任意的（2.4），排序程式也是任意的（2.10）——目標是排序程式的輸入、還是就是排序程式本身，沒說。
10. 排序是計算任務（2.8），那排序這個任務自己需不需要資源、誰排它——「一切都是計算任務」的遞迴底在哪，沒說。
11. 2.17 的「腦」是每個 agent 簽名裡的一樣東西，2.18 的「大腦」是很多 agent 搶的一個資源——這兩個腦是不是同一個東西，沒說。
12. 確定性是任務屬性、可預測性是觀察者的認識（C-21）——排序器排任務時用的是哪一個，排序器算不算一個觀察者，沒說。
13. 「tick 之間外部狀態一致」（09-24）和「停下來的世界裡可以含正在跑的任務」（2.11）——正在跑的任務在那個時間點算一致的狀態還是例外，沒說。
14. tick 什麼時候走：是誰說「下一個時間點到了」——agent 可以叫它停（2.11），但誰讓它動，沒說。
15. agent 是複合型任務（2.18）但計算任務是「一個行程」（2.7）——核心看到的 agent 是外迴圈那一個行程，還是裡面每一次模型呼叫各算一個，沒說。
16. 空間＝agent 的世界（2.12）——很多 agent 是共一個世界還是各有世界、資源住在哪個世界裡、格是空間裡的東西還是時間上的東西，沒說。
17. 09-19 說結果包含整套執行歷史——歷史是不是空間裡的東西、屬於哪個 tick，沒說。
18. 09-19 的 list／eval 和 2.16 的 S 表示式——節點是資料夾還是行程，「知道／不知道」的分界由誰判（可預測性有主體性），沒接起來。
19. 人類附加的特性是誰、在什麼時候附上去的——任務出生時、排序時、還是事後，沒說。
20. 「優先級」是任務身上帶的，還是排序算出來的結果，沒說。

## 4. 那四題為什麼問錯

他在 2.4 停住的地方是「到底有多任意」，在 2.7～2.10 定的是三個名詞的本質；AI 的四題（掃還是登記、一件一夾、幾支排序器、生成器進不進世界）全是「東西放哪、拆幾個」——那是空間裡的佈局，而上面二十個空白沒有一個是佈局題。他 10-04 說過還在高空，四題問的是落地後的地面；高度不對，答什麼都偏。
