# 05c 採納表（第三輪）：Argon 意見逐條處理（view-1114）

← [view-1114](../view-1114.md)｜對 [04c-Argon原文-第三輪](04c-Argon原文-第三輪.md) 逐條處理；採納的寫進 [03-計劃](03-計劃.md) §12.8｜ok-view，11-14

**結論**：17 條審查、6 條提案全部採納，其中 A12 是部分採納。fable 的骨架不動：三欄不捲、待辦隊伍、網址記位置、打字框釘在右欄，都照舊。

改得最多的是操作細節：
- 決定單改成停靠在右欄，不再蓋住中欄。
- 快捷鍵依焦點分區，並擋掉中文輸入法選字時的按鍵。
- 草稿一個對象一份，換說話、寄信、指令都不丟。
- 「已看過」只在明確打開時才算。

A10 已經實測，結果和 Argon 說的一樣：**pnpm 離線裝不起來**，連 react 都裝不了。但改走「複製本機現成專案的 node_modules」，hello 頁已經 build 成功。所以 12.5 第 2 件「連一次 npm registry」**拿掉**。

| A6 [高] | 中文輸入法選字時按 Enter／Esc 會誤觸 | **採納** | 所有按鍵處理先看 `e.isComposing \|\| e.keyCode === 229`，是就直接放過。Esc 在輸入框裡只做 blur（離開輸入框），不關面板、不清草稿。驗收加真 Chrome 和注音輸入的測試（下面 A17） |
| A7 [中] | 草稿 key 綁了模式，換「說話／寄信」就消失；多選時增減對象也會消失 | **採納**（P2） | 一個對象一份草稿，key 是 `draft:<主要對象 id>`，內容包含全部欄位：`{text, mailTitle, mailStatus, orderKind, expandFields, hireFields, powerFields, updatedAt}`，存在 localStorage。在同一個對象下切換說話、寄信、指令，內文都保留。多選時以第一個對象為主。送出成功才清掉；超過 14 天，或對象已經收隊的，自動清掉 |
| A8 [中] | 往來開著、背景抓到新回信，就自動算看過，會漏信 | **採納** | 只在兩種情況算看過：一是使用者主動切到那個對象的往來頁；二是往來已經開著，而且同時符合「分頁在前景、捲軸在最底、使用者在頁面上有動作」。捲軸不在底部時，往來底部顯示「↓ 有 1 則新回覆」，左欄待辦也保留 |
| A9 [中] | 方向鍵在中欄選取和右欄捲動之間沒有分區；J/K 大小寫 | **採納** | 分三區，用 Tab／Shift+Tab 換區。焦點在中欄（或沒有特定焦點）時，方向鍵和 j/k 移動卡片選取；在左欄時，上下鍵移動待辦項目；在右欄時，保留瀏覽器原生的上下鍵捲動。j/k 只認小寫。焦點所在的區畫清楚的外框 |
| A10 [高] | `pnpm --offline` 讀不到 npm 快取，離線會失敗 | **採納**（P6），**已實測** | 實測結果：`pnpm install --offline` 先卡在 vite，連 react 也報 `NO_OFFLINE_TARBALL`；`npm install --offline` 卡在 `@tailwindcss/postcss`。改用另一條路：從 `~/repo/game_dev/mecha-srpg/node_modules` 複製 vite、rolldown、postcss、typescript、playwright，從 `~/code/web-template/frontend/node_modules` 複製 react、react-dom、scheduler、tailwindcss、@tailwindcss/*，以及它們的相依（`cp -rL`，只讀不改原處）。在 `/tmp/ok-view-v2probe2` 用 `vite build` 編 React＋Tailwind 的 hello 頁，**成功**：15 個模組、JS 190 KB、CSS 4.7 KB，**不用 plugin-react**，靠 Vite 8 內建的 oxc 轉 JSX。施工時把這份複製做成腳本 `ui/v2/vendor.sh`，`node_modules` 不進版控，進版控的是腳本和版本清單。連網的備案拿掉 |
| A11 [中] | node 型別剝除要求 import 寫 `.ts` | **採納** | tsconfig 加 `allowImportingTsExtensions`、`erasableSyntaxOnly`、`noEmit`。純函式模組一律寫 `./x.ts` 匯入，不用 enum 和 namespace。localStorage 由外面注入，`node --test` 時換成記憶體版 |
| A12 [高] | 外送追蹤冷啟動是舊的、24 小時懸崖、拖慢 collector | **部分採納** | 收到 `/api/pulse` 或 `/api/outbox`、而且上次更新超過 30 秒時，在背景執行緒觸發一次檢查，不等下一輪。檢查跑在另一個執行緒，不卡 collector 主迴圈，v1 不受影響。每輪最多 6 個對象照舊。收到新的 relay 信件時，比對收件人，馬上更新那一筆。24 小時內的照舊每輪輪流查；1–7 天、還沒回的，每 6 輪查一次（Argon 說 5–10 輪，取中間）。部分採納的是：超過 7 天的不查，標「很久了，沒再追」 |
| A13 [高] | 「等很久」靠時間，前端要自己跳；外部服務的時間凍住 | **採納**（P1） | 前端有一個本地 10 秒的 tick，負責重算「幾分鐘前」和「等很久」，不重抓資料。外部服務的 `checked_at` 從 rev 雜湊扣掉之後，改放在 pulse 回應的 `ext_checked_at`，由前端顯示 |
