原型 · demo 版

資料夾，就是函數。

給 agent 的作業系統，不靠硬體，靠任意資源。

aos 把 AI agent 當成一般的 Linux 行程，住在資料夾裡。每個工具、每隻 agent、每封信，都是你可以 ls、可以讀、可以設權限的資料夾或檔案。

模型本來就懂。模型天生會讀寫檔案與資料夾，不用另學一套框架。
站在 Linux 上。權限就是檔案權限；工具用什麼語言寫都行。
小零件，unix 風格。幾支各做一件事的小程式：exec、loop、daemon。
腦和身都自己帶。先用假腦試、接任何 OpenAI 相容端點，或把你的 Claude Code 掛進樹裡當一隻 agent。
kernel 是一扇門。起行程、問模型都是寄一封信；門可以排隊、算預算、說不。
哪些是已完成、哪些還在實驗
  • 工具用任何語言寫、exec／loop／daemon 三支小程式、假腦與 OpenAI 相容端點：已能跑。
  • 權限隔離（沙箱）：實驗中。
  • 門（kernel）目前只有排隊、算預算、拒絕這幾樣。
  • 「模型天生會讀寫檔案」是設計出發點，不是量測結果，我們沒有拿它跟別的做法比準確度或速度。

怎麼組起來

exec 跑一步，loop 反覆跑，daemon 讓很多個一直跑。kernel 是每個請求都要經過的門。

不用任何模型，先試試

# 只設三個環境變數，不寫你的家目錄（實測不需跑 install.sh）
$ export AOS_HOME=~/aos/proto8
$ export PATH=$(ls -d "$AOS_HOME"/impls/*/bin "$AOS_HOME"/cmd/*/bin | tr '\n' ':')$PATH
$ export PYTHONPATH=$AOS_HOME/py:$AOS_HOME/lib
# 起腦（llms）與你的 agent 樹（tree），範本照抄自 $AOS_HOME
$ aos-exec --stack stacks/llm def &          # 在 ~/aos-demo/llms
$ aos-exec --stack stacks/root defs &       # 在 ~/aos-demo/tree
$ aos-agent -d stacks/root ctl add -w . defs/ann
$ aos-daemon-ctl -d stacks/root ls
$ aos-agent -d stacks/root -t ann say "hello, who are you?"
$ aos-agent -d stacks/root -t ann listen

需要先建置 C／C++ 部分一次。完整步驟（含建立 demo 資料夾與收尾）在 Get started。

現況與邀請

原型，請小心試 aos 還是原型：檔案格式和指令還會變。只支援 Linux（WSL2 可以）。一棵樹住一台機器；樹和樹之間現在還不會互相連線。
安全提醒 agent 會用你的帳號執行程式。請在拋棄式帳號、容器，或丟了也不心疼的資料夾裡試。沙箱是實驗功能。
已實測的環境
  • Python 3.11 以上已實測（3.14 與 3.11 皆通；3.10 沒測）。
  • 建置走 vcpkg 路線已實測；改用系統套件的路線尚未驗證。
  • 只在一台 Manjaro 機器上量過；其他發行版尚未實測。
