## 程式裡有、這版還沒驗

下面這些功能程式裡有，但這版還沒實際跑過，不要當成已驗證的能力。歡迎回報你試的結果。

- 把你的 Claude Code 掛進樹當一隻 agent
- 多隻 agent 互相寄信
- 把整棵樹搬到另一台接著跑
- 沙箱與限額（實驗功能）
