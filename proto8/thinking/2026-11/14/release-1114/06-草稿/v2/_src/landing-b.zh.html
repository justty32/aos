Get started ↗

# SETUP: use a fresh shell, a checkout at ~/aos,
# installed build dependencies, and a new ~/aos-demo.
# See Get started for prerequisites.
cd ~/aos/proto8/impls
cmake -B build && cmake --build build -j

export AOS_HOME=$HOME/aos/proto8
export PATH=$(ls -d "$AOS_HOME"/impls/*/bin "$AOS_HOME"/cmd/*/bin | tr '\n' ':')$PATH
export PYTHONPATH=$AOS_HOME/py:$AOS_HOME/lib

mkdir -p ~/aos-demo/llms ~/aos-demo/tree
cd ~/aos-demo/llms
cp -r "$AOS_HOME/kernel/llm-kernel" def
nohup aos-exec --stack stacks/llm def > llm.log 2>&1 &

cd ~/aos-demo/tree
cp -r "$AOS_HOME/templates/daemon-root" defs
cp -r "$AOS_HOME/templates/agent-fsm" defs/ann
nohup aos-exec --stack stacks/root defs > root.log 2>&1 &
sleep 2
aos-agent -d stacks/root ctl add -w . defs/ann
aos-daemon-ctl -d stacks/root ls

# INPUT
ls stacks/root/procs/ann/
aos-agent -d stacks/root -t ann say "hello, who are you?"
timeout 60 aos-agent -d stacks/root -t ann listen
ls stacks/root/procs/ann/

# STOP: stop only these demo stacks.
aos-daemon-ctl -d "$HOME/aos-demo/tree/stacks/root" shutdown
aos-daemon-ctl -d "$HOME/aos-demo/llms/stacks/llm" shutdown

01 / NOW

今天 clone 下來就能做的

資料夾＝函數。資料夾裡放一個 _entry 就能被呼叫，說明和資料就放在旁邊。

小零件，unix 風格。幾支各做一件事的小程式：exec、loop、daemon。

02 / Vision

從一隻 agent 開始，最後換成一支程式。

一步一步把 agent 換成確定的程式，token 用量往零走。

STATUS / prototype

aos 還是原型：檔案格式和指令還會變。只支援 Linux（WSL2 可以）。一棵樹住一台機器；樹和樹之間現在還不會互相連線。
