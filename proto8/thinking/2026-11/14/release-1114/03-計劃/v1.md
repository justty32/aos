## 0. 結論

1. **骨架照 fable 稿**：同一個 repo 發，新增頂層 `README.md`＋`README.zh-TW.md`、`docs/`（Pages 站，Jekyll 從 `main` 的 `/docs` 原生發、不用 workflow）、`LICENSE`；產品本體還是 `proto8/`；內部資料原地不動、對外不連，另寫一份**公開清單**把界線寫死。
2. **安裝四級**：L0 假腦（零模型、零帳號）→ L1 任何 OpenAI 相容端點 → L2 Claude Code 當身 → L3 沙箱與限額（實驗）。首頁與 README 只推 L0。
3. **第一印象不能只是「假腦回一句話」**（Argon）：L0 的 Get started 主角是「打開資料夾看見 agent、信、狀態在變」——每一步之後 `ls`／`cat` 一次給人看。
4. **「clone 下來馬上能用」有兩個可能的卡點要先實測**：沒有 vcpkg 時找不找得到系統的 nlohmann-json、`-static-pie` 在一般發行版缺不缺靜態庫（Argon）；接真腦時出廠只有叫 `LITELLM_KEY` 的 LiteLLM 端點，接 OpenAI／OpenRouter／Ollama 要自己加 pack（Argon）。**先驗（批 0），不先改程式**；驗出來真卡，再把最小修改（CMake 退路、中性 OpenAI 相容 pack、`quickstart.sh`）列成改程式申請送放行。
5. **宣傳頁是手寫單檔 HTML**，草稿＝成品；**文案只有一個正本**（文案表），每句記依據原話、已實作／願景、使用者點頭沒。
6. **規劃段到此結束**；接著做**批 0 驗事實**（只在 repo 外暫存夾，不改 repo），同時等使用者答 ★ 題；批 1 草稿 v1 在拿到 ★1、★3 的答案後開工。

## 3. 軟體包與安裝分級

| 級 | 必需 | 得到什麼 | 首頁說法 |
|---|---|---|---|
| L0 | Linux（含 WSL2）、git、bash、python3、CMake ≥ 3.21、C++20 編譯器、nlohmann-json（系統套件或 vcpkg） | 一棵樹、一隻 agent-fsm、假腦回話；「資料夾＝函數」小實驗 | 「五分鐘、不用任何模型」（**批 0 量過時間才准寫數字**） |
| L1 | ＋任一 OpenAI 相容端點與它的金鑰（環境變數） | 同一隻 agent 換真腦、會叫工具 | 「換一個設定接上你的模型」 |
| L2 | ＋claude CLI（已登入）、tmux | Claude Code 成為樹裡的一隻 agent，有互動畫面 | 「把你在用的 Claude Code 納進來」 |
| L3（實驗） | 依功能：bubblewrap、s6、newuidmap、setfacl、systemd／s6-supervise | 隔離、限額、分享、監管 | 只在手冊出現、標實驗 |

- 安裝頁第一屏講白：**Python 零第三方套件**、沒有 pip、沒有 venv。
- Python 版本：批 0 量 L0 路線的實際下限再寫；不寫「3.12 必需」除非實測如此。
- `install.sh` 照舊（會寫 `~/.local/bin` 與 Python user site 兩處，文件講白、附 `--uninstall`）；Get started 優先走「不寫家目錄」的 `env.sh` 路線，前提是批 0 驗過。
- 預編檔、Docker 映像、Release：都不在批 1；判準照 fable 3.3（乾淨環境建置失敗或 >10 分鐘就提前做預編檔）。**Dockerfile 只當我們自己的乾淨測試機**，要用它驗多發行版得先請使用者開 docker 服務（本機 docker 有裝、服務沒開，要 sudo）。

## 4. 使用手冊、安裝手冊、範例、教學

### 4.1 站台目錄（照 fable 4.2，opus 定名）

```
docs/
  _config.yml               Jekyll 設定（主題 just-the-docs 或 minima，批 1 煙霧測試後定）
  index.html                宣傳頁（英文）   zh/index.html  宣傳頁（繁中）
  assets/                   圖、終端畫面、樣式
  _data/public-surface.json 公開清單        _data/copy.json  文案表（正本）
  _tools/                   生成、抽指令實跑、隱私掃描腳本（底線開頭不發佈）
  en/ 與 zh/（同結構；reference 只有英文）
    get-started.md
    install/   index requirements real-brain claude-code optional uninstall
    tutorials/ 01-first-tree 02-real-brain 03-two-agents 04-write-a-tool 05-claude-code-body 06-a-kernel-that-says-no
    examples/  index ＋每例一頁（由 proto8/examples/<名>/README 生成）
    concepts/  in-one-page folder-as-function tree kernel-and-letters bodies-and-brains vision
    manual/    run-a-tree agents mail brains limits-and-sandbox home-layout troubleshooting security
    reference/ cli tools errors env files glossary   ← 生成
    faq.md  status.md  wiki/index.md
```

每篇要點照 fable 4.2 的表；opus 補三點：
- `manual/security.md`（新增）：agent 會在你的帳號下執行程式；同帳號沒有隔離；建議在拋棄式帳號／容器／工作夾裡試；沙箱是 L3 實驗。README 的 Security 節連過來。
- `manual/troubleshooting.md` 第一批就要有骨架：`command not found`（PATH）、找不到 nlohmann-json、static 連結失敗、殼裡殘留 `AOS_*`、殘留 stack／lock、Pages 上的 mermaid 不出圖——每條「症狀 → 為什麼 → 一行解法」，批 0 實際踩到的優先。
- `get-started.md` 固定節奏：每一步後面接「看一下」（`ls stacks/root/procs/ann/`、`cat …/history.jsonl | tail -1`、信箱裡那封信），結尾一張圖「你剛剛跑的四個資料夾」。

### 4.2 範例（照 fable 第 8 節）

| 批 | 範例 | 級 | 驗法 |
|---|---|---|---|
| 1 | hello-tree、folder-as-function | L0 | 乾淨複本全自動跑、`expected.txt` 由實跑抄錄 |

範例放 `proto8/examples/<名>/`（README、`run.sh`、`expected.txt`）——**新夾，批 1 開工前報 xiaosi 放行**（不在活樹 import 路徑上，但在 proto8 底下）。替代：放 `docs/examples/` 只當文件。推薦前者（範例是產品的一部分）。

### 4.3 需要改程式的申請（批 0 驗完再送，現在不做）

1. `proto8/quickstart.sh`（新檔）：`--check`／建置／建示範樹／寫 `env.sh`／`--stop`／`--clean`；不 sudo、不改 shell rc、預設不寫家目錄、不從網路抓東西執行、殼裡有 `AOS_*` 就拒絕、起了什麼停什麼都印出來。
2. `proto8/kernel/llm-kernel/` 加中性端點（例如 `endpoints/openai-compatible`，`--key-env` 由 pack 指定）＋一個示範 pack；**只加不改**既有 pack。
3. 只有批 0 證明卡住時才送：`settings.cmake` 的退路（找不到 vcpkg 用系統套件、static 連結失敗時可退動態）。這碰活樹 C++ 建置，要在 repo 外編、測過全套，交換時照停樹規矩。

## 5. 佈署分派

照 fable 第 7 節：單機六步（建置設環境 → 起 llm kernel〔假腦〕 → 起根 daemon → 掛 agent → 說話／寄信派工 → 看狀態、換腦、停樹），教學 01 手動走一次、quickstart 代走一次；長住的家（aos-home 佈局與備份）寫進 `manual/home-layout`，從現有手冊改寫時去掉私人環境。

## 11. 隊形

- **opus（ok-release）**：帶隊、定文案與每頁要寫什麼、審、commit 申請、所有對外動作的 NEEDS-USER。
- **sol**（agent-fsm，LiteLLM sol-high，`ok-release-sol-<n>`，limits `{"mem_mb":1024,"files":256}`）：批 0 實跑抄錄、照定好的目錄寫文件初稿、HTML 施工、生成與掃描腳本。sol 現有工具只能讀；要寫檔時給它 write 類工具（只限 `wf/temp/ok-release/` 與 `~/code/release-1114/`），或由它回文字、opus 落檔。**文案定稿與「這句能不能說」不交給 sol**。
- **astra**（同上，astra-high）：第二版宣傳頁視覺；每輪可再出一版對照。
- **fable**：使用者意見牽涉定位或範圍時再叫；施工時不即時參與。
- **Argon**：批 1 草稿出來審一次；之後每輪一兩次。
