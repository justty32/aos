## 二、「人是外部計算單元」的幾個方向（不收斂，並列）

1. **人＝一個很慢的端點包**（人1、人14）：照搬 llm kernel 的 slots／priority／budget／保留格；每隻 agent 每天能佔人幾題，用完回拒絕，agent 開始珍惜問題。A#6 再加一筆：寫得難懂的 agent 被扣問人額度。
2. **人前面串站、便宜的先擋**（人18）：規則站（答過同類的）→ 原則站（拿他講過的話推）→ 替身站（模仿他、標明替身答的）→ 真人。替身答對率就是「人的可預測性」（人19）。
3. **人只拉、不推**（人21、A#8）：人的 clock 是「他打開頁面或開口的那一刻」；與其通知，不如備好按耗腦程度分的牌堆（三秒二選一／試玩／燒腦大方向），他打遊戲讀取時自己抽。
4. **人有模式與快取**（人3、人5、人7、A#3、A#10）：打遊戲／專心／手機三種模式；剛聊完的主題最便宜（同主題湊一包）；反應時間（點一下，可批次）和思考時間（想方向，不能催）分開，混在同一頁前者會被後者拖死。累了就把五題細節壓成一題「這塊你放手嗎」。
5. **管的是債，不是流量**（人24）：代定清單是欠他的注意力債，128 題那次是破產；破產時排隊沒用，要丟（改成「已代定、不再問、出事再說」）。
6. **只報差異、做完給他看**（人31、人32）：照他預期走的不報；成品比問題好答（`trial` 信、使用者本來就愛「做原型讓他試」）。
7. **人的 `_metainfo` 從痕跡長出來**（人55、人56、人61）：`user.md` 就是寫成散文的宣告；各 agent 對使用者各有一份私有看法，人偷看哪份錯就糾正那份。人只說「不是這樣」。
8. **好不好懂一定有「對誰」、而且一筆分數是一次世界線取樣**（人48、人49、人50）：早上和深夜讀出來不同；AI 讀者便宜可大量取樣、人是貴的校準點——但 AI 覺得好懂和人覺得好懂可能不相關。
9. **人既是被管的資源、又是最頂的 kernel**（人11、人58）：「管人的 kernel」與「人自己當 kernel（`kernel_gate` 的放行／拒絕）」可以串起來；人隨口一句要能蓋掉所有排序。
10. **先在 agent 之間便宜地玩**（人59）：使用者自己寫過「對子節點來說，他的人類就是父節點」，上面每條都能先拿 agent 問上級來試。

opus 補三條：

- **O1　今早這段對話就是人 kernel 的現場樣本**：使用者邊打遊戲一題一題回 → 頂層 `repo-aos` 轉 → 帶隊線併進並寫「怎麼吸收」。頂層已經在當人前面的一站（做人45 說的「這段話回掉了哪幾題舊題」對帳）；值得看它自然長成什麼樣，而不是另造。
- **O2　「看得見」先於「管得到」**：專區 `log.jsonl` 已有 `seen`／`answered` 時戳，只是還沒真人信（01a）。什麼都不排、只讓真人信累積痕跡，人 kernel 該長什麼樣會自己浮出來——跟使用者「用多了自然長出來」同一個態度。
- **O3　人 kernel 自己不能變成人的負擔**（同人26）：任何要人去設定的東西都違反「懶」；設定只能從痕跡長，人只在不爽時說一句。

## 三、其他主題軸的亮點（各兩三條）

- **以前沒想過的軟體**：先能用、後變便宜，像珊瑚礁邊活邊鈣化（軟1、A#19）；名字是資源，專案的自創名詞有容量（軟6）；程式碼庫的戰爭迷霧——「上次有人真看懂它是什麼時候」（軟7、A#12）；一個人的一天是一台 daemon（軟4）；伏筆債、傲嬌預算當資源的寫作引擎（軟2、A#21）。
- **稀疏激活**：`_index` 那一句是 agent 的接受域、就是路由（稀2）；常一起醒的兩隻踩出捷徑（A#18）；死神經元看得見就能剪（稀8）；激活圖讓人不讀也知道系統在幹嘛（稀10）。**會誤導的**：神經元一樣、同步、單向一層層；agent 各不同、非同步、會回信、是繞回來的圖，「層」最不能照搬（稀13）。現況是閒著的 agent 也在輪詢，跟「睡著不花錢」的意象有落差（稀4）。
- **三處佔比**：其實是五處（多了 prompt 與人腦），沉澱方向大致人腦→prompt→json→程式、也有逆流（佔1）；誰要讀決定住哪（佔2）；搬家夠便宜就不必事先選對（佔4）——同像性正是讓它便宜的那件事。
- **lisp／lua**（等 kernel 穩定，只記）：fennel→lua→table→資料夾是一條現成鏈（L1）；反過來把活的資料夾樹印成 lua 當粗化視圖（L2）；資料夾本身就是攤開的語法樹（A#22）。

## 四、彼此矛盾（不用選邊，看場合自然消長）

- **讓人更懶 ↔ 讓答題更爽**（人12↔人13）。
- **等久升級 ↔ 等久爛掉**（人16↔人17）；**到期撤回 ↔ 人的背景線程幾天後才冒答案**（人20↔人6）。
- **替身／原則站擋題 ↔ 人推翻題目的價值**（人19↔人8、A 矛盾 3）。
- **照推薦＝好懂的綠燈 ↔ 定期抽檢防天書**（A#1、A#2↔A#12）：人一直放行，底下可能悄悄長成沒人懂的東西。
- **代定先跑 ↔ 扣著湊同主題一包／等它自己爛**（A#9↔A#3、A#5）。
- **跑熟了粗化封箱 ↔ 各 agent 要保留細節自己挑**（A#14↔A#15、A#16）。
- **用的人往上改那句 ↔ 生成器從本體重生把它洗掉**（粗3↔粗10）：這條跟現況直接相關，`index_gen` 現在就是後者。
- **看法會傳染 ↔ 看法各不相同才有價值**（看5↔看6、看11）：轉信中心（eca_main、repo-aos）是超級傳播者。
- **拿 AI 當好懂量具 ↔ AI 的好懂和人的好懂可能不相關**（人49↔人50）。

## 五、互相成就（湊起來會自己轉的）

- **原則飛輪**：人愛給原則 → 挑能生原則的題 → 記原則 → 原則站擋後面的題 → 人更少被問（人10＋27＋28＋18、A#7）。
- **不問分數的好懂量具**：「看不懂」鍵＋退回重講＋行為痕跡（人39＋44＋47、A#1），再接到 A#6 的問人額度，系統會自己往好懂的方向漂。
- **同一個機制用三處**：人的 `_metainfo` 從痕跡長、被騙了才往上改那句話、讀者指定那層就是私有看法（人56＋粗3＋看1）；再加線程的樂譜與演奏。
- **可逆性一條線**：代定是分支預測、事情可改回、「都按照推薦」才安全（人42＋25＋36、A#9）。
- **稀疏三件套**：平常只看 `_index` 粗字找路、只叫醒少數、常走的路留捷徑（A#13＋17＋18、稀2）。
- **便宜的來回**：值的粗細、描述的粗細、住處的搬遷，只要來回便宜就都不必事先定規則（粗6＋佔4）——就是「自然長出來」的前提。
