## 白話結論

1. 使用者說上一輪太早規劃：沉澱成程式、資源定義、改善、擋門 AI、開發函數的函數都是用多了自然長出來，開發函數的函數「現在就是了」；舊 D1～D16 全部不裁、自然浮現。這兩條偏好已寫進 wf。
2. 這輪 fable 出 120 條、Argon 獨立出 22 條，兩邊撞在同幾處：人最值錢的輸出是「原則」和「題目問錯了」。
3. 管人的 kernel 好成績＝人少答了幾題、事情還是對的；好不好懂不問幾分，看行為（沒看、退回重講、秒選推薦、沉默）。
4. 沉默有六種意思，題目可以自己爛掉；代定就是分支預測，所以人 kernel 的正事可能是把事情變得改得回來。
5. 粗化細化：名字→`_index` 一句→`_metainfo`→本體→跑過的軌跡，「驚訝」才往下鑽；`_metainfo` 是宣告（廣告），各 agent 的私有看法是評論，沒有誰的看法贏。
6. 精華 8 條、人 kernel 十個方向、矛盾與互相成就、建議先玩的 6 個實驗在 [05 匯總](05-匯總.md)；實驗都還沒跑。
7. arknights 凍結到至少 2026-12-14；lisp／lua 等 kernel 穩定再說。
