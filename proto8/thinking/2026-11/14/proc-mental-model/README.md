白話結論：
- **最對準你主軸的一張圖**：proc 是一把「世界線束」，純函數＝把整把線捏成一條；沉澱一個 llm 呼叫，就是在狀態圖上把一條機率邊換成確定邊（01 M3、M6）。
- **「應當」可以有好幾種意思**：一份譜（事先寫的 `_metainfo`）、一張契約（外界守 X、我就保證 Y）、某目標下最省的路徑（kernel 挑的）——你原話的「應當」是哪一種，值得自己挑（01 M2、02 第 1、8 個）。
- **「時間」不必是時鐘**：可以是 token 累計、信的序號、因果先後；挑哪根軸，就是在挑要優化什麼（01 M1、02 第 2 個）。
- **「外在影響」有現成的分法**：機率分「裡面擲骰」（換純函數去修）和「外面丟進來」（釘住輸入去修），兩種修法不同，所以以後量一致性時值得拆開（01 M5、02 第 5 個）。
- **函數九軸其實量的就是 proc**：你 11-06 說函數屬性是「時間軸、世界線上的區別」，那它就是這把線的形狀；有的屬性只看頭尾、有的看路徑（01 M7、02 第 4 個）。
