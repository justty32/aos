## 5. WAIT_USER：計數表、分類子檔與核對

### 是什麼、解決什麼

- `S/WAIT_USER.md:3` 定義：「只列需要使用者親自操作、實機驗收、外部環境或素材才能繼續的 open 項」。頂層只要掃類別與數字，就能知道人這一關還卡多少。
- `S/wait-user/README.md:3`：「WAIT_USER.md 是 hub，只放計數表；各類 open 項的內容在本目錄。」
- `S/AGENTS.md:7` 要每個 session 先看 SESSION-LOG 現役工作與 WAIT_USER open 計數表；`S/AGENTS.md:22` 將使用者驗證與跨 session 進度分開。

### 檔案、格式與狀態

| 類別 | hub 數字 | 一級分類檔 | 更深的內容形狀 |
|---|---:|---|---|
| 回家下載／重建 | 8 | S/wait-user/home-setup.md | home-setup/lorerim-leftovers.md |
| 整包 UI／中文／任務驗收 | 12 | S/wait-user/integrated-runtime.md | 4 個 md：localization-checks、new-game-followers、dmk-gameplay、quests-npc-text |
| 獨立功能驗收 | 18 | S/wait-user/feature-runtime.md | 6 個 md：asset-converter、scene-ghost、dsport-p3、crash-validation、simonrim-and-weaponry、baan-malur |
| 日後素材／清理決定 | 8 | S/wait-user/later-decisions.md | 直接寫在分類檔 |

- `wait-user/` 共 16 個檔：README＋4 分類檔＋11 深層內容檔；hub 在資料夾外。
- 每個分類檔用 `#` 作容器，每個 open 項一個 `##`；項下可寫敘述、清單、證據連結，或只連更深的主題檔。沒有統一的 JSON 欄位或狀態 enum；日期、BLOCKED、驗收界線寫在標題／正文。
- 例如 `S/wait-user/feature-runtime.md:7` 的 Sofia 項有新增內容、操作情境、正確結果、不能以短時間沒觸發判失效的界線，以及 REPORT 來源；`:76` 的 Astrid 項寫 BLOCKED、靜態檢查已過、測不出來不等於壞了、請人確認哪一點。
- 同一深層檔可以承接多個 hub 條目，例如 Simonrim 4E／4A／4M/P／Weaponry 四個 `##` 都指向 simonrim-and-weaponry.md。計數的是分類檔標題，不是深層檔數、checkbox 數或每個要測的 NPC。

### 核對工具的具體介面

來源：`S/tools/waituser_count.py:2`、`:21`、`:58`、`:104`、`:124`，解析在 `S/tools/waituser/parsing.py`。

```text
python3 tools/waituser_count.py [--root PATH] [--check] [--json]
文字輸出：<類別> hub=<N> actual=<M> <OK|MISMATCH>
```

- 預設 root 由腳本所在路徑推到母 repo 根；hub 固定 `WAIT_USER.md`。
- 在 Markdown 表中找含 `open` 欄的第一張候選表，該欄需是整數；最後一欄取連結，第一欄作 category。欄數不符、無連結、無資料列等都報解析錯誤。
- 子檔的第一個標題是容器；只數比容器深一層的標題。碰到下一個同級／更高層容器就停；fenced code block 裡的假標題不算。
- 保留對舊格式的辨識：同條目層標題含「封存」時停止計數，其後不算 open。不是掃每個已完成字樣，也不是遞迴數所有子檔。
- 能處理 hub 自指 `#錨點`，在相應 section 下數下一層標題；但目前 hub 沒有這種列。腳本 docstring 仍描述舊 Push 排程自指列，不能當成現有 hub 的內容。
- 預設發現 MISMATCH 仍 exit 0；加 `--check` 才 exit 1；任何 ERROR 優先 exit 2。`--fix` 是有解析旗標但未實作，會說明原因並 exit 2。
- `--json` 頂層欄位是 root、hub、rows、mismatches、errors、exit_code；每列含 category、hub、actual、status、source、self_reference、error。

### aos 事實對應：離線頁與新 user zone 都已存在

- `A/wf/workflows/decide-page.md` 是集中規範，程式在 A/wf/tools/decide_page/；不是 Skyrim 的每頁各寫 render。資料檔放出題線資料夾，`decide_<YYYYMMDD>[_短名].json`，contract=`wf-table/1`、kind=`decide-page/1`。
