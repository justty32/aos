## 做了什麼（頂層代做，可翻案）

試驗場的檔（都在 `~/code/playground/`，不在 git）：

- `agents/cathy/`：跟 bob 同一種的 agent——`_entry.json`（`claude -p --model haiku --tools "" --strict-mcp-config --max-budget-usd 0.1 --append-system-prompt-file system.txt`）＋`system.txt`（題目是一句話或 `{"text": …}`，沒有工具、直接用自己的話答，開頭寫「cathy：」）。單獨叫：`aos-exec ../agents/cathy -- "題"`。
- `agents/bob-cathy/`：bob 的複本＋串 MCP。
  - `_entry.json`＝bob 那串 argv 多兩組：`--mcp-config mcp.json`、`--allowedTools mcp__aos__cathy`。
  - `mcp.json`＝`{"mcpServers": {"aos": {"command": "aos-mcp", "args": ["--enable-logs"]}}}`：不帶登記檔＝預設 `./tools.json`，相對路徑從 claude 的 cwd＝這隻 agent 的資料夾算（aos-exec 會 cd 進來）；工作區與 stack 從 aos-exec 給的 `AOS_WS`／`AOS_STACK` 繼承；`--enable-logs` 記 `ws/.stack/aos-mcp-logs.jsonl`（[stack-tools 決定](../stack-tools/01-使用者原文-11-02-逐字.md#決定11-02使用者)）。
  - `system.txt`＝bob 的那份，cwd 改成 `agents/bob-cathy`，加一段「cathy 是另一隻 agent，會自己想、回以『cathy：』開頭的回答，可能要等十幾秒；照實用、不要自己編」。
  - `tools.json`＝在 `agents/bob-cathy/` 裡跑 `aos-tools add tools/cathy` 產生（寫絕對路徑）。
  - `tools/cathy/`＝工具小資料夾：`_entry.json`＝`["/home/guanyu/code/playground/agents/cathy"]`、`_tooldef.json`（`{"text"}`）、`_metainfo`（`time_ms` `{"val": 15000, "max": 120000}`、`resource` `llm`）（11-04 已改：aos-tools 只認 `_metainfo.json`，見 [four-elements 08 步 5](../../04/four-elements/08-實作步驟-等aos-agent後.md)）。
- `env.sh`：PATH 多放 `proto8/extras/ai_tools/bin`（aos-mcp 在那裡）。

用法：

```
cd ~/code/playground && source env.sh && cd ws
aos-exec ../agents/bob-cathy -- "請問 cathy：「為什麼天空是藍色的？用一句話回答。」把她的回答原封不動寫進 env:AOS_WS 的 cathy.txt。"
```

原本的 `aos-exec ../agents/bob -- "題"` 照舊（bob 沒動）。

結論：

- **aos-mcp 給登記檔**：`aos-mcp [--ws WS] [--stack DIR] [--timeout-s N] [REGISTRY...]`，位置參數是登記檔路徑（檔名不限、相對路徑從啟動時的 cwd 算），不給＝`./tools.json`（stack-tools 決定）；給資料夾或不存在的檔＝`ToolMissing`；好幾份照舊合併、撞名＝`ToolsBad`。說明在 [ai_tools README § aos-mcp](../../../../extras/ai_tools/README.md)。
- **claude 包 claude 不必清環境變數**：在 `CLAUDECODE=1`、`CLAUDE_CODE_ENTRYPOINT=cli` 下 bob（claude）→ aos-mcp → cathy（claude）照樣能跑，不必另外 `env -u`；`env.sh` 原本那行 unset 照留。
- **跟 C-51「固定名字判準」的關係**：aos-mcp 這次是「改成 argv 指定」那一條（C-51 的 10-31 加註：理想是只有一個檔固定、其餘由它指定，要更靈活就用環境變數或 argv 指定）。C-51 加註寫明使用者對判準還有後續想法，所以本次只當一個例子，不改 C-51 的條文。

代定清單（編號照原本，空號是被推翻而刪或已併進上面的結論）：

- 代定 2：**另開 `agents/bob-cathy`**，不改 `agents/bob`。
- 代定 3：**cathy 的工具小資料夾放在 `agents/bob-cathy/tools/cathy/`**：C-61「工具放在叫它的那一格自己的資料夾裡」。
- 代定 4：**登記用 `aos-tools add`**，所以登記檔裡是絕對路徑，整個試驗場搬家要重新 add；手寫相對路徑 `tools/cathy` 也行（10-28 結論 6）。
- 代定 6：**`mcp.json` 寫 `"command": "aos-mcp"`、靠 PATH 找**，所以 `env.sh` 加了 ai_tools/bin；不寫死 aos-mcp 的絕對路徑。
- 代定 7：**aos-mcp 的 stack 跟 bob 共用 `ws/.stack/`**（aos-mcp 預設：`$AOS_STACK`），cathy 每次叫的小格在 `ws/.stack/tools/cathy/`（[stack-tools](../stack-tools/README.md) 選 B）。
- 代定 8：**`--allowedTools mcp__aos__cathy`**：`-p` 加 `acceptEdits` 不會自動放行 MCP 工具，要明列。
- 代定 9：**cathy agent 放 `agents/cathy/`，跟 bob 並排**（使用者「跟bob類似」）；bob-cathy 裡只放工具小資料夾（照 `lib/aos/ask_round` 那種「`_entry` 是 JSON argv、`_tooldef.json`／`_metainfo` 在小資料夾」的接法），所以 cathy 本身也能單獨叫。不把 agent 整份搬進 `tools/cathy/`。
- 代定 10：**工具小資料夾的 `_entry.json` 只寫 `["<agents/cathy 的絕對路徑>"]`**：argv[0] 是資料夾＝前面插 aos-exec（N-61）；寫絕對路徑是為了不出現 `..`（C-61／P-25）。不給 `--ws`：cathy 吃 stdin 吐 stdout、不需要工作區，照 P-32「不需要工作區的工具不給 `--ws`（沿用），只給 stack」。
- 代定 11：**題目怎麼進 cathy**：arguments 的 JSON（`{"text": …}`）原樣從 stdin 進 `claude -p`（claude 沒給題目參數時讀 stdin），`system.txt` 告訴她只看 `text`；不另寫轉換程式（少用 sh、KISS）。
- 代定 12：**cathy 沒有工具**（`--tools ""`）、`--max-budget-usd 0.1`、不加 `--add-dir`：她只用腦答，結果由 bob 寫進工作區。
- 代定 13：**逾時**：cathy 的 `_metainfo` `time_ms.max` 120000（aos-mcp 拿它當這個工具的逾時，取代預設 60 秒）。
