## 4. 寫死的路徑

**程式邏輯本身沒有寫死路徑。** 專區的找法是 `--zone`，其次 `$AOS_USER_ZONE`，最後 `~/.aos/user`；`aos-post`、`notify-send` 都走 PATH。整份抄本裡沒有 `/home/lorkhan`。

寫死的都是字：

| 位置 | 寫了什麼 | 搬家後要改成 |
|---|---|---|
| `aos-user` 第 2 行註解 | 放 `~/aos-home/ws/tools/aos-user/`，「不在 repo」 | 新家與理由 |
| `zone.py:937`（usage 最後一行） | `more: ~/aos-home/ws/tools/aos-user/README.md` | 新家的 README |
| `README.md` 開頭那段與用法、計時器、測試三段 | `T=~/aos-home/ws/tools/aos-user/aos-user`、`cp ~/aos-home/ws/tools/aos-user/systemd/…`、測試跑法 | 直接打 `aos-user`；路徑改新家 |
| `tests/test_zone.py:2` | 跑法註解 | 新家 |
| `systemd/aos-user-tick.service` | `ExecStart=%h/aos-home/ws/tools/…`；註解說 aos-post 在 `~/.local/bin` | 學 `aos-frontend.service`：設 `AOS_HOME`，`source env.sh` 之後 `exec aos-user tick --quiet` |
