1. 代號結尾：「Hmmm，錯誤代號本身就千變萬化。concept內應該只是列出幾項基礎的、很通用大眾的，跟大家說類似的就盡量遵循這個。但其他的也可以自己隨意定。就是說偏向於推薦啦。」三個代號不改名。
2. knowledge_write 超過 8000 bytes：選「超過只提醒、照寫」。
3. thought 的預設定義：「啊？不是就呼叫者自己的範本嗎？應該說呼叫者的stack內，本身就會放自身的定義來源吧。」——施工記在 [do-task-rename](../do-task-rename.md)（同時改名 do_task）。
4. agent_def 的 `RootMissing`：選「從說明拿掉」。
5. run_python：選「改程式，在工作區跑」。
6. 知識庫 `aos/tools.json`：選「tools.json 改名 tools_def.json」。

## 施工

### 1. C-54 改推薦口氣

- C-54「錯誤若帶代號」那條尾巴加 11-11 加註：上面的結尾是推薦、類似的盡量照用、其他可自訂，「一律」照「推薦」讀（原句留著）。
- 引用它的地方：impls/docs/02 的慣例表改「C-54 推薦的六種結尾」；知識庫 `aos/errors.json#/codes` 表下加一句「這是常見的結尾、不是全部（`DepthExceeded`、`SubagentQueued`、`ChildrenExist`），看代號後面的原因」。
- `knowledge_check` 的 `codes` 拿掉結尾檢查（代定：整項拿掉，不留成資訊——留著的話每次跑都多三行沒人要處理的字；「庫裡找不到代號」那項照舊是 warning）。測試改成「結尾不在表裡也不提」。出廠庫 warning 42 → 39。

### 2. knowledge_write 超過 8000 bytes：只提醒、照寫

- `writing.py` 的 `MAX_BYTES` 改成推薦值：一次寫的 value 超過 8000 bytes（JSON 照編碼後算、非 JSON 照原文）＝stderr 一行 `knowledge_write: warning: value is N bytes, over the recommended 8000; written anyway (...)`、照寫、退 0（照既有慣例走 stderr 提醒行；腦經 act 的 stderr 尾巴看得到）。
- tooldef 的 value 說明、知識庫 `aos/knowledge.json` 的錯誤段（ValueBad 不再含「超過 8000」）、lib/docs/03 跟著改。測試：拿掉 8001 bytes＝ValueBad 那行，加一支「add／set、JSON／非 JSON 超過都提醒照寫、小的不提醒」。
- 代定：add 的 value 在其他檢查之前先量大小，所以「超過＋別的錯」會先印 warning 再印錯誤行（不擋事，懶得調順序）。

### 4. agent_def 的 RootMissing 從說明拿掉

- 程式在轉叫 defs check 之前自己先看 `path` 是不是資料夾（不是＝`DefMissing`），所以下層 defs 的 `RootMissing` 走不到。tooldef 的 `errors` 拿掉 `RootMissing`，知識庫 `aos/agents.json#/agent_def` 拿掉「check 也會 RootMissing」那半句。程式不動；lib/aos/defs 自己的 `RootMissing` 照留（它是另一支、真的會報）。

### 5. run_python 改在工作區跑

- `_entry`：cwd 改成 `$AOS_WS`（`tool_io.workspace()`，沒設或不是資料夾＝`WsMissing`，在寫 main.py、開帳之前判）；程式本身照舊寫進小格 `$AOS_STACK/main.py`（沒 stack 用暫存夾），用絕對路徑跑 `python3 -I <小格>/main.py`。tooldef 加 `WsMissing`，說明本來就寫「in your workspace」、不用改；知識庫 `aos/tools/run_python.json` 的 rules、errors 改成「current folder is your workspace, the same as shell」；lib/docs/02 從「不碰工作區」那串拿掉 run_python。
- 測試加一支：相對路徑寫進工作區、main.py 在小格、沒 `AOS_WS`＝WsMissing。
- 代定：沒 `AOS_WS` 以前照跑，現在報 `WsMissing`（跟 shell 一致）。
- **shell 順手對過**：`_entry` 的 cwd＝`tool_io.workspace()`、tooldef「the working folder is your workspace」、知識庫 `aos/tools/shell.json`「The current folder is your workspace」三處一致，沒東西要回報。
