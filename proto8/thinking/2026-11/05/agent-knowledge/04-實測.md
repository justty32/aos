# 實測：小模型拿著根能不能一路翻到對的頁、答出對的指令

使用者：「目標是haiku或codex-luna能懂」。做法：一支測試架（scratchpad，不進 repo）給模型「`memory read` 根的輸出＋規則」，模型每回合可以回一行 `MEMORY {json}`（架子真的跑 `memory` 工具、把輸出接回去，最多 3 次）或 `FINAL: …`（寫出它會下的工具呼叫／指令）。**不跑 memory 以外的任何工具**，只看它寫出的呼叫對不對。模型：WSL `claude -p --model haiku`（`--tools ""`、`--strict-mcp-config`）；codex `gpt-6-luna` 在公司這台 ChatGPT 帳號**不支援**（`model_not_found`，aos-teams 的名單是家機測的），改 `gpt-5.6-luna`。

## 題組（九題；角色：七題「aos 內的 agent，工具 memory／self_tools／agents／clock」、兩題「幫人用殼的 coding agent，只有 memory」）

| # | 題 | 期望 |
|---|---|---|
| 1 | 工作區有 `tools/math`，把它加給自己叫 `math` | `self_tools {op add, name math, path tools/math}` |
| 2 | 從 `agents/kid` 生一隻 `kid`、腦用 `fake`、問它幾點 | `agents add {name, def, endpoint fake}` → `agents ask` |
| 3 | 收到 `agents: AddRejected … SlotMissing max_running 4 reached`，怎麼了、下一步 | 判官拒、滿 4 隻；收一隻或回報；不迴圈 |
| 4 | （人問）工具裡怎麼知道叫我的 agent 叫什麼 | `aos-agent ctl who` |
| 5 | 想讓定義的每個未來實例都有 `tools/math`，可以用 bash 改定義的 tools.json 嗎 | 不行；自己用 self_tools（覆蓋層）、定義交給人改 |
| 6 | 收到 `self_tools: PathBad /etc/mytool …`，什麼意思、怎麼改 | 路徑要相對工作區或 `lib/` 下；改一次 |
| 7 | （人問）bob 是 stopped，怎麼看原因、修好怎麼叫回 | `aos-agent ctl state --target bob` 看 reason → `ctl start` |
| 8 | 子 agent 要最強的腦、事情急；給哪個 endpoint、能不能順手設 temperature 0 | `smart-high`；不能（包釘死＝`RequestBad`）；急＝信的 `priority.level high` |
| 9 | `agents ask` 回 `AnswerMissing`，查什麼、兩種情況 | `agents ls` 看 phase：stopped＋reason＝掛了；running＝慢，加長 timeout |

## 結果

| 模型 | 改前 | 改後 | 花費 |
|---|---|---|---|
| Claude Haiku | **9／9 答對**；但 Q1、2、3、4、8 第一次 `MEMORY` 都照目錄抄成 `me/`、`agents/`（尾巴斜線）被 `PathBad` 打回、多花一次；Q5 三次查詢用完沒翻到 `me/self_tools`，答對方向但寫「參數名文件沒寫」；Q9 只翻 `errors`，答「看 status 節」沒點名 `agents ls` | Q1 一次查詢直接答對；Q5 寫出精確呼叫；Q9 寫出 `agents {op ls}`＋兩種情況 | 9 題 0.0235 美金、補測 3 題 0.0036 美金 |
| codex gpt-5.6-luna | **9／9 答對**（Q3 同樣先抄 `agents/` 被打回一次）；Q2 還主動給子 agent `tools: [clock]`（題目沒要求但合理：要問時間就得有 clock）；Q7 多寫「信留在 queue 等它回來」 | （改後沒重跑；改的三處都是 Haiku 卡到的） | codex 方案、不計 |

## 改了什麼（改前 → 改後）

1. **工具認尾巴斜線**：`memory` 的 `path` 先 `strip("/")`——目錄裡資料夾節點印成 `me/`，腦照抄也算對（原本 `PathBad`）。
2. **`errors` 節的 `AnswerMissing` 一行**：原「Check its phase (node `status`)」→ 明寫「用 `agents {"op": "ls"}` 看那列：stopped＋reason＝掛了、running＝慢，加長 `timeout_s`；phase 的意思在 `status`」。
3. **`me` 節的 self_tools 一行**：加一個呼叫形狀的例子 `{"op": "add", "name": "<name>", "path": "tools/<name>"}`，再指到子節點——三次查詢用完也拿得到精確呼叫。

沒改的：Q8 Haiku 說「`agents add` 沒有 priority 參數，急只能由子 agent 自己寄信時寫」——這是對的（agents 工具確實沒有 priority；要不要加是 feat-proto 的題，記在 README 代定）。

## 測試架

`scratchpad/harness/harness.py`＋`questions.json`（不進 repo；要重跑：`python3 harness.py --model haiku|luna [--slug gpt-5.6-luna] --kb <knowledge/aos> --tool <lib/agent/memory/_entry> --questions questions.json --out DIR [--only 1,5]`）。花費從 `claude -p --output-format json` 的 `total_cost_usd` 加總；超過 0.25 美金自動停。
