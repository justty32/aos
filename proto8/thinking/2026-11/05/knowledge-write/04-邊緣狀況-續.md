## 11-05 夜實測（opus 邊緣員；只在 scratchpad，沒改 repo；測的是 `/usr/bin/grep` GNU 3.12）

結論已回寫進 [02](02-寫入設計.md) 與 [05](05-實作步驟草稿.md)；這裡留證據。

- **方案 A 現況**：`read /`、`ls /`、`read aos/errors`、memory_export 經捷徑全通（絕對、相對捷徑一樣）；**find 兩處都壞**——根下 `find query=refused` 只回 `notes/one`（`grep -r` 不跟資料夾裡的捷徑）；`find path=aos` grep 有命中但 `op_find` 先 `realpath` 再對根算成 `../../…` 被 `SEGMENT` 丟掉、回 `(none)`。`grep -R` 遇迴圈（`kb/self → kb`）結果正確、退出碼正確、每條迴圈多一行 stderr `warning: recursive directory loop`（R10 透出）。read／ls 對迴圈沒防護（`read self/self/self/…` 讀得到；腦自己給的路徑）。
- **find 撞上同時刪東西**：一邊反覆建刪 `.rm.x/`、`.tmp.q.md`，一邊 find：223 次 9 次 `ReadFailed`（grep 讀到剛被搬走的檔 ENOENT）。加 `--exclude='.*' --exclude-dir='.*'` 還剩 42／10232（GNU grep 的 include／exclude 互撞時**最後一個符合的生效**）；改成 `--include='*.md' --include='*.json' --exclude='.*' --exclude-dir='.*'` 這個順序：10293 次 0 失敗。刪真葉節點那一瞬還是可能 ENOENT → find 碰到退 2 但 stdout 有命中就照印（錯誤已在 stderr）。
- **aos-lock**：經捷徑 acquire，`.lock/` 在真資料夾；唯讀資料夾＝`MkdirFailed … Permission denied` 退 1；租約 2 秒過期後 `show` 仍印舊名牌（沒有過期標記）但別人 acquire 成功接手；持有者死（`--pid` 指 sleep 再 kill）＝立刻拿到；兩人各持 1 秒 `--wait-ms 3000`＝B 在 1.007 秒拿到，各持 4 秒＝後到的 3.017 秒退 10、stderr 沒字；十個一起搶每 0.22 秒換一人、順序不是先來先得；release 後無殘骸。**pid 預設＝叫它的行程**：同一 shell 再 acquire 退 10（不可重入）；`bash -c "aos-lock acquire X; true"` 一結束鎖就被別人拿走；release 不看是誰的（別人能放掉你的鎖）；重複 release＝`LockMissing` 退 1。
- **鎖沒有上下層**：A 鎖 `p/c/`，B 照拿 `p/` 的鎖並把 `c` rename 成 `.rm.3`，`.lock` 跟著搬走、A 之後 release 得 `LockMissing`。
- **Python 寫入**：`mkstemp`＋`os.replace`：0444 變 0600、inode 換新、硬連結斷；葉是捷徑時捷徑被換成一般檔、真檔沒改。兩行程各 `os.replace` 2000 次、旁邊讀 408198 次：0 半截、0 找不到；但先讀再改再寫＝後寫的贏。`os.link(tmp, a.md)` 兩人同建＝一個成功一個 `FileExistsError`。唯讀資料夾 `mkstemp` 直接 `PermissionError`。**升級順序**：先 `mkdir a/` 的那一刻 `read a` 只印 `node: a`、`ls /` 沒摘要、find `(none)`、export 空節點；改成先建 `.new.a/README.md`（含新子）→ `rename .new.a → a` → `unlink a.md`，中間每一刻都完整。目標 `a/` 已非空時 rename／replace 丟 `Errno 39`。
- **`.` 開頭藏得住**：`.lock/`、`.tmp.*`、`.rm.*/`、`x.md.lock/` 對 ls／read／export 完全不可見；find 是 grep 有命中、`file_node` 濾掉；直接讀 `.tmp`＝`PathBad`。
- **同名**：`a.md`＋`a/`＝只看資料夾；`b.md`＋`b.json`＝只看 `.md`；**空資料夾 `c/`＋`c.json`＝空資料夾贏、內容被遮**（最危險）；`D.md`、`e.MD`、`f.yaml`、`g h.md` 一律不可見。所以 `add` 的 `NodeExists` 要含空資料夾。
- **其他**：rename 捷徑成 `.rm.1` 再 `rmtree`＝`OSError`（rmtree 拒絕捷徑）、捷徑殘留、原庫沒事——rm 要先 `islink`；rmtree 資料夾裡有指別庫的捷徑＝別庫沒事。名字長度（tmpfs 255）：252 字段名建得起、但 `.tmp.<名>.…` 與 `<名>.md.lock` 都 `File name too long`；每段 200 字深 20 層撞路徑上限。空資料夾節點、沒根 README 都不報錯。跨檔案系統 rename 沒實測（暫存放真資料夾就碰不到）。
