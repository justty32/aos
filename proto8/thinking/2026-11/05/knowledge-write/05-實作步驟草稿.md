## 不做的（KISS，C-56）

- 不做 metadata／版本（題 4：要就 git）。不做 `append`／`patch`。不做 `mkdir -p`。不做 `AOS_MEMORY` 多路徑。不做權限管理指令（chmod 是人的事）。不做跨機器一致性（NFS／git 同步＝自擔）。
- `memory` 不加任何寫的 op、`_metainfo` 不動（仍 `side_effect false`）。

## 試驗劇本（WSL／家機，W5 之後）

起 daemon＋llm-kernel（fake 劇本 `fake-demo-write`）；`~/kb/{README.md, aos→…, notes/}`；agent-fsm 的 `tools/memory/_memory.json` 指 `~/kb`、`tools.json` 登記 memory＋memory_write；say「記住：今天把 daemon 搬到 /srv」→ 腦 `memory read notes`（空）→ `memory_write add notes/2026-11-06`；第二回合 system prompt 的根目錄多 `notes/`；再 say「剛剛記了什麼」→ 腦 `memory find query=srv` 一次命中。
