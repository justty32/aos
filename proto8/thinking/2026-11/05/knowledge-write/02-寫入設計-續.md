# 寫入設計（續）

## 權限：誰能寫（兩層，程式不驗身分）

1. **工具清單**（C-52）：定義或覆蓋層有配 `memory_write` 的 agent 才會寫；沒配的連 op 都看不到。出廠 `knowledge/aos` 建議**不配**（人改，根進所有人的 prompt）；agent 寫自己的庫（多庫見 [03](03-多庫設計.md)）。
2. **Linux 權限**（C-64）：資料夾對跑 agent 的使用者唯讀＝`WriteFailed <path>: permission denied (this folder is read-only for you; write elsewhere or report)`。鎖也要在那個資料夾 mkdir，所以唯讀的資料夾連鎖都拿不到——一致。

## 同像性：JSON 後端怎麼接（題 4「等大了」，這裡只留接口）

把「節點儲存」收成模組裡六個函數：`locate`、`read_text`、`children`、`write_text`、`make_child`、`remove`。檔案系統版＝現在；JSON 版（`base` 指到一份 `.json`）＝物件↔資料夾、`_text` 鍵↔`README.md`、字串值↔`.md` 葉、路徑 `a/b`↔`#/a/b`，寫走 `aos-json set/del FILE#/a/b`，鎖＝`aos-lock FILE`（整檔一把，因為 JSON 一次 rename 整檔）。做的時候只換模組、三支工具不動。

## 錯誤代號（C-54 四種結尾＋先例）

`ArgumentsBad`、`OpUnknown`、`PathBad`（段不合、根、掛載層）、`MemoryMissing`、`CfgBad`、`NodeMissing`、`NodeExists`（先例 `ToolExists`）、`ChildrenExist`、`TextBad`、`LockFailed`、`WriteFailed`（EACCES／ENOSPC／名字太長）、`ReadFailed`、`LaunchFailed`。stderr 與 stdout 各一行 `memory_write: error: 代號 原因`、退 1（tool_io）。成功 stdout：`node: <路徑>` 一行＋`written N bytes`／`removed`（腦看得到結果）。

## `_tooldef.json`（英文、≤ 80 字、只寫增量）

> Change the shared knowledge base. add creates a new node under an existing parent; edit replaces a node's whole text; rm deletes one (recursive: true for a subtree). text must start with `# Title`; keep a node under 2 KB and split when it grows. Errors: NodeExists, NodeMissing, TextBad, LockFailed (retry once later), WriteFailed (read-only for you). Details: memory node `memory`.

`_metainfo.json`：`side_effect true`、`idempotent false`、`deterministic false`、`parallel false`、`interrupt safe`、`resource io`、`time_ms val 100 / max 5000`。
