# J2 實作結果（11-06）

動了 `proto8/lib/` 的 27 支工具（`lib/base` 18 支、`lib/agent` 的 agents／claude／codex／memory／memory_export／pyfix／self_tools／thought、`lib/aos/check_inbox`）的 `_entry` 與 `_tooldef.json`、`lib/agent/agent_tool.py`，和 [lib/docs/01](../../../../lib/docs/01-分層等.md) 規則 1、4、5a、9 與契約表、[lib/docs/03](../../../../lib/docs/03-索引-agent等.md) 兩條。`tool_io.py`、判官、`cmd/`、`py/`、knowledge 沒動。

## 做了什麼

1. **手寫的參數段全刪**：每支 HELP 只留用法、做什麼、結果與錯誤行；參數一律看 tool_io 從 `_tooldef.json` 生的 Flags 段，同一個參數不再列兩次。`git grep "Arguments:" -- proto8/lib` 為 0。手寫段裡有、`_tooldef.json` 沒講的語意（agents 的 new／add／ask、thought 的工具路徑與追問、llm_fake 的輸出）改成 HELP 裡的一句話。
2. **`_tooldef.json` 補欄**：程式裡有實值的預設寫成 property 的 `default`（例 ls 的 `max_items` 100、bash 的 `timeout_s` 30、thought 的 `max_chars` 600）；頂層加 `errors`（`--help` 印成一行 `Error codes:`）。`description` 文字一字沒改（那是模型看的）。
3. **手驗型別只刪死碼**：schema 已經擋得一樣嚴的（string／boolean／array／object、required 的 null）刪掉；`missing path (a string)` 那種改成 `arguments("path")`（原因一字不差）。integer 的手驗、正數範圍、`strip()` 非空、`OpUnknown`、跨鍵檢查都留著。
4. **claude、codex 工具形改走 tool_io**（E4、A8）：邏輯搬到 `agent_tool.ask_cli`——`tool_io.start` → `cli_session.load_cfg` → `AOS_STACK` → `tool_io.workspace()` → `tool_io.arguments()` → prompt 非空 → `cli_session.ask`。所以兩支也有旗標（`--prompt hi`）與 Flags 段了。`cli_session.call_main` 照留給 `aos-eca-turn --one`。
5. **check_inbox、pyfix、claude、codex 不再把沒設的 `AOS_WS` 當 `.`**（E4、A11）：一律 `tool_io.workspace()`，沒設＝`WsMissing`。
6. thought 的 `GoalMissing`：P4 已拿掉，`git grep GoalMissing -- proto8/lib proto8/knowledge` 為 0。

## 代定（隊長；可翻案）

1. **API 照 J1 實際的**：`tool_io.start(NAME, HELP)`＋`args = tool_io.arguments(...)`（06 原寫 `args = tool_io.start(NAME)`，`start` 不回參數）。
2. **HELP 留手寫的用法與說明、只刪參數段**，不改成全生成：手寫那幾句講的是工作區、截斷規則、結果長怎樣，`_tooldef.json` 沒有。
3. **手寫段的語意沒地方放就寫進 HELP 的 prose，不改 `_tooldef.json` 的 description**：description 是模型的提示，J2 不動模型看到的字；只加 `default`（模型也看得到，但只是事實）。
4. **`default` 只寫有實值的**：程式裡是「沒給＝None 再看情況」的（read 的 `offset`／`max_lines`、view 的 `pointer`／`start`／`end`、llm_fake 的 `endpoint`）不寫；由環境或父 agent 決定的（thought 的 `endpoint`、`tools`）也不寫，description 本來就講了。codex 原本寫了 `"default": null`，隊長審 diff 時拿掉。
5. **`errors` 的寫法**：`ArgumentsBad` 第一，其餘照程式裡出現的順序；叫 `workspace()` 的列 `WsMissing`；每支共通的 `FlagUnknown`、`ModuleMissing` 不列；agents／self_tools／thought 這種「下層最後一行的代號照接」的只列自己會出的。
6. **claude／codex 的轉接放 `agent_tool.py`**（不是各自 `_entry` 抄一份）：兩支同形，`agent_tool` 本來就是「把 agent 包成工具」的共用一支；`import cli_session` 在函式裡才做。
7. **空 prompt 的原因照舊**（`missing prompt (a non-empty string)`），但沒給、給錯型別的現在先被 schema 擋，原因換成 tool_io 的字（代號、退出碼不變，同 J1）。
