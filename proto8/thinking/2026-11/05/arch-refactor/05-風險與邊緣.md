## 邊緣狀況（沒答案也沒關係的，照 user.md 通則：留在這裡供實作時想起）

- 使用者**兩台機器同時開著 daemon**時搬夾：跑著的 Python 行程已載入舊路徑的模組、照常跑到下次重啟；`install.sh` 換連結不影響正在跑的。重啟前 `aos-daemon-ctl sleep` 全部→搬→wake。
- `git mv` 一個含 symlink 的夾：連結目標是字串，相對連結會指錯；`find -xtype l` 抓。
- 頂層 CMake 加了之後有人在某專案夾裡 `cmake -B build` 又在頂層建：兩份 `compile_commands.json`，clangd 看哪份？——各專案 `build/` 的那份；頂層的也在 `impls/build/`，clangd 預設找最近的。
- 甲代 `.aos/tools/*.json`、`contacts.json` 進了版控，封存會一起搬到 `archive/aos-v1/.aos/`，隱藏夾在 archive 裡沒人看——可接受。
- codemap_gen 遇到沒有一句話的新檔：列 warning 不擋；要擋就把它變 wf-lint 的 broken（代定：先不擋，一個月後看數字）。
- aos-schema 封存後 `impls/docs/01` 的表、C-51「schema 當型別」那句、NORMS/10 提名字的地方：條文不改（概念還在），只在表上標「11-xx 封存」。
