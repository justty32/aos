**impls 依賴圖**（各 CMakeLists 的 `target_link_libraries` 實查；`(私)` 是 PRIVATE）：
```
aos-util ← nlohmann                       aos-schema → aos-util、json-schema-validator（沒人連它）
aos-directive → aos-util                  aos-lock → aos-util
aos-exec → aos-util (私)inst-static、aos-directive、Threads
aos-json → aos-util、aos-directive        aos-post → aos-util (私)aos-lock
aos-loop → aos-exec、aos-directive        aos-fsm → aos-loop
aos-daemon → aos-loop、aos-post           aos-llm-kernel → aos-loop (私)aos-post
aos-llm → aos-llm-kernel、aos-post        （所以 aos-llm 連帶拖進 loop→exec→inst→Threads 一整串）
```
每個專案都會自己 `add_subdirectory` 它的依賴，所以 testing.md 的「照順序建 13 次」其實是重工：aos-util 被編 12 次；13 次是因為各專案只有自己當頂層（`PROJECT_IS_TOP_LEVEL`）時才出 bin。
