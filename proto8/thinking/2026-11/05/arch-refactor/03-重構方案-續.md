# 重構方案（續）：§ 5～8（接 [03](03-重構方案.md)）

## 5. 去重與分層（對 D、F4）

- **aos-util 收**：`make_dir`／`is_dir`／`names_in`／`move`／`remove_tree`（三份逐字相同）、純文字原子寫檔 `write_text`（四份手寫 tmp＋rename）、擋訊號那組（`block_signals`／`take_signal` 從 aos-loop 下移）、`is_nat`→改用既有 `is_count`。各專案自己的錯誤代號回自己的 `common.hpp`，`aos-util/error.hpp` 只留通用代號（F4 下層知道上層）。
- **aos-llm 改走 aos-post 的 API**（`send_held`／`take` 不再重寫 tmp→new）；**kernel／llm 切斷對 loop 的依賴**（`llm_kernel.hpp` 不再 include `aos/loop.hpp`；代號用自己的）——aos-llm 變成只連 post＋util，靜態連結體積也小。
- **Python**：錯誤行只留兩份實作、各有理由——`tool_io.die`（工具：stdout 也印）、`aos_flags.die`（cmd：只 stderr）；`cli_session.py:49`、`aos-eca-turn:95` 改 import aos_flags。`aos-daemon-ctl` 改成**可 import 的模組＋薄殼**（`cmd/aos-daemon-ctl/daemon_ctl.py`），aos-agent 直接 import：找 daemon、判活著、`LIMIT_INTS`、讀表各只留一份（順便修 abspath／realpath 與殭屍判斷不一致，D3）。包 aos-post 的函式只留 `aos_ws.py` 那份。`inside()`／`inside_link` 12＋4 份→tool_io（die 隊地盤，交給他們）。

## 7. 命名（對 F1～F3、F5）

- `inst`→`aos-inst`（夾、target `aos-inst`／`aos-inst-static`、產物 `libaos-inst.a`、標頭 `aos/inst.h`），文件不再叫「libaos」；FFI 使用者只有 langs（janet／lua）要跟著改。
- aos-util 公開標頭搬進 `aos/util/*.hpp`（照它自己的規則）；lock／post／kernel 元素夾補同名 `.hpp` 或在 README 註明不補。
- 代號照 C-54 現行條文對一遍再改（候選：`InputExtra`、`DaemonRunning`、`DeadlineMissed`、`AddRejected`、`CtlRejected`；`LetterExists` 若 11-04 已補 `Exists` 結尾就合法）——改名是對外可見的，lib／Python／knowledge errors/codes.md 同一個 commit。
- extras 夾名 vs 指令名在 [03 § 2](03-重構方案.md) 搬夾時一併解。
