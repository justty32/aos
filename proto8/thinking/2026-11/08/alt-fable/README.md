**一句話**：要做的是「錘子的設計圖」。lv1 錘子造 lv2 錘子，錘子＝節點樹本身（本體、審查、改進），用暴力模式匹配去改進錘子。

**跑法（17:53 起，使用者要求提早開跑）**
1. **子題與經驗庫**：Q1～Q6 每批 3 題並行跑。同時跑 E0「過去經驗庫」，整理 arknights 第一～五輪、arcagi 第一～八輪、kb-ideas、wf 教訓（使用者：「這得多反芻幾次，並且搜集過去我們的各種經驗」）。
2. **v1**：Q7 整合 Q1～Q6 與 E0，產出設計圖 v1，接著 Argon 審（`out/Q7-Argon審.md`）。
3. **反芻 v2、v3…**：每版由 fable 讀上一版、Argon 審稿與經驗庫，重寫成完整新版，**每兩版之間都讓 Argon 審一次**（使用者：「每次反芻之間都讓argon參一腳」）。**只反芻兩次（v2、v3）**（使用者：「反芻兩次就夠了」），alt 額度先用完也停。反芻**不只修改字句**：每版至少往外發散一塊，並整理架構與設計體系（使用者：「反芻的時候，不要只是修修改改，可以往外發散拓展，乃至於稍微規劃一下架構與設計體系。」）。

**Argon 是共同設計者，不只是審稿人**（使用者：「argon也可以提出意見，不只是審查，他也是參與者」）。v1 之後，Argon 另寫一份自己的提案 `out/Q7-Argon提案.md`。v2、v3 的 Argon 檔都分成兩部分：(A) 審查、(B) 自己的提案。fable 改版時要吸收 Argon 的提案。

產出都放在 `out/`：`Qn.md`、`E0-經驗.md`、`vK-設計圖.md`、`vK-Argon審.md`。

## 使用者裁定（11-08 18:35）

「都按照推薦吧」→ v3 §五方向題 1～5 全照推薦：
1. 鑄模廠的 LLM 只在 `stall=stop` 時鑄一個蠟模。
2. 新原語入庫除了 MDL 省位元，還要出現在 ≥1 題新解路或見證命中。
3. aos-self-opt 第二輪推遲到 r09 收輪後。

5. H24 每個 epoch 都不准退步，仍是硬底線；震盪只在孵化狀態與 ΔAUC 面積上容許。

**定稿**：`out/v3-設計圖.md`（錘子設計圖 v3），交 arcagi 當 r09 規劃的依據。
