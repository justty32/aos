# 錘子設計圖 v3（反芻第 3 版）

## 一、ELI5 結論

錘子還是那棵活的資料夾樹，但 v3 把廠房分成兩間：**鑄模廠**髒而便宜地破冰，**無菌室**純而嚴格地計分，中間一道無菌鎖。卡住時允許 LLM 在鑄模廠寫粗糙程式解一題，留下的只有輸入輸出軌跡（蠟模），程式本身銷毀；枚舉器把軌跡逐段擬合、跨題反合一成不含題目常數的算子，過了壓縮檢驗、記了先驗位元，才准進無菌室。這一刀同時解掉 v2 的兩個矛盾：lv1 不能真空起步，又不能偷帶先驗；意見 3 的「agent→tool→程式」終於有管線而不是口號。

無菌室裡只剩三種檔：約束見證、統一算子表、權威帳。重寫、拆解、新原語、生長方向全是算子表上的一列，各自帶孵化狀態與環境雜湊；錘子造錘子就是算子表自己長出新列。真升級只認兩條公式：跨題遷移的搜尋壓縮倍率，和含元層總成本的學習曲線面積增益。

v3 往外發散兩塊：**對手鍛造**（鍛造爐專出錘子現在修不好的題型）與**算子二分**（曲線退步時像 git bisect 一樣找出拖累的那一列）。往上收斂的一層是「兩廠房、五層、三件套、十一條規範」。

## 三、完整設計

### 0. 架構體系（往上收斂一層）

```
鑄模廠 foundry/      髒、LLM 可進、不計分、產物只有 I/O 軌跡
   │  無菌鎖：軌跡→枚舉擬合→反合一→跨 ≥3 題壓縮檢驗→記先驗位元
無菌室 hammer/       純、計分、零 LLM
   A 身體   _metainfo.json、_entry（管線契約）、信箱
   B 真值   truth/{train, forge, cal}、_witness.jsonl
   C 評審   frozen.json、三判準、LTO-SCF、ΔAUC_total
   D 算子   ops.jsonl（rewrite|decomp|comb|route，含孵化狀態）
   E 生長   epochs/<n>/、stall、UCB 路由、parks/<p>/cache
   F 經濟排程 → r10
```

層間方向沿 v2：A 被讀不寫、B 只被 C／D 讀、C 裁 D、E 排 D、沒有一層能寫上一層規則。無菌鎖是唯一跨廠房的介面。

規範 N1～N8 沿 v2，改一條加三條：
- **N5'** 踏腳石是算子表的 `incubating` 狀態，TTL 到期轉 `dormant`，`env_hash` 變動自動回孵化；永不計分。
- **N9 無菌鎖**：LLM 與人的產物只能以 I/O 軌跡進無菌室；程式本體銷毀；進入的算子在 `frozen.json#/priors` 記位元。
- **N10 全成本計量**：任何學習曲線橫軸是本體＋元層＋鍛造爐的總評估次數。
- **N11 生長方向是算子**，可被 layer-2 改，不可寫死在程式裡。

候選 CONCEPTS 新增：鑄模廠、蠟模、無菌鎖、約束見證、橋接鍛造、對手鍛造、算子、LTO-SCF、ΔAUC_total、算子二分。

### 1. 鑄模廠與無菌鎖（失蠟法）

觸發：`stall` 判 `stop`（缺原語）時，鑄模廠對殘差最近的 1 題放 LLM 解一次，只留 `foundry/wax/<task>.jsonl`（每步中間狀態）。無菌鎖三步：枚舉器對相鄰狀態段擬合 seed 程式；跨 ≥3 個蠟模反合一（復用 `compress.py` 的 `anti_unify`）；過 MDL 與留一後寫進 `ops.jsonl` `kind:comb, status:incubating, by:foundry`，`frozen.json#/priors` 加它的位元數。人類干預走同一道鎖：手寫 Python 解一題也只留軌跡。

- 經驗：條 3（不得真空起步）與純度目標的矛盾在此化解；條 20（LLM 位置）；條 16（蠟模不計分，只做料）。

### 2. 身體：管線契約

`_metainfo.json` 沿 v2 的 key，`_entry` 一律 stdin JSONL 進、stdout JSONL 出；`pipe:[H,G]` 就是 Unix 管線。in-process 快路徑 import 同一函數，收輪抽成 `aos_metaopt` 時不改契約。`_view.sh` 把殘差印成終端色塊。

- 經驗：條 27、鐵律 6。

### 3. 真值：鍛造爐 v2 與對手鍛造（發散一）

每 epoch 兩種料各 500 題：單步破損（餵重寫）、橋接挖空（餵縱拆與拆解算子）。**對手鍛造**：抽樣權重 ∝ (1 − 該算子類型上一輪修補命中率)，鍛造爐自動對準錘子修不好的題型，形成課程；權重封頂 5 倍防單一類型壟斷。合成題永不計分、每 epoch 重抽。

約束見證：`{"task","pair","dir":"bwd","op":"wp_overlay","mask_grid":[[2,null,2]],"props":{"shape":[2,3]},"base_bits":48.0}`；`null` 格誤差記 0。起手逆推器 6 個（overlay、crop／paste、colormap、take／drop），列進 `priors`。

- 經驗：條 16、18（真值供給是主瓶頸）；條 4（合成不計分）；條 9（隔離矩陣）。

### 4. 評審：三判準、LTO-SCF、ΔAUC_total、算子二分（發散二）

主線沿 Q4 兩段判準；H24 不退是凍結集硬底線。lv2 門：`ledger.jsonl` 出現 `layer:2`、`by` 樹內節點、接受項是 `ops.jsonl` 列，且 LTO-SCF ≥1.5（訓練池對半切，A 折提煉的算子集凍結套入 B 折，幾何平均加速比，前提不丟已解題），且元層算力 ≤ 省下的 50%。自舉三階量 ΔAUC_total：stage1 與 stage3 從同一空種子起跑，橫軸 log₁₀ 總評估次數，縱軸盲測解出數。r09 只報。

**算子二分**：ΔAUC_total < 0 或 H24 退時，對本輪 `live` 算子列按 `born` 排序二分停用、重跑 4-pass 短曲線，找出拖累列標 `dormant` 並在 ledger 記 `blamed_by`。確定性搜尋下二分可靠，成本 log₂(列數) 次短曲線。

- 經驗：T4、條 8（整數事件與兩折）、條 11（封頂）、條 12（門檻先預核）。

### 5. 算子：一張表、四種列

`ops.jsonl` 一列：`{id, kind, status, when_res, lhs, rhs, free_slots, mdl_bits, ttl, env_hash, lto_scf, by, born}`。`kind`：`rewrite`（L2 專用替換，`free_slots` 交 `enum.py` 填）、`decomp`（拆解規則，含縱拆逆推器）、`comb`（新原語，來自睡眠造詞或無菌鎖）、`route`（生長方向，UCB 的臂）。`status`：`incubating|live|dormant`。蒸餾＝同一編輯簽名在接受紀錄 ≥3 次寫成 `rewrite` 列，影子 2 epoch 命中 ≥80% 才 `live`。固化（Q3）＝同一引擎換真值，進度量 EPC。

- 經驗：條 5（只對結構化槽位搜）、條 7、條 33。

### 6. 生長：epoch、停滯、UCB 路由、園區快取

epoch 四產物沿 Q4。`stall` 判餓死／飽和／stop 沿 Q4。路由：四條 `route` 列（縱拆、橫拆、睡眠造詞、鑄模破冰），UCB 獎勵＝每千次評估壓縮位元（每題封頂 2 bits）；起步先驗 = v2 順序。園區 r09 只有 `parks/list/cache/`，共用 `witness.py` 已算的特徵與中間列表雜湊。

- 經驗：T3、條 24、T10。

### 7. 推廣到 arcagi 與 aos 以外

失蠟法是通用的「agent→程式」管線：任何 aos agent 節點的 `observed.jsonl` 就是蠟模，Q3 的按 trace 拆、按殘差拆就是無菌鎖的前兩步。可直接套的：linker 的 kb_link（第二輪）、wf-lint 的規則（lint 判決當真值）。不能套的：arknights 的名字判斷，條 6 說殘差無結構，鎖會正確地什麼都不放行，這是設計要的結果。

## 五、要使用者裁的方向題

1. **鑄模廠的 LLM 何時開？** 推薦只在 `stall=stop` 時鑄一個蠟模。後果：破冰慢，但每個蠟模都對準確定缺的原語；若改每 epoch 配額 1 個，r09 曲線的 priors 帳會快速膨脹，從零純度的說法變弱。
2. **新原語入庫門要不要加「解題證據」？** 推薦要：MDL 省位元之外，還要出現在 ≥1 題新解路或見證命中。後果：長詞慢；只用 MDL 則條 4 的「17 倍壓縮多 1 題」會重演。
3. **aos-self-opt 第二輪推遲到 r09 收輪後？** 推薦是。後果：aos 線空窗約一輪，但格式只改一次、不再兩邊各記一筆。
4. **守門搜尋留選配還是砍？** 推薦留選配。後果：線 B 有餘力就多一條便宜的 layer-2 證據；砍了 r09 的 lv2 只剩 LTO-SCF 一種證法。
5. **H24 逐 epoch 不退要不要繼續當硬底線？** 推薦要，震盪只在孵化狀態與 ΔAUC 面積上容許。後果：某些要退一步的重構進不了主線，只能在孵化槽長；若放開，條 9、14 的汙染與背答案教訓會回來。

LLM 並行 ≤2、錢制影子帳延到 r10、園區只做快取，沿前兩版裁定不再問。
