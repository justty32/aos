### (A) 審查：盲點、原意偏離、過度保守與複雜化

1. **致命盲點：`H24` 既當「盲測」又當「轉正門檻」，實質洩漏真值**
   §五 `I-真值隔離` 規定盲測任何節點不可讀，§四 `轉正` 卻寫死 `H24 不退`。只要晉升判準讀了 `H24` 來決定去留，每淘汰一個候選就向主線洩漏 1 bit 盲測資訊（Adaptive Overfitting），`H24` 當場喪失盲測資格；且 24 題上單題波動高達 4.17%，拿它逐輪守門既破防又鎖死結構重構。
2. **自相矛盾（偏離意見 3）：「毀碼無菌鎖」撞死 `agent → tool → prog` 固化鏈**
   §六.c 要求無菌鎖銷毀 LLM 與人的程式、只過 I/O 蠟模；§四 `固化` 卻寫節點走 `agent→tool→prog`、棄權退回 `impl.prev`、計 `llm_share`。若過鎖必須毀碼、逼無菌室看 I/O 盲猜重湊，意見 3「把 agent 拆小逐步固化成 tool 乃至純程式」在架構上根本走不通——白交 $10^5$ LLM 稅還要從頭暴力枚舉。
3. **結構缺位（偏離意見 1／2／6）：「改進算子」從算子表蒸發，A～F 官僚分層破壞同構性**
   使用者原意是「本體、審查、改進全都是節點，全都要用同一套暴力模式匹配優化」，連園區都明講「2D 一團、程式改進一團」。但 S1 把 `ops.jsonl` 封死在 7 種 `kind`（4 本體＋3 審查），**唯獨漏了改進算子**；又用 A～F 單向層把 C／D／E 焊死，導致改進器無法像本體一樣聚成園區並被同一套引擎演化。
4. **機制懸空與過度保守（偏離意見 4／8）：缺「殘差帳」與「上下分岔公式」，主線鎖太死**
   意見 4 類比神經網路的精髓是「蒐集一批與 ground truth 的差異（殘差）拿去改進」，S1 的蠟模跑完即毀，沒留下供非 LLM 改進器做模式匹配的結構化誤差；「往上長 vs 往下拆」也只留空檔名 `stall.json`。意見 8 使用者看過 r08 後已明言「往後退正常，重點是整體趨勢」，S1 仍堅持主線逐輪不退＋禁止本體與審查同輪轉正，讓需要新 `gate` 護航的新算子永遠無法上線。
5. **過度複雜與形式主義**：lv1 還沒跑通就立 6 層 15 條法典；而 `H-15` 為遷就 C-52 竟規定「purity 只掃 `interfaces.json` 宣告、不讀實作」，直接違背自己的 `I-11 自報不當證據`。隔離該靠 `aos-exec` 掛載權限物理斷路，不是查自報戶口。

### (B) Argon 的共同設計提案：補齊引擎物理學

#### 1. 同構殘差樹（Homoiconic Residual Tree）——落實意見 4＋6
* **類比**：神經網路能疊層，靠的是全網共用一種反向貨幣——梯度；符號系統的梯度就是**結構化殘差（Typed Residual）**。
* **機制與格式**：撤除 C／D 硬分界，所有節點統一為 `(In -> Out)`，`ops.jsonl` 補第 8 種 `kind: "xform"`（吃 `AST × 殘差分群` 吐 `AST修補`）。蠟模銷毀前必須提煉**殘差帳 `_residuals.jsonl`**（保留近 $N$ 筆失敗差異並做反合一分群）：
  ```json
  {"ep":12,"node":"parks/2d/fill","task":"t04","err":"fn",
   "delta":{"hamming":4,"bbox":[2,2,4,4],"broken":["color_cnt"]},"cid":"r7f"}
  ```
  如此同一套暴力模式匹配既能吃網格殘差合成 2D 算子、吃誤判殘差合成 `gate`、也能吃修補殘差合成 `xform` 改進器，自然長出「2D 園區」與「改進器園區」。
* **量法**：**殘差熵減率** $\text{RCR} = \frac{H(\Delta_{\text{before}}) - H(\Delta_{\text{after}})}{\text{evals}/10^3}$。改進列留存判準為 $\mathbb{E}[\text{RCR}]$ 勝過盲枚舉基線。

#### 2. 熵導向雙向分岔器（Up/Down Bifurcator）——把意見 4 變成可算判準
* **類比**：JIT 剖析——函式太雜就拆子程序（往下拆）；函式已極簡卻搜不到解就換優化器（往上長）。
* **機制與格式**：節點連停滯 $K=3$ epoch 時，讀取 `_residuals.jsonl` 的分群數 $C$ 與群間熵 $H_{\text{cid}}$：
  * **往下拆**：殘差呈多峰（$C \ge 2$）或 $|\text{AST}| > L_{\max}$，代表職責糾纏，自動插 `route`（橫拆）或 `witness`（縱拆），子題變小後直接觸發暴力符號回歸。
  * **往上長**：節點已極小且殘差單峰集中（$C=1$），代表當前改進器的搜尋語法有盲區，自動掛上 `layer+1` 節點改寫該改進器的 `xform` 規則。
  * `stall.json` 格式：`{"node":"...","k":3,"clusters":3,"ast_sz":22,"bdi":6.8,"act":"split_h"}`。
* **量法**：**分岔指數** $\text{BDI} = H_{\text{cid}} \cdot \log_2(1 + |\text{AST}|)$。$\text{BDI} > \theta$ 往下拆，否則往上長；依事後 $\Delta\text{RCR}/\text{cost}$ 動態校準 $\theta$。

#### 3. 白箱結晶槽（Glass-Box Crystallizer）——打通意見 3 與無菌室
* **類比**：CPU Trace Cache——直譯器（`agent`）跑過的熱路徑自動錄軌，背景編譯成帶 `guard` 的純機器碼（`prog`）。
* **機制與格式**：無菌鎖改為「**禁執行期 LLM，准許付清先驗稅的白箱 DSL AST 過鎖**」。雙軌結晶：① 任何 `agent/tool`（含審查與改進）執行時自動把 I/O 寫入 `crystal_buf.jsonl`，由「結晶園區」背景跑低成本符號回歸／決策樹擬合；② 鑄模廠可直接提交 `frozen.json#/dsl_primitives` 組成的純 AST，但須扣繳 **MDL 先驗稅** $\text{Bits}_{\text{AST}} = N_{\text{op}}\log_2|\Sigma| + \text{lit\_bits}$，真題淨省位元大於稅額才准孵化，杜絕硬編碼作弊又免去毀碼瞎猜。
* **格式與量法**：`state.json` 記 `{"chain":[{"tier":"prog","guard":"h<=10","cov":0.82},{"tier":"agent","cov":0.18}]}`。**計分模式**硬切斷只跑 `prog`，並用 Linux namespace 卸載 `AOS_LLM_KERNEL` 與盲測目錄（物理保證 `llm_calls=0` 與隔離）；進度量看各園區**結晶覆蓋率** $\text{CR}$（`prog` 接手呼叫佔比）與單題成本 $\text{EPC}$。

#### 4. 三池隔離＋棘輪包絡線＋熱節點物化——落實意見 7＋8
* **三池與棘輪**：真值拆為 `train`、`canary`（輪替校準池，供 `promote` 裁判）與 `H24`（**絕對盲測金庫**，引擎無權限，僅外部程序畫趨勢圖，0 bit 回流）。主線採**棘輪包絡線**：分離 `best_ckpt` 與 `head`，當重構大幅降複雜度（$\Delta\text{MDL} < -B$ bits）時容許 `head` 在 `canary` 短暫退步 $\le \epsilon$ 達 $W=3$ epoch，逾期未創淨值新高（$\text{Solved\_bits} - \text{MDL\_bits}$）才退回 `best_ckpt`；並允許 `(本體列, 審查列)` 以 `tx_bundle` 同輪原子轉正。
* **活樹體感（補意見 7）**：不把萬物藏進單一 `ops.jsonl`——每個園區皆為實體資料夾；輕算子平時住列內，一旦殘差升溫就自動在 `parks/<p>/hot/<op_id>/` 物化出子資料夾（掛 `_residuals.jsonl` 與 `inbox/`），使用者隨時 `cd` 進去看病灶、投信干預，固化穩定後再收折回列。
