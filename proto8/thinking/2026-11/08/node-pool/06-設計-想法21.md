## 0. 一句話

第五輪的壓縮全部零 LLM，分兩塊：**規則池去重**（被同判決、更短的規則蓋住的標 `covered`，不刪；試算 186→95 條有效）和**短名嵌長名的本質**（不是「鄰字是漢字」，而是「這個短名在語料裡大多數時候都是同一個長字串的一部分」；試算在真庫找到 2 條還在庫裡的錯連、0 條誤擋）。

## 2. 改掉 05 的兩處

1. **M4 的本質換掉**（§1 試算）：「鄰字是漢字就判嵌在長名裡」會擋掉四分之三的對連結。改成**語料比例**：短名的某個延伸字串（左或右多一個漢字）在語料中出現次數佔短名總次數 ≥ 70% 且 ≥ 5 次，才判「嵌在更長的字串裡」。這是「記本質不記全貌」的實例：不用逐筆死記「開斯特、耶拉岡德…」，存一條比例規則＋語料計數就好。擋不到的「斯特」「大帝」型（短名分散在很多長名裡）第五輪**不追**，照舊由代定 73 兜底＋例外表，記成量法 d 的已知漏網。
2. **欄位名 `kind` 已被佔用**：現行每條規則都有 `kind: "pattern"`。05 的 general／exception／covered／literal 改叫 **`form`**，其餘照 05。

## 3. 檔與格式

1. `W/distill/rules.jsonl` 每條加欄位（缺欄＝`form: literal`；不遷移，第一次 compress 補上）：

   ```json
   {"form": "covered", "parent": "E3-d6c03407ad06", "covered_from": "live",
    "compress": {"at": "2026-11-xx", "by": "distill compress"}}
   ```

   - `form`：`general`（有子規則被它蓋住）｜`exception`｜`covered`｜`literal`。
   - `parent`：蓋住它的那條（取**最長**的一條，單值）；`covered_from`：被蓋前的 status，`uncompress` 照它恢復。
   - `status` 照舊（live／shadow／candidate）；covered 的 status 改成 `covered`，不參與作答，影子計分照記 `stats`。
2. 嵌詞表 `K/index/inword.json` 加 `templates`：`[{"tmpl": "X後", "chars": "其前幕戰日醒最"}, {"tmpl": "後X", "chars": "續"}]`，對應的 8 筆從 `words` 移到 `templates` 的 `from` 欄留底（照 05 Q5 推薦 A）；04 說的 9 筆裡「公爵後」是兩字＋後，模板只收單字 X，它留在 `words`。比對時 words 先、templates 後。
3. 短名嵌長名：
   - `K/index/embed.json`（工具產、隊長不手改）：`{ratio: 0.7, min: 5, corpus: "<語料路徑>", rev: "<語料 git rev>", names: {"耶拉": {"耶拉岡": [438, 517]}, …}}`——只存**超過門檻**的短名與延伸，不存全部計數。語料版本變了就重算。
   - `K/index/short_ok.json`：隊長手寫的例外（「這個延伸其實可以連」），起步空。

## 4. 工具（都在 `W/distill/` 與 `W/kb_link/`，Python，輸出英文、錯誤經 `tool_io`，不叫 LLM）

| 指令 | 做什麼 | 錯誤代號 |
|---|---|---|
| `distill compress [--dry-run]` | 對 rules.jsonl 算蓋住／例外、寫 `form`／`parent`／`covered_from`；**被蓋的是 live 時不自動**，列進 `--dry-run` 輸出的 `needs_captain` 等隊長加 `--approve <id>`（05 衝突 4）；嵌詞表收 templates | `RulesBad` |
| `distill uncompress <id>` | 把 `<id>` 的子規則照 `covered_from` 恢復、`<id>` 降一級 | `RuleMissing`、`NotGeneral` |
| `distill compress --suspect` | 照 05 §2 兩條訊號＋§3 例外 ≥20% 標 `suspect`，寫進收輪報告 | 同上 |
| `kb_link embed build` | 讀語料、產 `embed.json`；只算名字表 ≤3 字的名字 | `CorpusMissing` |
| 連結前檢查 | `kb_link` 在 T0 規則之後、live 規則之前查 `embed.json`：命中且不在 `short_ok` → 判 nolink，記 `rule: "embed"` | — |

## 5. 量法（取代 05 §5 表的 a、d；其餘照 05）

| 項 | 怎麼量 | 判準 |
|---|---|---|
| a 條數 | 有效規則（不含 covered） | ≤ 110；試算 95，第五輪新長的規則照同樣算 |
| b 留出題不掉 | 第四輪留出 113 題，壓前壓後 live 判決逐題比 | 判決不同的題 = 0（試算推得：被蓋的都在同級或更高級的同判決規則下） |
| c 換題不掉 | 第五輪新題上，壓前（影子跑原池）vs 壓後 | 覆蓋不降、錯不增 |
| d 短名嵌長名 | ①真庫現有連結重放 ②第三、四輪已知 5 例 ③第五輪每批抽查 | ①誤擋 ≤ 1／619（試算 0，2 個命中都是錯連）②擋到 ≥ 1/5（試算只擋到耶拉；斯特、大帝型是已知漏網，不算不過）③錯連 Z5 比第四輪 A 批少 |
| e、f、g | 照 05 | 照 05 |

退場照 05：a 或 b 不過→想法 21 第五輪收；d 不過只退 embed，不牽連 compress。
