## 結論（11-08）

- 第一輪＝在 PG5 第五輪紀錄上**離線重播**。用無神經網路、零 LLM 的枚舉式符號迴歸，從「零規則＋通用原語」長出 linker 判決規則（主功能）；量的是從空長到會的學習曲線。
- 背答案用兩種集抓：實體替換合成題抓「背名字」，兩折加 holdout 任務抓「背句式」。漢字常數一律禁。
- 共用核心（切分、枚舉、帳本、曲線、五種 JSON 格式）放 `proto8/py/aos_metaopt/`，arcagi 接同一份（代定 D6）。
- 驗收看兩折平均：非 T0 覆蓋 ≥15%、錯率 ≤5%、合成落差 ≤10 個百分點、被解的非 T0 題 ≥30、live 規則 ≥50% 用到非字元原語、一條曲線 ≤1 小時、LLM token 0。
- 4 個 ask 已上看板（C-52、C-84、核心放哪、KB 算不算先驗），等使用者裁；代定照推薦往下寫。
