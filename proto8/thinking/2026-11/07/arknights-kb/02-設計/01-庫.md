# 庫怎麼切（結論；裁題 1、2 在入口）

## 三層，只有一層進 memory 樹

| 層 | 在哪 | 誰寫 | 進 `memory` 樹？ |
|---|---|---|---|
| 原文證據層 | `ws/corpus/arknights/`（clone，`lore/evidence/`＋`corpus/processed/` 複本）| 沒人，唯讀 | 否（裁題 2）；節點用 `sources:` 回指 |
| 詞條層 | `ws/kb-ak/ak/<類>/…` | writer agent | 是 |
| 索引層 | `ws/kb-ak/ak/index/*.json`、`names.tsv` | 腳本 `ak_slug`／`kb_index` | 是（`.json` 葉，`find` 可命中別名） |

「轉格式 vs 重新歸納」：**第一～三輪只轉格式**（`lore/` 的 14 類本來就是詞條；一檔→一節點，超 2 KB 拆子節點）；**第四輪起重新歸納**（characters＋character_deep_dive＋relationship_map 三處講同一人的融成 `characters/<slug>/{README,relations,writing}`）。先轉再融，因為轉是確定性高的雜活、融是要腦的。

## 樹長相

```
ws/kb-ak/                      ← 一個庫；writer 的 memory 指這裡
├─ README.md                   ← 人寫：# Arknights KB / one-line summary / children
├─ aos -> ../../knowledge/aos  ← 捷徑，出廠知識唯讀（K7 方案 A）
├─ ak/
│  ├─ README.md                ← 英文：what each class is, how slugs are formed
│  ├─ places/<slug>.md         ← 第一輪（41）
│  ├─ factions/<slug>.md       ← 第二輪（93）
│  ├─ characters/<slug>.md 或 <slug>/README.md＋子節     ← 第二輪起
│  ├─ operators/<char_id>.md   ← 第三輪（400）
│  ├─ events/<act_id>.md、activities/、story/main_<n>/、timeline/、concepts/、items/
│  └─ index/{aliases.json, classes.json}   ← 腳本生：中文名／別名→路徑
└─ work/                       ← 隊伍工作記憶：batches/<n>.json、rejects.md、manual.md
```

`lore/` 的 `INDEX.md`、`_split_manifest.tsv`、`*.md` 舊入口 stub 不轉（導航由 memory 的目錄取代）。

## 段名：英文路徑，中文留在標題裡

- 規則不變：段名 `[a-z0-9_-]+`（不足 #4 不改程式，改資料）。
- **有 ID 的類用 ID**：operators `char_002_amiya`（`### 代號（char ID）` 行就有）、events／activities 用活動 ID（`act17mini`…）、story 用 `main_0`…。
- **沒 ID 的類（places、factions、characters、concepts、items）查對照表** `ws/kb-ak/ak/index/names.tsv`（三欄 `zh  slug  class`）：第一次由 gpt 一次生整類（拼音、`-` 連、撞名加 `-2`），進 git 之後**只查不生**；人可直接改表。機器沒有 pypinyin，裝了就改成腳本生初稿（代定）。
- 腳本 `ak_slug <class> <中文名>`：查表命中印 slug、沒命中退 `NameMissing`（批次先補表再派工，writer 永遠拿到現成路徑）。
- 標題雙語 `# 伊比利亞之眼 (yibiliya-zhi-yan)`，`find` 用中文或 slug 都命中（grep -F 掃內容）。

## 節點格式（給 writer 的 system.txt 就是這一段的英文版）

```
# 伊比利亞之眼 (yibiliya-zhi-yan)
One-line summary in the content language (printed by ls/read).

## facts
- ...（本文中文，短句；引文保留原文簡體）
## relations
- [[characters/<slug>]] 關係一句
## sources
- lore/places/伊比利亞之眼.md
- lore/evidence/places/xxx.md:L12-L40
```

- 第 1 行標題、第 2 個非空行摘要（memory 慣例）；≤ 2 KB，超過由 `kb_split` 拆成 `<slug>/README.md`＋子節（facts／relations／sources 各一節）。
- `[[class/slug]]` 是本庫內部連結寫法，`kb_lint` 驗目標存在；不用 Markdown 相對連結（memory 路徑不是檔案路徑）。
- `sources:` 只放路徑＋行號，不抄證據；要看原文→第一輪 `read`，第二輪 `ak_src`（專屬工具，`{"path", "lines"?}`，限 `ws/corpus/`）。

## 多庫

照 K7 已裁：`kb-ak/` 根放捷徑 `aos ->`。W1 沒做前 `find` 不跟捷徑（不足 #6），第一輪 writer 不需要 aos 知識、可忍；W1 做完自然好。隊長要看整棵＝`memory_export`。
