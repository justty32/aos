## 使用者裁定（11-07 午，對隊長六題）

原話逐字：「1.節點名確實建議英文，剩下隨意。內部內容建議按照語料原文，這樣能最大程度保持原意。這是儲存方面，至於使用者想看的時候，可以透過其他界面，比如做一份附屬知識庫，其中是翻譯過的白話，或是直接準備一個agent幫忙解答問題。類似RAG。2.不搬。3.可以。4.好。5.不限制。6.不用，按照現在的路走，會很自然的慢慢膨脹到上千上萬。」

決定：
1. 節點名英文；條目內文**照語料原文**存（保原意），不翻譯、不改寫；給人看的走另一層——附屬知識庫（翻成白話）或一個問答 agent（類似 RAG）。標題等其餘隨意。
2. `lore/evidence` 不搬進知識樹。
3. 格式檢查過就 commit，事後抽查。
4. 重跑一致率只記錄、不當門檻。
5. gpt 呼叫不設每日上限。
6. 不特地安排「上千 agent」測試輪；照現在的路走，自然膨脹。
