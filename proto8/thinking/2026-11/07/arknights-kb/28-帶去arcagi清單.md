## 0. 冷啟動：先看這段

**arknights-kb 是什麼**：把明日方舟的劇情文字整理成 aos 的知識庫（地點、人物、事件節點，以及節點之間的連結）。最核心、最花錢的一步是「這段文字裡的這個詞，是不是在指某個節點」——規則答得了就不問 AI，答不了才送 LLM。整條線五輪，第五輪不再擴範圍，改做**元優化**：同一批 22 個任務反覆跑，量「教練」（讓系統自己長規則的那套改進流程）改了之後學得有沒有比較快。

**詞彙對照**（左邊是本檔用語，右邊是 arcagi 大約對應的東西）：

| arknights-kb | 意思 | arcagi 大約是 |
|---|---|---|
| 任務 | 一個地點／人物／事件的整理工作 | 一題 ARC 任務 |
| T2 題、要問 AI 的題 | 規則答不了、得送 LLM 的小判斷 | 搜尋後還沒解的題（或要用到昂貴步驟的題） |
| pass | 從空知識的庫起跑，把 22 任務跑一遍；學到的規則留著，產物倒回 | 同一份 training 子集重跑一次、積木庫留著 |
| 改進者、教練 | 批末那一串：真值整理、規則升降、蒸餾、審視者 | 積木產生器＋帳本＋`_gen/_meta` |
| 元優化 | 改「改進者」本身，再跑一條比曲線 | 改產生器的產生器（`aos/blocks/_gen/_meta/`） |
| 真值 | 已知正確答案（隊長裁的、語料自帶的、參考與生產一致的） | training 範例的正解、過驗證的程式 |
| 參考呼叫 | 用貴的模型（sol）答同一題做交叉檢查 | 另一個求解器或 LLM 做交叉核對 |
| live 規則 | 已經上線、會實際作答的規則 | 正式進搜尋的積木 |

**第五輪的實測一句話**：舊教練跑兩條，曲線一模一樣（185→185→182→182→184 題），雜訊 0；新教練（讓參考答案涵蓋全部題、並把它記成真值；擋掉只看標點的規則）跑出 185→185→171→168→168，**少 9%、是真效果，但每條試驗多花 12～14%**，改教練本身又花了約一條試驗的錢。主要靠真值供給（已知答案 124→約 435 題），不是靠更聰明的規則。詳見 [27](27-第五輪總結簡報.md)。

**最重要的 5 項**（細節在第 2、3 節）：

1. **題數曲線＋空基準重跑＋兩條基準量雜訊**（§2.2）：先證明改進大過雜訊，才算數。
2. **打基準 tag 前先 diff**（§2.2「基準 tag 防汙染」、坑 1）：學到的東西會被快照進定義樹，tag 一打錯，「空基準」就不空了。
3. **教練學不動時先查真值供給**（§2.5「三層真值」、坑 5）：第五輪 9% 的改進幾乎全來自這裡。
4. **規則逐條升降＋同一題只算一次**（§2.3）：新積木先影子跑、過門檻才上線；門檻開跑前先預核。
5. **改進花費另記一本 meta 帳**（§2.1）：才算得出改教練回本了沒；第五輪的答案是「還沒」。

## 1. 一句話結論

能帶走的主要是**「量改進過程」的那套尺和帳**（題數曲線、從空基準重置重跑、兩條基準量雜訊、元審視要寫可核預測、改進花費另記帳），以及**規則怎麼長、怎麼升降、怎麼壓縮**的機制；arknights 的名字表、真值和庫本身不帶。

**元優化實測**（第五輪 v1）：改教練 −9%（要問 AI 的題 184→168，雜訊 0），主要靠真值供給（已知答案 124→約 435）；參考全涵蓋的錢比預期多（參考 token +48～80%，預估 ≤30%），每條試驗總分 +12～14%，生產那頭沒省（整個任務不用問 AI 的仍是 0 個）。

## 3. 別再踩的坑

1. **打基準 tag 前先 diff，確認只有碼**：pass 快照會把學到的規則一起 commit 進 `ws/defs`，在那上面打的 tag 會把規則帶進「空基準」；本任踩了兩次。每次 `git diff --stat base-v0 <tag> -- ws/defs`。出處：[代定 99、101](代定清單.md)。
2. **改了定義碼要先 commit 再 `git tag -f`**，不然 trial 重置會把新碼蓋回舊 tag。出處：[交棒「下一步」末行](交棒.md)。
3. **codex 沙箱不能寫 `.git`**：每任務要 commit 的批一個都進不了庫；codex 只寫碼，會 commit 的由 Claude 在沙箱外跑。出處：[代定 82](代定清單.md)、[23 §7](23-第四輪總結簡報.md)。
4. **只看標點的規則會套到不該套的地方**：自動學出的「標點旁就連」規則套到普通詞裡的單字名（安定的「安」、雪山的「山」）；規則要帶適用範圍。出處：[代定 96、98](代定清單.md)。
5. **改進者沒料可學**：參考只抽樣、答案也沒進真值，候選規則永遠到不了門檻；處方做一半（只多跑參考、沒把答案寫進真值）等於沒測。出處：[代定 98、101](代定清單.md)。
6. **門檻先預核**：同一批反覆跑時，不去重就灌水；去重後門檻可能結構上到不了。開跑前用舊資料算能過幾條，事先寫死「不夠就降到多少」。出處：[25c §4](25c-第五輪規劃-fable-反芻2.md)、[代定 95](代定清單.md)。
7. **主指標要選改進真的會動的量**：錢只在整個任務清零時才動，接走一題不省錢；指標選錯，曲線是平的也看不出改進者好壞。出處：[25c §0](25c-第五輪規劃-fable-反芻2.md)。
8. **格式對不代表判斷對**：本機 12B 格式全合法、check 照過，判斷卻默默退步；要有語意閘（對高階參考抽樣）。出處：[得失 第 2 輪「最重要的踩坑」](得失.md)。
9. **參考本身也會錯、規則直判也會錯**：整體同意率 ≥90% 就放行，單題的不同意沒人裁，錯連就進了庫；要逐題裁。出處：[得失 第三輪 C2～C4](得失.md)、[代定 59](代定清單.md)。
10. **只看比例的閘會誤擋**：全拒閘把「外國地名裡的普通字全答不連」（其實是對的）當異常整個擋下。出處：[得失 第三輪 C2](得失.md)、[代定 51](代定清單.md)。
11. **處方也會讓下游變貴**：改一步讓別步失敗退級，after 要看整個任務指標。出處：[得失 第 2 輪烏薩斯審視](得失.md)。
12. **「學」的步驟也要有失敗回饋**：學不到就默默丟，看不出來。出處：[得失 第 2 輪伊比利亞之眼審視](得失.md)。
13. **審視、試驗比生產還貴**：改善花費曾是生產 8.9 倍、降級階梯試驗是正式工作 3.7 倍；這類量只在換題型或換模型時跑。出處：[得失 第 2 輪](得失.md)、[代定 17](代定清單.md)。
14. **hold 的半成品會留在庫裡**，批末工具又假設它在；進 hold 當下就搬出。出處：[代定 84、91](代定清單.md)。
15. **zsh 分詞**：`$C:path` 要寫 `${C}:path`、`set -- $x` 不會分詞，要分詞就 `bash -c`。出處：[交棒「下一步」末行](交棒.md)。
16. **gpt 會把力氣花在寫測試與佐證**，AI 寫的測試多半沒用；任務書寫明「完成條件＝實跑一遍結果對、不寫測試」。出處：[kb-ideas 想法 19](../kb-ideas/README.md)。
17. **圖紙要寫清新舊機制怎麼共存、留出集怎麼定義**：沒寫清時施工者停下或各自猜。出處：[代定 72、80](代定清單.md)。
18. **模型容量已滿**（美國晚上尖峰）：隔幾分鐘重試，不行換同家族次一階、照記，不停線。出處：[交棒「規矩摘要」](交棒.md)。
19. **交叉檢查全涵蓋會比預估貴得多**（第五輪 v1）：預估參考 token +≤30%，實際 +48～80%，待人題還從 4 變 8（抓到更多不一致）。要補真值時只補「還沒有真值的題」，別每題都跑。出處：[27 §4](27-第五輪總結簡報.md)、[代定 98](代定清單.md)。
20. **只給 LLM 看字面樣本，它歸納出的「本質」也只是字面**：v1 的 12 條本質候選全是單字左右樣式、0 條上線。要它說出結構，輸入就得含結構（例如整題的前後文或失敗範例）。出處：[27 §2](27-第五輪總結簡報.md)。
21. **重跑某批前先把失敗那批搬走**：`batch_run --out` 要空，不然統計與曲線會重複算（v1 pass 5 有一個任務 LLM 回了格式錯的別名，失敗批留在 `R5/v1/p5-characters-fail1`）。出處：[交棒](交棒.md)。
22. **規則學到的若只是「這批題的答案」，驗證覆蓋會一直是 0**：第五輪三條試驗驗證 4 任務的 live 覆蓋都是 0。訓練分數變好不代表會帶到新題——arcagi 以 evaluation 為準正是同一件事。出處：[27 §2 元4](27-第五輪總結簡報.md)。
