施工時的小選擇（現行行為）：

- `promoted_at` 是 ISO UTC 毫秒，目錄名把冒號換掉；`restored` 回目錄名；時間名撞了取下一毫秒。
- 內部 symlink 保留；目標本身是 symlink 或 realpath 越出定義根回 `PathBad`；`target` 空段也算壞路徑。
- rollback 先把現版 rename 到 `.prev/.tmp-<時間>/`，前版就位後才刪暫存；前版就位後刪暫存失敗回 `SwapFailed` 並指出暫存位置。
- 裁判的 user 訊息帶 `expect`、`got`、`input` 三個 JSON 字串欄位；case 同時有 `stdin.json`、`say.txt` 就兩個都帶；壞 UTF-8 用替代字元。score 只收有限數字並夾到 0～1，缺 why 回空字串；設定或讀檔失敗＝`FileBad`，問腦失敗＝`BrainFailed`。
- 換版檢查與 proc 啟動之間的競態、同時改同一定義、強制中斷、跨檔案系統都不另加鎖；工具標 `parallel:false`、`interrupt:unsafe`。

已結案、照現狀（使用者 11-12 晚：「回滾的問題？關掉，我不知道那是啥」）：子定義名本身是時間形 `YYYY-MM-DDTHH-MM-SS.sssZ` 時，遇到「時間目錄內又有時間目錄」搬前回 `SwapFailed`、不動檔。

隊長真模型抽查：terra-low 跑兩題，答對 score 1、答錯 score 0 並附 diff 與 why；比對器起不來時 measure 當 score 0、`code: 1`。用 LiteLLM 端點要設 `LITELLM_KEY`。
