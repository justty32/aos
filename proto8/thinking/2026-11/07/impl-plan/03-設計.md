## 批 2：`_metainfo` 改格式（E1、E2、T2、A1、A2）

格式以 [N-68](../../../../docs/NORMS/10-基礎設施-定義與工作區/10-N-68.md) 為準（`token`／`counter_calls`／`time_ms`，不是 `calls`）。

**`proto8/lib/metainfo.py`**（lib 共用模組，跟 `tool_io.py` 同層、同 import 方式）：

- `read(def_dir) -> dict | None`：讀 `<def_dir>/_metainfo.json`；檔不存在回 `None`（N-68 不強迫）；JSON 壞或不是物件 raise `MetainfoError("FileBad", ...)`。JSON 檔型工具（`foo.json` 裡帶 `_metainfo` key）也收：傳檔案路徑時讀它的 `_metainfo` key。
- `timeout_ms(meta) -> int | None`：讀頂層 `timeout_ms`，純數或 `{"val": N}`；沒有＝`None`＝不逾時。
- `eval_cost(value, vars) -> float | None`：`value` 是 `cost` 裡的一格（例 `cost.time_ms`）。純數→該數；`{"val": N, ...}`→N；`{"cal": "..."}`→求值；其他只含一個不認得的 key（`lua`／`py`／`aos`…）→`None`；`None` 輸入→`None`。`cal` 用 `ast` 白名單：數字、變數名（只認 `vars` 裡有的，缺＝`CalBad`）、`+ - * /`、一元負號、括號、`min(...)`／`max(...)`；其他節點（屬性、下標、import、`__`、其他函數）一律 raise `MetainfoError("CalBad", ...)`。不用 `eval`。
- `MetainfoError(code, msg)`：`code` 屬性給呼叫者印錯誤行用；模組本身不印、不退出。

**一次性改檔腳本** `wf/tools/metainfo_migrate.py <root>`：走 `<root>` 下所有 `_metainfo.json` 與 JSON 檔型工具的 `_metainfo` key（跳過 `thinking/`、`archive/`、`.git/`）；`time_ms` 純數→`cost.time_ms`；`{"val","max"}`→`cost.time_ms = val`、`timeout_ms = max`；刪頂層 `time_ms`；保留其他 key 與 key 順序；冪等；印每個改過的檔（英文）。這支只為這次遷移與試驗場跑一次，arknights 跑過後刪（見代定）。

**改讀**：`templates/agent-fsm/act.py` 與任何拿 `time_ms.max` 當逾時的程式（grep 全 `proto8/`，含 aos-mcp、cmd、py、impls）改用 `metainfo.timeout_ms`；文件（`templates/docs/02-agent-fsm.md`、`lib/docs/01-分層等/01-工具契約與規則1至5.md`、`docs/CONVENTION/02-題目stack停錯腦/06-P-41.md` 等）裡描述 `time_ms` 格式的句子改成 N-68 的新格式。NORMS 條號表、舊名對照、N-42-1 只在描述格式時改；歷史敘述不改。

**T2**：`lib/base/bash`、`lib/base/run_python`、`lib/agent/self_tools`、`lib/agent/agents`、`lib/agent/thought` 的 `_metainfo.json` 加 `"arbitrary_exec": true`。

**A2**：`templates/agent-fsm/_metainfo.json`＝`{"summary": "<README 第一行>", "cost": {"time_ms": 30000}, "resource": ["llm"]}`。
