施工時的小選擇（現行行為）：

- shell_report 多 stack 輸出 `{"reports":[...]}`，按 agent 的 `self.def` 聚合；`shapes.cases` 用傳入 stack 的絕對字串；工具帳歸擁有者、child 抄本歸子；binaries 以當下主機 PATH 解析。
- bash-boxed 的 ro 只加三支執行期程式、rg／jq 與 bash 實際 import 的 `tool_io.py`、`shell_observed.py`、`observed.py`，不開整個 lib 或 `/usr/bin`。
- `/tmp` 是 bwrap 私有暫存；sandbox 預設不帶 HOME，所以 case 的 `$HOME/*` 會變 `/*`，那條只驗回傳沒有主機家目錄子項，單獨不足以證明 home 不可存取（case README 有寫）。
- files-only 出生沒有 from 時 `lineage.from` 記 null；新出生覆寫來源的舊 lineage、保留其他 metadata。
- defs 的工具路徑相對宣告工具表所在夾，記憶字串相對記憶宣告檔所在夾；相對 `AOS_THOUGHT_FROM` 用當前 `AOS_WS`，沒設就略過，不猜別人的工作區。
- review.json 存 `definition_signatures` 供下輪比 repeated_child；舊 review 沒快照就不猜；context 只採確切 usage，不從彙總成本推估。
- `prompt_tokens_median` 只算 int／float、排除 bool，不合併子節點。

隊長在 codex 沙箱外複驗：box_check 五項（含兩個 bwrap 實跑）與相關十組測試全過。
