## 小選擇

- shell_report 多 stack 輸出採 `{"reports":[...]}`，按 agent 的 self.def 聚合。case 沒有公開名稱欄，因此 shapes.cases 使用傳入 stack 的絕對字串，不猜 case 名。相同 stack 不重算；工具帳歸擁有者、child 抄本另依子 self.def 歸屬。每段 exit_zero 沿用整條 command 的 exit；binaries 以讀報告當下主機 PATH 解析。
- bash-boxed 的 ro 除圖紙三支執行期程式與 rg／jq，逐檔加入 bash 現在實際 import 的 tool_io.py、shell_observed.py、observed.py，沒有開放整個 lib 或 /usr/bin。白名單仍只在 metadata 的 sandbox 存一份。
- `/tmp` 是 bwrap 私有暫存，所以 R1 預期成功；由主機 `/tmp/aos-box-probe` 不存在驗隔離。box_check 從範例 metadata 讀唯一白名單，依賴 repo 內該範例位置；Python symlink 實體也列為允許可見路徑。
- sandbox 預設環境不帶 HOME，原圖 `$HOME/*` 會變成 `/*`；保留圖紙寫法並在 case README 說明。這條只檢查回傳沒有主機家目錄子項，單獨不足以證明 home 不可存取。
- files-only 出生沒有 from 時，lineage.from 記 null；新出生覆寫來源的舊 lineage，但保留其他 metadata，且在 files 之後才寫。顯式 null 沿用 tool_io 的省略規則。
- defs 工具路徑相對「宣告工具表所在夾」，記憶字串相對記憶宣告檔所在夾；環境物件照字面。相對 AOS_THOUGHT_FROM 依工具原規則用當前 AOS_WS，沒設就略過無法解析的相對引用；不猜別人的工作區。
