# 要他定的題：八題，最要緊的在前；每題都能答「先不定」，選項順序不代表推薦，名字都是示意

← [README](README.md)｜上一份：[04-邊緣狀況](04-邊緣狀況.md)

背景數字見 [02](02-數字.md)：信箱空的時候幾乎不花錢；每答一封 8～22 ms；10 封約 0.1～0.2 秒、100 封約 0.8～2 秒拖在同一輪；讀現成檔約 0.02 ms。

## 第 1 題　「直接回」要不要做成一套通用的，還是各用途各做

- **a. 做一套**：kernel、agent-fsm、eca 都用同一種問法、同一個位置、同一種回信。後果：要先定下面幾題；三種 body（或 aos-loop）都要接上。
- **b. 各用途各做**：像今天，kask 照 kask 的答案做、`/compact` 照 agent 的做、`procs_state_path` 照 daemon 的做。後果：不用現在定通用規則；問的人要記每一種怎麼問（[01](01-盤點.md) 已經有九處、過不過 hook 與進不進帳各不一樣）。
- **c. 先只做 kask，之後再看要不要抽出來**。
- 先不定。

## 第 2 題　誰答（吃誰的時間）

- **a. 對方的 body 答**（原型；[03 一、二](03-可能的形狀.md)）：答得最新、能現算；量大拖慢那一輪；agent 閒著才答。
- **b. 對方預先寫成檔、問的人自己讀**（像 `endpoints.json`）：不吃 body；只能同機讀得到的人問；對方停了檔還在、看起來像好的；不能帶參數。
- **c. aos-loop 兩輪之間代答**：一處改、三種 body 都有、不加在 body 那輪；body 正在跑時照樣答不了；只能答現成檔；沒實作、沒量。
- **d. daemon 代答**：吃 daemon 每圈；daemon 要知道每台的答案在哪；沒量。
- **e. 另起一個專門答的 proc**：不吃 body；每台多一個常駐行程。
- **f. 混著**：例如預設讀檔，要現算的才寄信給 body。後果：兩套都要有。
- 先不定。

## 第 3 題　body 答的話，一輪最多幾封、怎麼算

（kask 已選「一輪最多 N 封」，N 沒定；這題問的是通用時）

- **a. 不限**：全部答完；100 封拖 0.8～2 秒。
- **b. 合計 N 封**（所有種類加起來）：拖慢封頂 N×(8～22) ms；一種問句灌爆會擋到別種。
- **c. 每種 N 封**：種類多時封頂變大。
- **d. 每個寄件人 N 封**：一個人灌不會擋別人；要認得寄件人（今天信封有 `reply_to`，沒驗身分）。
- N 的大小：10（約 0.1～0.2 秒）、30（約 0.25～0.7 秒）、其他。
- 先不定。

## 第 4 題　agent 的「直接回」放在哪一格

- **a. 只放 idle**（像今天的 `/compact` 太短）：agent 在想或在做時不答，最壞等一整個回答做完。
- **b. 每一格都看**（idle、think、wait、act）：wait 每 300 ms 一拍、答得快；act 跑長工具那段還是答不了；四格都要改。
- **c. 交給 aos-loop 或預先寫檔**（第 2 題 b／c）：不用改格。
- 先不定。

## 第 5 題　一個信箱一種問句，還是一個信箱裝多種（靠「問什麼」那格分）

- **a. 一種一信箱**：空的時候每種多 0.024 ms，量不出；問的人看信箱名就知道問什麼；種類多信箱就多。
- **b. 一個信箱多種**（kask 已選「留一格問什麼」）：一個位置；限量要定合計還是每種；不認得的值回拒信（kask 已選）。
- 先不定。

## 第 6 題　過不過 hook、進不進帳本／history

（kask 已選「不過、不記」；今天 agent 的 `/compact` 直接回不過 hook 但**進 history**，eca 的 slash 過 hook 也進 history）

- **a. 一律不過、不記**：最快；hook 擋不了、事後查不到誰問過。
- **b. 一律過 hook**：hook 能擋能改；每封多起一個 hook 行程，灌 30 封慢約 5 倍（原型 A）。
- **c. 預設不過，掛了 hook 的才過**：使用者說的「硬要的話也可以，就是用 hook」；要定 hook 怎麼宣告「我要看問句」。
- **d. agent 那邊進 history、kernel 不進帳**：照今天各自的慣例。
- 先不定。

## 第 7 題　預先寫檔的話，怎麼分得出「對方停了、檔是舊的」

- **a. 檔裡寫時間（或 pid）**，問的人自己判斷多舊算過期。
- **b. 問的人旁邊讀 loop 的 `state.json`**（今天 `aos-llm send` 就這樣看 phase）。
- **c. 不管**：讀到什麼算什麼。
- 先不定（第 2 題沒選 b 就不用答）。

## 第 8 題　寄錯地方要不要管

（kask 已選「照今天」；今天掛 proc 的 kernel 把不認得的問句轉給 daemon、daemon 回 `applied: true` 的假成功）

- **a. 照今天**。
- **b. 收信那邊認得出是問句，回一句「請寄到哪裡」**：多一個判斷；`requests/` 的每封都多看一眼。
- **c. daemon 對不認得的鍵不再回 `applied: true`**：動 daemon；今天靠這個「不認得照收」的別的信也會變。
- 先不定。
