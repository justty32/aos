## D1　hook 要不要往「每圈都觸發」走？

你第 1 點說「基於loop，每次loop的時候都會觸發」；現況不是：九種事件是程式走到某個時機時明叫的，只有起來／停下與時鐘跟 loop 綁（[05](05-B3-fsm與eca差在哪.md)）。

| 選項 | 後果 |
|---|---|
| 維持現況（明叫的時機） | 不動程式；自己寫格程式的 agent 照舊沒點可掛 |
| 加 loop／格的通用點，跟九種並存（丁） | 要改 C++ 的 aos-loop 或 aos-fsm；每圈多起 Python 行程，效能要另想 |
| 先用 `on_clock` 配 `every_cycles: 1` 頂著，只把「不是每圈」寫清楚 | 不動程式；數的是時鐘格數，不是圈數 |

## D2　「提供 hook 點」要不要立一套規範或介面？

| 選項 | 後果 |
|---|---|
| 甲：只寫一頁規範與檢查清單 | 程式 0 行；加一個點還是約 16 處 |
| 甲＋：再加一支一致性測試 | 多一支測試；漏改 self_hook 清單、文件、知識庫會紅；gdb 的扣住／暫停仍抓不到 |
| 乙：事件表變宣告式 | 約 8～10 個程式檔＋一支生成器；加點＝宣告一段＋觸發一行；等於先定下「提供點長這樣」 |
| 丙：呼叫端收成小函式 | 約 9 個檔；10 份包裝與 3 組重抄收成一份；加點那十幾處不變 |
| 組合（例：乙＋丙、甲＋＋丙） | 改動相加 |
| 先不做 | 照舊；已經漂移過一次的情況會再發生 |

## D3　介面管到多大？

| 選項 | 後果 |
|---|---|
| 只管 agent | kernel 照舊自己一張表 |
| agent 與 kernel 共用一種格式 | kernel 的表也改；`agent_spec` 之後要編 kernel 時可以拿對的表驗 |
| 任何子程式，含非 Python（配戊：一支發事件的指令） | 多一支指令；C++、shell 也能提供點；每次發事件多一個行程 |

## D4　事件帶哪些欄位，要不要寫進表當唯一的來源？

| 選項 | 後果 |
|---|---|
| 要：文件、知識庫、self_hook 說明都從表出 | 要有生成器或測試；欄位不會再各說各的 |
| 不要：照舊各處手寫 | 不動；靠清單或測試防漂移 |

## D5　表要不要記「哪種身體會觸發這個事件」？

| 選項 | 後果 |
|---|---|
| 要：掛在這隻不會觸發的事件上，當場說 | 掛錯的會被擋或警告；要多維護一份「誰發哪些」 |
| 不要 | 照舊掛得上、永遠不跑、不報錯 |

## D6　fsm 與 eca 同名不同義怎麼辦？

例：before_tool 在 eca 只看得到 aos 工具、hook 失敗只算那次呼叫錯；`/compact` 信在 fsm 不過 before_queue、eca 的 slash 信會過（[05](05-B3-fsm與eca差在哪.md)）。

| 選項 | 後果 |
|---|---|
| 照舊，只在文件標清楚 | 不動程式 |
| 能統一的統一 | 要逐項改 fsm 或 eca；有些（CLI 自己的工具）統一不了 |
| 不同的分名（例：eca 叫 before_mcp_tool） | 名字變多；舊名當沒有舊版，清單要重寫 |

## D7　gdb 遇到新的「之前型」事件，怎麼知道要扣住？（沒把握是不是題：選了乙就自然有答案）

| 選項 | 後果 |
|---|---|
| 照名字猜（before_ 開頭＝扣住） | 不用維護；名字取錯就猜錯 |
| 從宣告讀（要乙） | 跟乙一起做 |
| 照舊手改 `HOLD_EVENTS`，加測試提醒 | 小改；靠人記得 |

## D8　kernel 要不要先加一個「每輪一次」的時機？（沒把握是不是題）

aos-htop 11-19 實測卡在「三個 hook 都是每封信觸發」；但你對自訂 kernel 說過「先不定，讓它自然長」。

| 選項 | 後果 |
|---|---|
| 現在加 | 動 kernel 的表、round.py、README、N-42 條文 |
| 先不加，等 kernel 那條再說 | 不動 |

## D9　查到的兩個小問題要不要派線？（沒把握是不是題）

1. 文件漂移：after_stop 的 `cause` 在 `06-hook.md` 與知識庫沒寫；brain_failed 的欄位三處講的不一樣（[04](04-B2-誰假設只有這九種.md)）。
2. 看程式推的：eca 等回答時來的 slash 信可能過兩次 before_queue（[05](05-B3-fsm與eca差在哪.md)，沒實跑）。

| 選項 | 後果 |
|---|---|
| 派線補文件、查證第 2 點 | 小工作；第 2 點若屬實再問修不修 |
| 只補文件 | 第 2 點照舊不確定 |
| 先不管 | 照舊 |

## D10　每個 hook 都另起行程，要不要現在就想效能？（沒把握是不是題）

跟 aos-compile-base-1120 的 B 題「同一個行程裡叫 Python 函數」是同一件事的兩面（[07-B](../aos-compile-base-1120/07-B-形狀.md)）。

| 選項 | 後果 |
|---|---|
| 現在一起想 | 跟那條線的 B 題併著裁 |
| 先不想，等慢了再說 | 不動 |
