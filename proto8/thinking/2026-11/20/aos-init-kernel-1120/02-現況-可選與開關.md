# 現況盤點（二）：每一件今天是不是可選、誰偷偷依賴它，以及每塊裡面有哪些開關、預設值、哪些寫死

← [README](README.md)｜上一份：[01-有哪些件](01-現況-有哪些件.md)｜下一份：[03-可能的形狀](03-可能的形狀.md)

## 可不可選

| 件 | 今天的狀態 | 依賴點（名義可選、別處假設它在） |
|---|---|---|
| daemon | **一定要有** | 一切 |
| llm kernel | 名義可選（範本可以不起），**實際上會想的 agent 都要它**：agent-fsm 與 agent-python 只會寄信給總機，沒有直連模型的模式（`templates/agent-fsm/brain.py:1`、`wait.py:481`；全樹查無直連開關） | guard 把 `$AOS_LLM_KERNEL/requests` 當 kernel 信箱擋（`py/tools/agent/guard/guard.py:411-418`）；`ctl` 的提示會檢查它（`py/aos/apps/agent/hints.py:41,90`）；`cli_mcp`／`cli_screen`／`cli_session`／sandbox 都轉傳這個變數；起手範本測試鎖這行（`templates/tests/test_start.py:65`）。**不需要它的**：eca-claude（走 `claude` CLI，`templates/start-eca/README.md:28`） |
| `AOS_KERNEL` 站 | 真的可選，預設不裝 | 一旦設了：「我是誰」、讀信箱、設鬧鐘都經它，3 秒不回就 `KernelFailed`（基底體檢 P4，使用者 11-19 選「維持現狀，只寫明」）；kernel_gate 的主人睡著，底下全部失敗 |
| kernel_gate | 真的可選，出廠不帶 | 同上 |
| limits | **程式寫死在 daemon**，設定全選填（沒寫＝不限） | `sub:N` 要 `uidmap` 套件；換了帳號的 agent 今天**寄不了信**（信箱權限還沒做，`thinking/2026-11/19/subuid-1119.md`「沒做與為什麼」） |
| aos-sandbox | 可選 | 起手範本 `-w .` 讓沙箱關不住樹的控制台（使用者 11-18 晚：風險自己承擔） |
| guard | 可選，而且目前**不建議掛** | 有 `self_hook` 的 agent 能自己拿掉 |
| 身分自報 | **寫死**，沒有開關 | llm 的 `budget.senders`、站的 `users` 都拿它當 key |
| `_clock` | 名義可選（刪那列） | `.env` 的 `AOS_CLOCK` 指著它；沒有它，按拍數的鬧鐘、`stuck_after_cycles` 不走，期限退回牆上時間（`py/aos/tool_io.py:85-100`） |
| `_sweeper` | 可選（README 寫「不要就刪」） | 沒人清，狂印的 proc 能把錯誤記錄撐爆（體檢 P1） |

## 每塊裡面的開關

### llm 那塊（`templates/kernel/llm-kernel/kernel.json`；說明 `py/tools/aos/kernel_llm/docs/01-用法.md`、`02-token-回報與額度.md`）

| 開關 | 預設 |
|---|---|
| `slots`（同時幾封） | 1（範本 2） |
| `reserved.high` | 範本 1 |
| `aging_cycles`（等久升級） | 3 |
| `timeout_ms` | 不限 |
| `endpoint`（預設腦包） | 範本 `fake` |
| `endpoints`（每包 url、model、fixed、slots、budget、speed、cost、context、backend、session_key） | 範本有 fake、smart-high、judge、stupid-fast、luna／terra／sol 等 |
| `budget`（頂層／每包／`senders`；`max_calls`、`max_tokens`、`window` hour｜day｜all、`spent` refuse｜wait） | 範本**不設**＝不限 |
| `hooks`（before_verdict、after_verdict、before_reply） | 無 |
| `llm_http` 的 `connect_timeout_s`、`read_timeout_s` | 10、900（`py/tools/base/llm_http/_entry:104-105`） |
| 金鑰 `LITELLM_KEY` | 起 kernel 的殼 export；沒設不帶 |

寫死沒開關：每輪 300 ms（`daemon.json`，改檔可以但不是旋鈕）；端點重打 1 次、隔 1 秒（`llm_http/_entry:107`）；半路死掉重掛 1 次、被停的 300 秒放棄（`py/tools/aos/kernel/runner.py:11,202-210`）；agent 端冷卻階梯 30 秒起翻倍到 30 分鐘（`py/aos/agentlib/cooldown.py:19`）；不支援串流；帳本 `ledger.jsonl` 不輪替；不會自動換包降級。

### 權限／沙箱那塊

| 地方 | 開關 | 預設 |
|---|---|---|
| 站 `kernel.json`（`py/tools/aos/kernel/README.md`） | `next`、`allowed`、`max_running`、`queue`、`keep_ordered`、`route_ordered`、`reply_via_me`、`limits`（default／max／by_sender）、`users`、`groups`、`hooks`、`queue_wait_ms` | `{}`＝全放行；`allowed`、`max_running` 不限；`route_ordered` true，其餘 false／無 |
| kernel_gate | 站的同一套，另加預設 `hold` 鉤子（`py/tools/agent/kernel_gate/hold:6-10`） | 除了查表全部扣著等人點頭 |
| daemon 表每列 `limits` | `mem_mb`、`cpu_s`、`procs`、`file_mb`、`files`、`user`（帳號或 `sub:N`）、`mem_total_mb`／`procs_total`（要 `cgroup: auto｜on`） | 全無＝不限；`cgroup` 預設 off；`limits_max` 超過＝`LimitBad` 不起 |
| daemon.json `group` | 子帳號主群組 | 60001 |
| aos-sandbox 設定 | `user`、`base`、`commands`、`ro`、`rw`、上限、網路 | 全選填 |
| guard `AOS_GUARD_CFG` | 寫入範圍、`deny_parts`、`shell_deny`、`mail_allow_to`、`mail_allow_box`、`mail_deny` | 沒列的工具一律擋 |

寫死沒開關：寄件人自報不驗；信箱只靠 Linux 檔案權限；每一層只管自己（C-52）；同一個 Linux 帳號底下沒有邊界（使用者 11-19 選維持現狀）。
