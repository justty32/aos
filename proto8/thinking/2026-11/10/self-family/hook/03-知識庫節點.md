```
# Hooks: run a program of yours when something happens to you

Tool `self_hook` is `aos-agent hook` aimed at you. A hook is a tool folder or an executable that runs when an event happens. It gets the event as one JSON object on stdin. Only your own hook list changes; your definition and other agents stay as they are. Changes work from the next event.

Events and their fields (every event also has `event`, `hook`, `stack`):

- `queue_before`: a message is about to enter your conversation (`letter`, `content`). Can change `content`, can drop the message.
- `queue_after`: a message entered your conversation (`letter`, `content`).
- `tool_before`: one of your tools is about to run (`name`, `id`, `arguments`). Can change `arguments`, can block the call.
- `tool_after`: a tool finished, before you see the result (`name`, `id`, `arguments`, `content`, `code`, `timed_out`). Can change `content`.
- `brain_failed`: your brain call failed (`name` = the error code, `reason`).
- `tool_added`: a new tool name appeared in your tool box (`name`, `path`).

One op per call:

- list: `{"op": "ls"}` (add `"long": true` to see every option and hooks you turned off)
- show one: `{"op": "get", "name": "guard"}`
- add: `{"op": "add", "on": "tool_before", "path": "hooks/guard", "match": "wall_clock"}`
- remove: `{"op": "rm", "name": "guard"}`
- back to your original hooks: `{"op": "reset"}`

Options of add: `name` (default: the file or folder name), `match` (only for this tool name or error code; not for queue events), `change` (true = the hook's answer counts), `wait` (false = do not wait for it), `on_fail` (`stop` = you stop when the hook fails, the default; `continue` = only a warning), `timeout_ms` (default 60000), `replace` (true = replace a hook with the same name).

How a hook answers (only when `change` is true):

- exit 0 and nothing on stdout: nothing changes.
- exit 0 and a JSON object on stdout: `{"content": "..."}` or `{"arguments": {...}}` replaces that field.
- exit 10: block it (the message is dropped; the tool does not run and you get the hook's stdout as the result).
- any other exit code, or a timeout: the hook failed.

Hooks are not checked for loops. A hook that sends you a message triggers your queue hooks again.

Errors: ArgumentsBad, OpUnknown, PathMissing, HookExists, HookMissing, HooksMissing, HooksBad, NameBad.
```
