三支都在 `proto8/lib/agent/`，樣板照 `self_tools/_entry`（檔頭、`tool_io`、錯誤兩邊各一行、下層 stderr 原樣透出、下層最後一行錯誤的代號與原因接成自己的、TERM 時先收子行程）。不認得的鍵＝`ArgumentsBad`；`op` 沒給＝`ArgumentsBad`、不認得＝`OpUnknown`。相對路徑一律從 `$AOS_WS` 算（`aos-agent` 在工作區跑）。tooldef 每個動作一個例子，寫給 gemma-4-e4b 級的腦看。

## 2a 為什麼另開 `agent_def`、不改 `lib/aos/defs`

`lib/aos/defs` 是給隊長盤整棵定義樹用的（每個動作都要 `root`），今晚另一隊正在改它（腦設定鍵改名）。所以新開一支只有兩個動作的小工具，check 直接轉叫那支；`lib/aos/defs` 一行不動。

## `agents_children`（1a）

環境：`AOS_DAEMON`、`AOS_STACK`（工具小格，記帳檔 `$AOS_STACK/children.json`，形狀與對帳照舊 `agents`）、`AOS_WS`。

| op | 收的鍵 | 轉成 |
|---|---|---|
| add | `def`｜`def_json`、`name`（給 `def_json` 時必填）、`ws`｜`ws_json`、`stack`｜`stack_json`、`limits`、`envs`、`auto_restart`、`timeout_s`、`on_queued` | 先對帳、數配額（滿＝`ChildSlotMissing`、不寄信）→ `ctl add`（旗標一對一）→ 記帳；`ws` 給了又不在＝先建（舊行為留著） |
| rm | `name`、`purge`、`timeout_s` | 先抄公開子帳 → `ctl rm [--purge -y]` → 從帳上拿掉 |
| stop／sleep | `name`、`timeout_s` | `ctl stop／sleep -t` |
| start／wake | `name`、`timeout_s`、`on_queued` | `ctl start／wake -t` |
| pause／resume／state | `name` | `ctl pause／resume／state -t` |
| ls | （無） | `{"children": [表上我生的那幾列], "max_children": N}`；還在排隊的列成 `{"name", "queued_letter"}` |
| say | `name`、`text` | `say -t`（話走 stdin） |
| listen | `name`、`timeout_s`｜`timeout_cycles`｜`last` | `listen -t`；三個都沒給＝等 600 秒 |
| ask | `name`、`text`、`timeout_s`｜`timeout_cycles` | say 接 listen（照舊） |
| tools／llm／history／hook | `name`、`args`（物件） | 跑旁邊的 `self_tools`／`self_llm`／`self_history`／`self_hook` 的 `_entry`：stdin＝`args`、`AOS_STACK` 換成 `<子的 stack>/tools/self_…`（那支靠它認自己＝變成改子的）；stdout 原樣（「your next turn」那句改成子的名字）；那支的錯誤代號與原因接成自己的；旁邊沒那支＝`ToolMissing` |

每個帶 `name` 的動作先驗帳：不是我生的＝`ChildUnknown`；記過但不在表上＝`ChildMissing`。配額設定：`children.json`（我的定義那份疊我的 stack 那份；都沒有＝4）。ask／listen／rm 照舊抄公開子帳（`observed_children.copy_child`）。

## `agents_ctl`（1b）

`aos-agent ctl` 的完整純包裝（使用者「有權限就能做」）：add、rm、ls、state、where、who、start／stop、sleep／wake、pause／resume，參數一對一；帶目標的收 `name`。對象是表上任何一隻，成不成交給權限與下層報錯。不記帳、不數配額。沒有 say／listen／ask、沒有調工具／腦／歷史／hook（那些不屬於 ctl，只在 `agents_children`）。兩支組旗標、跑 `aos-agent` 的程式共用一份（`lib/agent/agents_cmd.py`）；兩支 tooldef 第一句各說「什麼時候用我、什麼時候用另一支」。

別人用 `agents_ctl` rm 掉我帳上的子：我的 `agents_children` 下次對帳自己忘掉、配額空出來。

## `agent_def`（2a）

| op | 收的鍵 | 做什麼 |
|---|---|---|
| new | `from`、`path` | `from` 整份複製到 `path`（`path` 哪裡都行，已經在＝`DefExists`；`from` 不是資料夾＝`DefMissing`）；定義的 tools 檔裡相對路徑照舊 `agents` 的換算（`rebase_tools`）；先寫同層暫存夾再改名。不寫血統、不掛、不改內容 |
| check | `path` | 轉叫 `lib/aos/defs` 的 check（`root`＝這份定義），JSON 原樣印；有問題＝`DefBad` |
