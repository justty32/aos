# 04 知識庫節點：舊 `agents` 節點換成三支（交 json-memory 隊放進 `knowledge/aos`）

← [agents-split](README.md)｜介面以三支的 `_entry` 檔頭與 `_tooldef.json` 為準，施工單在 [02](02-施工單.md)

`knowledge/aos` 歸 json-memory 隊，這頁只給內容，`knowledge/` 底下一個檔都沒動。

## 結論

- `knowledge/aos/agents.json` **整份換成** [04-agents.json](04-agents.json)。檔名照舊，所以根表的路徑不用改，舊路徑 `agents.json#/thought` 也照樣能用。新檔長這樣：
  - 根 `_description`：選哪支的四行（agents_children／agents_ctl／agent_def／thought），再加一句「子 agent 不繼承你的腦與工具」。
  - `agents_children`：一個物件，`_description` 放每個 op 一例；子 key `errors` 放配額（`max_children`、`children.json` 放哪、記帳檔別手改）和每個錯誤代號怎麼辦。
  - `agents_ctl`：每個 op 一例；說明它不記帳、不算配額、對象是表上任何一隻、不能說話也不能調工具；附常見錯誤。
  - `agent_def`：new／check 各一例；新 agent 的四步（new → 用檔案工具改 → check → 用 agents_children 或 agents_ctl 掛）；附常見錯誤。
  - `thought`：原文照留，只把「Choosing a tool」那條的 `agents` 改成 `agents_children`。
- 四個轉手動作（tools／llm／history／hook）的 `args` 跟 self_tools／self_llm／self_history／self_hook 收的一模一樣；節點裡指去 `me.json` 看那幾支的用法，不重抄。
- 每段文字都在 2 KB 以內（根 617、agents_children 1507、errors 1410、agents_ctl 1647、agent_def 1516 bytes）。`thought` 原本就有 3660 bytes，超過 2 KB，那是舊的、這次沒動。

## `_index` 要改的

- 根表 `knowledge/aos/_index.json` 的 `agents.json` 那格，`_description` 換成：
  `Tools agents_children, agents_ctl and agent_def: your own child agents, any agent on the daemon table, and new definitions; thought for one-off tasks.`
- `agents.json` 檔內自己的 `_index`：已經寫在 04-agents.json 裡（四格：agents_children、agents_ctl、agent_def、thought；`agents_children` 物件裡另有一格 `errors`）。

## tooldef 的 "Details:" 指標

三支的 `_tooldef.json` 都**還沒寫** "Details: memory …"。照 self_tools、self_llm 的寫法（`Details: memory me.json#/self_tools.`），description 最後一句建議補成：

- agents_children：`Details: memory agents.json#/agents_children.`
- agents_ctl：`Details: memory agents.json#/agents_ctl.`
- agent_def：`Details: memory agents.json#/agent_def.`

另外，`lib/agent/thought/_tooldef.json` 寫的是 `Details: memory node agents/thought.`，這是舊格式。照新格式應該是 `agents.json#/thought`，可以順手一起改。
