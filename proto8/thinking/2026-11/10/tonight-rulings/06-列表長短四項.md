## 輸出例子

agents_children（測試裡的假表）：

```
{"op": "ls"}                 kid	running	-	-	-
                             children 1/4
{"op": "ls", "long": true}   kid	running	-	-	-	2	0	-	-
                             children 1/4
```

lib/base/ls（proto8 底下）：

```
{"path": "lib/base", "max_items": 2}
copy	dir
edit	dir
... next_offset 2 (20 items in all)

{"path": "lib/base/ls", "long": true}
_entry	file	7842	2026-11-10T14:42:40.981+00:00	exec
_tooldef.json	file	1651	2026-11-10T14:42:40.986+00:00	keys description,parameters,errors
```

history ls（23 則）：

```
(3 earlier messages not shown: lines 1-3; -a shows all, or give a RANGE)
4	assistant	message 4
…
23	user	message 23
```

self_history 把那行換成自己的鍵名：`(… ; "all": true shows all, or give a "range")`。`ctl state -t bob history`（轉叫 `history ls 19-`）照舊印最後 5 則。

## 代定

- 項 1：long 的四欄直接照抄 `ctl ls -l` 同名那行（多叫一次 ctl ls -l，不自己再算一遍）；排隊中的那隻四欄都是 `-`；`long` 和 `json` 同給＝JSON（同 agents_ctl 照下層）。
- 項 2：long 欄位 `NAME TYPE SIZE MTIME INFO`，SIZE 只有檔有（別的 `-`），INFO＝資料夾 `children N`＋`aos 記號`、檔 `exec`＋`.json` 的 `keys …`（多的 `+N`）、壞 JSON `json broken`、連結 `-> 目標`，都沒有＝`-`；分頁與藏檔改成最後幾行 `... ` 開頭的尾巴（`... next_offset N (M items in all)`、`... H hidden (names starting with .)`、空資料夾 `... empty`）；`long`＋`json`＝JSON。
- 項 4：旗標 `-a/--all`、工具鍵 `all`；省略的那句印在 **stdout 第一行**（不是 warning）——腦叫 self_history 時成功的 stderr 看不到，放 stdout 腦才知道前面還有；格式比照 self_history 尾巴那行用括號包；`-a` 跟 RANGE 同給＝`ArgumentsBad`；**`-j` 不截**（給程式吃的，比照 `aos-tools ls --json` 照舊完整；self_history 找鎖行、ctl state 數則數都靠它）；剛好 20 則以下不印那句。
