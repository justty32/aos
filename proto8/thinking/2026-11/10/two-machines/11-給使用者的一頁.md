# 兩台輪流跑：一頁說明

（指令名是推薦的 `aos-image`，還沒做；做好之前的手動做法在最後。）

## 每天

**離開這台（收工）——一個指令：**

```sh
cd ~/aos/img
aos-image freeze
```

它會等 agent 閒下來（最多 15 分鐘）、把整棵樹停乾淨、打包、推上 GitHub。看到 `frozen: … pushed` 才算好。趕時間加 `--now`（正在回答的那隻 claude 這一輪會白做）。

**到另一台（開工）——三件事：**

```sh
cd <aos 程式 repo> && git pull          # 有改到 C++ 才要重建＋install.sh；thaw 會提醒版本不一樣
# 確認知識庫資料夾已就位（它自己同步，aos 不管）
cd ~/aos/img && aos-image thaw
```

它會拉最新的一份、把指到 repo 的捷徑接到這台、檢查這台的設定、起整棵樹、逐台確認。看到 `thawed: …` 就能用。要看樹：`tmux attach -t aos-img`（`Ctrl-b d` 離開，不要關掉它）。

**隨時看狀況：** `aos-image status`——誰在跑、誰卡住、誰在反覆失敗與原因、信箱積了幾封。

**中途存檔**（午休、怕斷電）：`aos-image freeze && aos-image thaw`。

## 第一次建立

在第一台：

1. GitHub 開一個**私有** repo 放 image（不要開 main 的分支保護）。
2. `aos-image init ~/aos/img`，照它印的三行設 `origin`。
3. `cd ~/aos/img && cp -r local.example local`，改裡面的檔：這台叫什麼、這台的模型位址與型號、金鑰。
4. `ln -s <這台知識庫的位置> kb`。
5. 抄 agent：`copy-out agent-fsm agents/ann`、`copy-out eca-claude agents/bob`；要用自己的知識庫，把 `agents/<名>/tools/memory/_memory.json` 改成 `{"base": "../../../../kb"}`。
6. `aos-image thaw`，然後掛上去：`aos-agent ctl add --auto-restart agents/ann`。要讓它能寫知識庫：`aos-agent -t ann tools add memory_write tools/memory_write`。

在第二台：裝好 aos、`git clone <image repo> ~/aos/img`、做上面的 3 與 4、claude 登入、`aos-image thaw`。

## 要知道的坑

- **沒收工就換台**：另一台會拒絕開工。確定原來那台不會再推了才用 `aos-image thaw --takeover`（接的是上一次收工的狀態）；原來那台之後用 `aos-image freeze --rescue` 把沒收的那段存成標籤，不會無聲消失，但兩段合不起來。
- **image 只留最新一份**（外加自動留的「上一份」）。定義改壞、ws 刪壞，最多退一代。重要的改動前自己打個標籤。
- **知識庫不在 image 裡**。它在哪、怎麼同步、留不留歷史都是它自己的事；要留歷史請自己讓那個資料夾有版本管理。如果它是 git，記得在它的 `.gitignore` 加 `.lock/`、`.lock.releasing.*`、`.tmp.*`、`.new.*`、`.rm.*`。
- **多隻同時改同一個知識節點，後寫的贏。**
- **金鑰只放 `local/`**。ws 整份、定義資料夾、agent 的對話紀錄都會推上 GitHub；沒有任何掃描在擋。
- **claude 換台＝開新對話**：它會拿到一份「之前問過什麼、答過什麼」的整理，記得大意、不是逐字；中間用過哪些工具的細節不帶。換台本身不掉信。
- **claude 失敗（額度用完、登入過期、逾時）**：那一封信不會重答。開了 `--auto-restart` 的會自己冷卻再試（30 秒起、最長每 30 分鐘一次），冷卻期間信留在信箱。登入過期不會自己好，看到 `status` 一整排 `CliFailed` 就去重新登入。
- **兩台的 claude 盡量同版**，`local/env` 寫 `DISABLE_AUTOUPDATER=1`。
- **長跑的 fsm agent** 在它的 `fsm.json` think 那格加 `--history task`，不然對話越帶越長、遲早超過小模型的上限。
- **eca 範本的保守值要調**：`cli.json` 的 `--max-budget-usd 0.5` 與 10 分鐘逾時是試驗用的。
- **WSL**：樹是開在 tmux 裡的，關視窗沒事；但 `wsl --shutdown`、Windows 更新重開等於斷電——丟的是上次存檔之後的東西。再開就 `aos-image thaw`（同一台會直接接著起）。
- **image 要放在 Linux 檔案系統**（`~/…`），不能放 `/mnt/c`。
- **image repo 只用 `aos-image` 碰**，不要手動 `git pull`／`push`。
- 閒著的 agent 每隻約吃 0.1 顆 CPU；開很多隻就把範本 `loop.json` 的 `interval_ms` 調大。

## `aos-image` 做好之前（今天就要用的話）

只在一台跑沒問題。要換台，手動照 [04-搬家/02](../../../../cmd/aos-agent/docs/04-搬家/02-image保存與邊界.md) 的五行 git 食譜，另外記得四件事：

1. 收工前確認 claude 沒在答，再 `aos-daemon-ctl -d <根 stack> shutdown`。
2. 這台才有的檔（端點、金鑰）自己先別放進 image 資料夾，或手動加進 `.gitignore`。
3. 到另一台後跑 `copy-out --relink <image 根>`、刪各 stack 的 `think/request.json`。
4. **每個 eca 的小格手刪 `claude/session.txt`**——不刪的話第一封信會掉、而且那隻會一直失敗。刪了就是從頭開新對話（沒有開場整理）。
