# 試驗場怎麼玩三個工具（self_tools、self_llm、agents）

← [self-tools](README.md)｜驗收紀錄 [03](03-驗收結果.md)

**一句話**：照下面抄，起一棵小樹（llm kernel＋根 daemon＋一隻 fsm＋一隻 eca），跟 fsm 說話叫它改自己的工具、換自己的腦；eca 只起來看工具有沒有掛上，真對話你自己跑（會花 claude 額度）。

- **agents 段先空著**：agents 工具另一隊（agents-split）在拆成三支重做——`agents_children`（有生殺大權的子 agent 管理）、`agents_add`（普通 ctl add 包裝）、`agent_def`（定義的創造修改），等那邊好了再補。
- **self_llm 照新口徑寫**（op `ls`／`set`／`rm`／`reset`，腦的鍵叫 `model`）：11-10 晚已 push（見 [05](05-llm設定改名與ls.md)）。

## 0. 起樹（一次）

```sh
unset $(env | grep -o '^AOS_[A-Z_]*')          # 殼裡的 AOS_* 全清掉
export AOS_HOME=~/repo/simple_tools/aos/proto8
for d in $AOS_HOME/impls/*/bin $AOS_HOME/cmd/*/bin; do PATH=$d:$PATH; done
command -v claude                              # eca 要用：daemon 的 PATH 上找不到 claude＝CliMissing、eca 停在表上
mkdir -p ~/pt && cd ~/pt && mkdir llms something
cp -r $AOS_HOME/kernel/llm-kernel llms/def
cd something
cp -r $AOS_HOME/templates/daemon-root defs
cp -r $AOS_HOME/templates/agent-fsm defs/ann
cp -r $AOS_HOME/templates/eca-claude defs/eca
mkdir -p stacks && cp $AOS_HOME/cmd/aos-agent/stack.gitignore stacks/.gitignore
```

要真腦：在 `~/pt/llms/def/kernel.json` 的 `endpoints` 裡加一條（家機 LM Studio 要開著 gemma）：

```json
"gemma": {"backend": "lmstudio", "url": "http://localhost:1234/v1", "model": "google/gemma-4-e4b", "fixed": {"temperature": 0.7}, "slots": 1, "speed": "fast", "cost": "free", "context": 4096, "summary": "LM Studio gemma-4-e4b"}
```

視窗一、視窗二各起一台（前景、開著別關）：

```sh
cd ~/pt/llms && aos-exec --stack stacks/llm def            # 視窗一：llm kernel
cd ~/pt/something && aos-exec --stack stacks/root defs     # 視窗二：根 daemon
```

## 1. fsm：叫它改自己

視窗三（同樣先做第 0 段前四行設環境）：

```sh
cd ~/pt/something
aos-agent -d stacks/root ctl add --auto-restart -w . defs/ann
aos-agent -d stacks/root llm --target ann set model=gemma    # 換真腦（11-10 晚起鍵叫 model；原本叫 endpoint）
ask(){ echo "$1" | aos-agent -d stacks/root say --target ann >/dev/null; aos-agent -d stacks/root listen --target ann --timeout-s 300; }
ask "Use the self_tools tool to list your tools."
ask "Turn off your wall_clock tool for now."
ask "Which of your tools are turned off right now? Check your tool box."
ask "Give yourself the calculator tool at $AOS_HOME/lib/base/math, then use it to compute 2**10."
ask "Use self_tools to show the details of your math tool."
ask "You no longer need math. Remove it from your tools."
ask "Put your tool box back the way it was originally."
ask "What are your brain settings right now? Check with self_llm."
ask "Use self_llm to set your model to gemma."
ask "Undo your brain changes: go back to the brain settings from your definition."
ask "hello, who answers now?"
```

**算成功**：

- 每題它真的叫了工具（看 `stacks/root/procs/ann/history.jsonl`，有 `"name": "self_tools"`／`"self_llm"` 的 tool_calls），不是光用嘴說。
- 關掉 wall_clock 後問「哪些關掉了」，它答 wall_clock；加了 math 後同一題就算得出 `1024`；「back the way it was」它叫 `reset`。
- 最後兩題：reset 腦之後，下一題回 `FAKE ANSWER to: hello, who answers now? …`——表示它真的換回定義的腦（kernel 預設＝假腦）。
- 小模型偶爾會用嘴回答「做不到」而不叫工具（temperature 0.7），同一句再問一次通常就對。

## 2. eca：只看掛上沒（不花錢）

```sh
aos-agent -d stacks/root ctl add -w . defs/eca
aos-daemon-ctl -d stacks/root ls                       # eca 那列 running
aos-agent -d stacks/root tools --target eca ls -l      # 有 self_llm、self_tools 兩列（11-10 晚共 12 支）
```

**算成功**：表上 `eca running`；`ls -l` 五列都是 `dir`、memory 那列最後一欄 `AOS_MEMORY`。

**真對話（會花 claude 額度，每題上限 0.5 美金，範本值）**：

```sh
echo "Use your self_tools tool to list your tools, then tell me their names." | aos-agent -d stacks/root say --target eca
aos-agent -d stacks/root listen --target eca --timeout-s 600
```

**算成功**：回答列出五個名字；`stacks/root/procs/eca/` 底下的 tools 小格（`tools/self_tools/`）有被叫過的痕跡。

## 刷新 ~/code/playground 的指令（只寫、沒有執行；由頂層安排時機）

試驗場是 11-06 的舊佈局（自帶 `lib/`、`py/`、`templates/` 副本、相對路徑找）。11-10 起範本改 `{"$env": "AOS_HOME", …}`、`cp -r` 就能跑，副本不再需要。刷新＝停、備份、換定義：

```sh
cd ~/code/playground && source env.sh
aos-agent -d ws/.stack ctl rm eca_bob; aos-agent -d ws/.stack ctl rm fsm_ann     # 舊員工收掉（ctl rm 預設留 stack；要連 stack 刪加 --purge）
# 根視窗 Ctrl-C，等三行 "phase": "sleeping" 再往下
cp -a ~/code/playground ~/code/playground.bak-1110
rm -rf agents/fsm_ann agents/eca_bob llm_kernel/def
cp -r $HOME/repo/simple_tools/aos/proto8/templates/agent-fsm agents/fsm_ann
cp -r $HOME/repo/simple_tools/aos/proto8/templates/eca-claude agents/eca_bob
cp -r $HOME/repo/simple_tools/aos/proto8/kernel/llm-kernel llm_kernel/def
echo '{"model": "haiku"}' > agents/eca_bob/llm.json                  # 試驗場的 eca 用 haiku
sed -i 's/"--max-budget-usd", "0.5"/"--max-budget-usd", "0.2"/' agents/eca_bob/cli.json
grep -q AOS_HOME env.sh || echo 'export AOS_HOME=$HOME/repo/simple_tools/aos/proto8' >> env.sh
rm -rf .stack ws/.stack && find llm_kernel -mindepth 1 -maxdepth 1 ! -name def -exec rm -rf {} +   # 舊 image 清掉（持久格式改過）
```

然後在 `llm_kernel/def/kernel.json` 的 `stupid-fast` 把 `model` 改成 `google/gemma-4-e4b`（試驗場 README 第 0 段的規矩），照試驗場 README 第 1～3 段重起、重掛。

**只想留著舊員工、不整個刷新**：11-10 晚 fsm 的腦設定鍵 `endpoint` 改名 `model`（不留舊名），試驗場 stack 裡現有 4 份 `{"endpoint": "stupid-fast"}`（`ws/.stack/procs/{fsm_ann,fsm_b,fsm_c,kid_fsm_ann}/llm.json`）要改鍵名，不然那幾隻會改用 kernel 的預設腦：

```sh
cd ~/code/playground
for f in ws/.stack/procs/*/llm.json; do sed -i 's/"endpoint":/"model":/' "$f"; done
aos-agent -d ws/.stack llm --target fsm_ann ls -l      # 看到 model=stupid-fast TAB agent
```
