## 25 個 md 轉成什麼

使用者：「直接轉」（原話 7）、「所謂.md，本身也是純字串，丟進json內也可以」（原話 3）。不並存、不留舊格式；轉換腳本放 scratch、用完即丟（proto8 不寫遷移）。

| 舊 | 新 |
|---|---|
| 根 `README.md` | 根 `_description.json`（一個 JSON 字串，整頁原文，腦開場拿到的內容不變） |
| 單一葉 `x.md`（world、brain、status、memory、rules） | `x.json`＝一個 JSON 字串（md 原文）；根表一格 `"x.json"`，說明＝原本標題下那一句摘要 |
| 小資料夾 `errors/`、`me/`、`agents/`（README＋1～2 葉） | 一份 `errors.json`：`{"_description": README 原文, "_index": {"codes": …, "common": …}, "codes": "…", "common": "…"}` |
| 大資料夾 `cli/`（README＋10 葉） | 留資料夾：`cli/_index.json`＋`cli/_description.json`（README 原文）＋每葉一份 `.json` 字串 |

轉完共 2＋5＋3＋(2＋10)＝22 個檔。文字逐字搬，只改三種地方：① 文中教怎麼叫 `memory` 的路徑改成新寫法（`me` → `me.json`、`errors` 的子節點 `codes` → `errors.json#/codes`、`cli/flags` → `cli/flags.json`）；② `memory.json`（教寫入那頁）照 [03](03-工具.md) 重寫：`add` 帶 `value`＋`description`、`set`、沒有鎖與 `LockFailed`；③ `errors` 裡最後一句 `LockFailed` 拿掉。內容語言英文照舊；≤ 2 KB 改看每一段字串（現有超過的 `cli/daemon`、`agents/thought` 等照搬不拆，不在這輪範圍）。
