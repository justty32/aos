## 沒修（列給隊長／使用者）

1. 工具說明 12.5k tokens／34 支，小模型吃力；最大的五支每支都超過 3.3k 字元。
2. 工具出錯時給腦的結果，同一行錯誤會出現兩次（工具自己那行，再加上 `[aos] tool: … stderr` 尾巴又印一次），白白多花 token。
3. self_hook 的 `ls` 預設回整份 JSON 陣列（tooldef 和 CLI 的短版都是 `NAME EVENT HANDLER`）。rulings 把它算成「本來就是短版」，跟「預設都短版」有落差，算方向題，不動。
4. `aos-agent ctl state` 只收 `-t`，最後給 NAME 會被當成 part（`unknown part ann`），跟 start/stop 收 NAME 的寫法不一樣。help 有寫，只記錄。
5. self_llm set 只收字串值，小模型很可能送數字；錯誤行有講清楚。
6. state 一行寫 `1 hooks`（單複數）。
