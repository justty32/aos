# 01 盤點：aos 現在跟 MCP 有關的一切、這台的 claude／codex 怎麼接外部 MCP server、使用者講過與定過的

← [external-mcp](README.md)｜下一份：[02 設計](02-設計.md)

## 結論

- aos 現在只有「把自己的工具交出去」這個方向（aos-mcp），沒有任何一處會去連別人的 MCP server。
- eca 的 claude 被 `--strict-mcp-config` 鎖成只看得到 cli_session 寫的那一份設定，裡面只有 `aos` 一台；codex 沒有對應的鎖，會連 `~/.codex/config.toml` 裡的 server（這台那份檔裡沒有任何 `mcp_servers`）。
- 兩支 CLI 接外部 server 的入口都查到了（下表）；有幾項 `--help` 沒寫、要到施工第一步實跑才知道，表裡標「沒查到」。
- 使用者 11-11 已經對 aos 這邊的 MCP client 裁過 M1～M8；11-12 上午補一句「eca本身就能接mcp」。

## aos 現況

| 東西 | 現在做什麼 | 在哪 |
|---|---|---|
| aos-mcp | 一支 stdio MCP server：把 aos-tools 登記檔裡的工具列給外面的 CLI、代叫。只做 `initialize`、`ping`、`tools/list`、`tools/call`；每次列與叫都重讀登記檔，工具有增減會送 `list_changed`；`--hooks` 時在叫之前、之後跑 `before_tool`／`after_tool` | `proto8/cmd/aos-mcp/bin/aos-mcp`（344 行）、[README](../../../../cmd/aos-mcp/README.md) |
| cli_session 的 `mcp_argv` | 每次起 CLI 前把 aos-mcp 接上。claude：在小格寫 `mcp.json`（`{"mcpServers": {"aos": {"command": "aos-mcp", "args": […]}}}`），加 `--mcp-config 那份 --allowedTools mcp__aos`。codex：`-c mcp_servers.aos.command／args／env`，再加 `-c mcp_servers.aos.default_tools_approval_mode="approve"`。server 名寫死 `aos` | `proto8/lib/agent/cli_session.py` 255～279 行 |
| codex 的環境 | codex 起 MCP server 不帶父行程的環境變數（11-11 實測），所以 cli_session 明寫帶 `MCP_ENV` 那幾個 `AOS_*` 加 `AOS_WS`、`AOS_STACK`。claude 會把自己的環境傳給 server（aos-mcp 在 claude 底下不用另給環境就拿得到 `AOS_HOME`） | 同上 236～247 行 |
| `cli.json` | 認的鍵：`kind`、`flags`、`print_flags`、`tools_flags`、`tools`、`timeout_ms`、`reseed_bytes`；其他鍵不看。eca 範本的 `flags` 有 `--strict-mcp-config`；`lib/agent/claude` 那支工具的也有。codex 兩份都沒有對應的旗標 | `proto8/templates/eca-claude/cli.json`、`proto8/lib/agent/claude/cli.json`、`proto8/lib/agent/codex/cli.json` |
| aos-tools | 登記檔 `{"$override"?: 底檔, "tools": {名: {"path", "env"?, "env_file"?}}}`；工具三種（資料夾、JSON 物件或 `檔.json#/指標`、可執行檔）；頂層只擋 `add`／`rm` 兩個鍵（程式 590 行），其他不認得的頂層鍵放過（讀程式得知，沒實跑）；`env_file` 只記位置、每次叫才讀 | `proto8/cmd/aos-tools/bin/aos-tools`、[README](../../../../cmd/aos-tools/README.md) |
| hook | eca 的 `before_tool`／`after_tool` 只攔得到經 aos-mcp 叫的 aos 工具；CLI 自帶的工具沒經過 aos、攔不到（範本文件那張表已寫明） | [templates/docs/01](../../../../templates/docs/01-eca-claude.md) |
| fsm 身 | 工具全部來自 `aos-tools ls --json`；沒有 MCP client | `proto8/templates/agent-fsm/` |

這台裝的：claude `2.1.322`、codex `codex-cli 0.167.2`、`uvx 0.12.2`；沒有 `node`／`npx`；python3 沒有 `mcp` 這個套件。

## 兩支 CLI 怎麼接外部 MCP server

來源欄：「help」＝這台 `--help` 印的；「實跑」＝repo 紀錄裡真腦跑過；「本機查」＝今天在這台跑唯讀指令看到的；「沒查到」＝help 沒寫、今天沒有實跑，施工第一步要驗。

### Claude Code 2.1.322

| 項目 | 內容 | 來源 |
|---|---|---|
| 一次性給設定 | `--mcp-config <configs...>`：「Load MCP servers from JSON files or strings (space-separated)」——收檔案路徑，也收 JSON 字串，可以給好幾個 | help |
| 只用給的那些 | `--strict-mcp-config`：「Only use MCP servers from --mcp-config, ignoring all other MCP configurations」 | help |
| 常設設定 | `claude mcp add [-s local\|user\|project] [-t stdio\|sse\|http] [-e KEY=value] [-H "標頭: 值"] 名 指令或網址 [參數…]`、`add-json 名 JSON`、`list`、`get`、`remove`、`login`、`logout`、`reset-project-choices` | help |
| 設定檔形狀 | `{"mcpServers": {名: {"command", "args", "env"}}}`（stdio）；HTTP 是 `{"type": "http", "url", "headers"}` | stdio 那種＝實跑（cli_session 現在寫的就是）；HTTP 那種＝**11-12 下午實跑**（haiku、假 server，[06](06-施工結果.md)）：`{"type": "http", "url", "headers"}` 與 `{"type": "http", "url", "headersHelper": "指令"}` 都接得上 |
| 專案的 `.mcp.json` | 互動時要人核准才連；非互動（`-p`）不問就連；`--strict-mcp-config` 會擋掉 | 實跑（11-04 eca-claude-dir 實驗 E1b） |
| 工具名 | `mcp__server名__工具名` | 實跑 |
| 放行 | `--allowedTools`、`--disallowedTools` 收工具名；`mcp__aos` 這種只寫到 server 名的＝整台。兩個 `--allowedTools` 會合併（11-12 真腦實測）。`--permission-mode dontAsk` 下沒放行的直接拒 | help＋實跑 |
| 重複給 `--mcp-config` 會不會合併 | — | 沒查到 |
| `--mcp-config` 裡的 `env`／`headers` 會不會展開 `${VAR}` | `headers` 的 `"Bearer ${VAR}"` 會展開（server 記到 token 對）；但 VAR 得在 claude 的環境裡，它的 Bash `env` 看得到（`grep -c` 得 1） | 11-12 下午實跑；`env` 那格沒試 |
| http 的 token 怎麼給才不進 claude 的環境 | `headersHelper`：一條指令，印一行 JSON 標頭，claude 每次連線前叫；aos 用 `mcp_server_file.py --headers <env 檔> <變數>`，Bash `env` 看不到（`grep -c` 得 0） | 11-12 下午實跑（直接跑與經 aos 各一輪） |
| 自簽 CA | `NODE_EXTRA_CA_CERTS=<bundle>` 就通（claude 是 node） | 11-12 下午實跑 |
| server 起不來時 claude 怎麼辦、等多久 | — | 沒查到 |
| 遠端 server 的登入 | `claude mcp login 名`（HTTP、SSE、claude.ai connector） | help |

| 項目 | 內容 | 來源 |
