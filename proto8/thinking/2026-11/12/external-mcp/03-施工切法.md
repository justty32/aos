## 步 0：不改程式，先看到一隻 eca 叫到外部工具

**驗證對象（不用下載、不用金鑰、本機就有）**：再起一台 aos-mcp，換個名字當成「外部 server」。它本來就是一支標準的 stdio MCP server，登記檔只放一支 `peek_now_time`（`lib/packs/gadgets.json` 裡那支，回 UTC 時間）。

做法（都在 `/tmp` 的臨時樹，不動 repo）：

1. 抄 `proto8/templates/eca-claude` 到臨時定義；另寫一份只有一支工具的登記檔 `demo-tools.json`。
2. claude：臨時定義的 `cli.json` 的 `flags` 加 `"--mcp-config", "{\"mcpServers\": {\"demo\": {\"command\": \"aos-mcp\", \"args\": [\"--ws\", \"<工作區>\", \"--stack\", \"<臨時 stack>\", \"<demo-tools.json 絕對路徑>\"]}}}"` 與 `"--allowedTools", "mcp__demo"`。
3. `aos-eca-turn --one` 問一題「用 demo 那台的 peek_now_time 看現在幾點」（haiku，照今天各線驗真腦的做法）。看 `live.jsonl` 裡有一筆 `mcp__demo__peek_now_time`、`permission_denials` 是空的。
4. codex：`flags` 加 `-c mcp_servers.demo.command=…`、`args`、`env`（帶 `AOS_HOME`）、`default_tools_approval_mode="approve"`，luna 跑同一題。

順便記下來的（每項一句結果，寫進施工結果）：

| 要驗的 | 怎麼驗 |
|---|---|
| `--mcp-config` 給兩次會不會合併 | 步驟 2 就是（flags 一份、cli_session 自己再加一份）。不合併＝改用沒有 `tools.json` 的臨時定義重跑；步 1 的設計不靠這一點（cli_session 只寫一份） |
| server 起不來時 claude、codex 各怎麼辦 | 再加一台 `command` 是 `false` 的，看這一輪還答不答、輸出哪裡看得到 |
| claude 的 `--mcp-config` 會不會展開 `${VAR}` | `env` 裡寫一個 `${HOME}`，看 server 收到什麼（只為了寫進文件，設計不靠它） |
| codex 有沒有逐支開關的欄位 | `codex -c mcp_servers.demo.<欄位>=… --strict-config mcp list --json`，不起 server |
| codex 的沙盒管不管 MCP server | 讓 demo 那支工具寫一個工作區外的檔，看寫不寫得進去 |

**真的別人寫的 server**：步 0 通了之後換成 `uvx mcp-server-time`（MCP 官方的參考 server，PyPI 套件 `mcp-server-time`，stdio、不用金鑰）。取得方式：這台已有 `uvx`，`uvx mcp-server-time` 第一次執行會從 PyPI 下載套件到 `~/.cache/uv`。這次規劃沒有下載；要不要在公司機下載由使用者點頭。

驗：單元測試；假 server 掛給 haiku 與 luna 各一輪（定義裡只寫 `"mcp_servers": ["mcp/fake.json"]`）；`env_file` 裡放一個假值，假 server 的工具把它回出來證明收到，再 grep 小格、stack、`live.jsonl` 以外的落檔都沒有那個值（`live.jsonl` 會有，因為是工具自己回的，測試用的假值）。使用者點頭的話再跑一次 `uvx mcp-server-time`。

要重建什麼：不用。`cli.json` 多的是選填鍵，舊定義照跑。

## 步 2：收尾

- claude 非互動輸出的開場事件會列每台 server 的狀態（步 0 確認欄位）：宣告了卻沒連上的，cli_session 印 `cli_session: warning: MCP server 名 did not start`。codex 有對應的事件就比照，沒有就不做。
- `only`／`except` 在 codex 的落地：照步 0 查到的欄位寫；查不到對應欄位＝那台在 codex 底下不掛、印 warning（不默默整台放行）。
- `agent_def check`、`lib/aos/defs` 對 `cli.json` 的檢查認得 `mcp_servers`（指到的檔在不在、形狀對不對，報成檢查結果）。
