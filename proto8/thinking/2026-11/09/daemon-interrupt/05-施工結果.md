## 代定清單（使用者沒直接講、隊長照原則定的）

- **訊號號碼**：`SIGRTMIN+1`＝ctl、`+2`＝mail、`+3`＝all（即時訊號會排隊、不會像 SIGUSR 那樣合併丟失）。
- **state 欄 `poke`**：穩定欄 `{"ctl": N, "mail": N, "all": N}`，寄件人只照這欄送、沒這欄就拒。
- **pidfd**：先開 pidfd、再比 starttime 與 boot_id、再用 pidfd 送，關掉「比完到送之間 pid 被重用」的空窗。
- **錯誤代號 `PokeFailed`**：沒宣告 `poke` 欄、EPERM 等送不出去；對不上／不在沿用 `DaemonMissing`。
- **無開關**：不做 daemon.json 的 `interrupt`，daemon 一律接 poke、一律宣告 `poke` 欄。
- **`--ctl` 那圈不收信、不跑身體**；`--mail` 不跑身體。
- **`--all` 照 `max` 算圈**：提前跑的那次身體算進 `max`。

- **interval 0 也照取 poke**（隊長審 diff 時補）：`nap` 原本 `secs <= 0` 就直接回，interval 0、身體接著跑的 daemon 會讓 poke 一直排著；改成有 `wake_` 時零逾時取一次（aos-loop 沒設 `wake_`，行為不變）。
- **找 state 窗**：照 `aos-daemon-ctl` 找 state_flux 的老辦法，讀 `<D>/daemon.json` 的 `state`，讀不到用 `state.json`；daemon.json 不在 stack 裡又改了 state 檔名的，poke 找不到（報 `DaemonMissing`）。

## 實測（11-09，公司 WSL，/tmp 複本；量法：Python 直接呼叫 `daemon_ctl.poke` 前取時間、每 0.5 毫秒看一次窗）

| 情況 | 結果 |
|---|---|
| interval 10 秒、閒著，寫 ctl pause／resume 後 poke（10 次） | state 反映 **0.6～1.0 毫秒**（中位 0.6）；不 poke 的對照 0.1～630 毫秒（中位 629，靠每秒一圈） |
| 同上，走命令列 `aos-daemon-ctl poke`（含 Python 起動） | 從打指令到反映 26～60 毫秒（中位 28～29；幾乎全是 Python 起動） |
| procs_ctl 加一列後 poke | 1.3 毫秒出現在 procs_state |
| `poke --mail`：寄 ping 信後 poke（8 次） | 信 **0.6～0.7 毫秒**離開 `new/`；對照 `poke --ctl` 不收信，等下一個平常圈約 1000 毫秒才被收 |
| `poke --all`：有身體、interval 10 秒（5 次） | 身體 **1.8 毫秒**內多跑一次；`--ctl`、`--mail` 各 poke 一次，身體多跑 0 次 |
| 身體 `sleep 3`，跑到第 1 秒寫 pause＋poke | 身體沒被打斷、正常跑完；身體結束後 **0.9 毫秒**看到 pause（從 poke 起算 2.0 秒） |
| 連 poke 20 次（命令列） | 20 次都退 0、共 585 毫秒；daemon 活著、那列只起一次、stderr 空 |
| 對 daemon 送 SIGUSR1、SIGUSR2 | 都沒死；之後 ctl stop 正常退 0（改前：SIGUSR1 當場死、子項成孤兒） |
| 子項 `sleep 100`、身體的 SigBlk | 都是 0（遮罩已還原，收得到 SIGUSR1） |
| 護欄：state 的 pid 改成無關的 `sleep 300` | 退 1 `DaemonMissing … (pid N is now another process)`，那支 sleep 沒事 |
| 護欄：state 拿掉 `poke` 欄／daemon 停掉後／兩個模式旗標 | `PokeFailed`／`DaemonMissing … (pid N is gone)`／`ArgumentsBad`，都退 1 |
| `test_poke.py` | 10／10 過；aos-daemon unittest 全部 55／55 過 |
| P9 卡住列（`/tmp/clockhw/hw_stuck.py`） | 11／11 過 |
| 試驗場三層假腦（/tmp 複本） | 起根、問一題 `FAKE ANSWER`、對領班 `poke --mail` 31 毫秒退 0、kill -9 領班換 PID 後再問照答、Ctrl-C 全 sleeping、殘留 0 |
