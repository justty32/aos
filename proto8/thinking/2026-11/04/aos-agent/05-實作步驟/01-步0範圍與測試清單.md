## 測試清單（`test_agent_cmd.py`；每案一句；假腦、不碰網路，eca 用 `test_eca_cmd.py` 現成的假 CLI；起 daemon 照 `test_eca_cmd.py` 的寫法）

1. **宣告**：有 `interfaces.json`＋`aos-agent` key 的 `add` 過；沒檔、沒 key＝`InterfaceMissing` 不送信；壞 JSON＝`InterfaceBad`；把 `cli.json`／`fsm.json` 弄壞 `add` 照過、第一圈才下表（aos-agent 不看它們）。
2. **add 等上表**：兩種 `add --name` 回來時表上有、印的 stack＝`where`；撞名 `InstanceExists` 不送信。
3. **找 target**：`--target` 對；沒給看 `AOS_AGENT`；都沒有＝`TargetMissing`；表上沒有＝`InstanceMissing`；給 `--stack`＝`FlagUnknown`。
4. **ls／state／status**：兩隻一行一列、狀態、工作區、queue 數；`status` 輸出＝`state`；`pause` 後 `paused`。
5. **start／stop／pause／resume**：`stop`→`stopped`、`where` 照找得到、`say` 照寄；`start` 接著答；`pause`→新信留 `new/`；`resume` 答。
6. **rm**：`rm 名字` 下表、stack 不在（含副本）；再 `state`＝`InstanceMissing`；只設 `AOS_AGENT` 不給名字＝`ArgumentsBad`。
7. **say／listen**：`AOS_AGENT=… say 話 && listen` 兩種都答；`listen --last`／`--follow` 照舊；沒人在跑的提醒句印 `aos-agent start --target`。
8. **chat**：stdin 餵兩行→stdout 兩個回答、不含信件名稱；等答案時送 SIGINT→退 130、stderr 含「已寄出」、agent 照答、之後 `listen` 印得到。
9. **tools 副本**：`tools --target fsm1` 印 clock、stderr 說用的是定義；`tools add x 路徑`→`<stack>/tools.json` 出現、`path` 是絕對；下一題假腦叫得到 x；定義的 `tools.json` 沒動；`aos-tools --file <定義>/tools.json add y …` 之後 `tools ls` 看不到 y（副本不跟）；`tools reset` 刪副本後看得到 y；沒宣告＝`ToolsMissing`。
10. **llm 副本**：`llm --target fsm1 show` 有 `model=`；`set model=x`→`<stack>/llm.json`、下一題假端點收到 `model=x`、定義 `.env` 沒動；eca 的 `set model=haiku`→假 CLI 下一題收到 `--model haiku`；`reset` 刪檔；`set zzz=1`＝退 1、stderr `KeyUnknown`；沒宣告＝`LlmMissing`；`llm/` 沒宣告 `aos-agent/llm`＝`LlmBad`。
11. **同定義提醒**：bob、ann 都從同一資料夾 add，`tools add`／`llm set --target bob` 的 stderr 含「ann 也用這份定義」。
12. **screen**：`open`／`close`／`watch --target fsm1`＝`ScreenMissing` 訊息含 `listen --follow`；eca `screen/interfaces.json` 拿掉＝`ScreenBad`；eca `open -d` 開得了（假 CLI）；`rm` 時畫面正在答＝`SessionBad`。
13. **自己結束的**：fsm 腦失敗退 1 下表後 `ls` 不列、`state`＝`InstanceMissing`、同名再 `add` 接著答。
14. **daemon**：沒設 `AOS_DAEMON`＝`DaemonMissing`；設舊名＝`DaemonMissing` 提示新名；daemon 沒在跑 `ls` 照表印＋stderr 注意、`add`＝`DaemonMissing`。
15. **using-aos-agent.sh**：`bash -c 'source …sh bob; declare -f say listen chat status; echo $AOS_AGENT'` 四個函數在、變數對；`declare -f rm` 不在。
