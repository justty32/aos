# 骨架加 md 原型：json 只留導航骨架、文章搬進 md，三種指法兩種粒度實際做出來；`檔.md#/a/b` 查 md 的小腳本可跑

← [README](README.md)｜原話在 [00](00-使用者原話.md) 第 4、5 句｜樣本：[原型-骨架加md/](原型-骨架加md/README.md)

## 先講結論（只列事實）

- **做得出來，樣子在樣本夾**：`aos/me.json`、`aos/cli/agent.json`、`aos/tools/glob.json` 三頁，各做 A、B、C 三種。json 只剩鍵和「去哪拿」，文章原樣搬進 md。
- **今天的工具沒有一個能「一步拿到 md 裡的文章」**：`json_get` 拿到的是指向（`"me/stack.md"` 或 `{"$ref": …}`），還要再 `read` 一次。`$ref` 指 md 今天直接報錯（實跑：`aos-directive: error: DirectiveBad $ref …/me/stack.md is not JSON`）。
- **git diff 確實變好讀**：同一次真實修改（`fad6bef74` 改 `me.json` 的 `_description` 一句），純 json 的 diff 最長一行 3,577 字（整篇文章一行），骨架加 md 是 507 字（只有那一段）。
- **`#/a/b` 查 md 做得到**：小腳本 `mdget.py` 兩種對法都能跑，也能從 `aos/me.json#/stack` 一路跟到 md 那一節。

## 三種指法（今天誰能吃，讀程式加實跑確認）

| 寫法 | `json_get` | `$ref`／`jsonx_*` | index_view | 知識庫測試 |
|---|---|---|---|---|
| A 純字串 `"me/stack.md"` | 拿到字串 `"me/stack.md"`，再 `read` | 不涉及（只是字串） | 頁裡的值不歸它管；若把 `"鍵": "x.md"` 寫進 `_index`，**純字串那格只印鍵、字不見**（工具說明原文） | `test_hook_points_match` 直接讀 `me/self_hook.json` 的 `events`、`clock` 兩個字串，那頁若改就要改測試（約 2 行） |
| B `{"$ref": "me/stack.md"}` | 照寫印出 `{"$ref": …}` | `aos-json get --follow` 也照寫印出（follow 只穿過「路上」的 `$ref`）；`--resolve` 報 `DirectiveBad … is not JSON`。要能吃得改兩處 C++：`aos-directive` 讀檔那支（`ref.cpp` 的 `load()`，不是 JSON 就報錯）、`aos-json` 的 `load_file`（`doc/file.cpp`，不是 JSON 報 `FileBad`）；往回寫（`jsonx_set` follow 寫進 md）另算 | 同 A | 同 A |
| C 字串加錨 `"me.md#/stack"` | 拿到字串，再 `read` 整份 md（7,576 bytes）或另有查一節的工具 | `$ref` 的 `#` 右邊是 JSON 指標，不能拿來指 md 裡；要另訂規則 | 同 A | 同 A |

## 兩種粒度

- **一個值一份 md**（A、B）：`me/stack.md` 1,549 bytes、最大一份 3.5 KB；檔多（三頁共 12 份 md）。`me/` 夾裡會跟既有的 `me/self_tools.json` 等混在一起。
- **一頁一份 md**（C）：`me.md` 7,576 bytes，跟原 json 差不多大；檔少，md 裡每段前一行 `<!-- #/鍵 -->`，在 VS Code 預覽看不見。

## `#/a/b` 查 md（`~/.aos/scratch/top-1121-mdjson/skel/mdget.py`，實跑）

```text
$ mdget.py marker  C-…/aos/me.md#/stack                 → # What is in your stack …
$ mdget.py heading C-…/aos/me.md#/What is in your stack → # What is in your stack …
$ mdget.py heading edge.md#/規劃 A/兩個 字 有空白        → ## 兩個 字 有空白 …
$ mdget.py heading edge.md#/規劃 A/a~1b 斜線            → ## a/b 斜線 …
$ mdget.py heading edge.md#/規劃 A/重複                 → [2 sections match; showing the first]
$ mdget.py heading C-…/aos/me.md#/who am i              → PointerMissing（大小寫不同就找不到）
$ mdget.py chain   C-…/aos/me.json#/stack               → [via] … -> me.md#/stack，印出那一節
$ mdget.py chain   B-…/aos/me.json#/stack               → [via] … -> me/stack.md，印出整份
```

- **照標題**：改標題字就斷；重名時有兩節對上（腳本取第一個並警告）；中文與空白照寫，`/` 寫 `~1`；知識庫每篇都只有一個 `#` 標題、很少 `##`，所以實際上路徑是「文章標題」一層，例 `me.md#/What is in your stack`。程式碼區塊裡的 `#` 不算（腳本有跳過）。
- **照標記**：改標題不斷（名字在 `<!-- #/stack -->`）；重名只有人手寫兩個一樣的標記才會發生；路徑就是 json 那邊的鍵，`aos/me.json#/stack` → `me.md#/stack` 一路接得上（`chain` 實跑）。
- 兩種都不是今天 `json_get` 的一部分，`mdget.py` 只在暫存夾。

## 最要緊的邊緣狀況

1. **既有路徑不會 `PointerMissing`，但拿到的東西變了**：`aos/x.json#/鍵` 這種寫法知識庫裡有 321 處、程式與範本裡 20 處；骨架留著鍵，路徑還在，拿到的卻是指向不是文章，讀的人要多一步。
2. **md 改名**：骨架裡的字串不會跟著改，沒有工具檢查（`index_check` 只查 `_index`）。
3. **一份 md 被兩個鍵指**：讀沒問題；C 的標記一段只能有一個名字。
4. **中文映照版**：要嘛照舊從 json＋md 轉，要嘛 md 本身就是正本、旁邊另放中文 md。
5. **8 KB 規矩**：每值一檔天然遠小於 8 KB；整頁一檔跟原 json 一樣大。
