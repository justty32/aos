## 可能的樣子

每種一句話講它解掉原話哪一句（句號對照 [00](00-使用者原話.md)）。「疊」欄寫能跟哪幾種一起用。

| 樣子 | 是什麼 | 解掉哪句 | 疊 |
|---|---|---|---|
| A 看的旗標 | `aos-json-view --md` 或 `看 x.json`，當場把 json 印成 md，交給預覽或 `bat` | 句 5（不用另寫程式看，在終端與預覽裡就好） | 全部 |
| B 影子 md | 排隊時給每份 json 生成 `x.json.md` 並 commit，GitHub、編輯器直接看 | 句 4、句 5（基本可看；不用程式，打開就看） | A、C、F |
| C 字串陣列化 | 知識庫 `aos/` 那半的長文字照 11-13 的推薦改寫成字串陣列，json 在編輯器裡一行一句 | 句 5（原始檔就能看），不碰尋址 | A、B、D、F |
| D 文章拆成 .md、json 留骨架 | `"stack": {"$ref": "me/stack.md"}`，`$ref` 學會「非 JSON 檔整份當字串」 | 句 1（文章 AI 寫 md）、句 2（路徑照舊 `me.json#/stack`）、句 3（index 照舊、文章人直接看） | A、E |
| E md 裡嵌名字 | md 是正本，每段前一行 `<!-- #/鍵 -->`，工具讀成樹或生成影子 json | 句 1、句 2、句 3（名字明寫，改標題不斷；來回實測幾乎一字不差） | D（不同種類的檔）、F |
| F 用標題路徑查一節 | 一支 `md_get 檔 '#/標題/子標題'`，md 完全自由寫 | 句 2 的一半（查得到，不進 `$ref`、不往回寫）、句 3 的「方便查找」 | 全部 |
| G md 讀時當 json | `json_get`、`$ref` 直接收 `.md#/…`，標題＝鍵、表格＝物件陣列 | 句 1、句 2、句 3 的全部（最接近原話字面） | F；和 E 二選一（都是在 md 裡定鍵，規則不同） |

同一份檔「md 是正本」（D 的文章、E、F、G）和「json 是正本」（A、B、C）只能選一邊；不同種類的檔（知識庫文章、wf-table、progress、daemon 讀的設定）可以各選各的。

## 想請他先說的題

只列從原話推不出來的。

**題 1：哪些東西要變成「AI 主要寫 md」？**（可複選）

- a. 知識庫的文章（今天是 md 包在 json 字串裡）
- b. `wf/` 與 thinking 的資料表（`wf-table`、`progress.json`）
- c. daemon、loop 執行期讀的設定（`loop.json`、`body.json` 這類，有數字與布林）
- d. 都不用，AI 照寫 json，只要人看得舒服

**題 2：你說「我還要特別用程式去看」，平常是在哪裡打開這些檔？**（可複選）

- a. 終端
- b. 編輯器（VS Code、nvim）
- c. GitHub 網頁
- d. aos 前端網頁

**題 3：「aos index 方便查找」要查到多細？**

- a. 檔（今天 index 已經能描述一份 .md）
- b. md 裡的一節（標題）
- c. 一節裡的一個欄位（例：某一條的 `status`）
- d. 表格的某一列

**題 4：md 和 json 同時存在時，路徑的名字從哪來？**

- a. 看得見的標題字（好看，改字就斷）
- b. 明寫的名字（註解或 `<a id>`，穩，多一行）
- c. 名字只留在 json，md 只放文章（樣子 D）
- d. 不需要穩定名字，查不到就算了
