# 七種做法攤開：AI 寫起來、人看、路徑穩不穩、能不能往回寫、接不接得上 aos、要新寫多少

← [README](README.md)｜上一份：[02-md天然結構](02-md天然結構對到json.md)｜下一份：[04-外面現成的](04-外面現成的.md)

不互斥，很多可以疊（最後一節）。「接 aos」指 [01](01-現況-aos今天的尋址.md) 那八種尋址。

## 一覽

| 做法 | 一句話 | 正本 | 往回寫 |
|---|---|---|---|
| 甲 讀時轉換 | 規定一種 md 寫法，工具讀的時候把它當樹 | md | 改一整節可以；改表格裡一格難 |
| 乙 md＋生成影子 | md 是正本，排隊時另產一份 json／索引 | md | 只能改 md 再重生 |
| 丙 md 裡嵌名字 | 每段前面放一行看不見的 `<!-- #/鍵 -->` | md | 可以，來回一字不差（實測） |
| 丁 只做查一節 | 不轉換，給「用標題路徑拿 md 一節」的工具 | md | 不做 |
| 戊 json＋生成 md | json 照舊是正本，另產 md 給人看 | json | 照舊用 json 工具 |
| 己 json 骨架、文章拆成 .md | 值寫 `{"$ref": "me/stack.md"}`，文章是獨立 md 檔 | 兩邊各管一塊 | 改 md 檔就是改值 |
| 庚 不轉，換看的地方 | json 不動，讓編輯器／網頁／終端看得舒服 | json | 不涉及 |

## 甲 讀時轉換（.md 檔直接給 json 工具讀）

- **長相**：`json_get {"path": "aos/me.md#/stack"}` 有效。規定：標題＝鍵、標題下的字＝值、`- **k**: v`＝小物件、表格＝物件陣列。
- **AI 寫**：只要守「標題當鍵」這一條，其他照平常寫 md。但不守格式時（多一層標題、標題順手改個字）路徑就變了，而且不會報錯，只是指不到。
- **人看**：就是一份普通 md，最好看。
- **路徑穩不穩**：靠標題字，改字就斷；重名、標題裡有 `/`、在程式碼區塊裡的 `#` 註解都要規則（[07](07-邊緣狀況.md)）。
- **往回寫**：「整節換掉」做得到（外面的 `mq -U`、mdast 的 heading-range 都這樣做）；改表格一格、加一個欄位要重印那一塊，排版會漂。
- **接 aos**：`json_*` 工具底下是 C++ 的 `aos-json`，要嘛它學會讀 md，要嘛 python 那層先轉。`$ref` 要能指 md 就得改 `aos-directive`。index_view 讀 `_index` 不受影響。
- **要寫**：一個不會把程式碼區塊裡 `#` 當標題的 md 讀取器（原型用 regex 就誤認了，見 [07](07-邊緣狀況.md)；這台的 `cmark` 讀得對但不認表格，python 沒裝任何 md 套件）＋改幾支工具。中到大。

## 乙 md 是正本，排隊時另產 json 影子／索引

- **長相**：`x.md` 旁邊多一份生成的 `x.md.json`（或集中一份 `_index.json`，每節一格 `{"x.md#/某節": {"description": …}}`）。跟今天 `index_gen.py` 重生 `_index.json` 同一種流程。
- **AI 寫**／**人看**：同甲。
- **路徑穩不穩**：同甲；多一個「生成物舊了」的風險，排隊重生就好。
- **往回寫**：工具不能改影子（改了下次被蓋掉），只能改 md。
- **接 aos**：影子是普通 json，現有八種尋址**一個都不用改**就能讀。
- **要寫**：一支生成器，掛進 commit 排隊。中。

## 丙 md 裡嵌名字（HTML 註解當鍵）

- **長相**：

  ```md
  <!-- #/stack -->
  # What is in your stack
  …
  <!-- #/self_tools $ref -->
  → [me/self_tools.json](me/self_tools.json)
  ```

  畫面上看不到註解，只看到文章；工具照註解切段。原型 `style_marker`／`unmarker` 共 40 行。
- **AI 寫**：每段前多一行固定格式；漏寫的那段就沒有名字。
- **人看**：GitHub／預覽裡跟普通 md 一樣；原始檔多幾行註解。
- **路徑穩不穩**：名字是明寫的，改標題不斷。
- **往回寫**：可以。實測把知識庫 111 份物件頁 json → md → json，110 份一字不差（字串陣列算同一段的前提下），差的那 1 份是空物件 `{}` 沒有字可寫、掉了（[06](06-往返與最短解.md)）。
- **接 aos**：同甲，要有一層把它讀成樹（或配乙生成影子）。
- **要寫**：小。

## 丁 不轉換，只做「用路徑拿 md 一節」

- **長相**：`md_get x.md '#/規劃 A/重複'` 印出那一節。原型 25 行，中文、空白都能用（[07](07-邊緣狀況.md) 有實跑）。
- **AI 寫**：完全自由。
- **路徑穩不穩**：同甲。
- **往回寫**：不做。
- **接 aos**：是一支新工具，跟 `json_get` 平行，不進 `$ref`、不進 index_view。
- **要寫**：最小。

## 戊 json 照舊是正本，另產 md 給人看

- **長相**：每份 json 旁邊生成 `x.json.md`，或一支指令當場印。轉法與樣本見 [05](05-互轉樣本.md)。
- **AI 寫**：照舊寫 json（AI 寫 json 不比寫 md 難，只是人看不下去）。
- **人看**：看生成的 md；好不好看看形狀（文章型好、寬表糟）。
- **往回寫**：照舊。
- **要寫**：小（原型 60 行）；要不要進 git 是另一題（[07](07-邊緣狀況.md)）。

## 己 json 留骨架，文章拆成獨立 .md 檔

- **長相**：`me.json` 裡 `"stack": {"$ref": "me/stack.md"}`，`me/stack.md` 就是那篇文章原樣。
- **AI 寫**：骨架（名字、index、`$ref`）寫 json，文章寫 md。
- **人看**：文章是真的 .md，編輯器、GitHub 都直接看；骨架 json 很小、沒長字串。
- **路徑穩不穩**：名字在 json 的鍵上，跟今天一樣穩；8 KB 一檔的規矩自然對上「一篇一檔」。
- **往回寫**：改 md 檔＝改那個值。
- **接 aos**：要讓 `$ref` 指到非 JSON 檔時「整份當一個字串」——今天是 `DirectiveBad`（`aos-directive` 文件寫「`$ref` 的檔讀不到（含不是 JSON）」）。`json_get` 照舊印 `{"$ref": …}`，要 `jsonx_get` 帶 `follow` 才拿到文字。
- **要寫**：改 C++ 一處＋文件；中小。檔數會變多（知識庫 244 篇文章）。

## 庚 不轉，換看的地方

json 不動。終端已有 `aos-json-view`；缺的是在編輯器、GitHub 打開時好看。各種小解法在 [06](06-往返與最短解.md)。

## 哪些能疊

- 丙＋乙：md 裡嵌名字，排隊生成 json 影子，現有工具照用。
- 丁可以疊在任何一種上（只多一支查詢工具）。
- 戊＋庚：都在「json 是正本」那邊，互補。
- 己可以只用在知識庫，`wf-table` 那種真資料照舊 json＋戊。
- 甲和乙是同一件事的兩種時機（讀的時候轉、或事先轉好），通常擇一。
- 「md 是正本」（甲乙丙丁）和「json 是正本」（戊庚）對同一份檔只能選一邊；不同種類的檔可以各選各的。
