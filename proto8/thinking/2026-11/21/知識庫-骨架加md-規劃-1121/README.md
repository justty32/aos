## 設計一句話

**長文章的頁就是一份 `x.md`**（文章原樣一篇接一篇，不加任何標記，旁邊沒有 `x.json`）；**短資料的頁照舊是 json**；導航骨架是夾裡本來就有的 `_index.json`（鍵改成 `me.md`）。`aos/me.md#/What is in your stack` 照 md 現有的 `#` 標題拿那一節；`x.md#/標題/0` 拿那個標題底下第一個清單的第 0 項；`x.md#/標題/_` 拿只屬於那個標題、不含小節的那一段；`x.md#/標題/2/0` 拿第一張表第 2 列第 0 欄（表頭算第 0 列；同一段有清單時數字只指清單）；一個標題底下只有一個 json 區塊時那一節就是 json，可以繼續往下尋。md 可以自帶 `# index`／`# description`，夾裡可以有 `_index.md`（`_index.json` 優先）。`json_get`、`json_ls` 兩種頁都讀。細節在 [01](01-設計.md)，尋址規則全文在 [07](07-尋址規則.md)。
