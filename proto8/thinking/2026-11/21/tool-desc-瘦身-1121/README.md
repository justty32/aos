## 一頁結論

- **現在多大**：ann 掛 agent-fsm 範本預設的 11 包、40 支工具。問一句話的請求 52 KB，其中工具 50.8 KB；`prompt_tokens` 12,553，不送工具時是 1,954，所以**工具本身約 10,600 token**。一半是 description（23.7 KB），一半是參數 schema（22.8 KB，其中說明文字 11.8 KB、骨架約 11 KB）。前五名：mailbox_send 3.3 KB、self_history 2.9 KB、index_view 2.7 KB、self_tools 2.6 KB、grep 2.3 KB。拆帳見 [01](01-拆帳.md)。
- **肥在哪**：self_*、mailbox_*、todo、goal、do_task 把每個 op 的用法和例子整份寫進 description；index_view 用 1.5 KB 講 `$ref` 路徑語法。這些知識庫本來就一支一頁寫著，等於寫了兩次。只刪錯誤列表和例子（輕改寫）只省 7%。
- **各做法省多少**（sol 真量，問同一句）：

| 做法 | `prompt_tokens` | 比現狀 |
|---|---|---|
| 現狀 | 12,553 | — |
| C 只少掛（拿掉 json、self 兩包） | 7,953 | −37% |
| **B 只瘦文字（description 一兩句＋`More: 知識庫哪頁`）** | **6,185** | **−51%** |
| B＋C | 4,498 | −64% |

  同一題 4 次問腦的任務，合計 prompt 51,262 → 25,715。快取（`session_key`）另外算：它讓第 2 輪起便宜，但第一輪、換 session、壓縮之後照付；B 讓這幾種情況和 context 佔用一起減半。各做法細節與風險見 [02](02-做法與實測.md)。
- **原型跑小任務**（B、sol）：改檔、json_set、grep、todo、寄信給自己都做對，問腦次數跟現狀版一樣。踩到兩件事：
  1. 我第一版砍掉 mailbox_send 的「not self or me」，sol 就寫了 `to: "self"`、被拒一次才改對；補回去之後跟現狀版一樣。所以**原說明裡防錯的半句要逐支留著**。
  2. 照 `More:` 去知識庫查，繞了 5 次才找到夾子：系統文字只說「the aos knowledge folder」，沒說在哪。**這是現在就有的缺口**，B 讓 agent 更常去查，要一起補一句。
- **推薦**：做 B，加上系統文字補知識庫在哪那一句；預設包先不動。理由：B 一種就拿到一半，不改 aos 的方向（工具一樣多、行為一樣、細節本來就在知識庫，11-05 也寫過「description 之後只寫怎麼叫、哪一頁看細節」）；C 要改你 11-14 定的預設 11 包，而且拿掉 self 就加不回來，那是方向題。新文字、套用腳本、要改的檔都在 [03](03-施工檔單.md)，可以直接施工。

## 要你定的方向題

1. **預設包要不要縮**（跟 11-14「tools40: a」衝突）。B 做完後再縮，估計能從 −51% 到 −55%（b）或 −61%（c）。
   - a. 不縮，維持 11 包（推薦）：B 已經省一半；再縮只多省 4～10 個百分點，代價見 b、c。
   - b. self 只留 self_tools、self_state，其餘四支改成選掛的 `selfx` 包：再省約 3,200 bytes（瘦過的文字，估每輪約 5,650 token），agent 想改自己的系統文字、腦、對話時要先 `self_tools add`（每加一次對話快取失效一次）。
   - c. b 再加上拿掉 json 包：再省約 4,800 bytes（估每輪約 4,850 token）；JSON 設定檔要用 read＋edit 改。
2. **工具說明要「不查就會用」，還是「常用的會、細節去知識庫查」**。B 是後者。11-12 json 工具的規劃寫的是「description 短、第一句說做什麼、附一個例子、列錯誤代號」，`tools_def check` 的提示句也說 description 要「with an example」；11-14 的預設包設計稿說說明是「一路照讓弱模型看得懂磨出來的」、分短版長版先不做。B 不分兩版（只有一版、變短），但例子和錯誤列表多半搬去知識庫。C-92 只講「小模型裝不下就開大 context」，沒講為了省錢該不該縮，原則推不出答案。
   - a. 照 B（推薦）：省一半；代價是不常見的用法要多查一次知識庫，弱模型沒測過。
   - b. 只做輕改寫（刪錯誤列表、例子、重複句）：只省 7%，說明照舊自足。
