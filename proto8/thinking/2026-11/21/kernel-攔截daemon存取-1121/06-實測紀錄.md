## E2 站停著（`aos-daemon-ctl -d .stack stop perm`）

`mailbox_peek`、`mailbox_send`（to 名字與 box 路徑都試）、`clock_register add`（給了 box）、`goal get`、`agents_ctl ls`：全部 3.1 秒 `KernelFailed no reply from AOS_KERNEL=… within 3 s`。`clock_register ls`、`todo ls` 照通（0.0 秒）。之後 `start perm`。

## E3 kernel 回不同的位置（`view`）

`view` 收到 daemon 的回信時，讀那份表、拿掉 llm 那列、把各列相對路徑轉成絕對、`procs_requests` 也轉絕對，寫到 `<perm stack>/view/procs_state.json`，回 `{"body": {…, "procs_state_path": 那份}}`。

- `agents_ctl ls`：列出 `_clock`、`_sweeper`、`perm`、`ann`，沒有 llm。
- `agents_ctl where llm`：`InstanceMissing llm is not on the daemon table`。
- `self_state`：照通，7.4 秒（沒開代回時 3.5 秒）。
- `mailbox_send to llm`：照樣寄出（aos-mailbox 直讀 `AOS_DAEMON` 的表）。

## E4 kernel 拒查詢信（`deny`）

旗標檔在時 `goal get`：0.2 秒 `KernelFailed the state query sent to AOS_KERNEL=… was refused: HookRejected table not for you`。
