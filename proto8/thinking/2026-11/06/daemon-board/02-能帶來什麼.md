# 這個比喻能帶來什麼

原則：大重構＝行為不變（[refactor](../../../../../wf/workflows/refactor/README.md)），這裡全是新行為或條文，**不插 S 步**；排程對照 [apply-ideas 02](../apply-ideas/02-排程.md) 的 T1～T8、P6～P9、A 條文日。每處推薦放第一。

### 1. 晶振頻率要讓底下的人知道（`tick.interval_ms` → `AOS_TICK_INTERVAL`）

- **白話**：板子的晶振頻率寫在板子上，每個驅動都查得到；tick-time 03 只說 daemon 把 `AOS_TICK`（路徑）傳下去，`tick.interval_ms` 寫 500 時底下的人仍讀到預設 1000 → 退牆鐘換算差兩倍。
- **選項**：① **daemon 有 `tick` key 就一併把 `AOS_TICK_INTERVAL` 設成 `interval_ms`、近的贏（同 `AOS_TICK` 傳法）**——T7 多一行；不是新環境變數、不耦合（daemon 仍不讀時鐘）。② 不傳、文件寫「別亂設」（03 坑 4）——零程式，坑留著。③ 旁檔 `tick.interval`——違 02「時鐘檔只是一個數」。
- **推薦 ①**；判準：`interval_ms` 沒寫或＝1000 就不設（少一個變數）。
- **落**：`proto8/impls/aos-daemon/src/`（`tick` 展開處）、N-63 `AOS_TICK` 旁一句。
- **排**：併進 T7。→ README 方向題 2。

### 2. 看門狗：aos 的是「有刺激才啟動的看門狗」，不要加餵狗

- **白話**：板子 WDT 要定期餵、不餵就重啟；aos 的 stuck 是「有信沒收、有 ctl 沒採用才算」。差在板子睡覺要先關狗，aos 天生不會咬睡著的——這是比喻比真的**更好**的地方。
- **選項**：① **不加心跳；P5b／P7 條文（N-32 旁加註）用這句比喻解釋為什麼不餵狗**——零程式。② 加 `heartbeat_ticks` 每 tick 寫檔——破 N-09、N-32（11-02 已裁心跳拿掉）。③ `restart_on_stuck` 預設改 true（像 WDT 預設重啟）——翻 11-05 裁定「預設只標等人處理」。
- **推薦 ①**；判準：P9 實測若出現「身體一次跑超過 `stuck_after_ticks` 的 proc 被誤判」，解法是列上調 `stuck_after_ticks`，仍不加餵狗。
- **落**：`docs/NORMS/05-基礎設施-窗/`（N-32 旁）、no-pid 05。
- **排**：併 P5b（條文）、P7。

### 3. 上電自檢（POST）：冷啟／熱啟現在看不出來

- **白話**：板子開機會自報 cold／warm reset；daemon adopt 接回後列都是 `running`，窗上分不出「醒來接著做」還是「重起從頭」（log 預設不印）。
- **選項**：① **不加欄；P8 食譜寫「醒來看小格 `state.json` 的 `counter_runs` 繼續累加＋列從 `sleeping` 變 `running`＝熱啟成功」**——零程式，C-56。② `state.json` 頂層加 `boot: "cold"|"warm"`（adopt 接回 ≥1 列或 wake 了＝warm）——N-17 多一欄、30 分。
- **推薦 ①**；判準：P9 若人或 agent 照食譜仍分不出就改 ②。
- **落**：P8 食譜（thinking 或 aos-daemon docs/08）。
- **排**：併 P8。

### 4. 省電模式表：把五種「停」排成一張表

- **白話**：datasheet 有 idle／sleep／deep-sleep／halt 一張表，一眼知道哪些還在走；aos 的 loop pause／daemon pause／stop／sleep／`pause _tick` 散在 aos-daemon docs/03、04 與 tick-time 03。
- **選項**：① **aos-daemon docs/03 加一張表**：loop `pause`＝idle（時鐘走、工作停、窗照寫）；daemon `pause`＝idle 且不調表；`stop`＝halt（列留 `stopped` 要 `start`）；`sleep`＝deep sleep（RAM＝stack 留、行程不在、整樹 P6）；`rm`＝斷電；`pause _tick`＝**停時鐘不停工作**——板子沒這模式，標天然差異。零程式。② 寫進 CONCEPTS——概念層放實作表，過重。
- **推薦 ①**；判準：表不超過 6 列；P6 做完再寫（整樹睡才成立）。
- **落**：`proto8/impls/aos-daemon/docs/03-起-停-暫停.md`。
- **排**：P6 之後、跟 P8 食譜同一天。
