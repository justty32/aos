# 對照表：嵌入式板子 ↔ aos

銜接 [portable-flow 02 image 模型](../../05/portable-flow/02-image-模型.md)（daemon＝硬體、stack＝記憶體、ws＝外置記憶體、定義＝source、實例＝daemon 下的 stack——那幾列不重講）。狀態：**已經是這樣**／**差一點**（差在哪）／**天然差異**（不必貼合，09-01 通則）。

| 板子 | aos 現況 | 狀態 | 一句白話 |
|---|---|---|---|
| 板子本體 | root daemon（aos-daemon 行程＋它的 stack；no-pid「根就是普通 daemon、頭上沒人」） | 已經是這樣 | 使用者顧板子，板子顧底下。 |
| 內部晶振／SysTick | `tick` key → 展開成 `_tick` 子項跑 `aos-tick FILE`（讀 n 寫 n＋1）；`AOS_TICK` 指時鐘檔（tick-time 03） | 差一點：只規劃、T7 未實作 | 自由跑的計數器，誰要看誰讀（C-37 可看可不看）。 |
| 標稱頻率 | `AOS_TICK_INTERVAL`（預設 1000 ms） | 已經是這樣（默契） | 只給換算，不保證準。 |
| 晶振漂移 | `_tick` 是 loop 型，`interval_ms`＝「結束到下次開始至少隔」（N-32），不是固定週期 | 差一點：每格＝間隔＋aos-tick 跑一次，只會慢、會累積 | 見 [03「要對上的」3](03-天然差異與要對上的.md)、[02-續 § 8](02-能帶來什麼-續.md)。 |
| RTC（電池鐘） | Linux 牆鐘：`sent_at`、`updated_at`、`responded_at`、daemon 3 秒／10 秒；沒 `AOS_TICK` 退牆鐘（03 § 二） | 已經是這樣 | 深睡時 SysTick 停、RTC 照走——凍住時 tick 停、牆鐘照走，一樣。 |
| 多時鐘域 | 子 daemon 自寫 `tick`＝自己子樹的鐘、「近的贏」；跨樹不比 tick 只看 `sent_at`（03 § 三.3） | 差一點：未實作 | 跨時鐘域不能直接比，跟 CDC 同理。 |
| 復位向量＋開機模式腳 | `_entry`＋`AOS_ENTRY`（N-57） | 已經是這樣 | 上電先跳這裡；改腳換入口。 |
| 跳線／DIP 開關 | 定義夾的 `.env`（N-59 第 4 件，預設不蓋已有的） | 已經是這樣 | 板上預設值，外接線（已 export）優先。 |
| bootloader／燒錄＋上電 | aos-exec：cd、設六變數、讀 `.env`、挑入口、exec（N-59）；使用者 11-05 自己的用法「複製定義到 `~/x/def`、`aos-exec def`」 | 已經是這樣 | 定義＝韌體 image（portable-flow 02 已講）。 |
| 上電取樣腳（strapping pin） | aos-exec 六個 `AOS_*`＋hub 型 `AOS_DAEMON`、`AOS_TICK`（N-57、N-63） | 已經是這樣 | 起時定、跑中不變——所以它不是 GPIO。 |
| GPIO（跑中可翻） | 窗（`ctl.json`／`state.json`）與信箱 | 已經是這樣 | 跑中互動走檔案，不走環境變數（no-pid 裁定 5）。 |
| 記憶體映射暫存器 | 窗：`ctl`＝寫入暫存器（一物件一指令、`seq` 回 `ctl_seq`）；`state`＝唯讀狀態暫存器（N-09 一人寫）；N-14「只看最新那份」 | 已經是這樣 | 後寫的算、沒有歷史，正是暫存器語意。 |
| 硬體 mailbox／FIFO | aos-post 信箱（`tmp/new/cur/`、有序信先、照名字） | 已經是這樣 | 多核 SoC 的 mailbox IPC 就是這形狀。 |
| 中斷 | 沒有：daemon 每圈輪詢 ctl 與信箱（`interval_ms` 200）；inotify 只是加速（N-14） | 天然差異 | aos daemon 是 super-loop 韌體，不是 ISR 式。 |
| 中斷合併／ISR 要短 | 一圈：套完信→疊 procs_ctl→對表一次（aos-daemon docs/05）；模式 1 判官在圈內阻塞「要快」、慢的交模式 2 的 0 號 proc（kernel docs/02） | 已經是這樣 | 上半部／下半部分工，但無搶佔。 |
| 中斷遮罩 | `pause`／`stop` 那圈不認領信、信留 `new/`（N-28） | 已經是這樣 | 遮罩期間中斷排隊，解除才處理。 |
| 中斷優先序 | 有序信先、再照名字；沒有優先級欄位 | 差一點：要分優先只能多開信箱（[02-續 § 5](02-能帶來什麼-續.md)） | 多拉一條 IRQ 線，不在線上加號碼。 |
| RESET 腳／NMI | SIGKILL（擋不住）／SIGTERM（可處理）／Ctrl-C＝正常收工；訊號照 Unix、不是 aos 標準（N-07） | 已經是這樣 | |
