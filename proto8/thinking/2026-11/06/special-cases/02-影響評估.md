# 影響評估

每列的四欄評估在 [01-盤點.csv](01-盤點.csv)（`耦合`、`多記`、`可遷移`、`兩路徑`，值是 是／輕／否＋一句理由）；各群的計數在 [01-盤點](01-盤點.md)。

## 四個問題的總結

- **耦合**：集中在「認名」那一型（[03](03-歸群.md) 的甲：G01、G02、G11）。其他群幾乎都是「否」或「輕」——例外本身不會耦合，**寫死認得對方**才會。
- **多記**：幾乎每一列都是「是」或「輕」，這是例外的本性。真正傷人的是**清單沒有判準、又靠一層層加註長大**的那幾份（C-52 例外表、C-54 結尾、四種性質表）：讀者得自己合成現行清單，條文已經因此寫錯（[05](05-衝突與方向題.md) 的矛盾 8 條）。
- **可遷移**：只有少數幾列真的傷——靠 PATH 上 aos-tools 的真位置找模組（P42）、py 與 lib 互相依賴（P40、P41）、hub 變數悄悄退路（新機器少搬一個資料夾沒人發現）；root 例外是**刻意**集中的，有使用者保底（C-83），不算傷。值落檔的問題 J 隊已盤（[env-portability](../env-portability/README.md)），這裡不重列。
- **兩條路**：兩種來源——人殼對程式（G09，刻意的）與重複實作（G10，不刻意的）。刻意的只要收成一條判準（K2）；不刻意的要消掉。

## 最該處理的七個

照「耦合重、會再出現、現在改便宜」排。

1. **P7 判卡住還寫著要讀子的 ctl 信箱**（D06、T52）——下一個 P6。
   情境：子是用 exec 型掛的（15 之後子 daemon 就是這樣掛），它沒有 ctl 信箱，父就判不了；要判就得先認出「子是 daemon」，等於把 P6 剛拆掉的耦合裝回去。C-52 的規劃段跟 N-17 的 11-06 註也互相矛盾。**P7 開工前要先定**（15 已寫「P7 要重看」）。
2. **llm kernel 讀 daemon 的表、手拼掛 proc 的信**（I51、I52、I53）。
   情境：daemon 改 `mailbox_warning` 的字句，或改「出錯留 stopped＋reason」的規則，kernel 不會編譯失敗，只會**悄悄**把成功判成失敗；`procs_added` 信的格式沒有公開標頭，兩邊各寫一份。
3. **daemon 寫死 aos-loop 的入口、檔名、錯誤行字句**（I28、I29、I30、I41）。
   情境：aos-loop 的錯誤行字句改了（像 S9 改代號名那樣），daemon 的 `reason` 就變成整行包裝文字；`ctl.json`／`state.json` 的預設名在 daemon 和 aos-loop 各寫一份，改一邊另一邊就認不得。
4. **判官被別的程式認名字**（P03、P04、T15、D35）。
   情境：換一支判官實作，或判官改用另一種掛法，aos-agent 的 `is_kernel` 與兩套逾時提示都要跟著改；`AOS_KERNEL` 一設，`ctl add` 整條路換掉，人看到的錯誤也換一套。
5. **C-52 例外表本身**（D01～D08、I41、P18、P19、T04）。
   情境：下一個寫工具的人照條文看，以為「只限 aos-mcp」；照程式看，daemon、thought、agents 都已經在讀下層 stderr。表靠加註長大，正文三處還寫著舊數字。
6. **找共用模組靠 PATH 上 aos-tools 的真位置；py 與 lib 互相依賴**（P42、P40、P41）。
   情境：新機器把 aos-tools 用複本裝（不是 symlink），lib 每支工具、agent-fsm 的格全部 import 失敗；`py/` 跟 `lib/` 只能一起搬、還得擺同一層。直接傷 C-83。
7. **thought／agents 寫死範本與範本的逾時**（P44、P09）。
   情境：範本 act 格的 `timeout_ms` 從 1800000 改小，thought 與 agents 的 1700 秒上限就比外層還長，外層先殺、裡面的錯變成「被殺」。lib 工具認得上層的範本，是下層認上層（違反單向分層）。

次一級：aos-json `check` 寫死 exec 只出現在哪幾個 key（I66，新增帶 exec 的程式要回頭改它）；覆蓋檔名兩套規則（P47）；`.env` 解析兩份（G10）。

## 不用處理的

- **root daemon 例外**（C-83 ③）：使用者刻意把搬不走的東西集中在 root，有保底；它是判準不是漏洞。
- **`auto_restart`**（15）：原本是「子 daemon 特准重起」，已經收成任何 proc 都能寫的通用布林——這正是「特例升格成慣例」的範本，不用再動。
- **兩鐘**（N-65）：已升格；剩下的是 [05](05-衝突與方向題.md) 矛盾 8 那種不一致。
