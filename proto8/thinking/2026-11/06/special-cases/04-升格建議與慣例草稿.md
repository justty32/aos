# 升格建議與慣例草稿

判準照使用者的話：「往後可能還會有更多，其好處超過壞處很多」。**只是草稿，沒改條文**；要不要寫進條文見 [05](05-衝突與方向題.md)。

## 什麼時候升格、什麼時候消掉（可執行判準）

1. **認名型一律消掉，不看次數**：一個例外要成立，得讓 A 寫死認得 B 的程式名、內部檔名、格式或錯誤字句（[03](03-歸群.md) 的甲形狀）→ 第一次出現就改成「B 宣告、A 照宣告」或「任何人都能寫的通用欄位」。範本：P6 → `auto_restart`。
2. **同一形狀第 3 次就升格**：同一句「一般規則＋例外理由」在 3 個不同的程式或條文出現 → 寫一條判準取代逐項清單，之後照判準推得出來的就直接做、不再逐項裁。
3. **第 1、2 次維持特例**：寫在例外發生的地方，註明「同型第 N 次」，第 3 次照 2。
4. **清單長太快也升格**：一份例外清單到 5 項，或 3 天內加了 2 項 → 改寫成「判準＋現行表」（現行表只列現在有效的，作廢的移到續檔）。
5. **「先不做」要寫等什麼**：範圍限縮型的例外，寫一句「等 X 發生才動」；X 發生了就照 1～4 重審。

照這五條，15 群的推薦如下。

## 慣例草稿

一句規則＋什麼時候適用＋怎麼宣告。

- **K1 出口給看不到下層的讀者時，可以附下層最後的錯**
  - 規則：一層的出口讀者看不到下層的 stderr（外部 agent、腦、寄信方），這一層失敗時可以把下層錯誤行的「代號與原因」接進自己那一行，或附下層 stderr 最後 2 KB；成功時不附；下層 stderr 照樣原樣透出。
  - 適用：出口的讀者是外部 agent、腦，或回信的收件人。aos 內部上下層之間（讀者也是程式、看得到 stderr 檔）不適用。
  - 宣告：在該程式 README 寫一行「透出：哪一種（末行代號／尾 2 KB）、給誰」；C-52 例外表改成這條判準，下面附現行表。
- **K2 人殼只看一件事：stdin 是不是終端**
  - 規則：同一個指令，人打和程式叫只能在「stdin 是終端」這一點分岔；是終端才問、才印提示，其他行為一律跟程式叫的一樣。
  - 適用：給人用的指令（C-82、P-44 給人用的指令）。
  - 宣告：`--help` 寫一句「在終端時會…」；終端提示字（`> `、`[y/N]`）印 stderr 算 N-43 的明文例外。
- **K3 hub 變數沒設：報 Missing，或寫明一條退路；設了指不到就印提醒**
  - 規則：N-63 ② 改成「沒設＝`<名字>Missing`，或在條文寫明唯一一條退路」；設了但指不到時，照退路走並印一行 `warning:`。
  - 適用：`AOS_` 開頭、值是資料夾的變數。
  - 宣告：退路寫在四種性質表那一列。「印提醒」那半使用者 11-06 已裁（[env-portability](../env-portability/README.md) Q5）。
- **K4 同一個值有好幾層給，近的贏**
  - 規則：同一個設定值，自己這層的設定＞上一層傳下來的＞全樹預設。
  - 適用：`AOS_TICK_INTERVAL`、子 daemon 自帶時鐘、`.env` 外層。登記格對外面環境（env-portability Q2）照它那題裁。
  - 宣告：寫在 N-63 一次，各處引用，不再各寫一遍。
- **K5 程式預設照現況，新行為由範本開**
  - 規則：新加的行為，程式預設不開（跟加之前一樣）；要開寫在範本。
  - 適用：任何「加一個開關」的改動。
  - 宣告：README 的開關列寫「預設關；範本 X 開」。
- **K6 `_` 開頭的名字是 aos 的**
  - 規則：daemon 表的 proc 名、定義資料夾裡的檔名、信件 body 的 key，`_` 開頭保留給 aos；使用者自己取的名字不准 `_` 開頭。
  - 適用：`_tick`、`_entry`、`_tooldef.json`；以後新的保留名都照這個取。`ping` 這類舊保留字列在同一張表。
  - 宣告：C-54 加一句，保留名一張表。
- **K7 別人的 stack：對方宣告了才寫**
  - 規則：A 不寫 B 的 stack，除非 B 在 `interfaces.json` 宣告了「這個檔可以由外面寫」（覆蓋層），或 A 是起 B 的那一方、而且 B 還沒開跑。開跑後的其他事一律經 B 的信箱或 ctl。
  - 適用：aos-agent `llm set`／`tools add`、thought、agents。
  - 宣告：覆蓋層的檔名只寫在 `interfaces.json` 一處，aos-agent 與身體都照它讀（現在 llm 照宣告、tools 寫死 `<stack>/tools.json`，P47）。
