## 使用者原文（11-05 晚，字句照原話；全文在 [json-argv README](../../05/json-argv/README.md)、[07](../../05/json-argv/07-使用者回覆-11-05晚.md)）

> 另一面則是這東西可以給人使用，畢竟你讓人去寫json，其實不太方面。
> 若是要給人操作的(或是agent使用shell工具操作的)，那就是用法要遵循unix/linux習慣，man/--help要有，設計要符合人體工學(以人爲主)。若是單純的aos函數，不需要給人操作的，那就是argv的旗標盡量不要濫用，大多東西都走要給stdin的json。
> 從一開始設計程式的時候就該想好這個程式是設計給誰用的了。不過就像先前說的，依據實際需要去做吧，比如方便與否。
> 子資料夾就是子動作，我覺得這個最好，但這個之後實作的時候我要看一眼，怕有些問題。
> 你要在argv塞一些不會在stdin裏面出現的東西的話，那代表這個程式就比較偏向於給人用的那種。

## 使用者裁定（11-06，選項原文；四題都已裁）

1. 子命令套件：選「群組＝子資料夾」（推薦）。
2. 短旗標：選「開幾個常用短名」——選項說明是「例如 -h、-q、-j（--json），每支指令各自定」；頂層原補共用表禁令已由 11-07 使用者裁定 sol 審查 #22 取代：每支各自定短名，同名可不同義，常用表只作預設。→ [03 H4](03-慣例草案.md#h4-旗標命名)
3. man：選「不手寫 man」（推薦）。
4. 不可逆動作確認：選「終端問、非終端不問」——人在終端打時問一句，程式或 agent 呼叫（stdin 不是 tty）時不問。補充原話：「不可逆動作那塊，幫我加上--yes跳過」——**一律提供 `--yes` 跳過確認（終端裡也可用）**；短名 `-y`（本指令採用的常用預設；11-07 使用者裁定 sol 審查 #22）。→ [03-續 H11](03-慣例草案-續.md#h11-互動確認與---yes使用者-11-06-裁終端問非終端不問加上--yes跳過)

11-06 頂層與使用者同意：這份慣例在今晚家機 S8（拆大檔、aos-agent 拆套件、說明只留英文 `--help`）與 S9（命名）**之前**定下，S8／S9 照著做一次。

## 一句話結論

**給人用的指令現在缺的不是 `--help`（全有了），是 `--help` 沒分層、錯誤行的 usage 兩極、人看的輸出不齊**——慣例只要定三件事：① 每個子命令一份自己的英文 `--help`（頂層一屏、子命令一屏、長篇規則進 README）；② 錯誤行後面只接**那個子命令**的一行 usage 或 `see 程式 子命令 --help`；③ 會列資料的子命令都有 `--json`、人看的一列一筆 TAB 分欄。其餘（長旗標為主＋每支各自定短名（11-07 使用者裁定 sol 審查 #22）、位置參數、不顏色、env 只當人殼預設）寫成條文就好；不可逆的三個子命令（`ctl rm`、`tools reset`、`llm reset`）stdin 是終端才問一句 `[y/N]`、`-y` 跳過。子命令套件照「群組＝子資料夾、動作＝模組、顯式派發表」拆，子資料夾＝子動作已定稿、不用再看（11-07 使用者裁定 sol 審查 #33）。

一行版：① 套件結構→群組＝子資料夾、動作＝模組、顯式派發表（照推薦，[01](01-樣本-aos-agent.md)）；② 短旗標→每支各自定、常用表只作預設（11-07 使用者裁定 sol 審查 #22）（[03 H4](03-慣例草案.md#h4-旗標命名)）；③ man→不手寫、`--help` 一屏＋README（照推薦）；④ 不可逆→stdin 是終端才問、一律提供 `--yes`／`-y`（[03-續 H11](03-慣例草案-續.md)）。

## fable 代定（可翻案；細節在 03）

- 頂層 `--help` ≤ 40 行、子命令 ≤ 25 行、每行 ≤ 100 字；固定段序 NAME／usage／subcommands／flags／（一段散文）／exit codes／more。
- 錯誤行：頂層缺子命令＝列子命令名單＋`see X --help`；子命令層＝`(usage: 那個子命令那一行)`；子命令前 FlagUnknown 不附 usage（stdio-unify D9 照舊）。
- 人看的表無表頭、TAB 分欄（R15 照舊）；`#` 開頭＝註解行，`--json` 不印；清單空＝stdout 空、退 0（退 10 只給「查單件沒有」）。
- 全域旗標只放「選哪個容器」；`aos-grow --dry-run` 這種全域開關算例外、不改。
- 使用者 11-07 裁定維持：不做 `--version`、不做 `--quiet`／`--verbose`、不做顏色、不做進度條（sol 審查 #34-3）。
- 常用預設短名表九個（`-h -j -t -d -n -w -s -f -y`）；每支可自定，不禁止表外短名（11-07 使用者裁定 sol 審查 #22）；確認判 stdin 是否終端、問句在 stderr、答 No 退 0 加提醒行；不可逆清單只有三個子命令（細節 03 H4、03-續 H11）。
