# 盤點表（二）：eca、LLM kernel、ws、定義資料夾

判法同 [01](01-盤點表.md)：**搬**／**可擋**（醒來重建）／**可擋（紀錄）**／**必擋**（只對這台這一刻）。

## eca 小格（`$AOS_STACK/claude/` 或 `codex/`，`py/cli_session.py`）

| 路徑 | 寫法 | 會長嗎 | 判 |
|---|---|---|---|
| `history.jsonl` | 只附加：user 全文＋最後答案（不含工具往來） | 無上限，但比 agent-fsm 小 | **搬** |
| `session.txt` | 第一次講完寫 id | 一行 | **搬**（同一台才接得上；別台 `--resume` 找不到就從頭開，[aos-agent docs/04](../../../../cmd/aos-agent/docs/04-搬家.md)） |
| `queue/` | 交給 CLI 那一刻就刪 | 不累積 | **搬** |
| **`live.jsonl`** | 只附加：stream-json／`--json` 每個事件一行，含工具結果 | **最大的檔**，一輪幾十 KB～數 MB、無上限 | **可擋（紀錄）**：只有 `aos-eca-screen watch` 給人看（`cmd/aos-eca/bin/aos-eca-screen:209`） |
| `turns.jsonl` | hook 附加，一輪一行 | 無上限、小 | 可擋（紀錄） |
| `mcp.json`、`tmux.conf`、`tool.txt`、`ws.txt`、`stack.txt`、`last.txt`、`busy.txt` | 每次起 CLI／開畫面前重寫 | 不長 | **可擋**（醒來重寫） |
| `lock`（fcntl）、`tty.sock`（tmux socket） | — | — | **必擋** |
| `transcripts/<kind>-<id>.jsonl` | symlink 到 `~/.claude`／`~/.codex` | 本體在家目錄 | **可擋**（到別台是斷鏈） |

## LLM kernel stack（身體＝`aos-llm-kernel`）

| 路徑 | 寫法 | 會長嗎 | 判 |
|---|---|---|---|
| `mailbox/new/<uid>/letter.json` | 每次問腦一封；body.request＝整份 messages＋tools | 收了就進 cur | **搬**（排隊中的請求） |
| `mailbox/cur/<uid>/`（＝問腦 proc 的 stack：`request.json`、`proc.json`、`loop.json`、`state.json`、`reply.json`、`reply_letter.txt`、`stderr.txt`） | 回信寄出後**整個刪掉**（`reply.cpp:96-117`） | 不累積；在飛時每封約 2×request | **搬**（在飛的那題醒來自己重跑）；裡面的 `stderr.txt` 照通則可擋 |
| `mailbox/tmp/`、`mailbox/.flock`、`sender.flock` | 寄一半／鎖 | — | **必擋** |
| `mailbox/reply/` | ask 模式共用回信 | 收了就刪 | 搬（小；寄件人走掉時會剩） |
| `queue.json` | **每次 kernel 跑都蓋寫**（約 300 ms），`seen_at_runs` 排隊帳 | 不長 | **可擋**（重算也沒差，[portable-flow 02](../../05/portable-flow/02-image-模型.md)） |
| `used.json` | 每次問腦結束蓋寫 | 不長；每窗歸零 | **搬**（額度帳，擋了＝醒來額度重算＝多花錢） |
| `endpoints.json` | 有變才寫 | 不長 | 可擋（從 kernel.json 推得出） |

## 工作區 ws（`AOS_WS`）

| 路徑 | 會長嗎 | 判 |
|---|---|---|
| agent 用工具寫的檔（write／edit／copy／json_edit…） | 由腦決定 | **搬**（這就是成果）；**不能用 `**/tmp/` 這種寬規則**，會誤擋使用者自己的 `tmp/` |
| `.trash/<YYYYmmdd-HHMMSS[-n]>/<原路徑>` | **無上限**（「清垃圾桶是人的事」，`lib/base/trash/_entry:66-77`） | 判斷題：擋了＝搬過去就不能還原；推薦擋＋人定期清（[04](04-gitignore建議.md)） |
| agents `new` 產生的子定義資料夾 | 每隻子一份 | **搬**（它是定義） |
| `.stack/` | 見 [01](01-盤點表.md) | — |

## 定義資料夾

執行期不寫（P-15）。例外都是人或工具主動叫的：`aos-tools add/rm`（沒給 `--overlay`）、agents `new`、`aos-grow`。一律**搬**，跟 image 同一個 commit。

## 不存在的（任務書列了、程式裡沒有）

- `.aos/batch/<turn>/out/` 只在封存的甲代 `archive/aos-v1`，proto8 沒有。
- `_tick` 時鐘檔：proto8 沒人寫；只有人跑 `aos-tick FILE` 時才有（`.FILE`→rename、一行）。
- `reply_letter.txt` 只在 kernel 的 `cur/<uid>/` 裡，跟著那夾一起刪。
