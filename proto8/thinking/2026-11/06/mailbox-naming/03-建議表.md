## 判準（照 [04 草稿](04-規則草稿.md) 第 2、6 點）

叫 **queue** 要四條都成立：① 寄的人程式裡全帶 `--ordered`；② 一個讀者；③ 照順序一封封消費；④ 順序錯了結果就錯。任一條不成立就是收件箱（mailbox，或照裝的東西取名）。只記排隊狀況的檔是窗或帳，不是箱。

## 表

| 現名 | 是什麼（[02](02-有序是什麼.md)） | 推薦 | 理由 |
|---|---|---|---|
| agent 的 `$AOS_STACK/queue/` | 四條都成立 | **不改**（已經叫 queue） | 全 repo 唯一一個當 queue 用的信箱；N-16 10-30、P-11 已這樣定 |
| `procs_ctl_mailbox`（資料夾、daemon.json key、procs_state 欄） | 寄件人不帶序號、多寄件人、各信獨立、可要回信、整批拿 | **不改** | ①④ 不成立；11-03 使用者定的名字（R7 例）；改成 queue 反而讓人以為照先來後到套 |
| llm kernel 的 `$AOS_STACK/mailbox/` | 收件箱＋優先序待辦池（級數＋aging→deadline→speed→等得久） | **不改** | ①③ 不成立；照優先序挑的叫 queue 會誤導成 FIFO（草稿 3） |
| 判官的 `$AOS_STACK/requests/` | 收件箱（裝掛子請求）；排隊選項上線後等格的信留在 `requests/cur/` | **不改** | 名字講裝什麼，符合草稿 2 第三種；排隊順序由窗 `queue.json` 說 |
| `daemon_reply/`、`<ctl 信箱>/reply/`、`<kernel>/mailbox/reply/`、fsm 的 `think/reply/`、`--reply-to BOX` | 共用回信箱，多讀者挑著收 | **不改** | 順序無意義、多讀者，正是收件箱 |
| llm kernel 的 `queue.json` | kernel 自己的排隊帳（N-13 身體自訂名） | **不改**（方向題 2） | 不是箱；記的就是「誰在排」 |
| 判官的 `queue.json`（未實作） | 窗：誰在排、排第幾、先來先掛 | **不改**（方向題 2） | N-14 的窗；os-impl 05 已裁的名字 |
| `mailbox_warning`（state 欄）、`$AOS_STACK/mailbox_warning.txt` | 壞信原因 | **不改** | 使用者 11-02「要」統一的通稱；講機制不講用途（草稿 1），queue 的壞信也是信箱的壞信 |
| `MailboxMissing`、`MailboxBad`、`OrderBad`、`QueueBad` | 錯誤代號 | **不改** | 機制名；`QueueBad` 講的是 `queue.json` |
| `aos::post::Mailbox`、`mbox_*`、`src/mailbox/`、`open_mailbox`… | 程式識別字 | **不改** | 機制名、對內 |
| `--ordered`、`order.lock/`、`order.json` | 信的屬性與取號 | **不改** | 說的就是信，不是箱 |
| `queued`、`queue_wait_ms`、`--on-queued`、`--queue-wait-s` | 排隊中的狀態與期限 | **不改** | 動詞「排隊」，不是箱名 |
| 判官程式裡的變數 `inbox`（= `requests/` 路徑） | 對內識別字 | 可順手改 `requests`（不急） | R4 一詞一義：inbox 不在 aos 詞彙裡；對內、1 檔 |
| 知識庫 `me/README.md`「`queue/`: your inbox」、`status.md`「wait in its inbox」 | 腦看的用語 | 改成 queue 的說法（「your queue: letters wait here in order」） | 腦看到的同一樣東西三個字；英文提示照 R4 一詞一義 |
| 文件「有順序的信箱」（`py/aos_ws.py` 第 7 行註解、`cmd/aos-agent/README.md` 第 78 行；條文 P-11「有順序信箱」） | 用語 | 改說「當 queue 用的信箱（寄的都帶序號）」 | 11-04 起箱沒有有序屬性（草稿 5）；條文裡的（P-11）不動，加註要使用者裁 |
| 名詞表板子比喻「信箱＝mailbox FIFO」 | 條文 | 加註，不改原句（方向題 3） | 只有 queue 是 FIFO |
| `wf/inbox/`、`inbox_*.sh`、`WF_INBOX_*` | agent 之間的工作流信件，不是 aos 程式 | **不改** | 不在 proto8 的命名體系內 |

**推薦把 mailbox 改名成 queue 的：0 個。** 唯一當 queue 用的箱本來就叫 queue；其餘名字帶 mailbox 的都不是 queue。要動的只有用語：判官的 `inbox` 變數（選做）、知識庫 2 檔、文件「有順序的信箱」2 處、條文加註（P-11、板子比喻、C-54 R14，要使用者裁）。
