Optional parts of an org: take the ones this org needs, move each to the place the table names, and delete this folder.

# extras

Back to [org](../README.md).

| part | take it when | move it to |
|---|---|---|
| [system.seat.txt](system.seat.txt) | a seat gets a definition of its own | the definition's `system.txt` (for a coding CLI: its system text file) |
| [site.txt](site.txt) | helpers are made from kits | between the general part and the role part of the kit's `system.txt` |
| [helper/](helper/README.md) | work is given to helpers attached for one job | `wf/org/helper/` |
| [improvements.md](improvements.md) | seats may improve themselves when idle (CHOICE 8) | `wf/org/<SEAT>/improvements.md`, one per seat |
| [gates.md](gates.md) | every piece of work passes the same line of checks | `wf/org/gates.md` |

The two `.txt` files have no describing first line, because the whole text is sent to the model. The links inside `helper/`, `improvements.md` and `gates.md` are written for the place each one is moved to.

Not shipped, because they grow out of real work and differ everywhere: a seat's `assets/` folder (make it when the seat has its first lasting output; split it when it grows), a notice board, a review after each round of work.
