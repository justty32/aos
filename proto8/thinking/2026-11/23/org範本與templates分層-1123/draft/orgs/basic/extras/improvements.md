# Improvements of `<SEAT>`

Back to the [role card](README.md). Move this file to `wf/org/<SEAT>/improvements.md` if the org lets seats improve themselves (CHOICE 8).

Rules:

- **Where items come from:** only from things this seat has really done at least twice. Do not invent.
- **One line per item:** seen -> proposed -> state. Give paths, not stories.
- **One item per idle period.** When it is done, send one `PROGRESS` to the lead: what was done and where it is. Real work from the lead comes first; stop improving when it arrives.
- **A new tool** goes into the seat's own tool folder, is tried by the seat itself first, and enters a definition only after someone else has reviewed it and the author has shown a real run.
- **A checklist** grows the same way: when the same kind of problem shows up a second time, it becomes an item. An item names what to check and links to the reason; it does not copy the rule.
