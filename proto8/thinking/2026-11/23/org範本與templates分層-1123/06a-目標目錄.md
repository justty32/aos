# 06a 目標目錄

← [06 入口](06-三分的施工設計.md)｜現有每夾歸哪一類的理由在 [03](03-templates分層.md)

## 結論

- 六個類別夾：`agents`、`kernels`、`orgs`、`daemons`、`starts`、`tools`。`docs`、`tests`、`README.md`、`_index.json` 留頂層。
- **範本自己的名字都不改**，只是多一層類別夾（`starts/start-api`、`daemons/daemon-root`、`tools/tool-python`）。名字裡的 `start-`、`daemon-` 跟類別夾重複，但改名會讓每份文件、每個測試多改一輪，這次不做。
- `kernel/` 整夾改名成 `kernels/`，裡面不動（它自己的 `docs/`、`tests/` 跟著走）。
- `kits` 放 `agents/kits/`，名字照舊。
- `templates/tests/` 底下**不跟著分類**，留 `tests/<範本名>/`（理由見下）。
- `agent-fsm` 範本少九個檔（八支 `.py` 與 `hooks.json`），搬去 `py/aos/apps/agent_fsm/`，見 [06b](06b-執行期的東西搬進lib.md)。

## 搬完的樹

```
proto8/templates/
├─ README.md            入口（目錄那一段要重寫）
├─ _index.json          生成的
├─ docs/                01-eca-claude、02-agent-fsm、03-eca-pi（不動）
├─ tests/               不動位置：agent-fsm/ image-move-check/ judge-llm/ kits/ orgs/
│                       reviewer/ tool-python/ 與九支 test_*.py
├─ agents/
│  ├─ agent-fsm/        README _entry _metainfo body fsm hookeds interfaces llm loop
│  │                    subagents system.txt tools（沒有 .py、沒有 hooks.json）
│  ├─ agent-python/     agent.py 與它編譯出的那幾份
│  ├─ eca-claude/  eca-claude-alt/  eca-pi/      內容不動
│  ├─ reviewer/         fsm.json 四格改指 lib
│  └─ kits/             README kits.json general.A.txt gather/ review/ roles/
├─ kernels/             原 kernel/：README daemon-kernel/ procs-kernel/ llm-kernel/
│                       llm-team/ kernel-python/ docs/ tests/
├─ orgs/                今天新開的（範本位子在做），不搬
├─ daemons/             daemon-root/ daemon-sub/
├─ starts/              start-api/ start-eca/
└─ tools/               tool-python/ judge-llm/
```

類別夾 `agents/`、`daemons/`、`starts/`、`tools/` 不另寫 README：頂層 `README.md` 列六類各一句就夠；`_index.json` 要的那一句說明由 `wf/tools/index_gen_desc.json` 給（[06c](06c-要改的每一處與分工.md)）。`kernels/`、`orgs/` 原本就有 README，照舊。

## 為什麼 `tests/` 不跟著分

1. 測試檔用「往上數幾層」找 `proto8`（`Path(__file__).resolve().parents[3]` 這種；`templates/tests` 與 `kernel/tests` 裡 `parents[…]` 有 66 行，連 `dirname` 的寫法共 40 個檔）。測試夾的深度不變，這些一行都不用動，只要改「`templates` 底下接哪個夾名」那一段。
2. `tests/` 的子夾名就是範本名，六類裡沒有同名的範本，不會撞。
3. `wf/tools/index_gen.json` 裡 `proto8/templates/tests` 那一格不用改。

代價：看 `tests/agent-fsm/` 時要自己知道它對的是 `agents/agent-fsm/`。`tests/agent-fsm/` 那 27 支其實在測格程式（搬去 `py/` 之後算核心程式的東西），這次**不搬**，留給之後另一件事決定；這是替使用者做的小選擇。

## 路徑對照表（搬遷腳本與改表腳本共用）

先比對上面兩列（檔比夾長），再比對下面的夾；同一列裡長的名字先比（`eca-claude-alt` 先於 `eca-claude`）。名字後面要接 `/`、`"`、`#`、空白、`)`、`` ` `` 或行尾才算，免得 `templates/kernels` 被再改一次。這張表跑兩次結果一樣。

| 舊（都在 `templates/` 底下） | 新 |
|---|---|
| `agent-fsm/{idle,brain,wait,act,compact,cell_common,atomic_file,llm_settings}.py` | 原始碼 `py/aos/apps/agent_fsm/同名`；定義裡寫 `lib/aos/apps/agent_fsm/同名` |
| `agent-fsm/hooks.json` | 原始碼 `py/aos/apps/agent_fsm/hooks.json`；定義裡寫 `lib/aos/apps/agent_fsm/hooks.json` |
| `agent-fsm`、`agent-python`、`eca-claude`、`eca-claude-alt`、`eca-pi`、`reviewer`、`kits` | `agents/同名` |
| `kernel` | `kernels` |
| `daemon-root`、`daemon-sub` | `daemons/同名` |
| `start-api`、`start-eca` | `starts/同名` |
| `tool-python`、`judge-llm` | `tools/同名` |

不在表上、所以不動的：`templates/docs`、`templates/tests`、`templates/orgs`、`templates/README.md`。

## 抄出去的人會看到什麼不一樣

| 以前 | 之後 |
|---|---|
| `cp -r $AOS_HOME/templates/start-api ~/aos-home` | `cp -r $AOS_HOME/templates/starts/start-api ~/aos-home` |
| `aos-agent ctl add … $AOS_HOME/templates/eca-claude` | `… $AOS_HOME/templates/agents/eca-claude` |
| `agent_def new`，`template` 寫 `agent-fsm` | 一樣寫 `agent-fsm`（程式自己去 `agents/` 找；使用者第 2 件選 a） |
| `--kit $AOS_HOME/templates/kits/gather` | `--kit $AOS_HOME/templates/agents/kits/gather` |
| 抄 `agent-fsm` 會連八支 `.py` 一起抄到 | 抄到的定義沒有 `.py`，四格指 `$AOS_HOME/lib/aos/apps/agent_fsm/` |
