## 必讀量（使用者最有感的成本）

### 一個新 session 開場

照 AGENTS.md「開場與入口」字面走：

| 檔 | 位元組 |
|---|---|
| 知識庫入口 `aos/_description.json` | 2,508 |
| `AGENTS.md` | 10,758 |
| `wf/workflows/common/user.md`（「每個 session 都要先讀」） | 7,613 |
| `wf/SESSION-LOG.md` | 37,210 |
| `wf/WAIT_USER.md` | 4,509 |
| **合計** | **62,598** |

- SESSION-LOG 一個檔就佔 59%。
- 點進 `wait-user/` 四份再加 4,091（66,689）；`user.md` 只是目錄，三份分檔才是內容，再加 19,083（85,772）。
- 頂層是調度者，還要讀隊形短卡 `aos-teams.md` 11,401（97,173）；真的要動手再讀 `WORKFLOWS.md` 7,722（104,895）。
- compact 後 hook 自動灌回的是 `user.md` 加三份分檔 26,696，加 HANDOFF 那一條約 2.6 KB，共約 29 KB。

### 一隻被派出去的 agent「通讀 wf 規矩」

`user.md` 與 `aos-teams.md` 寫的清單是「`AGENTS.md`、`WORKFLOWS.md`、`common/user.md`、`common/conventions.md` 等」，前面先讀知識庫入口。

| 讀法 | 讀哪些 | 位元組 |
|---|---|---|
| 只照字面那四個檔 | 知識庫入口＋AGENTS＋WORKFLOWS＋user.md＋conventions.md | 29,523 |
| 老實讀（兩個入口都只是目錄，要讀分檔） | 上面＋`user/01～03`（19,083）＋`conventions/01～02`（9,488） | 58,094 |
| 被派來當一條線 | 上面＋`aos-teams.md`（11,401）＋`aos-teams/06` 硬規則（7,574） | 77,069 |
| 再讀 07 預設流程 | 上面＋`aos-teams/07`（12,671） | 89,740 |

- 清單尾巴那個「等」字沒有邊界，讀多少看 agent 自己。
- 參考：這次派我做這份規劃的任務書點名的 wf 必讀檔（AGENTS、WORKFLOWS 與分檔、INDEX 與分檔、STRUCTURE、user 與三份分檔、conventions 與分檔、data-files、tidy 入口與 content-trim、moving-things）加起來 103,266 位元組，還沒算知識庫入口、wf-into-aos-plan 與今天的盤點報告。
- 已經有的小卡：sol 隊員的配給包站台層 `kits/site.txt` 只有 734 位元組；隊形短卡 `aos-teams.md` 11.4 KB。中間沒有一張給一般被派 agent 用的。
