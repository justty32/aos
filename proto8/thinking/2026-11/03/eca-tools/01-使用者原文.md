## 決定（11-03，使用者）

1. 要做：給 eca 一個正式的「工具登記檔」接法，由 aos-eca／aos-eca-turn／cli_session 自己接上 aos-mcp，工作區與 stack 跟著那隻 eca 實例走（「要，派人規劃」）。
2. 方向題 1 選 (a)：`cli.json` 沒寫 `tools` 就找 eca 資料夾裡預設的 `tools.json`，寫了就用指的那份（見[方向題 1](04-要使用者看的.md#方向題-1預設要不要自動接-eca-資料夾裡的-toolsjson)）。（11-04 已改：沒寫 `tools` 時先用那隻 stack 裡的副本 `$AOS_STACK/tools.json`〔`aos-agent tools` 改的〕、再用同層 `tools.json`，見 [11-04 aos-agent 子命令](../../04/aos-agent/01-子命令.md)、[P-43](../../../../docs/CONVENTION/02-題目stack停錯腦.md)）

> 11-04 已改：aos-eca 退場、併進 `aos-agent`（`extras/eca` 刪掉，6179a4e3），見 [11-04 aos-agent](../../04/aos-agent/README.md)。本資料夾寫的 `aos-eca add／open／state／rm` 現在是 `aos-agent` 的同名子命令（`open` 經 `aos-eca-screen`）。

## 規劃（fable，照原則定的細節，可翻案）

一句話：**eca 資料夾裡放一份 aos-tools 的登記檔（預設 `tools.json`，`cli.json` 的 `tools` 可改指），cli_session 每次起 CLI 時自己把 `aos-mcp --ws <這隻的工作區> --stack <這隻的 stack> <登記檔絕對路徑>` 包成 MCP 設定交給 claude／codex；設定檔寫在 CLI 小格裡，定義資料夾一個字都不寫。**

### 1. 登記檔放哪、怎麼指

- **登記檔＝aos-tools 的那份**（格式 `{"tools": {名: {"path": …}}}`），**放在 eca 資料夾裡**，跟 `cli.json` 同一層。工具箱屬於**定義**：同一份定義掛到幾個工作區就共用同一箱；要不同的工具箱＝複製一份 eca 資料夾改它。
- **怎麼指**：`cli.json` 多一個選填 key **`tools`**＝登記檔路徑（字串；相對路徑**從 cli.json 所在的資料夾算**）。**沒寫 `tools`＝看 eca 資料夾裡有沒有 `tools.json`**：有就用、沒有＝不接工具。
- 不用 `add` 旗標、不用環境變數指。
- `tools` 的值只收字串（一份登記檔）；要多份就在那份裡 `{"tools": {"$ref": ["base.json", "mine.json"]}}`，不在 cli.json 開陣列。寫成別的型別＝`CfgBad`。

### 2. MCP 設定由誰、何時產生、放哪

- **誰**：`lib/agent/cli_session.py`（唯一拼 claude／codex argv 的地方），非互動、畫面、`--one` 工具形、`lib/agent/claude`／`codex` 工具四條路一次全接上。aos-eca-turn、aos-eca 不碰 argv。
- **何時**：每次起 CLI 之前重寫一次（N-05 先寫暫存再改名）；定義改了下次起就用新的。
- **放哪**：claude 的寫在 **CLI 小格** `<stack>/<kind>/mcp.json`（eca 平級形的小格是 `$AOS_STACK/claude/`，工具形就是 `$AOS_STACK` 本身）；**定義資料夾不被寫**（P-15）。內容：

  ```json
  {"mcpServers": {"aos": {"command": "aos-mcp",
    "args": ["--ws", "<這隻的工作區>", "--stack", "<這隻的 stack>", "<tools_flags…>", "<登記檔絕對路徑>"]}}}
  ```

  codex 不寫檔（§ 5）。
- **`command` 寫 `aos-mcp`、靠 PATH 找**，不寫死絕對路徑（N-50／N-59）；daemon 的 PATH 要有 `extras/ai_tools/bin`。
- 伺服器名字固定 `aos`（工具就叫 `mcp__aos__<登記名>`）。
