# 02 pi coding agent 是什麼：出處、模式、對話檔、外掛、權限、MCP、模型（11-18 上網查）

← [01](01-aos-eca要什麼.md)｜[入口](README.md)｜下一份 [03-對照表](03-對照表.md)

**結論**：pi 是一個「故意做小、靠外掛長大」的終端機 coding agent。給 aos 接最有用的四樣：`--session-id`／`--session-dir`（對話 id 與存放處自己定）、`--mode json`（一次跑完、吐事件流）、`--mode rpc`（長駐、stdin 收指令、能插話）、TypeScript 外掛（每個事件都能掛）。最大的不同：**不問權限、沒沙盒**。以下都是讀文件得來，沒裝、沒跑過。

## 出處與現況

- 作者 Mario Zechner（libGDX 作者，GitHub `badlogic`）。**2026-04-08 Earendil 收購**，他留任、管 pi 的決定。**2026-05-07** 公告搬家：repo `badlogic/pi-mono` → `github.com/earendil-works/pi`；npm `@mariozechner/*` → `@earendil-works/*`，主套件 `@earendil-works/pi-coding-agent`；舊名停在 0.73.1（標 deprecated、沒下架），新名從 0.74.0 起。指令仍叫 `pi`，授權 MIT。
- 很活躍：1.0.0 在 2026-10-01，之後 1.1～1.5，**最新 1.5.2（11-10）**；另有 `legacy-node20` 標籤 0.74.2。要 Node ≥ 22.19。
- 沒查到別的「pi coding agent」更像；有不少社群外掛名字帶 pi（例 `pi-exa-mcp` 被標成惡意，見 05），不要搞混。

## 安裝

官方給三種：`curl -fsSL https://pi.dev/install.sh | sh`、`npm install -g --ignore-scripts @earendil-works/pi-coding-agent`、Nix。更新 `pi update`。（本線沒裝。）

## 執行模式

| 模式 | 怎麼起 | 重點 |
|---|---|---|
| 互動 TUI | `pi` | 1.0 起預設全螢幕（alternate screen），`--tui-mode regular` 回一般捲動；官方有 tmux 說明頁 |
| 一次性文字 | `pi -p "…"` | 印最後的回答就結束；stdin／stdout 被導走又沒指定模式＝自動當 print |
| JSON 事件流 | `pi --mode json "…"` | 一行一事件跑完就結束。第一行 `session`（`id`＝對話 id），之後 `agent_start`、`turn_start/end`、`message_start/update/end`、`tool_execution_*`、`compaction_*`、`auto_retry_*`、`agent_end`、`agent_settled`。**最後回答＝`role` 是 assistant 的 `message_end`** |
| RPC | `pi --mode rpc` | stdin 收 JSONL 指令、stdout 回 `response` 與事件。指令有 `prompt`、`steer`、`follow_up`、`abort`、`compact`、`new_session`、`switch_session`、`fork`、`get_state`（含 `sessionFile`、`sessionId`、`isStreaming`）、`get_last_assistant_text`、`set_model`…。**答完要等 `agent_settled`，不是 `agent_end`**（之後還可能重試、壓縮、接著做）。只用 LF 切行（Node 的 readline 會在 U+2028 切錯）。關 stdin＝有秩序地收工 |
| SDK | TypeScript | 把 pi 當函式庫嵌進 Node 程式 |

stdin：管線進來的字**接在第一則題目前面**；`--` 之後才是題目（題目開頭是 `-` 時用）。

## 對話檔、續接、分支、壓縮

- 預設存 `~/.pi/agent/sessions/`，依工作資料夾分組；`--session-dir`＞環境變數 `PI_CODING_AGENT_SESSION_DIR`＞設定 `sessionDir`。`--no-session`＝不存。
- 續接：`-c`（這個資料夾最近一段）、`--session <路徑或 id>`、**`--session-id <id>`（用這個 id 開或建這個資料夾的對話）**、`--fork`。對話檔是一棵樹（`/tree` 在裡面跳、`/fork`、`/clone`），回到前面不會丟分支。每段對話記下開它的資料夾、之後不變。
- 壓縮：快滿時自動壓；`/compact [指示]` 手動，RPC 有 `compact` 指令（回 `summary`、`tokensBefore`、`estimatedTokensAfter`），也有 `set_auto_compaction`。壓縮＝加一段摘要、留最近的訊息，原文不刪。

## 外掛（extension）與 hook

- TypeScript 模組，用 jiti 直接載（不用編）。放 `~/.pi/agent/extensions/`、專案 `.pi/extensions/`（專案要先被信任），或 `pi -e <檔>`（可重複）；`-ne` 全關。
- 事件很全：`session_start`、`input`、`before_agent_start`、`agent_start`、`agent_end`、`agent_settled`、`turn_start/end`、`tool_call`（**可擋**：回 `{block: true, reason}`；可改參數）、`tool_result`（可改結果）、`session_before_compact`（可取消）、`session_compact`、`context`（可改送給模型的訊息）…。
- 外掛能 `registerTool`、`registerCommand`（`/名字`）、`ctx.ui.confirm` 問人、`pi.sendMessage(…)` 塞訊息（送達方式 `steer`／`followUp`／`nextTurn` 三選一）、`pi.exec` 跑指令。
- 官方明講：外掛在 pi 行程裡跑、權限跟使用者一樣，「can execute arbitrary code」。

## 權限

- **預設不問**：官方安全頁原話大意「pi 不會在每次叫工具前要核准」，沒有核准模式可切；也沒有沙盒。要擋就寫外掛掛 `tool_call`，或整隻放容器／VM（官方說這是最實在的做法）。
- 另有「專案信任」：`.pi/settings.json`、`.pi/mcp.json`、`.pi/extensions` 等專案資源要信任才載。決定順序：`--approve`／`--no-approve` 最大 → 外掛 → `~/.pi/agent/trust.json` → 設定 `defaultProjectTrust`（預設 `"ask"`）。**非互動模式（print、json、rpc）遇到 `"ask"` 一律不載**。`AGENTS.md`、`CLAUDE.md` 不受信任管，一律讀。

## 工具與 MCP

- 內建工具 read、write、edit、bash 等；`-t` 白名單、`-xt` 排除、`-nbt` 關內建、`-nt` 全關。
- **MCP 現在是內建的**（以前官網說永不做；1.0 起進核心，經 Codemode：模型寫一小段 JS 去叫工具）。設定在 `~/.pi/agent/mcp.json` 或專案 `.pi/mcp.json`（要信任）；`pi mcp add|remove|list|login|logout`、`/mcp`；外掛也能 `pi.registerMcpServer()`；`--no-mcp` 關。**沒查到「這次起動用這份 MCP 設定」的命令列旗標**，要接 aos-mcp 可能得走外掛或設定檔（待實測）。

## 系統提示與 AGENTS.md

- `--system-prompt <字或檔>` 整個換、`--append-system-prompt <字或檔>` 附加（可重複）；`~/.pi/agent/SYSTEM.md`／`APPEND_SYSTEM.md`、專案 `.pi/` 同名檔（要信任）。
- 情境檔：依序找帳號資料夾、工作資料夾、往上各層的 `AGENTS.override.md`、`AGENTS.md`、`CLAUDE.md`；`-nc` 關掉。

## 模型與登入

- 帳號資料夾 `~/.pi/agent`（`PI_CODING_AGENT_DIR` 可改），裡面有 `auth.json`（`/login` 存的 key 與 OAuth）、`models.json`、`settings.json`、`mcp.json`。
- **指到 OpenAI 相容端點**：`models.json` 加一個 provider，`baseUrl`、`api`（`openai-completions` 或 `openai-responses`）、`apiKey`（可寫 `$變數名`）、`models: [{id}]`。官方例是 Ollama `http://localhost:11434/v1`；litellm proxy 同理寫 `http://localhost:4000/v1`。也可只改內建 provider 的 `baseUrl`。命令列 `--provider`、`--model 供應商/id`、`--api-key`、`--thinking`。
- **訂閱登入**：`/login`。ChatGPT Plus／Pro 可以（新版 `/login openai` → Sign in with ChatGPT）；**Claude 訂閱不行**——Anthropic 只准訂閱額度在 Claude Code 裡用，pi 叫 claude 模型走 API 計費。
