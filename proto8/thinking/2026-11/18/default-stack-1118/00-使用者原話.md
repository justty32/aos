## 11-18 這一輪

1. 下午，小試驗第 2 題（[交接-各線/使用者原話-1118下午](../交接-各線/使用者原話-1118下午.md) 第 7 條）：
   「2.我記得stack沒指定的話，就是默認./.stack？那我想試試看cd到daemon stack / proc/ agent-1/，然後直接跟他agent say。」
   ——試驗結果在 [小試驗教學 02](../eca-claude-小試驗教學/02-預設stack與站在agent夾裡.md)：站在 agent 的夾裡直接 say 不行，要打 `aos-agent -d ../.. -t ann say …`。
2. 下午，看完第一批教學後（同檔第 22 條，只摘跟本題有關的那句）：
   「預設stack那塊我得再想想，因為我覺得這種cd過去的感覺挺好的，之後再來規劃吧。」
3. 晚上（頂層轉述，派這條線時給的）：
   「預設stack這個確實，派個標準調查流程去幫我想想。」

**要注意的一點**：第 1 句他說的是 cd 到「daemon stack / proc / agent-1」，也就是 **agent 的 stack**（`<樹>/.stack/procs/ann/`）。頂層派工時寫成「cd 到某個 agent **定義夾**就能直接 say、不用先 `ctl add`」，那是另一種讀法。兩種讀法在 [03](03-發想.md) 都列了，哪一種才是他想要的，要他說。
