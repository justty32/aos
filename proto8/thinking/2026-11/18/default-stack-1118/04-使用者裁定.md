# 預設 stack：使用者裁定（11-18 晚，逐字）

← [README](README.md)｜上一份：[03-發想](03-發想.md)

## 使用者原話

「stack這塊，我想要走丁，也就是agent的stack裏面加一個路標，表示他在哪個daemon底下，感覺如何？」

## 之後補的一句（同晚，頂層轉述）

「不過老實說，stack這塊說不定我之後會改主意，改成往上層資料夾找，先留着。」

意思：走丁的裁定暫不動工，可能改成戊（像 git 一樣往上層找），先留著。

## 選項框（三題）

1. 路標由誰寫：選「daemon 寫」（不是推薦的「ctl add 寫」）。
2. 丁要順便帶上乙（改錯誤訊息）：選「一起做 (Recommended)」。
3. 現在就派線嗎：選「先記著，之後再做」。

## 註（記錄者加，不是使用者的話）

- 丁要改規則表 N-63 的一列、並為 `AOS_AGENT` 開一條退路（站在 agent 的 stack 裡時不設也找得到對象）。
- 「daemon 寫路標」要改 C++ daemon（`proto8/cpp/`），不是只動 Python 的 `ctl add`。
- 沒派線、沒改程式；進度檔 `default-stack` 一條記著。
