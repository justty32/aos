### `~/.zshrc` 改了什麼

備份在 `~/.zshrc.bak-1118`。只改第 92～93 行：

```diff
-# aos: auto-source the tree env in my own windows; skip inside an agent's shell (it carries AOS_STACK).
-[[ -z $AOS_STACK && -f ~/aos-home/env.sh ]] && source ~/aos-home/env.sh
+# aos: AOS_HOME = the proto8 home (new flow, 11-18 rebuild); auto-source the tree env in my own windows; skip inside an agent's shell (it carries AOS_STACK).
+[[ -z $AOS_STACK ]] && export AOS_HOME=~/repo/aos/proto8 && [[ -f ~/aos-home/env.sh ]] && source ~/aos-home/env.sh
```

舊的 `env.sh` 會把 `AOS_HOME` 設成樹本身；新的 `env.sh` 不設，要外面先設成 `proto8`。**已經開著的視窗（含頂層 Claude Code 這個 session）環境裡還是 `AOS_HOME=/home/lorkhan/aos-home`，要重開才會變**；沒重開就 `source ~/aos-home/env.sh` 會報 `EnvBad AOS_HOME=… is not an aos home`。

### 留著跑的樹

步驟單第 6 步是前景跑在視窗裡，但這條線不能留自己的 tmux，所以最後一次再起改成：

```sh
cd / && env -i HOME=$HOME PATH=/usr/local/bin:/usr/bin:/bin LANG=$LANG AOS_HOME=$HOME/repo/aos/proto8 \
  setsid bash --norc --noprofile -c 'cd ~/aos-home && source env.sh && exec aos-exec root' > ~/.aos/scratch/home-rebuild-1118/root.log 2>&1 < /dev/null &
cd / && env -i … setsid bash --norc --noprofile -c 'cd ~/aos-home && source env.sh && cd llms && exec aos-exec --stack stacks/llm def' > /dev/null 2>> ~/.aos/scratch/home-rebuild-1118/llm.err < /dev/null &
```

llm kernel 的 stdout 每 0.34 秒一行 `counter_runs`（一天約 35 MB），所以丟 `/dev/null`，只留 stderr。關法照步驟單「關」那兩句；要改回前景看畫面，關掉後照「再起」在自己的視窗起就好。
