## 10-24 稍晚：資料夾與檔案的工具要特別設計（file-tools）

### 使用者原文

> 因爲很多東西都是靠資料夾和檔案。所以資料夾修改和檔案這兩個工具我需要特別設計。比如ls工具，返回一個陣列，AI可以在去看特定檔案的屬性和內容

（前文，JSON 工具那條：「agent說想要看某些json，那就是給他json頂層，他說想看特定key，再逐一給他看細節」——同一個「漸進展開」的精神。）

> 修改檔案這塊，json檔案修改起來，其實對AI很友好，一方面AI熟這些，AI生成json幾乎不會有問題，另一方面因爲是分層的，所以AI可以只去看他想看的東西。

### 決定（使用者 10-24「都按建議做」，照推薦定、可翻案）

1. **pi 四個之外再加一層層看的工具**：`ls`、`stat`、`view`、`json_edit`、`mkdir`、`move`、`copy`、`trash`，各一份 `tool.json`；「先看結構、再看屬性、再展開內容」，**輸出一律 JSON**。
2. **ls** 回一頁子項；每項 `name`、`type`（file／dir／link）、`mtime`；檔多 `size`、`exec`；`.json` 檔多 `keys`（頂層 key，最多 12 個，多的寫 `keys_more`）；資料夾多子項數與 `aos`（裡面有 `_entry`、`_entry.json`、`_metainfo`、`_metainfo.json`、`.env`、`tool.json`、`loop.json`、`fsm.json` 的哪幾個）；連結多 `link_to`。`.` 開頭的預設不列（`hidden: true` 才列）。資料夾在前、照名字排；一次預設 100 項、上限 500，分頁用 `offset`。
3. **stat** 看單一個：`type`、`mtime`、`mode`；檔多 `size`、`exec`、`text`、行數、`format`（json／python／markdown／shell／text），JSON 檔多 `top`（頂層摘要）；資料夾多子項數、`aos`；連結多 `link_to`（斷的標 `broken`）。
4. **view 漸進看內容**：**JSON 檔走分層**——`pointer`（RFC 6901，空字串＝整份）一次看一層，序列化後 ≤ 1000 字直接給 `value`，大的給 `children`（每個子項的型別與大小：物件幾個 key、陣列幾項、長字串幾字），要看哪個就把 key 接到 pointer 後面再叫。內容解得開就算 JSON（含沒副檔名的 `_entry`）。**文字檔**：≤ 200 行且 ≤ 8KB 整份給；大的先給大綱（Python 的 class／def 與行號範圍、Markdown 的標題與行號、其他給前 40 行），再用 `start`／`end`（行號）看那段；一次最多 2000 行或 50KB（同 read）。JSON 檔給 `start`／`end` 就當文字看。
5. **json_edit 照指標改 JSON**：`{path, set: {指標: 值}, del: [指標]}`；先檢查全部指得到（`PointerMissing` 就都不改），寫檔交給 **aos-json**（`proto8/impls/aos-json`，照 PATH 找；它的 stderr 原樣往上、這裡不讀，C-53；失敗只說 `WriteFailed aos-json … 結束碼 N`）。新的 JSON 檔用 write 整份寫。
6. **資料夾修改**：`mkdir`（上層一起建、已有＝`created: false`）、`move`（搬移／改名，`to` 上層自動建，`to` 已有東西就不搬——要蓋先 trash）、`copy`（檔或整個資料夾，連結照連結複製、不跟進去；先複製到 `.` 開頭的暫存再改名）、`trash`（**刪除＝搬進 `$AOS_WS/.trash/<時間>/<原路徑>`**，同一秒再丟加 `-1`、`-2`；垃圾桶裡的不再丟；要救用 move 搬回來；真的清掉垃圾桶是人的事）。原子寫入照 write（N-05）。
7. **限制在工作資料夾**同上（`PathBad`；move／copy／trash 的最後一節是連結時動連結本身、不跟進去）。新代號：`PointerMissing`、`MoveFailed`、`CopyFailed`。
8. **agent-pip 兩組一起掛**（十二條捷徑）；`system.txt` 加「先 ls 看結構、JSON 用 view 的 pointer 與 json_edit、其他文字檔大的先看大綱、刪東西用 trash」。

### 邊緣狀況

- **json_edit 同時給 set 與 del**：先檢查過指標，正常不會一半寫進去。
- **ls 會列出 agent 自己的題目資料夾**（`new/`、`cur/`）與 `.trash`（hidden）：腦可能動到自己的題目；要隔離就把題目與 stack 放工作區外。
- **垃圾桶只進不出**：沒有自動清；工作區越用越大。
- **view 判斷 JSON 是「解得開就算」**：一個剛好是合法 JSON 的文字檔（例如只有一個數字）會被當 JSON 看；要看原文給 `start`／`end`。
- **大 JSON 陣列**：children 最多列 200 個（多的寫 `children_more`），沒有分頁；要看後面的直接指標到那一項。
