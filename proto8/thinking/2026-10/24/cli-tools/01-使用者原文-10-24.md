## 結論（照推薦定、可翻案）

### 1. 兩條路並用——平常非互動續同一段對話；人接進去時開真的互動畫面（tmux），跳出後畫面留著、agent 改從畫面送字

| 情況 | agent 叫工具時怎麼做 |
|---|---|
| 畫面沒開（平常） | 非互動：claude `-p --resume <id>`（第一次 `--session-id <新 uuid>`）；codex `exec resume <id> -`（第一次 `exec -`、從 `thread.started` 拿 id）。回答從 JSON／`-o` 檔拿 |
| 畫面開著、沒人接著 | 從 pty 送字：`tmux paste-buffer -p`（bracketed paste，多行不會半路送出）＋Enter；回答**不解析畫面**，等 CLI 自己的 hook 在小格的 `turns.jsonl` 接一行（claude 用 `Stop` hook、codex 用 `notify`） |
| 有人接在畫面上、或 claude 正在跑一輪 | 不送，`SessionBad`（人跳出後再跑一次） |

同一段對話只有一個 id（`session.txt`），兩條路都接它，所以人在畫面上看得到 agent 之前問過的每一句，agent 之後也接得上人講過的話。

CLI 旗標要點：codex 的 `exec resume` 沒有 `-s`、`-C`，沙盒用 `-c sandbox_mode="read-only"`、工作資料夾用 cwd；`-c notify=[…]`＝每講完一輪叫一支程式、最後一個參數是 JSON（`type: agent-turn-complete`、`thread-id`、`last-assistant-message`）。claude `--max-budget-usd` 只對 `-p` 有效。

### 2. 接入／跳出

- 指令：agent 資料夾裡的 **`attach`**（`attach claude`、`attach codex`；`attach -d <名>` 只開不接；`attach` 不帶名字＝列出各工具的狀態與對話 id）。名字照 C-54：單一動詞、跟 `claude attach`、`tmux attach` 同字。
- 在**工作區**打（或 `--ws <工作區>`），不是在 agent 資料夾裡：畫面與對話屬於某一次跑的 stack（`$AOS_WS/.stack/tools/<工具名>/`；11-02 起進 `tools/`，當時是 `.stack/<工具名>/`），同一個 agent 資料夾可以同時跑在好幾個工作區（N-55、C-65）。使用者原話「cd 到 agent-bob/」照這條改成 cd 到工作區、用 agent 資料夾裡的 `attach`。
- 畫面沒開就先開（有對話就 `--resume`／`resume` 接著那段），然後 `tmux -S <小格>/tty.sock attach`——**「接入某個檔」就是這個 socket 檔**。
- **跳出＝Ctrl-\\**（tmux 不用 prefix，Ctrl-b 留給 Claude Code 自己用）；畫面底下狀態列寫著。在畫面裡 `/exit`（claude）或 `/quit`（codex）＝真的結束 CLI，畫面關掉，之後 agent 回到非互動那條路、接同一段對話。
- **只有人開畫面**（`attach`），agent 從不自己開：開畫面可能撞到信任資料夾、權限之類要人回答的提問。

### 3. 保守的權限（寫在各工具的 `cli.json`，要放寬就改那份）

- claude：`--tools Read,Glob,Grep`（只能讀；沒有 Bash、沒有開子 agent 的 Task，所以不會遞迴開 agent）、`--permission-mode dontAsk`（沒允許的直接拒，畫面不會卡在提問上）、`--strict-mcp-config`（不載任何 MCP server）、`--model sonnet`；非互動另加 `--max-budget-usd 0.5`。互動畫面用同一組旗標。
- codex：`-c sandbox_mode="read-only"`、`-c approval_policy="never"`（exec、resume、互動畫面都帶）；非 git 資料夾要 `--skip-git-repo-check`（程式自己加）。
- CLI 的工作資料夾＝`$AOS_WS`（工作區）。

### 4. 小格（工具自己的 stack，`$AOS_STACK/<工具名>/`）

`session.txt`（對話 id）、`tty.sock`（tmux socket）、`tmux.conf`（開畫面時寫，`focus-events` 打開）、`turns.jsonl`（hook 接的每一輪 `{"at", "text"}`，人在畫面上講的也進來）、`busy.txt`（claude 的 `UserPromptSubmit` hook 寫、`Stop` 刪）、`lock`（flock：agent 的一次呼叫、attach 開畫面互斥）、`last.txt`（codex `-o`）。

### 5. 錯（一行 `代號 原因`、退 1 → agent-fay 的 act 把那行回給腦）

`ArgumentsBad`（stdin 不是 `{"prompt": 非空字串}`）、`CliMissing`（PATH 上沒有 claude／codex）、`CliFailed`（結束碼非 0、`is_error`、逾時、畫面在講完前關掉）、`ReplyMissing`（畫面開著、送出後等到 `timeout_ms` 還沒有 hook 回來）、`SessionBad`（有人接著、正在跑一輪、這段對話有人在用）、`CfgMissing`／`CfgBad`（`cli.json`）、`StackMissing`；attach 另有 `ToolUnknown`、`TmuxMissing`、`WsMissing`、`ArgumentsBad`、`FlagUnknown`。

### 6. 名字（C-54）

| 名字 | 一句白話 |
|---|---|
| `agent-fay` | 腦有 claude、codex 兩個 CLI 工具、人可以接進去的問答 agent（demo 的 agent 用人名） |
| `attach` | 接進某個 CLI 工具的互動畫面 |
| `cli_session.py` | 把 CLI 的一段對話接成工具（兩條路、hook、開畫面） |
| `tools/<名>/cli.json` | 這個工具怎麼叫 CLI：`kind`（claude／codex）、`flags`（兩條路都帶）、`print_flags`（只有非互動帶）、`timeout_ms` |
| `session.txt`、`tty.sock`、`turns.jsonl`、`busy.txt` | 見第 4 點 |
