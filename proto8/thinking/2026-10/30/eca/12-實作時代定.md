## 實作時代定（10-30，隊長與工人照原則定的細節，可翻案）

- **daemon `ws`**：列上沒設 `ws` 就不寫這欄；`null`＝沒寫，空字串或其他型別照該處既有的壞值規則（daemon.json CfgBad、loops_ctl 整份不採用、信算壞信）；`ws` 的指示詞照解（N-45）；相對路徑從 daemon 的 cwd 轉絕對；不驗資料夾在不在（aos-exec 報 `WsMissing`）；改了 `ws` 照 N-54 不重起；只有物件子項能寫；adopt 保留舊列的 `ws`。
- **aos-daemon-ctl**：`--ws` 從呼叫當下的 cwd 轉絕對、必須是現有資料夾（`PathMissing`）。（`.stack` 捷徑的規則 11-03 起拿掉，見 [11-03 stack-where](../../../2026-11/03/stack-where.md)。）
- **cli_session**：`register` 刪，寫 `tool.txt`／`ws.txt` 那段留下改名 `note_cell`（叫回畫面要用）；抽出共用 `ask()`（note_cell → lock → 畫面／非互動 → transcripts）。
- **turn**：定義資料夾由 argv 傳（`{"$env": "AOS_CD"}`，同 round）；turn 自己叫 aos-post、自己附加 history，不經 aos-parts 找 queue／history 格；小格＝`$AOS_STACK/<kind>/`；好信＝`{"role": "user", "content": 非空字串}`；`SessionBad` 與 queue 空都不寫 trace（免得洗版，Q-9）；壞信 trace 一行 code 0 帶 `letter_warning`；CLI 失敗退 1、信留 `cur/`（P-20）；queue 沒有就 `aos-post init`；`eca.json` 有變才寫。（11-03 起不寫 trace、壞信記 `mailbox_warning.txt`，見 [11-03 trace](../../../2026-11/03/trace.md)；交給 CLI 之後失敗信已收，見 [20](20-11-03-交出去就收.md)。）
- **範本**：`lib/agent/claude`、`codex` 不改叫 turn（它們是工具形，問 CLI 那段已共用 `ask`；使用者 11-02 晚認可，[14 決定 9](14-11-02-晚使用者想法.md#決定11-02-晚使用者)）；射後不理在 aos-loop 外面看是退 0（內層退 10＝loop 以 0 收工）；範本 `cli.json` 沿用 lib 工具的保守旗標。
- **aos-eca-hub**：用 daemon 表的心跳判 daemon 活不活；等 daemon 收掉最多 30 秒（`Timeout`）。（stop、歸檔、重新掛上的規則見 [14](14-11-02-晚使用者想法.md#決定11-02-晚使用者)、[15](15-實作時代定.md)、[18](18-11-03-單隻-add-rm.md)。）
- **human**：aos-listen「trace 有 question＋error」的判斷保留（turn 失敗也這樣寫）。
- **條文**：N-63 的 `AOS_HUB` 直接刪字、② 的例子 `HubMissing` 換 `DaemonMissing`；P-43 照實作多寫幾件（`letter_warning`、`eca.json`、CLI 錯照 P-20）；舊協議半句直接接在原句後面、原文不改。
