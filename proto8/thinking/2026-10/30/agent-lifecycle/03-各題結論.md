### B. 納管外部 coding agent 的生命週期

11. **aos agent：agent 是函數、停著等交給 aos-loop**（決定 34；N-53）。範本 `_entry` 寫 `["aos-loop", "loop.json"]`，`loop.json` 開窗 `"ctl": "ctl.json"`、`"state": "state.json"`（落在 `$AOS_STACK`）。暫停／停＝寫 `$AOS_STACK/ctl.json` 的 `paused`／`stopped`（N-07），一次＝一輪 round；agent 自己寫循環、自己讀 ctl 的做法不做（agent 這層沒有 ctl）。
    - **跑完要不要結束寫在定義裡**（playground-queue 結論 2），落在 round 這格的設定：`ROUND_ON_EMPTY=stop`（預設；queue 空＝退 10、loop 收工＝**射後不理**）或 `idle`（queue 空＝退 0、什麼都不做，由 loop 的 `interval_ms` 隔一下再來＝**射後有理**）。寫在 `parts.json` 那格的 `env` 或 round 格的 `.env`。不加阻塞等待；pause／stop 的反應時間＝`interval_ms`。
    - 場景二「暫停狀態機、改東西」＝fsm agent 的 loop `paused` 停在格與格之間；round agent 的 `paused` 停在輪與輪之間。同一個詞同一個意思（N-07），「一次」多大各程式自己說。
12. **外部 coding agent（黑盒子）掛 aos-daemon**，兩條：
    - **① 包成 `max: 1` 的 loop**（使用者「包成max:1也是可以」）。daemon.json：`"loops": {"bob": {"exec": "/path/agent-bob", "max": 1}}`（相對路徑從 daemon 的 cwd 算，N-28）。退 0 或 10＝`done`、不自動重起；退非 0＝記 `code`。**沒寫 `max`＝退 0 就立刻再跑**，一次性的東西一定要寫 `max: 1`。停：daemon SIGTERM loop → loop 轉給子程式 → 10 秒不退 SIGKILL 整個 session 群組（P-36）。掛 aos agent 時外層 loop 的窗跟它自己的窗撞同一個檔，要把裡面那層的窗改名或不開窗。
    - **② daemon 原生掛一個 exec 型子項**（使用者「讓daemon可以掛aos-exec，也是不錯的」）。daemon.json 多一個選填 key **`execs`**，形狀同 `loops`：`{"名字": 目標}` 或 `{"名字": {"exec": 目標}}`。daemon 直接 `aos-exec` 它一次：小格 `$AOS_STACK/<名字>/`、`AOS_STACK`＝小格、stderr 附加到小格 `stderr.txt`、自成 session 群組、stdin 接 `/dev/null`，**不包 aos-loop、不寫 `loop.json`、不補 `ctl`／`state`**。退了＝`done`（記 `code`／`signal`），不重起。`loops_state.json` 多一張 **`execs` 表**（列同 `loops`，`phase` 同 N-17）；`adopt` 兩張表都接。`loops_ctl.json` 與信箱模式的信多認 `execs_added`／`execs_removed`（N-54）。停：SIGTERM 直接打那支程式、10 秒 SIGKILL 整群。`execs` 與 `loops` 共用名字空間。
      - **11-03 併進 `procs`**（[11-03 procs](../../../2026-11/03/procs.md)）：`execs` 與 `loops` 合成一份名單 `procs`，`execs_added`／`execs_removed` 併進 `procs_added`／`procs_removed`；一項怎麼起看寫法（字串、陣列、只有 `exec` 的物件＝跑一次），沒有種類欄。本段照 10 月的舊名。
    - **沒掛 daemon＝Linux 管**（決定 1；使用者「linux本身的proc管理就夠」）：aos 不另做 `aos-ps`。
13. **aos-hub 留什麼**：hub 是替要畫面、要接回舊對話的外部 CLI 做的（tmux、Ctrl-]、`--resume`、session 檔），這幾樣全部留在 hub；hub 的 `pause` 改名 **`close`**（跟 `open` 成對：關畫面、對話留著、照樣收題），`stop` 照舊；hub 收題改走 queue（A-9）；hub 的 `ls`／`state` 對 daemon 那邊的對應物是讀 `loops_state.json`，不另做指令。hub-kernel 掛在 daemon 底下當 `execs` 子項：可以、不強制（hub-kernel 決定 14「沒差」）。「暫停＝不收新題」留給 N-07 的 `paused`，hub 不加。
