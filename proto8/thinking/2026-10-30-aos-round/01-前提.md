## 前提（引用哪些決定）

- **使用者 10-30 澄清**（[eca § 翻案](../2026-10-30-eca/11-10-31-使用者想法-turn-改名-把-tu.md#翻案round-化作-aos-round-薄殼10-30使用者澄清)）：round「裡面的迴圈那塊可以用 loop/fsm 實作，外部這塊各類用到的函數也可以用 aos 函數替代。整個框架則化作 aos-round。整體看起來就像是包在 aos loop/fsm agent 上的一層薄殼」；「把 round 拆散放進每一格……這也算是一種實作，以後可能在一些特定情況下會用上」；「fsm 的 next 可以按照結束碼分岔……他的 json 格式可以稍微變換一下，依據不同結束碼導向不同分支」。
- **三條決定**：round → `aos-round`；fsm 的 `next` 照結束碼分岔**已定選甲（改 N-36）**，乙（N-43 加「成功但留在原地」碼）不走；「拆散放進每一格」留作另一種實作、不刪不做。eca 方向題 1「留骨架」作廢。
- **隊長查過的五個難點**（agent-lifecycle 文末）：idle 等不阻塞、插話（act 退 10 被 loop 當成停）、答完一題就停、retry／switch 的計數、trace 撞檔；外加「可有可無的 hook」「補認領不叫 pre_round」要在格裡判。
- **N-36／N-38／N-39（fsm 現行）**：一次只跑一格、`next` 是一個狀態名、**格退 0 才換狀態**、其他碼 state 不動並以那個碼退出；fsm 不數次數（無窮轉移只有 loop 的 `max` 擋）、不開 ctl；trace 一格一行 `{"started_at","state","code","signal","elapsed_ms"}`；自己收到訊號＝那格跑完照寫 trace／state、再以 128＋N 結束。
- **N-43／P-19（結束碼）**：`0` 正常、`10` 正常停（要求外面的 loop 別再跑了）、其他非 0 有錯；每層只說自己；loop 收到 10 以 0 結束、其他非 0 以那個碼結束。使用者 10-15「結束碼不要太依賴……0 就是通用正常，非 0 就是有錯，沒了」。
- **P-20／N-53／N-38**：任一格失敗＝整隻停下等人，fsm 不換狀態；**agent 自己不數連錯**，重試幾次看外面；10-28 起 endpoint 失敗先問 `hook/on_error`，沒掛＝停。
- **P-35／P-36**：格可以是一整隻 agent、「10 只有 idle 退」；逾時打整棵子樹，被殺的格＝失敗（128＋訊號），上面照 P-20 停。
- **10-28 medium 決定 2**：aos-loop＝「常駐＋暴露狀態＋控制手把」套在 aos 函數上的包裝；**agent-bob 決定 34**：aos-loop 是 aos agent 的內部組件。
- **10-28 agent-round 已定與代定**：round 的順序（pre_round → claim → [pre_think → endpoint → on_error → post_think → append → emit → act → append → pause]… → finish → post_round）、九個掛勾、不另設狀態檔（看 `cur/` 與 history 最後一則）、`--step`、`MAX_RETRIES` 在 round、trace 的 `unit` 行、`ask_round` 重叫 round 的規則（代定 46）。10-30 已改走 queue（`$AOS_STACK/queue/`、答案＝history 最新 assistant、`ROUND_ON_EMPTY=stop|idle`）。
- **C-54**：命名照老慣例查 Unix；R13 程式名 `aos-<領域>-<功能>`，一個領域只有一支時可只寫領域。
- **實作現況（這次翻過）**：aos-fsm 的 `Cell` 只有 `{exec, next: string}`，`main.cpp` 是「跑格 → 寫 trace → 碼 0 才寫 state → 以格的碼退出」，分岔沒有任何痕跡；aos-loop 自己沒有 trace、子程式非 0 非 10 就停；`lib/agent/round/_entry`（Python 415 行）每步重算「現在在哪」、每格一行 `{"unit"}` trace、retry 計數在行程記憶體；agent-nia 的 loop.json 是單子 `aos-parts run round $AOS_CD`、`timeout_ms` 600000、開 ctl／state 窗；agent-dan-q 是 loop → `fsm.json`（idle／think／act 三格、字串 `next`），idle 空了退 10、loop 停；`lib/eca/turn` 一格做完整一輪（claim → CLI → append → finish），`ECA_ON_EMPTY=stop|idle`；`$AOS_STACK/trace.jsonl` 現在 fsm（`state`、時間 `+00:00`）、round（`unit`、時間 `Z`）、turn（`unit: turn`）三種行同名檔，沒撞只因沒有 demo 同時疊。
