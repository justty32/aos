## 11-03 ls 改英文

使用者 11-03（逐字）：「ws aos-eca ls → eca_bob      收起了        claude /home/guanyu/code/playground/ws  對話 154bb4f3。能不能改成用英文，就用我們先前的名詞表。」

**決定**：狀態欄只用 procs 名詞表的狀態——`running`、`paused`、`stopping`、`stopped`（daemon 表上其他的 phase 照印）。原本混在狀態裡的「畫面開沒開」拆成另一欄。

**頂層代定**（可翻案）：

1. **`paused` 怎麼認**：daemon 表上 `running`、而它的 stack 裡子 loop 的 `state.json`（照 stack 裡 `loop.json` 的 `state` 那格，沒寫＝`state.json`）`phase` 是 `paused`（`aos-daemon-ctl pause` 寫的）；讀不到就當 `running`。daemon 表本身不轉述暫停（procs § 0），所以只能這樣看。
2. **畫面那欄**：值 `open`／`closed`，對應 `aos-eca open`／`close` 這對動作；`ls --json` 的 `screen` 也改成同一個字串（原本是布林），跟文字版一個字彙。
3. **`ls` 一行**：`名字 狀態 畫面 種類 工作區  session 對話id前8碼`，「對話」改 `session`。例：

   ```
   eca_bob      running  closed claude /home/guanyu/code/playground/ws  session 154bb4f3
   ```

4. **`state`**：「狀態」那行印英文狀態（後面照舊帶 daemon phase），下一行多「畫面 open／closed」；欄名（名字、狀態、畫面、對話…）留中文。`start`／`stop`／`open`／`close` 印的中文句子不改，只有括號裡帶的狀態跟著變英文（例「本來就停著（stopped）」）。
