# 2026-10-13 kernel／agent：結論與未決

← [kernel／agent 入口](../2026-10-13-kernel-agent.md)

## 1. 結論

- **kernel**：管任務／排程／資源的行為就是 kernel 的行為；能操控某些東西被執行的就算 kernel（直接當宿主、或寫檔給獨立的 daemon 讀都算；被執行的東西不一定是 inst）。標準規範裡 kernel 以 daemon 為基礎、決定 daemon 跑哪些 inst。
- **任務屬性**：隱性的行程屬性、檔案屬性（身在 Linux 就有）＋我們的九軸（`_metainfo`，為自我改進）。規範只定義屬性；要不要跑、怎麼決定，是程式內部的演算法，隨便。
- **agent**：有記憶、思考中心、工具，是一個狀態機。形式不限（也可以是一個 inst 跑 Claude Code）；自我改進用的是 **loop＋狀態切換程式**，每步狀態落檔（建議、非必要），方便自省、zip／git。
- **第一個標準版 agent**：等待、思考、工具執行三態；思考＝呼叫某個 inst 跑大語言模型。

## 2. 未決

- 工具（OpenAI 工具呼叫 JSON）和 inst（argv）怎麼配合——後續再說。
- agent 資料夾裡記憶／思考中心／工具怎麼放、每步留什麼紀錄、agent 對自己與對別的 daemon 是否同一種寫法、daemon 管 daemon 的收工（使用者：確實麻煩）——等開始規劃 agent 時再說。
