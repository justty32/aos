## 決定（10-28）

1. **各種單位都要是 aos 函數**，也就是 aos-exec 能跑的東西：queue 的各種操作、endpoint、tools、迴圈裡各個時間點的掛勾，乃至一輪本身——**包括 endpoint**（使用者「各種單位都要跟aos函數對上，也就是aos-exec可以跑的單位目標。包括endpoint」）。目標是用在 aos agent 體系。
2. 頂層的第一份回答（提案一）**記下來**（使用者「記下來」），內容仍是提案、不是逐條採納。
3. **跟規範衝突時照新做法走**（endpoint 是 aos 函數、各單位都是 aos 函數）：**P-23**（endpoint 由環境變數 `AOS_BRAIN_URL` 等給）改成 endpoint 是 aos 函數；**P-41**（腦寫在 think 格裡的程式）的 brain 拆成 endpoint 資料夾（使用者「跟規範不一樣...就是要這樣，我覺得我們現在這樣比較先進。」）。NORMS／CONVENTION 條文待實作時改。
4. **迴圈上的固定時間點都是插座**，每個點都能掛 aos 函數；tools 何時生效＝掛在哪個點（使用者「好主意」）。
5. **history 是一個單位**，摘要、刪舊是 aos 函數（例 history/compact）、掛在問腦前（使用者「對的對的」）。
6. **endpoint 介面要講清楚**：輸入輸出格式、串流、錯誤分類（429 重試、401 停）、usage 回報，這些要處理（使用者「要，這個確實需要處理」）。
7. **引用共用零件可以用 symlink**（使用者「在aos體系下，引用，可以用symlink」）；agent 只寫自己要換的格。symlink 是方便用的捷徑，正式機制是格的註冊檔（決定 16）。
8. **多個工具平行或依序，交給一個 aos 函數決定**（使用者「對的」）。
9. **不考慮跟 kernel 的關係**：我們就是呼叫函數，函數背後有沒有被 kernel 管，呼叫者不知道；之後再說（使用者「不需要考慮跟kernel的關係……那是後續了」）。
10. **引用跟 P-25、C-61「零個 `..`」衝突時，照新做法走**（使用者「撞到就撞到。反正我是覺得我們這個比較先進」）：註冊檔存絕對路徑（跟 aos-tools 對 C-61／P-25 的加註同一種），`..` 只出現在捷徑、手寫的相對路徑裡；條文待實作時改。
11. **agent-round 文末四條衝突照新做法走**（使用者「照新做法」）：每格拿 agent 資料夾當第一個參數（P-33／C-52）、只有 compact 可以改寫 history（P-41）、錯誤分類靠 stderr 代號（N-43）、`on_error` 預設停（P-20 改成「預設」）；另三題由決定 12、13、16 定。見 [agent-round 文末](../2026-10-28-agent-round/05-已定.md#已定原本要使用者看的七條10-28)；條文待實作時改。
12. **粒度不是二選一的預設，是 agent 的設定**（使用者「aos-exec他的時候要跑哪個，那就看_entry是設定要哪個」）：格只有一套；`_entry` 寫 aos-loop 就一格一格跑，寫 round 就一次跑完一輪；N-53／C-25 的一格一次用 aos-loop。
13. **round 留在零件庫（lib），不升成 aos 指令**；它是**語法糖**，等於 aos-loop 加上「這一輪結束就停」的條件（使用者「還是零件庫吧……aos-round他是一個語法糖，沒有他，我們也可以用aos-loop加上一些東西去實現」）。
14. **aos 體系歸 aos 體系**：loop、fsm、round、各單位跟外部 CLI agent 分開；claude code、codex、pi 不納入 round、不另做東西，只提供跟 aos 接入的接口（現有的 hub、aos-mcp、say／listen 協議）（使用者「先不要把兩個扯在一起，aos體系就歸aos體系」）；不把 claude code 的 -p 當黑盒子 round。
15. **round 列入外部接口**，跟 hub、aos-mcp、say／listen 並列：外面呼叫一次 round＝同步問一題、等答案，不需要 agent 常駐；例如在 claude code 的 tools.json 登記「問 agent-xxx」、經 aos-mcp 呼叫。claude code 只是呼叫 round、不變成 round。**搶信箱是呼叫者自己的風險**，工具不另加保護（使用者「那就是使用者要自己承擔的風險」；呼應 C-53「入口默認正常、誤用不歸組件管」）。
16. **格全部走註冊檔，捷徑只是方便用**（使用者「全部走註冊檔好了，捷徑就是方便使用」「註冊檔案中沒寫的，那就是走固定名字」）：叫一格的查找順序：**註冊檔 → agent 資料夾裡的固定名字（捷徑、真的資料夾或檔都行）→ 預設**（掛勾＝沒掛的預設行為）。細節照原則代定，在 [agent-round § 格怎麼找](../2026-10-28-agent-round/01-白話版.md#格怎麼找註冊檔--固定名字--預設決定-16)。

決定 4～9 的細節設計照原則代定，在 [agent-round](../2026-10-28-agent-round.md)。
