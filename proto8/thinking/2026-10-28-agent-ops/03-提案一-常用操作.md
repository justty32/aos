## 提案一：常用操作（提案，未定）

### queue 對到既有信箱（提案，未定）

- 對應：`new/`＝排隊中、`cur/`＝處理中、`done/`＋`out/`＝處理過、`history.jsonl`＝副產物（P-11～P-13、P-41）。
- 操作：say（push）、listen（pop）、看排隊、看當前（`current.txt`）、看處理過、跟著看 history、撤回（刪 `new/` 裡那題）、插隊（改檔名，靠 P-12 照檔名排序取題）、改題目。
- **「認領」（搬進 `cur/`）是界線**：認領前可以改、可以撤回；認領後只能看。

### endpoint 中途換（提案，未定）

- 環境變數在行程跑起來後改不到，所以要改成**每次問腦前去讀一個東西**。操作：get、set、候選名單。
- 跟原則的衝突：**P-23**（endpoint 由環境變數 `AOS_BRAIN_URL` 給）；**P-20**（出錯就停、不自動重試）——所以「失敗了重試」「失敗了換下一個 endpoint」算各 agent 自己的設定，範本預設照樣停。

### tools（提案，未定）

- 增刪改查已有 [aos-tools](../2026-10-28-aos-tools.md)。
- 生效時間點三種：一輪開頭拍快照、每次問腦前重讀、跑工具中途被刪（這種已定：`ToolUnknown` 回給腦，P-41）。
- 代價：中途改工具清單，模型的 prompt cache 會失效，所以**時間點也交給 agent 自己設定**。
- 延伸：題目資料夾自帶工具（P-13 的資料夾題），只對那一題有效。

### 阻塞（提案，未定）

| 操作 | 預設 | 可選 |
|---|---|---|
| say | 不等 | `--wait` 等到答案 |
| listen | 等 | 設逾時；或不等、沒有就回一個結束碼 |
| 查看（排隊、當前、處理過） | 永遠不等 | — |
| 改設定（endpoint、tools） | 寫完就走 | 等到 agent 真的用上（要 trace 記這輪用的是哪一版） |
| pause | 等到下一個安全點 | — |

多人同時寫同一份東西，要先寫暫存再改名。

## 提案二：照決定 1 重寫的 pseudo code（提案，未定）

原樣收錄：

```python
# aos(X, ...) = AOS_STACK=<小格> aos-exec X ...；stdin／stdout／結束碼就是介面
# 迴圈裡的變數一律是 $AOS_STACK 裡的檔，所以每一步都能是獨立的行程

def round():                                   # 一輪本身也是 aos 函數：aos-exec round
    if not aos("queue/claim"):                 # new/ 最前面一題搬進 cur/；沒題目就退 10
        return 10
    while True:
        ep    = aos("endpoint/pick")           # stdout：這次要用的 endpoint 路徑
        tdefs = aos("tools/defs")              # = aos-tools ls；何時重讀由這格自己決定
        r = aos(ep, stdin=history() + tdefs)   # endpoint 本身是 aos 函數：messages 進，一則 assistant 出
        if r.code != 0:
            what = aos("hook/on_error", stdin=r.stderr)    # 印 retry／switch／stop；範本預設 stop（P-20）
            if what == "retry":  continue
            if what == "switch": aos("endpoint/next"); continue
            return r.code                      # 停下等人；狀態都在 stack，修好再跑一次接著做
        aos("history/append", stdin=r.out)
        aos("queue/emit", stdin=r.out)         # 吐給外面（out/ 或串流）
        if not r.tool_calls:
            aos("queue/finish")                # 答案寫 out/，題目 cur/ → done/
            return 0
        for call in r.tool_calls:
            if aos("queue/peek").has_new and aos("hook/on_interrupt") == "打斷":
                aos("history/append", stdin=aos("queue/claim_extra"))
                break
            out = aos("tools/call", call.name, stdin=call.arguments)   # = aos-tools call
            aos("history/append", stdin=out)
            if aos("hook/should_pause"):
                return 0                       # yield 在 aos 裡就是「結束並把狀態留在 stack」，下次從這接

def agent():                                   # 外層 = aos loop／fsm 反覆跑 round
    while (code := aos("round")) == 0: pass
```
