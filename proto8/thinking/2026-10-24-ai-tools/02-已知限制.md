## 已知限制

- **背景的 agent 每 2 秒被叫一次**：沒題時 idle 退 10、子 loop 照 `interval_ms` 再叫，`trace.jsonl` 每次多一行 idle；要省就把 `--interval-ms` 調大。
- **前景與背景的互斥只擋得住 aos-ai 自己**：有人直接 `aos-exec` 同一個工作區，兩邊一樣會互搶（loop 沒鎖）。
- **ctl 是宣告**：aos-ai 讀－改－寫整份，兩支 aos-ai 同時寫靠 `daemon/.ctl.lock`；人手改 ctl 同時 aos-ai 也在寫，後寫的蓋前寫的。
- daemon 沒在跑時 `wait` 立刻失敗（`WaitFailed`）。
- **`run` 收集答案看的是「這次多出來的 out/ 檔」**：題名跟舊答案同名就看不到，所以 `ask` 擋重複題名。
- **`ask` 的暫存檔放在 `new/` 外面**（工作區根）：agent-dan 的 `brain.py` 撿題時連 `.` 開頭的也撿過。
- **zsh 會把 `17*23` 當萬用字元**：題目要加引號；SKILL.md 的例子有加。
- **`--argv` 給字串是照空白切**（`'sh -c "echo x"'` 會切壞），要精確就給 JSON 陣列。
- **Claude Code 的 Bash 權限可能擋含 `$AOS_STACK` 的指令**、也可能擋用完整路徑叫的 `aos-ai`；非互動用時要另外允許。
- 工具結果是 aos-ai 的 JSON 原樣，腦看到的是 `{"ok": true, "answer": …}` 整串。
- **② 子 agent 的腦跟老闆同一個**：`AOS_BRAIN_URL` 等一路傳下去，`.env` 預設不蓋外面已設的（N-58）；aos-ai 沒開 `--dotenv-override`。
- **巢狀深度沒限制**：helper 也掛 `ask_agent` 就能一直往下叫；每層前景跑，最外層 act 的 60 秒逾時會先到。
- `ai`（`aos-ai`、`AOS_AI_ROOT`）不在 C-54 縮寫表上（留給整理時補）。
