## 定了的（續）：窗的族譜（來自 [thinking 10-14 JSON 入口](../thinking/2026-10-14-json-entry.md) §1p、[IPC 研究頁](https://claude.ai/artifact/7QcbQjrK2h7U9LPcApwpvH)）

N-13 只有 state／ctl 兩扇窗；本段把它擴成一族。

- **N-14**（10-14 定，草稿）窗一族總則：除了 state／ctl，鎖、號誌、信箱、公告、一問一答…都是窗，每種一條規範。共通：位置由 stdin 參數用攤平的 key 指定（例 `{"state": "s.json", "ctl": "c.json", "lock": "brain.lock/"}`），沒給照 N-13（不開、不提醒；loop／daemon 的 state／ctl、fsm 的 state 例外，必填，[N-19](03-實作分級-N18至N20.md)）；窗內自述種類（`kind`）；內容是 JSON；原子性只靠三種——rename（照 N-05）、mkdir／O_EXCL、flock；fsync 不強制；判斷變化比內容或序號，不比 stat；回音以序號 seq 為準（例：ctl 加 seq，state 回報 `ctl_seq`＝讀到第幾號；10-14 夜重做時已落實）；等變化輪詢保底、inotify 加速（/mnt/c 上 inotify 會靜默失效）。號誌、公告、一問一答的細節待實作時定，見 [IPC 研究頁](https://claude.ai/artifact/7QcbQjrK2h7U9LPcApwpvH)（AI 建議，未拍板）。FUSE 等效能很糟時再說。（10-14）
- **N-15**（10-14 定，草稿）鎖：鎖窗是一個資料夾，mkdir 建成功的人拿到鎖，在裡面寫名牌 `holder.json`（租約）；flock 只當同機加速。收屍看 pid（＋啟動時間）與租約：確認持有者已死或租約過期，搶的人可以自己收，帶序號防兩人同時收。（10-14）
- **N-16**（10-14 定，草稿）信箱：兩種都收——資料夾式（Maildir：tmp／new／cur，認領靠改名）＝一封封信；JSONL 追加檔（照 N-12 的 JSON 串流）＝一條流。（10-14）
- **N-17**（10-14 定，草稿）心跳：state 帶 pid、啟動時間、開機 id；內容沒變也每隔一段碰一下；超過 3 倍間隔沒動靜算疑似死亡（確定要看 pid＋啟動時間，N-15）。間隔預設值未定。（10-14）
