```mermaid
flowchart LR
    A[等問腦收完] --> B[整樹 sleep、根退出]
    B --> C[sync、保存 image]
    C --> D[重設這台的值]
    D --> E[起根、逐層接回]
```

搬家單位是一棵樹、一份 image；同一份 image 一次只在一台醒著。根也是普通 daemon，使用者顧它正常運行；父把子 daemon 當普通 proc，只看活著與公開 ctl／state 的回應，不讀子信箱或子項表。

**兩台經 git 輪流跑**（11-10）最簡單：搬過去（git 或 `cp -a`）＋設好這台的環境變數＋起根，不用跑任何換台指令，見 [04-兩台輪流](04-搬家/04-兩台輪流.md)。下面 01～03 是完整的拆解與手動做法。
