# 全景 v1（清單版）

凍結於 2026-11-14（使用者：「目前的全景已經很好用了。希望能把版本獨立成一套。」）。版本號見 `VERSION`。

- 網址：http://127.0.0.1:8767/ ，只聽本機。
- 這裡是 v1 的前端（`index.html`、`app.js`、`map.js`、`style.css`），由上一層的 `aos-view serve` 提供。
- 規矩：**之後只修 bug，不加新功能**。新功能做在新 UI（公司部門版，規劃中，見 repo `proto8/thinking/2026-11/14/view-1114/`）。
- 後端和 JSON API（`view-api/0`，見 `../../API.md`）新舊兩版共用。後端可以補新的 API，但不改 v1 已經在用的欄位和行為。
- 只能有一個後端程序在收中轉信箱。新 UI 要由同一個程序提供（另開一個 port 或一條路徑），不要再起第二個 `aos-view serve` 去讀同一個 `~/.aos/view`。
- 上一層的 `web/` 是凍結前的舊位置，檔案留著，但已經不再提供。
