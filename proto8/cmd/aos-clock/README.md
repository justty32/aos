# aos-clock — 把時鐘檔的回合數往前走一格

← [cmd](../README.md)

`bin/aos-clock`（Python）讀出時鐘檔的 n、寫回 n＋1。說明在 [cmd/docs/02](../docs/02-aos-clock與已定值.md)。第一個參數正好是 `register`＝整個交給 [aos-clock-register](../aos-clock-register/README.md)（`aos-clock register add …`＝`aos-clock-register add …`；11-10 深夜使用者「7.不衝突，要用的人要自己分辨，這很容易分辨的。程式實作上也就自然而然。」）；時鐘檔真的叫 register 的寫 `./register`。
