- **where --stack 名字**：印這個子項的 stack＝procs_state 那一列的 `stack`（預設小格 `<D>/procs/<名字>`、或 add `--stack` 給的；表上存相對 daemon stack、這裡拼回絕對印一行、結尾不帶 `/`；拿 stack 只在 `cell_of` 一處）。**只認 daemon 表上的**（`running`、`stopping`、`stopped`、`sleeping` 都算；使用者「一個proc在daemon中的狀態，包括運行中、暫停中，除此之外就是不存在於daemon了」「拿下名單後，對於daemon來說他就不存在了，自然找不到」）：表上沒有＝`ProcMissing`、退 1，小格資料夾還在也一樣。`procs_state.json` 不在＝`StateMissing`；daemon 沒在跑＝同 ls 那句注意、照表印。只收 `--stack`（沒給、多給位置參數＝`ArgumentsBad`）。
- **ls**：讀 `procs_state.json` 的一張表 `procs`（切檔的 `$ref` 合回來），一行「名字 TAB phase TAB pid TAB code TAB ws TAB reason」（reason 裡的控制字元——TAB、換行、CR、ESC——換成空白，11-05 第二輪）（pid、code、ws、reason 沒有＝`-`，stopped、sleeping 的 pid 是 `-`；ws 印絕對）；`--json`＝一行 `{"procs": 表}`（列照 procs_state 原樣：`pid`、`started_at_ticks`、`phase`、`code`、`signal`、`stack`、有給 ws 的帶 `ws`、`exec`、`def`、`reason`；路徑欄拼回絕對）。**`reason`**（11-05）＝出錯結束（loop 型退非 0，含被訊號打掉；例搬家沒帶定義、身體報錯）留成 `stopped` 的列，daemon 寫的原因（英文：wake／start 後 3 秒內＝`failed to start: …`、其他＝`failed while running: …`，接小格 stderr 最後一行），`null`＝沒有；修好用 `start` 起、不要了 `rm`。**做完的不在表上**（表上是 `running`、收的途中 `stopping`、daemon 停掉或出錯結束的 `stopped`、收工時還在跑的 `sleeping`）：子項退 0（`done`、別人直接寫它 ctl 的 stop）、exec 型、接回的結束了 daemon 就拿掉，**結束碼看 daemon 的 log**（`aos-daemon --enable-logs` 時 stdout 每個子項起來一行、結束一行 JSON，`{"at","name","phase","pid","code","signal"(,"ws")}`），所以 code 那欄平常是 `-`（出錯結束留下的 `stopped` 列有碼）。
- **ls 另判 daemon 活著**（使用者「要看一個proc是否還活著，除去linux底層proc機制外，我們的aos-daemon-ctl問詢也是一個方式，兩者並存」）：procs_state 頂層的 `pid`＋`started_at_ticks`（＋`boot_id`）對 /proc（N-17 的確定法），對不上＝stderr 一行提醒 `aos-daemon-ctl: warning: daemon is not running (pid N); the table is what it last wrote`（11-05 stdio-unify R1；原本是 `note:`），照樣列、退 0（`--json` 也一樣，輸出不加欄）。不看 `updated_at` 或檔案新不新（state 窗有變才寫、沒心跳）。
- **錯**：stderr 一行 `aos-daemon-ctl: error: 代號 原因`、退 1（`ArgumentsBad`、`FlagUnknown`、`CommandUnknown`、`DaemonMissing`、`MailboxMissing`、`PathMissing`、`LoopBad`、`StateMissing`、`StateBad`、`ProcMissing`、`CtlMissing`、`PhaseBad`（stop／start／sleep／wake 用在不對的 phase，11-05）、`WriteFailed`（pause／resume 寫不了 ctl）、`CommandMissing`、`SendFailed`）。要 PATH 上有 aos-post。

例：`aos-daemon-ctl add --stack /tmp/c --name c ../agents/clock`、`aos-daemon-ctl pause c`、`cat /tmp/c/state.json`、`aos-daemon-ctl resume c`、`aos-daemon-ctl stop c`（`ls` 見 `c TAB stopped TAB - TAB 0 TAB -`）、`aos-daemon-ctl start c`、`aos-daemon-ctl sleep c`（`ls` 見 `c TAB sleeping …`）、`aos-daemon-ctl start c`（`PhaseBad c is sleeping; use wake (start only starts stopped ones)`）、`aos-daemon-ctl wake c`、`aos-daemon-ctl rm c`（`/tmp/c` 留著）。
