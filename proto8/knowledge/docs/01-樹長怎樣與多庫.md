## 樹長怎樣

出廠的根是 `knowledge/` 這一層（11-10 深夜起；範本的 `AOS_MEMORY` 指這裡）：`knowledge/_index.json` 只列 `aos/`（先讀）與給人看的 `README.md`、`docs/`，所以路徑寫 `aos/rules.json`、`aos/errors.json#/codes`。下面這棵是 `aos/` 裡面的樣子（把它單獨當根也行，路徑就少一層 `aos/`）：

```text
knowledge/aos/            ← 一本庫（knowledge/ 的子資料夾）
├─ _index.json            ← 這個資料夾的表（整個檔就是表）
├─ _description.json      ← 這個資料夾自己的簡介（一個 JSON 字串）
├─ rules.json             ← 一個檔＝一個 JSON 值（這份是一段文字）
├─ errors.json            ← 一個物件，裡面自己有 _index 與 _description 兩個 key
└─ cli/
   ├─ _index.json
   ├─ _description.json
   └─ flags.json
```

- **統一路徑**＝`資料夾/檔.json#/JSON Pointer`（RFC 6901：`/` 分段、`~1`＝`/`、`~0`＝`~`），檔名**帶副檔名**：`rules.json`、`errors.json#/codes`、`cli/flags.json`、`cli/`。相對從庫根算；`""` 或 `/`＝根；其他 `/` 開頭＝檔案系統絕對路徑。工具印出的每條路徑都能直接貼回 `path`。
- **資料夾的表＝`_index.json`**，整個檔就是表：`{"rules.json": {"_description": "…"}, "cli/": {…}}`，key 從這個資料夾算。**JSON 物件的表＝`_index` 這個 key**：`{"_index": {"codes": {"_description": "…"}}, "codes": "# Code endings …"}`，key 從這個物件算。
- 表裡每一格是 `"path": {...}`；有 `_description`（字串）＝ls／read 印的那句說明；`tags`（字串陣列）給 `find` 的 `tag` 用；其餘隨意。內容放在 path 指到的地方，不放格裡。
- **自己的簡介**（使用者 11-10「那就是同資料夾下的_description.json啊」）：資料夾＝同資料夾的 `_description.json`（內容是一個 JSON 字串）；JSON 物件＝它的 `_description` key（字串，跟 `_index` 並排）。read 時印在表前面，沒有就只印表；兩者都不是子節點。根的一頁簡介就在 `knowledge/aos/_description.json`。
- path 想指多遠就指多遠（隔壁、往下、`../`、絕對路徑），內容裡可寫 `{"$ref": "別的檔.json#/位置"}`，表的格可帶 `$env`（可加 `$path`）＝實際指到解出來的路徑（使用者 11-10「想指多遠就指多遠，只要你有權限。指示詞$ref,$env也可以用，自己要檢測嵌套迴圈」）。繞圈由工具自己擋。
- 資料夾裡有、表沒列的檔或 key：照樣讀得到，ls 列在 `not in index:` 一段；`.` 與 `_` 開頭的檔不列。

## 多庫

**多庫＝根表多一格指到別的庫**，`base`／`AOS_MEMORY` 仍只指一個根，不加設定格式。例如人先準備：

```json
// ~/kb/_description.json
"My notes, plus the aos knowledge."

// ~/kb/_index.json
{"notes/":                            {"_description": "My own notes."},
 "/path/to/proto8/knowledge/aos/":    {"_description": "aos itself (read-only)."},
 "team":                              {"_description": "Team notes", "$env": "TEAM_KB"}}
```

`read` 根會列出這幾格；`find` 跟著表指到外面的格一起找；`memory_export` 也跟，同一個地方只印一次。舊的「資料夾放捷徑」照樣能走（檔案系統本來就會跟），只是捷徑那格不在表裡就沒說明。
