## 寫入

要讓 agent 寫自己的庫，另配 [memory_write](../../lib/agent/memory_write/)；它沿用同一套找根：`add` 新增（帶 `value` 與 `description`，內容與表裡那格一次寫好；路徑以 `/` 結尾＝開資料夾）、`set` 換內容（可一起換說明）、`rm` 刪掉並拔掉表裡那格（不空的資料夾要 `recursive: true`；根＝`PathBad`）。agent 不自己改 `_index.json`。**寫入不限範圍**：`../`、絕對路徑、捷徑、掛進來的別庫，指到哪就寫到哪，作業系統不讓寫＝`WriteFailed`（使用者 11-10「寫入這個沒差，想怎麽寫就怎麼寫，有權限就能動」）。自己的簡介（資料夾的 `_description.json`、物件的 `_description` key）就當普通路徑用 `add`／`set`／`rm` 寫：`value` 是一個字串、不給 `description`、不進表；`add` 資料夾時給的 `description` 寫進上一層的表，不自動建 `_description.json`。兩份 agent 範本不預先登記 `memory_write`；要寫的 agent 在定義的 `tools.json` 照 `memory` 的寫法加一格 `lib/agent/memory_write`，`env` 給同一個 `AOS_MEMORY`，並先把它指到有權寫的庫（相對、絕對或 `{"$env": "MY_KNOWLEDGE"}`）。寫入指引在出廠庫的 `memory.json`。

**沒有鎖**：兩邊同時寫同一份檔＝後寫的蓋掉先寫的（使用者 11-10「不管，自行承擔風險」）。剩下的保證只有 aos-json 的：每份檔暫存成 `.名字.<pid>.tmp` 再原子 rename，不會寫出半份檔（非 `.json` 檔由 memory_write 暫存成 `.tmp.*` 再換）。新增要動兩份檔（內容＋表），中途死掉＝留下一個沒登記的檔，ls 的 `not in index:` 看得到。

**掛出廠庫要由人設成唯讀**（11-07 晚審裁定 7 選推薦，[晚審 04](../../../wf/workflows/refactor/reports/2026-11-07-晚審/04b-要使用者裁定-續.md)）：跑 agent 的通常就是 repo 主人，「沒權限＝唯讀」不成立；`memory_write` 的庫若直接就是 `knowledge/aos`，會真的改到 repo、污染每隻 agent 的 system prompt。所以要給 agent 寫的庫不要指到 `knowledge/aos`，要共用就由人先設唯讀（`chmod -R a-w` 那份，或掛一份唯讀副本）。

庫在 git 下時，`.gitignore` 加 `.*.tmp`、`.tmp.*`，不要把暫存檔當知識提交。

## 節點怎麼寫（給人改內容時看）

- 一段文字＝一個 JSON 字串（Markdown 也是字串，`\n` 是換行）；放成一份 `x.json`，或放成某個物件的一個 key。幾段相關的併成一份物件檔，自己帶 `_index`；大一點的就開資料夾、帶 `_index.json`。
- 每新增一個位置，就在它所在那張表加一格，`_description` 寫**一句話**（ls／read 的目錄印這句）；資料夾自己的簡介放同資料夾的 `_description.json`、物件自己的簡介放它的 `_description` key。名字只用 `[a-z0-9_-]`（檔名加 `.json`）；`.`、`_` 開頭的保留（`_description.json`、`_description` 例外）。
- 寫給小模型：短句、具體的呼叫例子、一致用詞、**一段文字（一個字串值）≤ 2 KB**；撐大就拆成物件的幾個 key 或幾個檔、上層只留說明。陣列只讀（`#/items/0`），要穩定的名字就用物件。拆檔搬走時要留路，在原位放一格 `$ref` 指過去。
- 內容語言英文（AI 讀）；本說明（knowledge 的 README 與 docs）與各庫的人用說明繁中。**11-07 改讀**：「內容語言英文」管的是出廠的 `knowledge/aos`；從外部語料收進來的庫，節點名英文、內文照語料原文存（見 [CONCEPTS C-42 續「知識庫存什麼、給人看什麼」](../../docs/CONCEPTS/05-agent/01-續-C-42.md)）。（11-07 使用者裁定，傍晚選項框 ltn-7 選推薦，[lift-to-norms](../../thinking/2026-11/07/lift-to-norms/README.md)）
