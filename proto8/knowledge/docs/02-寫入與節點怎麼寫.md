## 節點怎麼寫（給人改內容時看）

- 一段文字＝一個 JSON 字串（Markdown 也是字串，`\n` 是換行），**也可以寫成字串陣列**（一行一個元素：`["# Title", "", "First line."]`，讀的時候等於用換行接起來的一段）；兩種寫法由寫的人自己選。多行的長文字推薦用陣列（進 git 時逐行比對，改一行只動那一行；寫成一個字串時整段是檔案裡的一行），不強制（使用者 11-13「我會覺得陣列這塊，是可選的。就是說AI可以隨便寫，也可以按照推薦用字串陣列。」，[thinking text-as-string-array](../../thinking/2026-11/13/text-as-string-array.md)）。`index_view` 兩種都認（index 那一格的 `description`）；`json_get` 照實印出陣列；`aos-json get --str` 只認字串，值是字串陣列時用 `get`（不帶 `--str`）拿到陣列。放成一份 `x.json`，或放成某個物件的一個鍵。幾段相關的併成一份物件檔；大一點的就開資料夾。
- index 只給太大的節點補（門檻見 [01](01-樹長怎樣與多庫.md)：夾裡超過 15 個東西、檔超過 8000 bytes 或頂層內容鍵超過 10 個）；夠小的不加，直接讀。上一層已經有 index 時，新增一個節點就在那份 index 加一格 `"名字": {"description": "…"}`，description 寫**英文一句話**；那個節點自己也帶 index 時，同一格可再加 `"index": "路徑"` 指過去（路徑寫法同 `$ref`，[01](01-樹長怎樣與多庫.md)）；資料夾的 `_index.json` 要列出夾裡每一個東西（`_description.json`、`README.md`、`docs` 也列）。資料夾自己的正文放同夾的 `_description.json`、物件自己的正文放它的 `_description` 鍵（都是一段文字：字串或字串陣列）。名字只用 `[a-z0-9_-]`（檔名加 `.json`）；`.`、`_` 開頭的保留（`_index.json`、`_index`、`_description.json`、`_description` 例外）。
- 寫給小模型：短句、具體的呼叫例子、一致用詞、**建議一段文字（一個字串值）約 1 KB、一個檔約 8 KB**（使用者 11-11：「這個"不超過2kb"我沒說過，拿掉。不過也可以用，我的建議是改成一個檔案不超過8kb，一段不超過1kb。」「那個知識庫上限，只是推薦，不要訂死。」）；撐大就拆成物件的幾個鍵或幾個檔、上層只留說明。要穩定的名字就用物件、不用陣列——這句講的是**給節點取名**：別人會用路徑指到的東西（`檔#/鍵`）放成物件的鍵，不放成陣列的第幾個（中間插一個，後面的號碼全變）。一段文字寫成字串陣列是另一回事：那個陣列整個是一個節點（一段），裡面的行不是讓人個別指的東西，所以不衝突。記錄表也照同一把尺：**會被單獨引用的用鍵；只會整批讀、不會單筆引用的同質記錄可以用陣列**（例：決策、踩坑、想法這類「新的在上」的表）（使用者 11-13 收工待裁頁 W18 照推薦，[收工待裁-回覆落地](../../thinking/2026-11/13/收工待裁-回覆落地.md#逐題落地表)）。拆檔搬走時要留路，在原位放 `{"$ref": "新檔.json"}` 指過去（`aos-json ref --move` 一步做完）。
- **檔案格式（推薦，不強制）：跟 `aos-json set` 寫出來的一樣**——UTF-8、換行 LF、中文等非 ASCII 字照原字寫（不轉成 `\uXXXX`）、檔尾一個換行；縮排照那份檔原本的（`aos-json set` 看第一個有縮排的行猜每層幾格、照它寫回，只重寫有變的那一塊），這棵樹的多行檔幾乎都是每層 1 個空白，新檔照這樣寫。手改的與工具改的照同一個格式，git diff 才不會多出整份重排的雜訊（使用者 11-13 收工待裁頁 W17 照推薦；`aos-json` 怎麼寫回見 [aos-json docs/01](../../impls/aos-json/docs/01-用法與寫回去-原子-只改變的那一塊.md#寫回去原子只改變的那一塊)）。
- 內容語言英文（AI 讀）；本說明（knowledge 的 README 與 docs）與各庫的人用說明繁中。**範圍**：「內容語言英文」管的是出廠的 `knowledge/aos`；從外部語料收進來的庫，節點名英文、內文照語料原文存（見 [CONCEPTS C-42 續「知識庫存什麼、給人看什麼」](../../docs/CONCEPTS/05-agent/01-續-C-42.md)）。（使用者 11-07 裁定，選項框 ltn-7 選推薦，[lift-to-norms](../../thinking/2026-11/07/lift-to-norms/README.md)）
