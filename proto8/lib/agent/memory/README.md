# memory — 查詢節點文字、子節點、單一標籤與 JSON 葉的指定值。

`read` 的 `path` 使用節點路徑；加上 `#/JSON/Pointer` 可讀 `.json` 葉的指定位置。未帶指標時沿用原文與子節點輸出；`ls`／`find` 只收節點路徑。

指標遵循 RFC6901：`/` 分段、`~0` 代表 `~`、`~1` 代表 `/`；物件依鍵取值（含空鍵），陣列用從 0 起算的十進位索引，不收前導零與 `-`。不做 URI 百分比解碼；`#` 後須有 `/`。輸出保留 `node:` 首行，下一段是選中值的 JSON（包含字串引號與 null），沿用 `max_bytes` 截斷。

錯誤沿用既有代號：`PathBad`＝節點或指標寫法不合、`ls`／`find` 帶 `#`；`TargetBad`＝對資料夾或 `.md` 葉用指標；`PointerMissing`＝指標找不到值（含陣列索引不合）；`FileBad`＝JSON 葉內容不是合法 JSON；`NodeMissing`＝節點不存在。定址優先序仍是資料夾、`.md`、`.json`，不因帶指標改選同名檔。

`find` 收選填 `query`（非空字串，不分大小寫的文字搜尋）與 `tag`（單一字串，逐字比對）；至少提供一個，兩者都有時須同時符合。搜尋範圍是 `path` 的子樹（含自己），預設根節點；最多列 20 筆。

標籤取自 JSON 葉頂層的 `tags` 字串陣列，或資料夾內 `_tags.json` 的 `tags` 字串陣列；不繼承父節點標籤。沒有 README 的資料夾也能依標籤找到。壞 JSON、非字串陣列視為沒有標籤，不報錯；`_tags.json` 本身不列為節點。Markdown 葉沒有標籤。

連結值是 `node/path#/json/pointer` 字串，交給 `read` 的 `path` 即可跟隨連結讀值。
