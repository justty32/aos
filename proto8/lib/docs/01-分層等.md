## 分層（每層只依賴下層）

```
<agent>/                   最上層：agent 本身（也是函數；例 templates/agent-fsm）
  tools/<名> ─捷徑─▶ lib/<層>/<名>/        引用，不複製（見下「怎麼引用」）
lib/agent/                 高層：裡面是一整隻 agent（或外部 agent CLI）的工具（claude、codex、json_rewrite…）＋共用模組 agent_tool.py、cli_session.py、agent_files.py
lib/aos/                   中層：動 aos 自己東西的工具（jsonx_*〔認 $ref／$env 的 JSON 工具〕、判官 judge）
lib/base/                  底層原語：檔案、資料夾、JSON、行程（bash）、小工具——Linux＋Python 標準庫（不叫 aos 的程式；例外 json_*：讀寫交給 aos-json，寫入帶 --raw）、只碰 $AOS_WS
lib/aos_json.py            json 工具一族（base 的 json_*、aos 的 jsonx_*）共用的程式，各夾 _entry 只是殼（11-12）
lib/tool_spec.py           給 AI 寫新工具的輔助（接在 tool_io 上）：Python 宣告 → _tooldef／_metainfo、驗參數、叫 run（11-10 深夜）
lib/tool_io.py             最底：每個工具共用的開頭（--help、Ctrl-C、錯誤行／提醒行、讀 stdin＋旗標映射與最小型別檢查、查工作區）——不是工具，是共用模組（11-05 晚）
impls/                     基礎層與標準庫（C-74）：aos-exec 把工具叫起來，loop／fsm 跑 agent
```

`lib` 不 import 上層 `py`；`py`／`cmd`／範本需要工具共用功能時可以依賴 `lib`（11-06 晚 K-5）。

層名只是資料夾名，不進工具名；還沒有工具的層不先建空資料夾（STRUCTURE：不預先建空檔）。
