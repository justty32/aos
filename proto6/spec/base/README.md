## B-000：責任與驗收〔建議預設，未拍板〕

基底接受控制層已認證、已准入的工作，回交持久結果；不決定任務意圖、重試政策或 LLM 預算。控制層是 SQLite 單一寫入者，啟動器管理程序與隔離，降權後 runner 解讀工作。三者是責任，可在同一部署內，不能以同程序為理由取消信任邊界。所有葉篇條款的 Given／When／Then 是首版必要驗收案例；故障注入必須覆蓋發布、DB 提交、放行與確認前後。

**Given** 工作未獲准入；**When** 呼叫啟動入口；**Then** 拒絕且沒有工作程序與外部副作用。已准入但任何隔離前置失敗亦同。

## 待使用者拍板與現況

六篇中除明標使用者方向者，其餘 schema、數字預設與流程均為建議。部署外牆未選定；規格要求明示與驗證 deployment profile，不能以空白 profile 上線。proto6 目前是規劃文件，這組條款不代表功能、權限隔離或萬級負载已驗收。
