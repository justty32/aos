# Agent 規格入口

← [規格總入口](../README.md)｜[共用契約](../contracts.md)｜[概念來源](../../notes/agent.md)

本區規定 agent 如何理解輸入、建立 context、選擇工具及提交下一步。全部是 proto6 待實作規格；標為建議預設的條款尚未獲使用者拍板。來源筆記保留討論脈絡，不因本稿而變成已接受的產品決定。

| 閱讀順序 | 責任 |
|---|---|
| [設定與版本](configuration.md) | 身分引用、模型與人格、設定版本引用與更新（下一次 tick 生效） |
| [輸入與回覆](input.md) | 收件、去重、下一輪邊界、取消與暫停 |
| [記憶與 context](memory.md) | 歷史、筆記、摘要、配額及可追溯材料 |
| [工具與 LLM](tools.md) | 能力登記、呼叫驗證、結果及未知狀態 |
| [tick 與恢復](tick.md) | 狀態、單寫者、proposal 提交與完成條件、tick 前後掛勾 |

識別、控制層權威與工作狀態一律沿用共用契約。agent 提出決策；控制層驗證及持久化；底座執行程序；排程分配准入與預算。此處不新增父子制度、固定 worker、FUSE 或分散式協定。
