## 卡點與改動

1. 成員一開始把 `team/projects` 解成自己的資料夾，PM 連續兩次 `ls` 失敗。新建流程已給每個孩子一個指向根共用區的 `team` symlink，之後可一律寫 `team/projects/...`。
2. 加 symlink 後第一次實玩揭露身分判定 bug：PM 被誤認為 owner，第一筆 `team_grant` 從 owner 的 10% 救急額度扣。已改成信任 `team.json.root` 再比對成員路徑；測試會驗 PM 的 90% 才是來源。
3. 200k tokens 在四層協調還沒到寫 code 就用完。工具多、system prompt 長、review 自動提醒與多輪 mail 都會放大上下文。
4. 預算不是強制閘門。owner／PM 的動態 prompt 現在每次都帶即時剩餘與停工規則，但已送出的 LLM 請求不能追回；這次仍到 1.20M 才由人收隊。
5. 各人的 cost ledger 與整隊 LLM requester 帳口徑不同。chief 看自己帳說沒超支；`team status` 才看到全隊已爆。money 因 engine 無 price 只能報 0。
6. `team status` 的 hours 是整隊開隊後時間與 8 小時總額；訂單自己的 1 小時只在訂單信，第一版沒有逐案彙總。
