# fs 工具包

這包讓 agent 看檔案、改檔案，也能跑很快會結束的指令。
所有路徑都從世界資料夾算起。

## 工具

- `ls(path=".", all=false)`：先看一層有什麼。不會往下找。預設藏起點開頭的檔案。最多列 200 個。
- `read(path, start=1, count=200)`：讀文字檔的一段。會回總行數，也會說下一段從哪一行開始。
- `write(path, text, append=false)`：寫整個檔案。父資料夾不存在會建立。`append=true` 是接在後面。
- `edit(path, old, new)`：只換一小段。`old` 剛好出現一次才會改；零次或多次都不動原檔。
- `sh(command, stdin, timeout=60)`：在世界資料夾跑短指令。最長 120 秒。會回退出碼、秒數，以及兩邊輸出的最後 1500 字。

## 什麼時候用

先用 `ls` 看名字，再用 `read` 只讀需要的行。
小修改用 `edit`。新檔或整份重寫才用 `write`。
結果太長，就縮小 `read` 的 `start` 和 `count`。
可能超過一分鐘的指令不要用 `sh`，改用 `run_long`。

## 設定

在 agent 的 `tools.json` 打開這包：

```json
{"packs": ["fs"], "tools": []}
```

舊的 `shell` 包也有 `sh`。兩包一起開時，先把 `fs` 寫在 `packs` 前面。

## 坑

這不是沙箱。`../`、絕對路徑和 shell 都能碰世界外面。
文字檔固定當 UTF-8。沒有二進位檔支援。
同時有別人在寫同一個檔時，內容可能互相蓋掉。
