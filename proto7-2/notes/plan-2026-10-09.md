## 4. 交接書要點（每隊都要有）

- 開頭一句「可以開自己的 subagent 平行做事，最多 4 條」。範圍＝json 領地欄，**其餘一律不得寫**（別隊領地、wf hub 檔、`proto7/user-advice.md`、`tests/_proc.py` 語意）。
- 件數 gate：只做 json `items` 欄的編號，想多修一條先回報。容量 gate：diff 超過 json `gates` 的行數、或要碰領地外的檔→停下回報。
- 工人不 commit；隊長 `git commit <明確路徑>`、不用 `-A`。交棒前 `git rebase main`、跑自己領地的測試、全套一次；頂層只做 `git merge --ff-only loop7/<隊>`＋push。
- codex 呼叫：寫碼 `codex exec -m gpt-6.1-sol -C <worktree> -o <out.md> - < task.md`；審查 `codex exec -m gpt-6-astra -c model_reasoning_effort="high" -s read-only -C <worktree> -o <review.md> - < task.md`。任務書從 stdin 餵、背景跑也要餵；家機 config 已 danger-full-access。報告一律寫進 repo 路徑。
- 驗收條數寫死（json `done` 欄），回報只要那幾條：commit 雜湊、測試數與退出碼、翻紅清單、沒做的與原因。
