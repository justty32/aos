# 專案週報彙整（範例用長文件）

這份檔故意寫得很長，用來示範「太長的段落會自動收起來」。

## 第 1 週

- 本週重點：整理文件相關的待辦，確認每一項都有負責人與預計完成日。
- 進度：上週留下的三件事完成兩件，剩一件文件的細節等對方回覆，預計下週二前收尾。
- 風險：文件這塊若下週還沒回覆，就先用舊做法頂著，並在週會上提出來討論。
