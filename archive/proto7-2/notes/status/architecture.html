aos 時空架構圖解

10-05 時 aos 只有下面兩層：daemon 和回合。今天一天上面長出了 agent 層。現在一個指令就能起一個「住在資料夾裡的 AI」：寄信叫它做事，它每次心跳醒來看信、問模型、回信、記進工作簿，被砍掉也能接著做。底下的核心沒換架構，只補了 loop7 的十個修補，行數上限改成只印出來、不擋。這一頁由上往下講：先看新人眼中的 aos，再一層層往下拆。

01新人看到的 aos：5 個詞、3 個指令

一鍵入口 aos7-up 把帳、回合、預留、ack、退出碼全部藏到預設值裡。新人只要看懂下面這張圖。預設用假 AI：不連網、不花錢，照抄你的信；要接真 AI 加 --model。

02四層：agent 層今天長出來了

上層只透過下層給的時空做事，每一層的狀態和控制都是 JSON 檔。10-05 時只有下兩層；今天 agent 層做出了第一版，全部都是包，核心一行都沒為它改。kernel 層還是提案。

術語：daemon＝背景常駐的管理員程式。node＝一個被登記的資料夾，有自己的回合。tick／tock＝開回合／關回合。核心＝daemon、tick、tock、run 四支程式，加上讀檔、程序事實、槽判定、掛載這幾個程式庫；包＝核心以外的可選擴充。

03空間與 node：登記制，外加 agent 的房子

daemon 拿一個資料夾當空間根，只跑 .aosd/nodes.json 上登記的 node，看不到不等於不存在。這部分沒變。紅字是 10-05 之後新加的東西。

術語：槽＝任務的固定資料夾 .aos/tasks/<名字>/，同名重用。run＝一次執行，有流水號，寫成 hello#57。只留上一次＝每個 node 只留最近一回合的總結、每個槽只留最近一次 run，跑一年檔案也不會變多。

04daemon：回收和倒數都先落盤

主迴圈大約每 20 ms 讀控制檔、檢查 node 還在不在、寫 status；每條時間線跑 tick → 等 → tock。10-05 的審查找到「義務只記在 daemon 記憶體」這個反覆出現的毛病：daemon 被砍，該收的任務、該扣的倒數就忘了。今天把這兩件寫到磁碟上（D8、R8-02／03）。

op意思（只列有變的）
unregister馬上從清單拿掉。預設會收掉活著的任務；回收意圖先寫進 reaping，沒確認收乾淨就下一圈再試
resume"rounds": N 的倒數存進 paused.json 的 steps，daemon 重開後照樣有效
stop"kill": true 收尾時，如果還不確定收乾淨了，就寫一筆 stop-kill 意圖，下次啟動接著收
register／pause／wake不變

05一個回合（沒變）

tick 起完任務就走，不等它們跑完。tock 不收掉任務，只判斷每個槽的狀態、寫總結，然後在每個活任務的槽裡放一張 tock.json。aos7-up 的「心跳」就是這個回合：每下心跳叫醒一次腦。

06任務與槽

只有一張任務表 tasks.json，三種模式 keep／each／once。砍任務要指定 run 號。今天的改動（D1）：如果 runner 還在啟動交接中，kill 不硬砍，回「不知道」，請求留到下一圈。清場之後會再做身分複查，最多補收 3 輪；node 級別用記下的 pgid 砍之前，會先確認這個 pgid 還屬於這個 node（D2）。

欄位意思
name／mode槽名；each（預設）／keep／once
argv 或 inst直接跑，或交給 aos-exec 跑 inst JSON。起任務的環境只帶核心的六個 AOS7_* 變數，不帶繼承來的（唯一例外：明列放行 AOS7_LITELLM_KEY，金鑰只經環境、不落地）
from_round／until_round／max_live從第幾回合起、到第幾回合停、同名最多同時跑幾個
mounts／enabled／x掛別人的資料夾；開關；x 欄核心不看，原樣抄進 birth.json

07核心承諾，和全 aos 共用的錯誤語言

核心的承諾沒變，只有「行數上限」這條改了。今天下午另外定了一套全 aos 共用的退出碼，十二個包全部照改。這算是 r7 第 2 題「『不知道』要不要變成大家共用的語言」的第一個實際回答。

承諾白話現況
不雙開同一個槽同時只跑一份不變；kill 在交接中回「不知道」，堵住一個縫
不知道≠失敗只有是／否／不知道三種答案不變，而且推到所有包：退出碼 3
只留上一次總結、run、回條都只留最新一份不變；events 的 must 帳例外：沒人 ack 就不丟，滿了就停收
登記，不掃描只跑 nodes.json 上的 node不變
先寫證據再動作被砍掉靠順序和重做撐住擴大到 daemon：reaping、owe 先落盤
核心不長新功能新功能一律做成包保留。改 行數上限取消，只印不擋（現 3004／2353）
誤用不防不守前置條件算誤用不變

統一退出碼（notes/blueprint-errors.md）

意圖卡（notes/intents/，共 18 張）：每個包或功能一張，不超過 1.5 KiB，寫四件事：要解決什麼、哪些副作用非留不可、明確不做什麼、現在多出來的副作用要保留、改成可選還是移除。從 16:10 起規定，開新隊之前先寫卡。照卡拿掉了一批多餘的副作用，例如不再替別人建資料夾、不再偷改任務表。

08包的全貌：14 個模組包、6 個任務包

核心不呼叫任何包。包的接法只有三種：當任務（tick 起它）、當包裝程式、當工具。今天新增 9 個模組包（events、routines、skills、wfnode、metrics、compact、mail、up，還有已經併掉的 llmdiag）和 3 個任務包（llmcall、author、prompt）。最上面是一鍵入口 aos7-up，把需要的包裝好、接好。

10腦：一封信怎麼辦完

brain 是 node 上的 keep 任務。每回合最多處理一封要辦的信，先進先出。一封信可以跨很多回合：AI 每回合只回三種開頭之一。它沒有工具，只能讀信、讀工作簿，然後寫字。
