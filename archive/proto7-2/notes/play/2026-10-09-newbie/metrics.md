## 卡點（新手視角，依嚴重度）

1. `--overhead 1644` 照抄能跑，但不知道 1644 是什麼、怎麼量，換自己的資料就不會設（Haiku）
2. 輸出一行塞十幾個數字和 ｜＝ 分隔，不知道該看哪個；單／呼叫／區間／預留／未結都是新詞（兩位都提）
3. README 第 3 行基線連到 notes（不准讀），不知道「R1 基線」怎麼來、自己該拿什麼資料去跑（兩位都提）
4. `--help` 只列參數名，沒說 PATH 給資料夾還是檔案、`--json` 有哪些欄位（Haiku）

## ELI5

這是一把量尺，專門看 AI 工作留下的紀錄。你指一個資料夾給它，它數出用了多少 token、同時跑了幾個、花幾秒、重試幾次，印成一行。它只讀不寫。

## ELI5 之後還複雜嗎

是（兩位都說是）。指令只有一個，但要看懂那一行輸出要先懂五個詞，`--overhead` 沒來源。

## 回改

狀態：已改（回改隊 metrics，分支 `loop9/metrics`），重試見下段。

- [x] `--overhead` 說明是什麼、怎麼量，或給預設值讓第一次跑不用填
- [x] 第一次跑的輸出逐欄用白話標一次（哪個是 token、哪個是並行、哪個是秒數）
- [x] 說明「拿什麼資料夾來量」：自己的 author／llmcall 跑完後指哪一層
- [x] `--help` 補 PATH 的意思與 --json 欄位

改法：預設輸出換成白話一行 `名稱：N 件工作｜每件用 X token｜同時最多 P 個在問模型｜花 S 秒｜重試 R 次`，舊細節行移到 `--detail`、`--json` 不變；`--overhead` 預設 0、第一次跑不出現，進階段說明 1644 來由與量法；README 先放一條指令＋逐格表＋「量自己的資料」（認 `llmcall/`、`budget/`、`author/` 子資料夾，指上層也行，指錯印「沒找到 AI 工作紀錄」），契約與算法移到分隔線後的維護者段；`--help` 補 PATH、逐格、各選項與 JSON 欄位、退出碼。
