## 踩過的坑
- 索引列放進 `files` → 索引列是頂層 `row` 欄位，不是檔案。
- 驗收只看測試通過 → 三關都要核對；未實際執行測試或 checker，不可宣稱通過。
- 入口檔過長或直接塞入實作 → 入口保持精簡，將邏輯放在同包模組。
- 測試檔被 runner 漏掉 → 測試要能由指定 runner discover，且使用明確的匯入方式。
- README 缺少指定章節 → 按要求使用明確的必要章節標題。
- report 沒有指定結尾 → 確認最後一節與最後內容符合交付要求。

```python
#!/usr/bin/env python3
import os, sys
sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
from aos7_runs import main
if __name__ == "__main__":
    raise SystemExit(main())
```
