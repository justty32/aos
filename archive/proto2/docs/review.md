# review 工具包

這包會回頭看工具帳、思考紀錄和最後回話。
它只做摘要，不把原文整包塞回記憶。

## 工具清單

### `review_recent`

看剛才做得怎樣。

參數二選一：

- `n_steps`：往回看幾格。要大於 0。
- `since`：從哪個時間開始看。例：`2026-09-06T14:00:00`。

它會回工具次數、錯誤次數、秒數、token、錢、繞路和最後有沒有回話。
帳本沒寫單價時，錢是 `null`。它不猜。

### `review_patterns`

看最近 30 天。
不用參數。

結果先列最貴的工具，再列最貴的任務、重複卻沒進展的工具、反覆錯誤。
每項都有次數、錢、格數、秒數和最近時間。

### `review_thoughts`

看深度思考和分支有沒有白花錢。

- `id` 可不填。填了只看那次。
- 不填就看最近五次。

它只回題目短句、短結論、花費和「有採用／未採用／不知道」。

### `lesson_add`

新增一條教訓。
參數只有 `text`。
一定要一行，而且要有數字。

```text
查文件：原本平均 0.12 元／8 格 → 先讀索引 → 之後平均 0.08 元／5 格
```

若新舊金額都沒降，而且格數也沒降，下次回顧會在後面標 `【無效】`。
不會自動刪掉。

### `lessons_list`

列最近 20 條教訓。
不用參數。
新的在前面。

### `improve_prompt`

整份換掉一個工具包的 prompt 覆蓋。

- `pack`：工具包名字。
- `text`：新的完整內容。

只能改 `tools.json` 已開啟的包。
它會先讀舊檔，再原子換成新內容。
下次走格才生效。

## 自動提醒

下面任一項成立，就往 `inbox/self/` 丟一封「該回顧了」：

- 連續 3 格 idle，而且上次回顧後多了至少 10 次工具呼叫。
- 今天花費超過門檻。
- 最新一個任務花費超過同類舊任務平均的兩倍。
- 某工具連續 3 次都超過自己的成本門檻。

同一批只提醒一次。
自動提醒不會自己問 LLM，也不會自己改東西。

成本門檻寫在自己的 `llm.json`：

```json
{
  "dir": "../llm",
  "review": {
    "daily_cost": 1.0,
    "tool_cost": {
      "sh": 0.05
    }
  }
}
```

`daily_cost` 是一天的金額門檻。
`tool_cost` 是「工具名 → 單次金額門檻」。
不寫就不檢查那種門檻。

任務的兩倍規則要帳本有 `task_key` 和 `task_id` 才算得出來。
舊帳沒有就跳過。

## 放在哪裡

- 帳本：`<home>/ledger/<日期>.jsonl`。只讀。
- 教訓：`<home>/memory/lessons.md`。
- 舊教訓：`<home>/memory/lessons-archive/<日期>.md`。
- prompt 覆蓋：`<home>/prompt-overrides/<包>.md`。
- 思考：`<home>/thoughts/` 和 `<home>/branches/`。只讀。

`lessons.md` 最多 100 條。
第 101 條進來時，最舊 20 條會一起歸檔。
每次組 system prompt，會附最近 20 條教訓。

## 什麼時候用

- 一件事剛做完：先 `review_recent`。
- 同一問題又卡住：再 `review_patterns`。
- 深度思考很貴：用 `review_thoughts`。
- 找到能改變下次做法的事：用 `lesson_add`。
- 某個包反覆帶錯方向：最後才用 `improve_prompt`。

## 坑

- cost 包還沒寫出帳本時，回顧會是空的，不會報錯。
- 舊帳缺 `ok`、`error_kind`、任務編號或單價時，只算拿得到的欄位。
- 採用紀錄沒有明確證據時，`review_thoughts` 只會說「不知道」。
- 目前不處理兩個進程同時寫教訓或 prompt。
- 資料多了會逐行讀最近 30 天帳本。第一版先求簡單。
