### 6. agent 就是一個 list（09-08 12:xx，使用者偽碼 `src/agent.janet`）

偽碼：`(def new [context engine tools] '(next :statue :idle :content @{…}))`、`(def next [agent] (agent))`。

→ 我的理解：agent 本身就是一個 form，`new` 回傳它；「跑一步」＝求值這個 form，**求值的結果就是
  下一個 agent**。比 proto3-1 更純：不用 `(next …)` 寫回環境，直接拿回傳值 `(set a (agent/next a))`。
→ 補全時的取捨：form 的頭改叫 `step`（偽碼裡頭和「跑一步」都叫 next 會打架）；`:statue` → `:status`；
  engine 先是同步函式、tools 是 table（之後接 LLM 世界再改非同步）；狀態機先勾 idle／think／act 三態。
→ 踩到的坑：**eval 會把 form 裡的 table 當建構式**，每次求值新建一張，content 就不是同一張了；
  要用 `(quote …)` 包住，編譯器才當常數原樣放回去（內層 array 也保住）。所以 form 長這樣：
  `(step :status :idle :content (quote @{…}))`。
→ 沒動：clock.janet（`()`）、kernel.janet、main.janet 還是偽碼，等使用者。
