# zh-tw — 繁體中文用字（writing 子檔）

[writing](../writing.md)｜[common/README](../README.md)

參考聲音若來自簡體中文的寫作，學的是**節奏和態度，不是用字**。輸出一律繁中，別讓簡體語感滲進來。

| 簡 | 繁 |
|----|----|
| 視頻 / 信息 / 網絡 / 屏幕 / 鼠標 | 影片 / 資訊 / 網路 / 螢幕 / 滑鼠 |
| 軟件 / 硬件 / 內存 / 緩存 / 字節 | 軟體 / 硬體 / 記憶體 / 快取 / 位元組 |
| 代碼 / 函數 / 對象 / 變量 | 程式碼 / 函式 / 物件 / 變數 |
| 線程 / 進程 / 默認 | 執行緒 / 行程 / 預設 |
| 用戶 / 鏈接 / 通過 | 使用者 / 連結 / 透過、藉由 |

「數據／資料」「質量／品質」看領域自己拿捏，同一份文件內統一即可。

> 〔導入判斷〕非繁中專案 → 刪除本檔，並移除 [writing](../writing.md)「繁體中文用字」段那行連結。同步：`workflows/common/writing.md`。

> 〔模板說明〕不是繁中、但也要一份用字規範的專案（簡中、日文、英文…），把上表換成你那個語言的常見誤用對照，檔名改成對應語言代碼。
