# enrich-existing — 只加厚既有課的文字

[study-site](README.md)｜[WORKFLOWS](../../WORKFLOWS.md)｜驗收關卡 [quality-gates](quality-gates.md)

課程網站**已經存在、互動也能動**，只是文字講解太薄、讀者讀不懂時，把每頁的解說加厚。指揮者只做調度與驗證，改寫交給便宜的批次執行者。

**何時用**：目標是加厚文字——白話直覺、實例演算、因果與可觀察證據、常見誤解、術語對照。
**何時不用**：要新增或改造互動元件、改版面、改結構 → 回 [study-site](README.md) 走建置契約與派工；課程還不存在 → 從 [study-site](README.md) 第 1 步開始。

## Done when

- 下方五條紅線的驗收片段全數通過（`app.js` 差異空、缺 id 0、外部資源 0、殘留語法 0）。
- 每一群課程頁都有一份「這一頁補了什麼」的簡短清單。
- 未通過項在 [SESSION-LOG](../../SESSION-LOG.md) 或 [WAIT_USER](../../WAIT_USER.md) 各有一行。

## 硬性紅線（原文傳給執行者，違反即失敗）

1. **不得修改互動程式**（`app.js` 之類）一個字。
2. **不得改動、改名或刪除任何既有 `id`、`class`、`data-*` 或互動元件的 DOM**——互動靠它們運作；只在其**周圍**增補文字。
3. **不得改檔名，不得動頁首導覽、上一頁／下一頁與頁間相對連結。**
4. **不得加任何外部資源**：圖片、外部字型、CDN、遠端 API、分析碼、第三方腳本一律禁止，維持純離線。
5. **不改原意、不杜撰**；簡化模型要標明假設與適用範圍。
6. **公式照既有頁面的慣例寫**。沒有數學渲染器的站禁止 LaTeX 語法（會顯示成生的反斜線）——改用 Unicode 符號（θ × · √ ≈ ≤ ≥ Σ π Δ →）搭配 `<sub>`／`<sup>`。

> 〔導入判斷〕課程頁面有數學渲染器 → 第 6 條改成「一律用 `{{語法，如 KaTeX}}`」，並刪掉驗收片段第 3 項。同步：`workflows/study-site/quality-gates.md` 的驗收片段第 3 項。

## 要補的東西（逐頁）

- **白話先講**：每個關鍵概念先用一兩句讀者熟悉的說法點出「它在解決什麼問題」，再回到真實機制與名詞。比喻之後一定要收回真實運作與其限制。
- **推導與實例**：公式附符號、單位、假設、量綱，並帶**一組具體數字**的實例演算。
- **因果鏈與證據**：操作 → 狀態變化 → 結果 → 可在哪裡看到證據（紀錄、輸出、系統狀態、量測），並指出該工具**證明不了**什麼。
- **常見誤解**：用清單明確拆開容易混淆的相鄰概念。
- **術語**：首次出現給中英對照與必要縮寫，與其他頁、字典用語一致。
- **既有互動的引導文字**：補「這個實驗在示範什麼、怎麼玩、數字變化代表什麼、為什麼」，但**不新增需要寫程式的元件**。
- **字典頁**：補齊每個名詞的位置／功能／機制／邊界，每個概念的角色／狀態或資料流／因果／結果／可觀察證據。

風格上沿用既有 CSS class 排新內容，盡量不動樣式檔；內容更豐富但不灌水，每段都要有資訊量。

## 流程

1. **盤點**：列出目標群的所有頁面，確認該群的互動程式與樣式檔在哪。
2. **試點一群**：先跑一個代表性的群，人工檢視風格與厚度，**取得使用者同意**再往下。
3. **逐群套用**：同意後依序跑完其餘群；寫入不同資料夾者才可並行，一次控制在少數幾群。
4. **每群驗證**：跑下面的片段。有殘留就補一個 focused 修正 pass（例如「殘留語法 → 純文字」），不要整群重跑。
5. **交付**：更新 open 狀態；沒有 build／test 的專案，驗收以內容、連結、格式、編碼為準。

各群的字數門檻**一開始就統一講好**，否則前後群厚薄不均，還要追加一輪加厚——而加厚後又得逐一位元組比對互動區塊沒被動到。

## 每群驗收片段（指揮者親自跑）

```sh
d="<目標群目錄>"
# 1) 互動程式與樣式未被動（輸出應為空）
git diff --stat -- "$d/app.js" "$d/styles.css"
# 2) 互動程式依賴的所有 id 仍存在（輸出應為空）
ids=$(grep -ohE 'getElementById\("[^"]+"\)' "$d"/*.js | grep -oE '"[^"]+"' | tr -d '"' | sort -u)
for id in $ids; do grep -qF "id=\"$id\"" "$d"/*.html || echo "MISSING id: $id"; done
# 3) 無 LaTeX 殘留（無數學渲染器時；輸出應為空）
grep -lE '\\\(|\\\)|\\\[|\\\]|\$\$' "$d"/*.html
# 4) 無新增外部資源（只允許回自家主站；輸出應為空）
grep -ohiE '(src|href)="https?://[^"]+"' "$d"/*.html | grep -viE '{{自家網域}}'
# 5) 編碼與語法
for f in "$d"/*.html; do iconv -f UTF-8 -t UTF-8 "$f" >/dev/null || echo "BAD ENCODING: $f"; done
node --check "$d/app.js"
```

四項輸出全空才算該群完成。**掃描前先把 HTML 字元實體反跳脫**再比對關鍵詞——否則被禁的詞寫成 `&#…;` 會同時躲過掃描、卻照樣渲染出來。
